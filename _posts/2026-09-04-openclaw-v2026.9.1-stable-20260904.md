## 확정된 하이라이트 — 어제 '예고' → 오늘 '확정' 8가지

정식 릴리스 노트에 **하이라이트 8개**가 모두 확정됐습니다. 프리뷰에서 강조했던 항목들이 그대로, 일부는 더 구체화되어 실렸어요.

1. **모든 채팅에서 다이어그램** — 머메이드(Mermaid) 블록이 Control UI는 물론 네이티브 **macOS·iOS·Android 앱**에서 다이어그램으로 렌더링됩니다. 확대 미리보기, 모바일에서 렌더링 실패 시 재시도까지 지원해요.
2. **설치 → 채팅 1프롬프트 (이번에 새로 확인된 최대 디테일!)** — 신규 설치(`npx openclaw@latest` 포함) 시 **기존 Claude Code·Codex 로그인과 API 키를 자동 감지**해 실시간 검증하고, 곧바로 웹 대시보드를 엽니다. 전체 마법사는 'Custom setup'으로 유지되고요.
3. **공유 게이트웨이의 개인 스킬 라이브러리** — `openclaw skills library`로 워크스페이스 스킬 옆에 내 스킬을 두고, ZIP 아카이브로 가져오거나 팀 게이트웨이에서 신원(identity)별로 공유·게시할 수 있습니다.
4. **일을 방해하지 않는 업데이트** — `openclaw update`가 **npm 후보 롤백**, 설정·시크릿 참조 보존, **내장 트리아지 에이전트**에게 실패 처리 위임, 플러그인 준비 완료 후 재시작, npm 12 로컬 아카이브 지원까지. 서비스 매니저가 없는 환경에서도 거부 대신 진행합니다.
5. **계속 살아있는 게이트웨이** — 부하·대규모 에이전트 명단에서도 시작 복구, 잘못된 레거시 cron 행은 격리, 로컬 모델 서버를 OOM 우선 대상으로, Windows 게이트웨이는 에이전트 재시작 후에도 온라인 유지.
6. **Codex 승인이 '지속'됩니다** — OpenClaw 설정 서버의 MCP 도구에 대한 **'Allow Always'가 durable**해지고, 승인은 세션 포스처를 따르며, 활성 Codex 배치에 부여된 승인은 다시 묻지 않습니다.
7. **승인 카드가 내 채팅으로** — 위임된 시스템 에이전트가 설정 변경·게이트웨이 재시작을 제안하면 승인 카드가 **원래 채널(텔레그램 토픽 포함)**로 전달됩니다. 조용히 멈춰 있던 과거와 다릅니다.
8. **안드로이드가 웹 UI를 따라잡음** — 채팅 화면·사이드바·외관 설정이 Control UI와 동일해지고, 작성창은 6줄까지, 받아쓰기가 없으면 녹음을 제안합니다.

## 변경점에서 새로 확인된 것들 — 모델·로컬·운영 설정

하이라이트 외 **Changes** 섹션에서 눈에 띄는 것만 골랐습니다.

- **모델 지원** — Anthropic **Fable 5.1**을 공유 모델 메타데이터로 지원, **GPT-5.6 Ultra** 선택 상태가 런타임 경계와 네이티브 계정을 넘어 유지, **SuperGrok 사용량**을 `openclaw models`와 사용량 패널에 표시, Vertex의 Sonnet 5 가격 갱신.
- **로컬·설정형 프로바이더** — 웹앱 엔드포인트 뒤의 llama.cpp 모델 발견, 로컬 Ollama 라우트 유지, Google 프로바이더 플러그인 자동 활성화, 인증·설정 변경 후 재시작 없이 모델 카탈로그 새로고침.
- **운영 설정** — 에이전트 기본 작업 디렉터리(`agents.defaults.cwd` / 에이전트별 `cwd`)와 **워크트리**(최대 100개 관리 체크아웃), `cron.skipMissedJobs`(시작 시 밀린 반복 작업 스킵), SSRF 정책에 `blockedHostnames`, `config set`의 `--dry-run`·`--strict-json` 등, `channels.<id>.enabled: false`면 해당 채널 플러그인 자체를 로드하지 않음.
- **메모리 유지보수** — `openclaw memory reset`은 세션을 지우지 않고 파생 인덱스만 재구축. 어제 프리뷰에서 다뤘던 그대로 확정됐습니다.
- **개인 GitHub 계정** — 시스템 계정 옆 'My GitHub' 연결, 개인 신원으로 PR 게시, 세션 전환 시 재인증 불필요.

보안 픽스도 꽤 촘촘합니다. SMS 웹훅의 동시 사전인증 읽기 제한, 폐기된 Watch 노드로의 명령 전달 중단, Copilot Azure BYOK 프록시 nonce 요구, 웹훅 rate limit 클라이언트별 격리, 과도한 A2A JSON-RPC 배치 거부, `config.get`의 마이그레이션 전 스냅샷 미가드 처리, systemd 유닛 백업의 게이트웨이 토큰 누출 방지, Chrome MCP `--browserUrl`의 CDP 정책 준수, 심볼릭 링크·비정규 워크스페이스 파일의 메모리 동기화 스킵 등이 포함됐습니다.

## 실제 사용감 — 솔직한 장단점

프리뷰→정식 하루 만에 출시된 만큼, **"정식판을 실제로 올려 쓰는 입장"**에서 장단점을 정리하면요.

**👍 좋은 점**
- **기다림이 없어졌다** — 릴리스 노트 공개(9/3) → 정식 배포(9/4 새벽) 간격이 채 하루. 2.0 이후 OpenClaw의 배포 속도가 정말 빨라졌습니다.
- **설치 장벽이 한 단계 내려감** — Claude Code나 Codex를 이미 쓰는 분은 로그인을 다시 입력할 필요 없이 1프롬프트로 끝나는 건 생각보다 큽니다. 신규 유입에 체감이 클 부분이에요.
- **업데이트 실패 공포 완화** — 롤백 + 설정 보존 + 트리아지 에이전트까지. \"업데이트했다가 게이트웨이를 잃는\" 최악의 시나리오를 공식적으로 줄여줍니다.
- **모델 선택지 확장** — GPT-5.6 Ultra 유지, Fable 5.1 지원, SuperGrok 사용량 표시까지. 메인 모델을 자주 바꾸는 분께 반가운 소식.

**⚠️ 주의할 점 / 단점**
- **1,195개 PR 규모의 마이그레이션** — 8.2와는 비교가 안 되는 큰 업데이트입니다. 솔직히 업데이트 전 **백업은 필수**예요. 공식 노트도 업데이트 실패 시 로컬 코딩 하네스로 진단하라고 안내할 만큼, 변경 범위가 넓습니다.
- **서비스 매니저 없는 8.2 사용자는 1회 수동 명령 필요** — 공식 노트에 \"서비스 매니저가 없는 2026.8.2 사용자는 `openclaw update --no-restart`를 1회 실행하라\"고 명시돼 있습니다. 자동 업데이트가 멈춘 것처럼 보여도 당황하지 마세요.
- **문서 요약(922 PR)과 정식 집계(1,195 PR)의 괴리** — 릴리스 노트가 '살아있는 문서'라서 그렇긴 한데, 블로그나 뉴스에서 인용할 땐 버전·시점을 확인하는 게 좋겠습니다.

## 업데이트 방법 — v2026.8.2 → v2026.9.1

기존에 8.2(또는 2.0)를 쓰고 계신 분들은 터미널 한 줄이면 됩니다.

```bash
openclaw update
```

- **서비스 매니저가 없는 환경(8.2 사용자)** — 아래 명령을 1회 실행해 주세요.
  ```bash
  openclaw update --no-restart
  ```
- **업데이트가 실패하거나 상태 점검이 필요할 때**
  ```bash
  openclaw doctor
  openclaw doctor --fix
  ```
- **대화는 보존한 채 메모리 인덱스만 정리하고 싶을 때**
  ```bash
  openclaw memory reset
  ```

정식 출시 후 체크리스트로는 ①업데이트 전 백업 → ②`openclaw doctor` 상태 점검 → ③메모리 인덱스가 꼬였다고 느껴지면 `memory reset` → ④자동화 운영자라면 `cron.skipMissedJobs` 설정 검토 → ⑤팀 공유 게이트웨이라면 개인 스킬 라이브러리(`openclaw skills library`) 도입 여부 결정, 순으로 권합니다.

## 마무리

정리하면, **v2026.9.1은 어제 프리뷰로 다뤘던 9월 메이저가 하루 만에 정식으로 확정된 업데이트**입니다. 최종 집계 **1,195개 PR** 규모로, 머메이드 렌더링·1프롬프트 설치·개인 스킬 라이브러리·업데이트 안전 복구·안드로이드 UI 통합까지 **2.0에서 만든 것들을 실제 일상으로 끌어올리는** 내용이 확정됐어요. GPT-5.6 Ultra·Fable 5.1 등 모델 지원과 보안 픽스도 빼놓을 수 없고요.

요즘 저처럼 **무료 오픈소스 AI 에이전트로 업무 자동화를 직접 해보시는 분들**, 특히 **Claude Code·Codex를 이미 쓰다가 OpenClaw로 옮겨오시는 분들**께는 설치 퀵스타트만으로도 업데이트할 가치가 충분합니다. 솔직히 요즘 AI 툴 중에 **가성비 좋은 제품 찾는 분께 추천**할 만한 건 OpenClaw가 계속 1순위네요. 🦞

저도 이제 `openclaw update` 누르고, **실제 업데이트 후기**로 다시 찾아오겠습니다.
