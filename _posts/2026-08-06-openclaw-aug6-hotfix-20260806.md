요즘 저처럼 **오픈소스 AI 에이전트 OpenClaw** 소식을 매일 챙겨보시는 분들, 계시죠? 지난 8월 3일 글([크롬 확장프로그램 공식 등재 + v2026.7.2 릴리즈 임박](/2026/08/03/openclaw-aug3-20260803/))에서 "이제 정식판만 기다리면 되겠다"고 말씀드렸는데, **사흘 사이에 또 챙길 소식**이 나왔습니다.

오늘(8월 6일) 아침, GitHub API와 npm 저장소, 공식 릴리즈 노트를 직접 확인한 결과 기준으로 정리하면 **① 8월 4일 v2026.7.1-1·v2026.7.1-2 핫픽스 릴리즈 2종 발행, ② extended-stable 채널 2026.6.34 발행(LTS 로드맵 후속), ③ GitHub 스타 385,260개·주간 다운로드 316만 건 돌파, ④ v2026.7.2 정식판은 아직"** 이렇게 네 가지로 요약됩니다.

## 1. 핵심 소식 ① — v2026.7.1-1·v2026.7.1-2 핫픽스 릴리즈 (8/4 발행)

8월 4일(한국 시간 기준), OpenClaw 유지보수 담당자 **vincentkoc** 님에 의해 안정판 **v2026.7.1의 핫픽스 릴리즈 2개가 연달아 발행**됐습니다. 정식판이 나오기 전에 기존 안정판 사용자가 겪던 문제부터 먼저 정리하는, **"안정판 안정화"** 성격의 업데이트입니다.

![OpenClaw GitHub Releases 페이지](/assets/images/posts/openclaw-aug6-20260806/openclaw-github-releases.png)
*GitHub Releases 페이지 — v2026.7.1-2가 Latest로 표시, 그 아래 v2026.7.1-1 핫픽스 확인 가능 (출처: github.com/openclaw/openclaw/releases, 확인일 2026-08-06)*

### v2026.7.1-1 (2026-08-04) — 5가지 수정

| 수정 항목 | 내용 |
|:----|:----|
| **Codex 진행 메시지** | 진행 상황(progress) 메시지를 보낸 뒤에도 앱 서버 턴이 중단되지 않도록 수정 — GPT/Codex가 **마지막 답변까지 끝까지** 도달 (#106961, #108487) |
| **Memory Core 시작 복구** | 파생 레거시 인덱스·캐시 사이드카 충돌로 **게이트웨이가 재시작 루프에 빠지는 문제** 복구 (#107220, #108652) |
| **WSL 상태 권한** | WSL에서 `EROFS`(읽기전용 파일시스템) 오류를 **기존 상태 경로가 이미 private일 때만** 허용, 광범위 권한은 차단 유지 (#108250, #108258) |
| **레거시 마이그레이션 복구** | 업그레이드 시 남은 마이그레이션 잔여물이 **시작을 막지 않도록** 처리 (#106101) |
| **관리 플러그인 업데이트** | 오래된 npm lock 메타데이터를 복구해 공식 관리 플러그인이 **깔끔하게 업데이트**되도록 (#107294, #107866) |

### v2026.7.1-2 (2026-08-04) — npm 플러그인 수정

- **npm 플러그인 업데이트**: 최신 npm 클라이언트가 보내는 **singleton-array 메타데이터를 수용**해, 추적 중인 공식 플러그인이 **수정 릴리즈(correction release)로 정상 설치·업데이트**되도록 수정 (#108336)

솔직히 "화려한 신기능"은 아니지만, **"재시작 루프"나 "플러그인 업데이트 실패"처럼 실제로 운영 중인 분들을 괴롭히던 문제들**을 정조준한 릴리즈라 반가운 소식입니다. 특히 Memory Core 시작 복구는 **"아침에 일어나니 게이트웨이가 죽어있던"** 분들에게 체감이 클 것 같아요.

## 2. 핵심 소식 ② — extended-stable 채널 2026.6.34 발행

지난 7월 30일 공식 블로그에서 발표된 **LTS 로드맵**(extended-stable 릴리즈)의 후속 움직임도 확인됐습니다. npm의 `extended-stable` 채널에 **2026.6.34**가 **8월 4일 발행**됐습니다.

| npm 채널 | 버전 | 발행일 |
|:----|:----|:----|
| **latest** (안정판) | **2026.7.1-2** | 2026-07-18 |
| **extended-stable** (LTS) | **2026.6.34** | 2026-08-04 |
| **beta** | **2026.7.2-beta.7** | 2026-08-02 |

`extended-stable`은 **"검증된 안정성"**을 우선하는 채널이라, "매일 업데이트 따라가기보다 검증된 버전을 오래 쓰고 싶다" 하시는 분(특히 자동화·서버 운영자)께 어울리는 선택지입니다. 정식 v2026.7.2가 나온 뒤에도 이 채널은 별도 라인으로 꾸준히 유지될 예정이라, **업데이트 정책을 미리 정해두면** 나중에 헷갈리지 않습니다.

## 4. 핵심 소식 ④ — 개발 속도는 여전히 "풀가스" (8/5~8/6 커밋 하이라이트)

v2026.7.2 정식판이 아직 안 나왔는데도, 지난 이틀간 커밋은 쉬지 않고 올라오고 있습니다. 일반 사용자에게 의미 있는 것만 골라보면:

- **`fix(browser): preserve locale, timezone, and device overrides (#119695)`** — 브라우저 제어 시 **언어·시간대·기기 설정이 초기화되던 문제** 수정. 해외 사이트에서 "AI가 이상한 언어로 접속한다"는 경험을 하셨던 분께 해당
- **`improve(ollama): reduce inactive startup cost (#119745)`** + **`improve(gateway): defer inactive plugin runtime imports (#119733)`** — **Ollama 로컬 추론·플러그인 시작 비용 절감**. 저사양 머신에서 체감되는 최적화
- **`fix(matrix): prevent shared client key collisions (#119667)`** — Matrix 채널에서 **클라이언트 키 충돌 방지**
- **`fix(worktrees): preserve registered roots during orphan cleanup (#119709)`** — 워크트리 정리 중 등록된 루트가 사라지던 문제 수정
- **`fix(gateway): finish successful sessions after timestamp races (#119752)`** — 타임스탬프 경합으로 **성공한 세션이 끝나지 않던 문제** 수정
- **`fix(memory): keep post-ready RPCs responsive (#119710)`** — 메모리 RPC 응답성 유지
- **`fix(whatsapp): exercise descriptor-safe credential persistence (#119621)`** — WhatsApp 자격증명 저장 안정화
- **`fix(msteams): consolidate channel action target resolution (#119632)`** — Microsoft Teams 채널 동작 정리

솔직히 **"정식판 직전에 안정성·최적화에 집중하는 전형적인 패턴"**입니다. 베타.7에서 이미 완성된 하이라이트 문서(상태 안전성·복구, 지속 채널 전달, 세션 되감기·브랜칭, Wear OS 등)를 감안하면, **v2026.7.2 정식판이 조만간 나올 것**이라는 기대가 더 굳어지는 흐름이에요.

커뮤니티에서도 관심이 뜨겁습니다. 8월 4일에는 **"ClawdBot의 63가지 미친 사용 사례"** 영상이 올라왔고, 레딧에는 **"지금 어떤 버전 쓰고 계세요?"** 설문이 올라와 있어요. 지난주 Tom's Hardware가 "로컬 AI 하드웨어에서 OpenClaw 돌리기"를 다루는 등 **일반 미디어의 관심도 계속 확산**되는 중입니다.

## 5. 지금 설치해도 될까? — 버전 현황과 솔직한 판단

오늘(8/6) 기준 버전 현황은 이렇습니다.

| 채널 | 버전 | 상태 |
|:----|:----|:----|
| npm 안정판 | **2026.7.1-2** | 최신 안정판 (8/4 핫픽스 반영) |
| npm extended-stable | **2026.6.34** | LTS 지향 검증판 (8/4 발행) |
| npm 베타판 | **2026.7.2-beta.7** | 안정화 막바지 |
| 예정 | **v2026.7.2 정식판** | 하이라이트 문서 완비 → 릴리즈 대기 중 |

```bash
# 안정판 유지 (현재 최신: 2026.7.1-2)
npm install -g openclaw@latest

# LTS 지향 검증판
npm install -g openclaw@extended-stable

# 베타 미리 써보기
npm install -g openclaw@beta

# 버전 확인 & 문제 자동 수정
openclaw version
openclaw doctor --fix
```

![OpenClaw 실제 사용 화면](/assets/images/posts/openclaw-aug6-20260806/openclaw-wikimedia-screenshot.png)
*OpenClaw 실제 사용 화면 (출처: Wikimedia Commons "OpenClaw Screenshot.png", MIT 라이선스, 확인일 2026-08-06)*

**제 솔직한 판단**은 이렇습니다.

- **지금 안정판(2026.7.1-2)을 쓰고 계신 분** → 이번 핫픽스로 **재시작 루프·플러그인 업데이트 문제가 정리**됐으니 그대로 유지하셔도 좋습니다. `openclaw doctor --fix` 한 번 돌려서 상태 점검만 해두시길 추천해요.
- **자동화를 밤새 돌리는 분** → extended-stable(2026.6.34)도 좋은 선택입니다. 검증된 버전을 오래 쓰는 게 오히려 안정적이에요.
- **베타.7을 쓰고 계신 분** → 정식 v2026.7.2가 나오면 **한 번에 올리는 것**이 가장 안전합니다. 베타.6부터 GPT Live는 OpenAI Platform API 키가 필수라는 점, 아직 기억해두세요.

주의할 점 하나만 더 — 지난 글에서도 말씀드렸듯 **Wear OS 페어링 버그(#116049)**는 여전히 베타에 남아 있습니다. 손목 앱을 메인으로 쓰시는 분은 정식판 릴리즈 노트에서 해당 이슈가 닫혔는지 꼭 확인해보세요.

## 마무리 — 오늘 소식 한 줄 정리

1. **v2026.7.1-1·v2026.7.1-2 핫픽스 릴리즈 (8/4)** — Codex 진행 메시지·Memory Core 시작 복구·WSL 권한·npm 플러그인 업데이트 수정
2. **extended-stable 2026.6.34 발행 (8/4)** — LTS 로드맵 후속, 검증판 채널 운영 본격화
3. **스타 385,260개·주간 다운로드 316만 건 (8/6)** — 사흘 만에 +302, 글로벌 5위 진입 눈앞
4. **v2026.7.2 정식판은 "릴리즈 대기 중"** — 8/5~8/6에도 안정화·최적화 커밋 지속

저처럼 **"안정판은 검증된 버전으로, 신기능은 정식판에서"** 전략으로 OpenClaw를 운영하시는 분께는, 이번 핫픽스 릴리즈가 "이제 안심하고 놔둬도 되겠다"는 신호로 다가올 겁니다. 다만 AI 에이전트에게 **로그인된 브라우저나 파일 접근 권한**을 줄 때는 언제나 최소 권한 원칙을 지키시는 걸 권해요. 중요한 작업은 신뢰할 수 있는 스킬·채널에서만 시키시고요.

관련해서 지난 글([8/3 크롬 확장프로그램 등재 총정리](/2026/08/03/openclaw-aug3-20260803/), [베타.6·베타.7 총정리](/2026/08/02/openclaw-v202672-beta7-update/), [v2026.7.1 LTS·성숙도 점수카드](/2026/07/31/openclaw-v202671-lts-maturity-scorecard/))과 함께 읽으시면 전체 흐름이 잡힙니다. **정식 v2026.7.2가 나오는 대로 다시 찾아뵙겠습니다.**
