요즘 저처럼 **오픈소스 AI 에이전트**를 실제 업무에 붙여 쓰는 분들, 특히 **Hermes Agent**로 자동화 파이프라인을 돌리시는 분들 많으시죠? 저도 이 블로그의 자동 포스팅 일부를 **Hermes Agent 크론잡**으로 돌리고 있어서, 릴리스 소식은 거의 매일 같이 보고 있는데요.

지난 8월 3일, **Hermes Agent v0.20.0 'Herald 릴리스'**가 배포됐습니다. 공식 표현을 빌리자면 **프로젝트 역사상 가장 큰 단일 릴리스**인데요 — v0.19.0 이후 **약 3,650개 커밋, 1,400개 PR, 5,200개 파일 변경, 1,200개 이슈 클로즈, 650+ 기여자**가 모였습니다. 숫자부터가 다릅니다.

이번 글에서는 릴리스 노트를 그대로 옮기는 대신, **실사용자 관점에서 진짜 체감되는 변화** 위주로 정리해 드릴게요. 특히 이번 릴리스의 정체성은 '전령(Herald)'입니다. **말을 하고(음성), 다른 에이전트에게 말을 전하고(A2A), 내 시스템에 소식을 알리고(웹훅), 근거를 보여줍니다(인용).** 하나씩 풀어보겠습니다.

## 1. 헤드라인: "메시지 보내기"가 아니라 "전화 통화"가 된 음성 모드

솔직히 이번 릴리스에서 제일 놀란 부분이 음성입니다. 기존 음성 모드는 **워키토키 방식**이었어요. 내가 말하고 → 답변이 끝까지 생성될 때까지 기다리고 → 긴 오디오 파일 하나를 통째로 듣는 구조였죠.

v0.20.0부터는 완전히 달라졌습니다.

- **생각하면서 동시에 말한다** — 답변이 스트리밍되는 동안 절(clause) 단위로 음성을 합성
- **Barge-in(끼어들기)** — 내가 말하는 중간에 말을 걸면 Hermes가 멈추고 듣고, **모델이 "사용자가 끼어들었다"는 사실을 인지**해서 이후 답변을 조정
- **바쁠 때 감지하는 침묵 감지** — 절대 내 말을 끊지 않음

실제로 써보면 "헤이 Hermes, 오늘 날씨 어때?"라고 물어보고, 답변이 절반쯤 진행될 때 "...그리고 내일 것도 확인해 줘"라고 덧붙이면 **바로 방향을 틉니다.** 공식 요약 표현 그대로, "음성 사서함 교환"에서 "실제 대화"로 바뀐 느낌이에요. CLI 음성 모드, 데스크톱, 오디오를 지원하는 모든 게이트웨이 어댑터에서 동작합니다.

## 2. 웨이크워드 — 방 건너편에서 터미널에 말 걸기

대화형 음성과 짝을 이루는 게 **온디바이스 웨이크워드 감지**입니다.

- **오픈 보캐블러리** — "헤이 Hermes"뿐 아니라 원하는 아무 구절이나 지정 가능
- **온디바이스 감지** — 대기 중에는 **오디오가 기계를 떠나지 않음** (프라이버시 포인트)
- **멀티 프로필 음성 라우팅** — 웨이크워드별로 다른 프로필에 연결 가능
- 어떤 화면에서든 **"stop"이라고 말하면** 음성 채팅 종료

두 번째 모니터에 켜둔 Hermes 데스크톱에 방 건너편에서 "헤이 Hermes"라고 말하면 **일어나서 응답**합니다. 터미널이 "방 건너편에서 말 걸 수 있는 존재"가 된 거죠.

## 3. 음성은 어디에나 — 메신저 음성 메모도 이제 통역

WhatsApp, Feishu(飞书), DingTalk, LINE, QQ, Photon, Weixin 등에서 **음성 메모를 보내면** 받아쓰기(STT) 후 답변해 주고, **플랫폼에 맞는 자동 TTS 답장**(opus 코덱, 캡션 첨부)까지 붙여서 돌아옵니다.

STT도 제대로 커스터마이징됩니다.

- 전용 `hermes tools` 카테고리, GUI 토글, 대시보드 드롭다운
- "전사 결과가 엉뚱한 언어로 나오는" 고질병을 잡는 **통합 언어 해석**
- **OpenAI gpt-transcribe 지원**
- 모든 TTS 제공자가 공유하는 **통합 발화 전처리기** — 말하기 전에 마크다운·코드·URL을 정리해서 읽어줌

## 4. 믿을 수 있는 리서치 — '근거 인용' 스킬

이번 릴리스에서 연구 목적으로 쓰시는 분들께 가장 추천하는 기능입니다. 새 **grounded-citations 스킬**은 **모든 주장에 검증 가능한 출처를 붙입니다.**

- 인용이 실제 페이지 텍스트와 **일치하는지 대조** (기억에서 지어낸 게 아니라)
- 인용이 **정확한 증거로 링크**
- **팩트체크 모드** — 어떤 문서나 주장에든 같은 장치를 돌려서 "검증됨 / 검증 안 됨 / 확인 불가"를 판정

공식 표현이 딱인데요, "그럴듯해 보이는(sounds right)"과 "증명된 출처(provably sourced)"의 차이를 만들어 준다고. Hermes를 리서치에 쓰시는 분이라면 **필수 기능**입니다.

## 5. 아웃바운드 웹훅 — 이제 Hermes가 먼저 내 시스템에 연락

기존에는 Hermes와 연동하려면 폴링하거나 플랫폼에서 듣고 있어야 했는데, 이제 반대 방향이 생겼습니다. **서명된 라이프사이클 이벤트**(세션 활동, 턴 완료, 도구 이벤트)를 등록한 HTTP 엔드포인트로 **Hermes가 직접 푸시**합니다.

- **HMAC 서명**으로 수신 측이 진위 검증 가능
- CI, 홈 오토메이션, 대시보드 등 HTTP를 말하는 어디든 연결
- **폴링 루프 불필요**

"에이전트가 일을 끝내면 슬랙/대시보드로 알림을 보낸다" 같은 시나리오를 깔끔하게 짤 수 있어요.

## 6. 데스크톱 앱이 '플랫폼'이 되다 — 아티팩트·플러그인 SDK

Hermes Desktop은 채팅 클라이언트를 넘어 **워크벤치**가 됐습니다.

- **아티팩트(Artifacts)** — 버전 관리되는 카드 + **샌드박스 라이브 미리보기**(우측 레일 뷰어). 생성된 HTML 앱을 채팅 옆에서 안전하게 실행
- **플러그인 SDK** — 칸반(Kanban)이 첫 데스크톱 플러그인으로 탑재, `ctx.download`로 파일 전달, 플로팅 팬 배치
- **퀵 엔트리 창** — 전역 단축키로 OS 어디서든 생각을 세션에 캡처
- **멀티 GUI 창** 지원

MCP로 연결된 도구가 만든 이미지, HTML 앱 등 **모든 플랫폼에서 만든 산출물이 아티팩트에 모이고**, 미리보기가 샌드박스라 테스트도 안전합니다.

## 7. A2A v1.0 — 에이전트들이 마침내 '공통어'를 말하다

이번 릴리스에서 의미심장한 변화는 **A2A(Agent-to-Agent) 프로토콜 v1.0** 플러그인 탑재입니다. Hermes가 다른 A2A 호환 에이전트를 **발견하고, 대화하고, 구동당할 수** 있게 됐어요. 저장소에서 **가장 오래된 오픈 기능 요청 중 하나(#514)를 클로즈**한 기능이기도 합니다.

실무 가치로 보면, 서로 다른 에이전트 스택이 섞여 있는 워크플로우라면 **Hermes가 표준 와이어 프로토콜로 합류**할 수 있습니다. "Hermes가 내 다른 에이전트들을 오케스트레이션하거나, 반대로 다른 에이전트가 Hermes를 구동"하는 구조가 가능해지는 거죠.

## 8. CLI 파워 유저 물결 — !, /init, /diff, /context, /focus

v0.20은 CLI 커맨드 물결도 실었습니다.

| 커맨드 | 역할 |
|:---|:---|
| `!명령어` | 모델 턴을 소모하지 않고 **셸 명령 즉시 실행** |
| `/init` | 프로젝트를 스캔해 **AGENTS.md 생성·갱신** |
| `/diff` | staged/전체/세션 변경분을 어느 화면에서든 표시 |
| `/context` | **컨텍스트 창을 뭐가 채우고 있는지** 정밀 분석 |
| `/focus` | 줄인 출력 뷰 + 숨은 줄 복구 |
| `Ctrl+S` | 작성 중인 프롬프트를 **임시 저장** |

게다가 `hermes import-agent` 한 줄이면 **Claude Code나 Codex CLI 설정을 Hermes로 이전**할 수 있습니다.

## 9. 잘못 가면 '재시작'이 아니라 '방향 전환' — 미드턴 리다이렉트

Hermes가 엉뚱한 방향으로 가고 있을 때, 더 이상 `/stop` 후 처음부터 설명할 필요가 없습니다. **작업 중에 교정을 입력하면 진행 중인 턴이 리다이렉트**됩니다.

- 진행 중이던 작업은 보존
- 원래 프롬프트는 유지
- 에이전트가 새 지침으로 **코스 수정**

더블 ESC 초안 폐기, 컴포저 실행취소 스택과 맞물려서, "에이전트를 붙잡는 일"이 재시작이 아니라 **편집처럼** 느껴집니다.

## 10. 스스로 고쳐지는 도구 + 압축 개편 + 똑똑해진 승인

자잘하지만 체감 큰 개선들도 챙겨갈 만합니다.

- **자기 회복 도구** — 잘린 터미널 출력은 파일로 넘겨 재읽기, `patch`는 이미 적용된 편집 감지, `write_file`은 디스크 기록 검증, 검색 무결과 시 근접 매치 복구. **기본 도구 호출 반복 한도가 90→500**으로 늘어나 긴 자동 실행이 인공 벽에 안 막힘
- **대화 존중 압축** — 대형 윈도우 모델용 사전 정리, 턴별 마이크로 압축, **최근 N개 사용자 메시지 보장 유지**(`compression.min_tail_user_messages`), 모델별·절대 토큰 임계값 설정. 긴 세션이 끊기지 않음
- **스마트 승인 성장** — `hermes approvals suggest`로 승인 이력에서 허용목록 제안, 연속 거부 시 **회로 차단기**, docker/podman 데몬 리다이렉트용 새 승인 게이트까지

## 11. 또 빨라졌다 — 콜드 스타트 14초 → 1.8초

성능도 계속 쌓입니다. **`hermes -w` 콜드 스타트가 약 14초 → 1.8초**, `hermes update` 무변경 시 2~6초 단축, 무거운 SDK는 import 경로에서 지연 로드, 설정 읽기는 텔레메트리 게이트에서 54배 빨라졌습니다. 데스크톱은 **두 번째 60fps 물결** — 스트리밍 탭 5개를 켜도 60fps 드래그, 유휴 CPU는 거의 0에 수렴합니다.

> 참고: "퍼스트 토큰 4.3초 → 0.9초"로 자주 인용되는 수치는 v0.19.0(Quicksilver)의 성과입니다. v0.20은 그 위에 콜드 스타트·캐싱·렌더링 이득을 더한 구조예요.

## 12. 솔직한 단점 — v0.20.0을 쓰면서 짚어야 할 것

좋은 점만 나열하면 솔직한 리뷰가 아니죠. 짚어야 할 것들입니다.

1. **Node 26 필수** — 이번 릴리스부터 Node 26이 필요합니다. 인스톨러/셀프힐/업그레이드 경로가 처리해 주지만, 구버전 Node 환경을 직접 관리하시는 분은 확인 필요
2. **brew·pip 채널 은퇴** — 설치 채널이 **셸 인스톨러, Docker, Nix 3개로 정리**됐습니다. 기존 brew/pip 설치자는 마이그레이션이 필요해요
3. **큐레이티드 릴리스 노트는 v0.21.0에** — v0.20.0 창의 전체 하이라이트 정리는 다음 메이저 릴리스에서 나옵니다. 지금은 릴리스 노트 원문 + 커뮤니티 딥다이브로 갈음해야 합니다
4. **A2A는 '초기 단계'** — 프로토콜 표준 자체가 막 v1.0이 된 만큼, A2A 호환 에이전트 생태계가 두터워지는 건 시간이 걸릴 전망

## 13. 마무리 — 업그레이드는 'hermes update' 한 줄, 체험 팁

정리하면, **Herald 릴리스의 핵심은 '전령'**입니다. 나에게 말하고(대화형 음성·웨이크워드), 다른 에이전트에게 말을 전하고(A2A v1.0), 내 시스템에 소식을 알리고(서명 웹훅), 근거를 보여줍니다(근거 인용). 거기에 데스크톱 플랫폼화, CLI 파워 커맨드, 압축·승인 개편까지 — **"도구"에서 "말하고 협업하고 출처를 대는 동료"로** 레벨이 바뀐 느낌입니다.

업그레이드는 기존 설치자 기준 **`hermes update` 한 줄**이면 끝입니다.

```
# 기존 설치
hermes update

# 새로 설치
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

솔직히 저처럼 **AI 에이전트를 매일 쓰는 분들**이라면, 이번 업데이트에서 꼭 한 가지는 체험해 보시길 권합니다. 업그레이드하고 Hermes에게 말을 걸어 보세요. 그러다 **답변 중간에 끼어들어 보세요.** "음성 사서함"과 "전화 통화"의 차이가 확실히 느껴질 겁니다. 대화형 음성·A2A 같은 최신 에이전트 기능을 **무료 오픈소스(MIT)로** 써보고 싶은 분, 가성비 좋은 AI 에이전트 찾는 분께 추천드려요.
