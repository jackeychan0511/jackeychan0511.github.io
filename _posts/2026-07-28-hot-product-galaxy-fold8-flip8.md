**2026년 7월 28일, 삼성 갤럭시 Z 폴드8·Z 플립8의 국내 사전예약이 오늘부터 시작됩니다!**

지난 7월 22일 영국 런던에서 열린 갤럭시 언팩 2026에서 공개된 신제품들이 드디어 한국에서 사전예약에 돌입했습니다. 사전예약 기간은 **7월 28일 ~ 8월 3일**이며, 공식 출시는 **8월 7일**입니다.

## 📋 사전예약 개요

| 항목 | 내용 |
|:----|:------|
| 🗓️ **사전예약 기간** | **7월 28일(화) ~ 8월 3일(월)** ← 오늘부터! |
| 📅 **공식 출시일** | 8월 7일(금) |
| 📱 **신제품 라인업** | 갤럭시 Z 폴드8 (울트라·와이드), Z 플립8, 갤럭시 워치8 |
| 🏪 **구매처** | 삼성스토어, 통신사 (SKT/KT/LGU+), 온라인 쇼핑몰 |

## 📱 갤럭시 Z 폴드8: 울트라 vs 와이드

이번 폴드8은 처음으로 **울트라(Ultra)**와 **와이드(Wide)** 두 가지 모델로 출시됩니다.

| 구분 | 폴드8 울트라 | 폴드8 와이드 |
|:----|:----------:|:----------:|
| **메인 디스플레이** | 8.0인치 | 7.6인치 |
| **커버 디스플레이** | 6.5인치 | 6.3인치 |
| **프로세서** | Snapdragon 8 Gen 4 | Snapdragon 8 Gen 4 |
| **RAM** | 16GB | 12GB |
| **스토리지** | 256GB / 512GB / 1TB | 256GB / 512GB |
| **카메라** | 2억화소 + 초광각 + 망원3배 + 잠망경10배 | 5천만화소 + 초광각 + 망원3배 |
| **배터리** | 5,000mAh | 4,400mAh |
| **S펜** | 지원 (별도 케이스) | 지원 (별도 케이스) |
| **두께 (펼쳤을 때)** | 5.6mm | 5.9mm |
| **무게** | 245g | 228g |

> 💡 **울트라**는 카메라 성능이 핵심 차이입니다.

사진 많이 찍는 분에게 추천합니다. **와이드**는 가성비를 원하는 분에게 적합합니다.

## 📱 갤럭시 Z 플립8

플립8은 컴팩트한 폴더블을 원하는 사용자를 위한 모델입니다.

| 항목 | 스펙 |
|:----|:----:|
| 메인 디스플레이 | 6.9인치 AMOLED, 120Hz |
| 커버 디스플레이 | 3.8인치 (대폭 확대!) |
| 프로세서 | Snapdragon 8 Gen 4 |
| RAM / 스토리지 | 12GB / 256GB~512GB |
| 카메라 | 5천만화소 듀얼 |
| 배터리 | 4,000mAh |
| 무게 | 185g |

> 🔥 플립8의 가장 큰 변화는 **3.8인치 커버 디스플레이**입니다. 전작 대비 커버 화면이 대폭 커져서 폴더블을 열지 않고도 많은 작업이 가능해졌습니다.
