## 1. 요즘 저처럼 OpenClaw 업데이트를 매일 챙겨보시는 분들

요즘 저처럼 **오픈소스 AI 에이전트 OpenClaw**의 릴리즈를 챙겨보시는 분들, 7월에 이어 8월 초도 정신없으실 겁니다. 지난주 글에서 v2026.7.2 베타가 7월 15일부터 시작돼 7월 28일 베타.5까지 나왔다고 정리해드렸는데요.

그런데 그 뒤로 상황이 빠르게 굴러갔습니다. **7월 28일 베타.5 → 8월 1일 베타.6 → 8월 2일 베타.7.** 이틀 연속으로 새 베타가 나온 건, 그만큼 **기능 추가보다 안정화와 버그 수정에 집중하고 있다**는 뜻입니다.

이번 글에서는 어제와 오늘 나온 **베타.6·베타.7의 핵심 변화**와, 제가 실제로 확인한 **정식 릴리즈 임박 신호**까지 정리해드립니다. 특히 **GPT Live를 Codex 계정(OAuth)으로 쓰고 계셨던 분들은 꼭 읽어보셔야 합니다.** 인증 방식이 바뀌었거든요.

## 2. 오늘(8/2) 나온 v2026.7.2 베타.7 — 뭐가 바뀌었나

먼저 오늘 배포된 **베타.7(2026-08-02, 한국시간 오후 5시 11분경)**부터 살펴보겠습니다. 베타.6에서 이어진 **안정화 수정** 두 건과, 눈여겨볼 **프로세스 변화** 하나가 핵심입니다.

| 구분 | 내용 |
|:-----|:-----|
| **채널 전달 수정** | 네이티브 큐(queue) 인자 오류가 발생했을 때 "모델 실패"로 오인해 잘못된 대체(fallback)를 쓰지 않고, **정확한 오류 원인을 설명**하도록 개선 |
| **세션·트랜스크립트 수정** | 재시작 시 프롬프트가 **활성 트랜스크립트의 꼬리에 유지**되도록 수정 (기존에는 재시작 후 대화 위치가 흐트러지는 문제가 있었음) |
| **릴리즈 검증 절차 도입** 🔥 | npm 패키지 무결성(SHA-512), 릴리즈 SHA, 전체 CI 리포트, 릴리즈 증거 문서(release evidence)를 **배포할 때마다 공개**하기 시작 |

솔직히 베타.6→베타.7의 기능 변화는 크지 않습니다. 다만 **릴리즈 검증 절차**가 생긴 게 의미가 큽니다. "이 버전이 정말 배포 가능한 상태인가"를 CI로 증명하고 그 기록을 남기는 절차는, **정식 릴리즈(Stable)를 앞두고 품질 게이트를 세우는 과정**으로 보는 게 자연스럽습니다.

## 3. 어제(8/1) 베타.6 — 놓치면 안 되는 변화 3가지

어제 나온 **베타.6**에는 사용자에게 직접 영향을 주는 변경이 몇 개 있었습니다. 특히 아래 3가지는 **버전 업데이트 전에 꼭 알아두셔야** 합니다.

### ① GPT Live 인증 변경 — Codex OAuth 폴백 제거, Platform API 키 필수 ⚠️

베타.5까지 GPT Live(실시간 음성 대화)는 **Codex OAuth 경유**를 지원했습니다. 그런데 베타.6부터 이 폴백 경로가 **공식적으로 제거(rejected)**됐습니다.

> 이제 GPT Live를 쓰려면 **지원되는 OpenAI Platform API 키**가 필요합니다. Codex 로그인만으로는 실시간 Talk가 동작하지 않습니다.

지난 글에서 "GPT Live(Codex OAuth 경유)가 추가됐다"고 정리해드렸는데, **일주일 만에 정책이 바뀐** 셈입니다. GPT Live를 베타에서 즐겨 쓰시던 분이라면 OpenAI Platform 콘솔에서 API 키를 발급받아 재설정하셔야 합니다. 실시간 Talk의 **OpenAI·Gemini 영상 지원**은 그대로 유지됩니다.

### ② cron 도구 → Automations 개명

스케줄 작업을 관리하던 **cron 도구가 'Automations'로 개명**됐습니다. CLI·UI 표면에서 새 이름을 쓰되, **기존 cron 명령어는 호환 별칭(alias)으로 계속 동작**합니다.

제 경우처럼 기존 스크립트에 `cron` 명령을 쓰고 계셨다면 당장 고장 나지는 않지만, **문서·튜토리얼이 Automations 기준으로 바뀌고 있으니** 새 프로젝트에서는 새 이름으로 익숙해지시는 걸 추천합니다.

### ③ DuckDuckGo 검색이 플러그인으로 분리

**DuckDuckGo 웹 검색이 코어에서 분리**돼 플러그인 경계로 이동했습니다. 소유권·설치·런타임 동작이 코어 밖으로 나간다는 뜻이라, 검색 기능을 쓰시는 분은 **관련 플러그인 설치 여부를 확인**하셔야 할 수 있습니다.

이 밖에 베타.6에는 **Fish Audio 음성 합성**(호스티드 S2.1: 스트리밍·음성 메모·음성 검색·전화 통화 지원, 로컬 Fish S2 Pro는 macOS 네이티브 Talk에서 참조 음성 스트리밍), **Buzz 메시징 개선**(마크다운 보존·방/스레드 단위 타이핑 표시), **Control UI 셋업 개선**(채널 연결 없이도 웹 앱 사용 가능 안내)도 포함됐습니다.

## 4. 데이터 안전성·안정화 수정 — 이번 베타의 숨은 공통점

베타.6·베타.7의 공통 키워드는 **"안정화"**입니다. 지난 글에서 다룬 데이터 안전성 작업이 이번에도 이어졌는데, 눈에 띄는 것만 추리면 이렇습니다.

- **SQLite 데이터 안전**: 손상된 캐시 DB의 **소유자만 정확히 골라 제거**해, 게이트웨이 재시작 없이 복구되도록 개선
- **채널 전달**: 텔레그램 durable-ingress 유실 방지, **Discord·iMessage·WhatsApp** 트래픽이 크래시·재시작에도 보존
- **제공자 신뢰성**: Anthropic의 Retry-After 응답 존중, Codex Computer Use 경로 복구, Ollama/LM Studio 등 로컬 모델 탐지 안정화
- **시스템**: systemd 게이트웨이 중복 소유권 방지 등

솔직히 "기능이 화려하게 늘었다"기보다는 **"쌓인 기능이 흔들리지 않게 다지는"** 성격의 업데이트입니다. 밤새 자동화 작업을 돌려놓는 분에게는 오히려 이런 업데이트가 더 반갑습니다. 크래시 한 번에 작업이 증발하는 일이 없어야 하니까요.

## 5. '릴리즈 검증 절차' — 정식 릴리즈 임박 신호

제가 이번 글에서 가장 주목하는 부분은 따로 있습니다. 베타.7부터 배포 노트에 추가된 **릴리즈 검증(Release Verification)** 항목입니다.

- npm 패키지 주소와 **무결성 해시(SHA-512)**
- 릴리즈 SHA, **전체 릴리즈 CI 리포트**
- **릴리즈 증거 문서**(release-evidence.md)
- npm 프리플라이트·플러그인 퍼블리시 검증 기록

이건 단순한 형식 변화가 아니라 **"배포할 때마다 이 버전이 검증됐는지 증명을 남기는"** 품질 게이트입니다. 여기에 릴리즈 주기가 **7/28 → 8/1 → 8/2로 급격히 짧아진** 점까지 합치면, **v2026.7.2 정식판(Stable)이 머지않아 나올 가능성이 높다**고 보는 게 합리적입니다.

참고로 프로젝트 규모도 계속 커지고 있습니다. GitHub 기준 **스타 약 38만 5,000개(384,903개, 2026-08-02 확인)**, 포크 약 8만 1,000개 수준입니다. 7월 13일 정식 릴리즈된 v2026.7.1(3,063개 커밋·532명 컨트리뷰터) 이후에도 개발 속도는 꺾이지 않는 모양새입니다.

## 6. 지금 베타로 갈아탈까? — 솔직한 판단 기준

그럼 "지금 베타를 설치해야 할까?"가 궁금하실 텐데요. 제 기준은 이렇습니다.

**베타를 써도 좋은 분**
- 세션 되감기·브랜칭, Wear OS, 실시간 Talk 같은 신기능을 **미리 써보고 싶은** 분
- 데이터 유실에 민감하지 않은 **테스트·개인 용도**로 쓰는 분

**안정판을 유지하길 권하는 분**
- 자동화·장기 작업을 **운영 중**인 분 — 지난 글에서도 말씀드렸듯 **Wear OS 페어링 버그(#116049)**가 아직 베타에 남아 있습니다
- GPT Live를 Codex OAuth로 쓰다가 **전환 작업을 피하고 싶은** 분

현재 npm 안정판은 **2026.7.1-2**, 베타판은 **2026.7.2-beta.7**입니다. 정식판이 곧 나올 것으로 보이니, **급하지 않다면 정식 릴리즈를 기다렸다가 한 번에 올리는 것**도 좋은 선택입니다.

### 업데이트 방법 (참고용)

```bash
# 안정판
npm install -g openclaw@latest

# 베타판
npm install -g openclaw@beta

# 버전 확인 & 문제 자동 수정
openclaw version
openclaw doctor --fix
```
