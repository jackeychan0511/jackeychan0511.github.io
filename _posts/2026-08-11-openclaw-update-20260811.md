**8월 4일 안정판 핫픽스 → 8월 8일 보안 강화 릴리즈 → 8월 10일 새 베타 라인 v2026.8.1 공개.** 한 주 사이에 안정판과 베타판이 동시에 움직인, 꽤 바쁜 한 주였습니다. 오늘은 제가 GitHub 릴리즈와 공식 사이트에서 직접 확인한 **8월 둘째 주 OpenClaw 소식**을 정리해드립니다.

## 1. 8/10(월) v2026.8.1-beta.1 공개 — 8월 새 베타 라인 시작 🔥

가장 최신 소식은 어제(8/10) 공개된 **v2026.8.1-beta.1**입니다. 7월 한 달간 이어졌던 **v2026.7.2 베타 라인(베타.1~베타.7)이 마무리되고, 8월 라인 v2026.8.1 베타가 시작된** 모양새입니다.

7.2 베타에서 공개된 대형 기능들이 아직 눈앞에 선명한데요. **원격 코딩 세션(클라우드 워커에서 Control UI 세션 실행), 세션 되감기·브랜칭, MCP 앱과 대시보드, Teams·Zoom·Meet 미팅 참여와 실시간 Talk, Wear OS 동반 앱**까지. 이 기능들이 8.1 라인에서 안정화를 이어갈 것으로 보입니다.

> 릴리즈 공개 직후라 상세 노트는 아직 간결한 상태입니다. 새 라인의 첫 베타인 만큼, 기능보다는 **8월 라인의 기반을 다지는 릴리즈**로 읽히는데요. 다음 베타가 나오는 대로 세부 변경을 다시 정리해드리겠습니다.

## 2. 8/8(토) v2026.6.34 — 안정화·보안 강화 릴리즈 (Extended-Stable)

이번 주 가장 의미 있는 릴리즈는 **8월 8일 배포된 v2026.6.34**입니다. 신기능을 얹는 대신 **보안과 안정성을 다지는 유지보수 릴리즈**인데, 내용이 알차서 따로 짚고 갑니다.

### ① 브라우저·네트워크 경계 보안 강화

- **샌드박스 브라우저 라우트, 신뢰된 DNS 대상, 커스텀 브라우저 오리진, 루프백 제공자 엔드포인트**가 이제 안전하지 않은 접근 경로를 거부합니다.
- 에이전트가 인터넷을 돌아다닐 때 **허용되지 않은 주소로 접근하는 시도를 원천 차단**하는 구조입니다. 에이전트에게 브라우저 권한을 주고 쓰시는 분이라면 반가운 소식입니다.

### ② 의존성 보안 패치

- `brace-expansion`, `PostCSS`, `fast-uri`, `ip-address`, **Undici** 등 핵심 의존성 패키지의 **보안 패치 버전으로 일괄 업데이트**됐습니다.
- 평소에 잘 안 보이는 부분이지만, **장기간 게이트웨이를 켜두고 쓰는 분에게는 꼭 필요한 업데이트**입니다.

### ③ 채널·게이트웨이 복구력 개선

- 대기 중이던 **채널 작업이 복구 후 재개**되고, 승인(ack)이 **멱등(idempotent)**하게 처리됩니다.
- Discord 게이트웨이 폭주 시 **버스트가 일정 수준으로 제한**되며, SQLite 체크포인트·워크스페이스 읽기·플러그인 HTTP 응답 등이 **일시적 호스트 문제로 실패 처리되지 않도록** 개선됐습니다.

솔직히 눈에 확 띄는 신기능은 없지만, "**밤새 자동화를 돌려놓는 사람**" 입장에서는 오히려 이런 릴리즈가 더 든든합니다. 크래시 한 번에 작업이 증발하는 일이 없어야 하니까요.

## 3. 8/4(화) v2026.7.1-1·-2 — 안정판 핫픽스 2종

8월 4일에는 안정판 **v2026.7.1-1, v2026.7.1-2**가 이어서 배포됐습니다. 지난 글에서 "npm 안정판은 2026.7.1-2"라고 말씀드린 그 버전들이죠. 이번 핫픽스에서 고쳐진 것들 중 눈에 띄는 항목입니다.

- **Codex 진행 응답**: 중간 진행 메시지 전달 후에도 턴이 끝나지 않고 **GPT/Codex의 최종 응답까지 정상 도달**하도록 수정
- **메모리 코어 시작 복구**: 레거시 인덱스·캐시 사이드카 충돌로 **게이트웨이가 재시작 루프에 빠지는 문제** 복구
- **WSL 상태 권한**: `EROFS`(읽기 전용 파일시스템) 오류를 기존 권한이 private일 때만 허용하도록 **fail-closed 유지**
- **관리형 플러그인 업데이트**: 오래된 npm lock 메타데이터로 공식 플러그인 업데이트가 막히는 문제 복구

정식 릴리즈를 운영 중이신 분들은 **v2026.7.1-2로 업데이트**해두시면 이번 주 핫픽스가 모두 반영됩니다.

## 4. 잠깐, 그동안 7.2 베타의 대형 기능들은? — 현 상태 정리

7월 내내 화제였던 **세션 되감기·브랜칭, MCP 앱, 미팅·실시간 Talk, Wear OS** 기능들은 아직 베타 라인에 있습니다. 지금 시점의 버전 구도를 정리하면 이렇습니다.

| 구분 | 버전 | 상태 |
|:-----|:-----|:-----|
| **안정판 (Stable)** | v2026.7.1-2 | 8/4 핫픽스 반영, 무난하게 운영 가능 |
| **연장 안정판 (Extended-Stable)** | v2026.6.34 | 8/8 보안·안정화 릴리즈, 장기 운영용 |
| **베타 (Beta)** | v2026.8.1-beta.1 | 8/10 시작, 7.2 대형 기능의 안정화 이어갈 전망 |

참고로 프로젝트 규모는 계속 커지고 있습니다. GitHub 기준 **스타 약 38만 5,800개(385,827개, 2026-08-11 확인)**로, 지난주(384,958개)보다 일주일 만에 약 870개가 늘었습니다. 그리고 공식 홈페이지에는 창시자 **피터 스타인버거(Peter Steinberger)가 Fast Company의 'AI 20 for 2026'에 선정**됐고, **약 50만 대의 시스템이 OpenClaw를 운영 중**이라는 소개가 걸려 있습니다. 오픈소스 AI 에이전트 생태계에서 입지가 점점 단단해지는 느낌입니다.

## 5. 지금 뭘 설치하면 좋을까? — 솔직한 판단 기준

그럼 "지금은 뭘 깔아야 하냐"가 궁금하실 텐데요. 제 기준은 이렇습니다.

**안정판(v2026.7.1-2)을 쓰시길 권하는 분**
- 자동화·장기 작업을 **운영 중**인 분 — 이번 주 핫픽스까지 반영된 안정판이 가장 무난합니다
- 보안에 민감한 환경이라면 **연장 안정판 v2026.6.34**도 좋은 선택입니다 (의존성 보안 패치 포함)

**베타(v2026.8.1-beta.1)를 미리 써보고 싶은 분**
- 세션 되감기·MCP 앱 같은 7.2 신기능을 **개인 용도로 미리 만져보고 싶은** 분
- 데이터 유실에 민감하지 않은 **테스트 환경**에서 쓰는 분

새 베타 라인이 막 시작된 만큼, **급하지 않다면 베타가 몇 차례 더 쌓인 뒤 올라타는 것**도 좋은 전략입니다.

### 업데이트 방법 (참고용)

```bash
# 안정판
npm install -g openclaw@latest

# 연장 안정판
npm install -g openclaw@extended-stable

# 베타판
npm install -g openclaw@beta

# 버전 확인 & 문제 자동 수정
openclaw version
openclaw doctor --fix
```
