요즘 저처럼 **OpenClaw 2026.8.1 정식판이 드디어 npm에 올라왔을까** 하고 아침마다 npm 태그부터 확인하시는 분들, 계시죠? 어제(8/19) 글에서 공동 창업자 **Hannes Rudolph(@hrudolph)**가 예고한 **"8월 18일(화) 출시"**가, 미국 서부 기준으로도 **이미 지나갔습니다.** 그래서 오늘도 저는 출근 전에 npm 레지스트리와 GitHub를 직접 열어봤습니다. 결과부터 말씀드리면 — **정식판은 아직 없습니다.** 대신 이번엔 확정된 기능 목록이 10만 자가 넘는 베타.2 릴리스 노트로 다 공개되어 있고, 지난 24시간 동안 **247개 커밋**이 또 쌓였습니다. 오늘은 **"어디까지 확정됐는지"**를 실측 기준으로 전부 정리해드립니다.

## 1. ⭐ 오늘의 메인 뉴스 — '8/18(화) 출시' 약속, 결국 또 미뤄짐 (npm 실측)

어제 글에서 **"미국 기준 8/18(화)이 아직 안 끝났다. 오늘 안에 나올 가능성이 남아 있다"**고 말씀드렸는데 — **그 8/18(화)도 지나갔고, 오늘(8/20) 아침 10시 20분 KST 기준으로도 정식판은 없습니다.** 제가 방금 npm 레지스트리에서 직접 확인한 결과입니다.

| 트랙 | 버전 | 배포 시각 (UTC) |
|:-----|:-----|:----------------|
| **latest (정식)** | `2026.7.1-2` | 2026-07-18 |
| **beta** | `2026.8.1-beta.2` | 2026-08-15 |
| **extended-stable** | `2026.6.34` | 2026-08-08 |

- **npm latest는 여전히 `2026.7.1-2`** 그대로입니다. 어제와 완전히 동일한 상태예요.
- **GitHub에도 `v2026.8.1` 태그가 아직 없습니다.** (방금 GitHub API로 직접 확인 — 404) 최신 릴리스 태그는 여전히 `v2026.8.1-beta.2`(8/15 배포)입니다.
- 솔직히 저는 **"출시가 늦어지는 게 오히려 안심된다"**는 어제의 평가를 그대로 유지합니다. 8/15 베타.2가 사후 전체 검증(Full Release Validation)에서 실패했던 걸 떠올리면, 이번엔 "서두르지 않고 제대로" 가는 게 맞거든요. 6월 릴리스 사태([OpenClaw Had a Rough Week](/2026/08/16/openclaw-update-20260816/)) 이후 검증 프로세스를 지키는 모습 자체가 신뢰가 갑니다.

다만 기다리는 동안 **확정된 기능 목록은 이미 다 나와 있다**는 게 오늘의 핵심입니다. 베타.2 릴리스 노트가 무려 **10만 자가 넘는 분량**으로 공개되어 있어서, 그중 핵심만 추려봤습니다.

## 2. 2026.8.1에 확정된 기능 — 베타.2 릴리스 노트 실측 총정리

베타.2 릴리스 노트(2026.8.1 기준)에서 **확정된 하이라이트 7가지 + 숨은 기능들**을 정리했습니다.

### ① 보안 — 시크릿 이그레스 호스트 바인딩 (Secret egress host binding)
공유 스토어(shared-store)의 **시크릿(API 키 등)을 정확한 HTTPS 대상 호스트에 바인딩**합니다. CLI·Gateway RPC·Control UI 전반에서, **바인딩되지 않은 시크릿 치환은 평문 이그레스(외부 유출) 전에 fail-closed**로 차단됩니다. 지난주부터 이어지는 "네트워크 경계 강화" 행보의 연장선이면서, **"키가 설정은 됐는데 어디로 새나갔을지 모르는"** 불안을 구조적으로 없애는 변경입니다.

### ② 모델 — GPT-5.6 Ultra와 Sol/Terra/Luna 런타임 전환
**GPT-5.6 Ultra 계열(Sol·Terra·Luna)**을 OpenClaw 엔진과 Codex 엔진 **양쪽에서** 지원합니다. 핵심은 **모델·런타임·thinking 선택이 `/model` 명령으로 원자적으로(atomic) 함께 바뀐다**는 점 — "모델만 바꿨는데 런타임이 안 따라오는" 꼬임을 막아줍니다. 신규 API 키 설정 시 기본값도 `openai/gpt-5.6`(Sol 별칭)로 바뀝니다.

### ③ 데이터 — SQLite 스냅샷 백업/복원 (`openclaw backup sqlite`)
`openclaw backup sqlite create|list|verify|restore` 명령으로 **검증된 백업 아티팩트**를 만들고, **fresh-target 전용 복원**으로 안전하게 되살릴 수 있습니다. 전역 DB와 에이전트별 DB를 각각 지원합니다. 크론잡을 돌리며 세션·메모리 데이터가 쌓이는 분들에게 **"업그레이드 전에 한 방"** 백업 수단이 생긴 셈입니다.

### ④ macOS — 앱 프로필 격리 (App profiles)
이름이 붙은 앱 인스턴스별로 **state·환경설정·Keychain·Gateway 서비스**를 격리하고 중복 인스턴스 소유권도 분리합니다. "회사용 프로필 / 개인용 프로필"을 같은 맥에서 분리해서 쓰고 싶었던 분들에게 딱 맞는 기능입니다.

### ⑤ 플러그인 — 설치 출처 경고 (Provenance warnings)
**임의 실행 파일(arbitrary executable) 소스의 플러그인 설치는 명시적 `--force` 확인을 요구**합니다. ClawHub·번들·공식 카탈로그·추적 업데이트 흐름은 그대로 두고, **Crestodian 설치는 신뢰 소스로 제한**합니다. 2월에 논란이 됐던 "스킬/플러그인 악성코드" 이슈([The Verge 보도](https://www.theverge.com/news/874011/openclaw-ai-skill-clawhub-extensions-security-nightmare))에 대한 지속적인 대응입니다.

### ⑥ Control UI — 업데이트 복구 버튼
"A new version is available" Reload 버튼이 **게이트웨이 재시작을 기다렸다가** 로드되도록 수정됐습니다. 기존에는 버튼을 눌러도 조용히 아무 일도 안 일어나서 **수동 하드 리로드**만 남았는데, 이제 버튼 하나로 끝납니다.

### ⑦ 채널 플러그인 — 공유 수명주기 모니터
**IRC·Synology Chat·Google Chat**이 공유 플러그인 SDK 모니터(durable admission·polling·pruning·claim identity 검증·adoption handoff·shutdown)로 이전됩니다. 채널 플러그인들의 "죽은 것처럼 멈추는" 문제를 공통 인프라로 잡는 작업입니다.

### ⑧ 그 외에 눈에 띄는 것들
- **Fish Audio 음성**: 호스팅 S2.1 합성·스트리밍·음성 노트·발견·전화 + macOS 네이티브 Talk의 로컬 Fish S2 Pro 참조 음성
- **Meta Muse Spark 1.1** 프로바이더 번들 지원 (Responses API 스트리밍·도구 호출·암호화 reasoning 재생)
- **ClickClack**: guided 셋업·커맨드 메뉴 자동완성·봇 협업(기본 차단, opt-in)
- **Dashboard MCP 앱**: 원본 세션의 MCP 앱 뷰를 대시보드 위젯으로 고정
- **외부 게이트웨이 감독**: `OPENCLAW_SUPERVISOR_MODE=external` — OCM 같은 라이프사이클 관리자용
- **iOS 오프라인 채팅**·**Android 채팅 에이전트 선택기**·**게이트웨이 호스트 상태(CPU/RAM/디스크) 표시**·**로컬 모델 셋업(Ollama/llama.cpp/LM Studio)**

솔직히 이 정도면 **"정식판 한 방"**으로 묶어서 나올 기능 치고는 꽤 알찹니다. 특히 ① 보안·③ SQLite 백업·⑦ 채널 수명주기는 "쓰다가 당하는" 문제를 미리 막아주는 성격이라, 정식판이 나오면 바로 체감될 변경들이에요.

## 3. 지난 24시간 커밋 점검 — 8/19 00:00 UTC ~ 8/20 01:14 UTC, 247건

출시를 기다리는 동안에도 커밋은 멈추지 않았습니다. GitHub API 실측 기준 **247건**이 쌓였는데, 그중 제가 눈여겨본 것들입니다.

### ① 크론잡 쓰는 블로거로서 제일 반가운 커밋 — 실패 알림 임계값
- **`fix(cron): honor failure alert thresholds` (#126483)** — 크론 실패 시 **알림 임계값(failure alert thresholds) 설정을 실제로 존중**하도록 수정했습니다. 저처럼 크론잡 알림을 메신저로 받아보는 입장에서는, "실패할 때마다 스팸처럼 알림이 오던" 문제와 "임계값을 설정해도 무시되던" 문제를 같이 정리해주는 변경입니다.
- **`fix(cron): report removed-agent notification failures` (#126361)** — 삭제된 에이전트의 알림 실패를 정확히 보고.

### ② GitHub 연동 2종 — 설정에서 에이전트 신원 승인
- **`feat(github): authorize agent identities from Settings` (#126474)** — **GitHub 설정 화면에서 에이전트 신원을 승인**할 수 있게 됐습니다.
- **`feat(gateway): broker GitHub publication` (#126306)** — 게이트웨이가 GitHub 발행(publication)을 중개.

### ③ 채널 수정 2종 — Telegram·Discord
- **`fix(telegram): preserve direct-message topic routing` (#126207)** — **Telegram DM의 토픽 라우팅 보존**. DM을 토픽별로 분리해 쓰시는 분들이라면 반가운 수정입니다.
- **`fix(discord): route polls through canonical delivery` (#126250)** — Discord 폴(투표) 메시지를 정식 전달 경로로 라우팅.

### ④ 안정성·보안 — Tailscale·Codex·OOM
- **`fix(tailscale): preserve privileged route conflicts` (#126449)** — **특권 라우트(privileged route) 충돌 보존**. Tailscale로 집 밖에서 접속하시는 분들에게 계속 이어지는 관리 포인트입니다.
- **`fix(codex): refresh stale isolated Computer Use bundles` (#126080)** + **`fix(codex): Computer Use fails when Desktop bundles a newer app-server` (#125883)** — **Codex Computer Use**가 데스크톱 앱의 최신 app-server와 꼬여서 죽던 문제를 번들 갱신으로 해결.
- **`fix: move raw call transcripts from system to user prompt to protect provenance` (#123846)** — 원시 호출 트랜스크립트를 시스템 프롬프트에서 **유저 프롬프트로 이동해 출처(provenance) 보호**.
- **`fix: large base64 attachments on /v1/responses crash the gateway with heap OOM` (#126017)** — **대형 base64 첨부로 게이트웨이가 힙 OOM으로 죽던** 문제 수정.
- **`fix(state): migrate exact v14 session schema` (#126354)** — 세션 스키마 v14 정확 마이그레이션. **`fix(cli): CLI commands crash on multi-agent rosters without --agent` (#126418)** — 멀티 에이전트 환경에서 `--agent` 없이 CLI 명령을 내리면 죽던 크래시 수정.

## 5. 마무리 — 정식판 기다리는 분들을 위한 사용 팁 3가지

정리하면, 오늘(8/20)의 키워드는 **"'8/18(화) 출시' 약속은 미뤄졌지만, 확정 기능 7종 + 24시간 247개 커밋으로 분명 '완성 직전'이다"**입니다. 정식판이 안 나온 건 솔직히 아쉽지만, **베타.2 릴리스 노트에 확정된 기능 목록이 이렇게 구체적으로 공개된 건 처음**이라, "이제 정말 머지않았다"는 확신은 생깁니다.

**기다리는 동안 쓸만한 팁 3가지:**

1. **지금 당장 안정적으로 쓰고 싶다면** — `openclaw update --channel extended-stable`로 **2026.6.34(extended-stable)**를 유지하세요. 정식판 검증이 끝날 때까지 가장 보수적인 트랙입니다.
2. **정식판 출시 알림 받기** — npm 폴링 크론을 걸어두면 됩니다. 저는 아래 명령을 30분 간격 크론으로 돌려서, 값이 바뀌면 알림이 오게 해뒀습니다.
   ```bash
   npm view openclaw dist-tags.latest
   ```
3. **정식판 업그레이드 체크리스트** — 나오면 이 순서로 확인해보세요: ① `openclaw backup sqlite create`로 **백업부터**(이번에 추가된 신기능), ② Tailscale 쓰시는 분은 **특권 라우트 충돌이 없는지**(#126449), ③ 크론잡 쓰시는 분은 **실패 알림 임계값이 동작하는지**(#126483) 테스트.
