## AI 에이전트를 업무에 붙여 쓰는 분들이라면, 이번 릴리스는 그냥 지나치기 아깝습니다

요즘 AI 에이전트를 단순 채팅용이 아니라 **업무 자동화 파이프라인**에 얹어서 돌리는 분들이 꽤 많아졌습니다. 메신저로 일을 시키고, 스케줄러로 정해진 시간에 알아서 돌게 하고, 스킬을 붙여서 반복 작업을 줄이는 식이죠. 그 중심에 있는 오픈소스 프로젝트가 바로 **오픈클로(OpenClaw)** 입니다.

그런데 오픈클로는 릴리스가 워낙 자주 나와서, 어느 업데이트를 봐야 하는지 헷갈릴 때가 많습니다. 저도 자동화 파이프라인을 운영하면서 버전 노트를 매번 챙겨 보는 편인데, 이번 **v2026.9.7**은 포인트 릴리스치고 알맹이가 꽤 있습니다. 단순 버그픽스가 아니라 **새로운 에이전트 런타임과 로그인 방식**이 들어왔기 때문입니다.

이 글에서는 2026년 9월 30일 배포된 v2026.9.7에서 실제로 무엇이 바뀌었는지, 그리고 에이전트를 업무에 쓰는 입장에서 이게 왜 중요한지를 솔직하게 정리해 보겠습니다.

## 한눈에 보는 v2026.9.7 핵심 변경

공식 릴리스 노트와 커밋 로그를 기준으로, 이번 버전의 굵직한 변화는 다음 네 가지입니다.

| 구분 | 내용 | 실질 영향 |
|:----|:----|:----|
| 🆕 오픈AI Agents API | 호스팅/셀프호스팅 워크스페이스에서 채팅 실행하는 새 런타임 추가 | 에이전트 실행 환경 선택지 확대 |
| 🔐 Sign in with ChatGPT (Beta) | ChatGPT 구독 계정으로 연결하는 로그인 추가 | 인증·과금 경로 추가 |
| 🛡️ 업데이트 백업·롤백 보호 | 이전 패키지·설정 보존, 자동 롤백 | 업데이트 사고 위험 감소 |
| ⚡ 성능·안정화 | 부하 시 응답 개선, 긴 대화·긴 표 안정화 | 실사용 체감 품질 향상 |

릴리스 규모 자체도 작지 않습니다. 이번 버전은 **2,818개 풀 리퀘스트**, 518개 직접 커밋, 약 340여 명의 컨트리뷰터가 참여했습니다.

## 1) 오픈AI Agents API — 이제 '호스팅 워크스페이스'에서도 돌린다

이번 업데이트에서 가장 눈에 띄는 건 **오픈AI Agents API 런타임**의 공식 지원입니다. 쉽게 말하면, 오픈클로의 에이전트 대화를 **오픈AI가 관리하는 호스팅 리눅스 워크스페이스**에서 실행할 수 있게 됐습니다.

공식 문서를 보면 이 런타임은 다음을 지원합니다.

- **지속형(persistent) 호스팅 워크스페이스**에서 에이전트 대화 실행
- **실시간 웹 검색**, OpenClaw 자체 도구, 파일 전송(지원되는 리눅스 스토리지 한정)
- 세션 간 **도구 이력 보존**, 페르소나·워크스페이스 컨텍스트 전달
- 토큰 사용량 집계

즉, 내 컴퓨터에서 다 돌리는 게 부담스럽거나, 오픈AI 쪽 인프라를 활용해 에이전트를 굴리고 싶은 경우 선택지가 하나 늘어난 셈입니다.

여기서 중요한 조건이 있습니다. **오픈AI API 키가 필수**이고, 이 런타임의 사용량은 **ChatGPT·Codex 구독과 별도로 과금**됩니다. 헷갈리기 쉬운 부분이라 문서에서도 따로 강조하고 있습니다.

셀프호스팅 실행도 가능하지만, 이 경우 **직접 컨트롤러와 일치하는 워크스페이스 경로**가 필요하고 파일 전송은 지원되지 않습니다. 제출 데드라인은 60초로 공유된다는 점도 알아두면 좋습니다.

## 2) Sign in with ChatGPT (Beta) — 구독으로 연결하는 새 경로

두 번째는 **Sign in with ChatGPT (Beta)** 입니다. 이름 그대로, ChatGPT 계정으로 로그인해 에이전트를 연결하는 방식입니다.

다만 베타인 만큼 **한계가 명확**합니다. 공식 문서 기준으로,

- **등록과 토큰 공유 동의**가 필요합니다.
- **모든 모델·미디어 도구를 커버하지 않습니다.**
- 오픈클로가 **할당량(쿼터)을 표시하거나 앱별 한도를 설정할 수 없습니다.**
- 자동 컨텍스트 압축은 네이티브 Codex에서만 동작하고, **수동 압축·원격 실행은 미지원**입니다.

즉 "ChatGPT 구독이 있으니 API 키 없이도 되겠네"라고 기대했다면, 아직은 **지원 범위가 제한적**이라는 점을 감안해야 합니다. 인증 화면에서 Codex 로그인, ChatGPT 로그인, API 키가 각각 구분되어 안내되니, 어떤 자격증명이 필요한지는 공식 인증 비교 문서를 보고 고르는 게 안전합니다.

## 3) 업데이트 백업·롤백 보호 — 지난 사고의 보완

이번 버전에서 실무적으로 반가운 부분은 **업데이트 복구와 롤백 보호**입니다. 최근 몇 차례 업데이트 과정에서 macOS 앱이 실행 직후 크래시하거나, 특정 버전에서 업데이트 롤백이 필요했던 이슈가 있었는데, 2026.9.7은 **이전 패키지와 설정을 보존하고 자동 롤백**하는 안전장치를 강화했습니다.

특히 **2026.9.5에서 올라오는 경로의 업그레이드 버그**도 함께 수정됐습니다. 여러 대의 머신에서 에이전트를 굴리는 분들이라면, 이 안전장치 하나만으로도 업데이트 리스크가 꽤 줄어듭니다.

## 4) 성능·모델·미디어 확장

체감 영역도 챙겼습니다.

- **성능**: 부하가 걸린 상황에서 더 빠르게 반응하고, 긴 대화가 매끄러워졌습니다. 터미널·맥·아이폰·아이패드의 채팅 경험도 개선됐습니다.
- **모델**: **Claude Opus 5.5**가 추가됐고, GPT-6 Sol·Luna를 구독 계정에서도 찾을 수 있도록 검색 로직이 보완됐습니다. (모델만 고르는 것으로는 런타임이 바뀌지 않으니, 런타임 설정에서 명시적으로 선택해야 합니다.)
- **비디오 생성**: **Kie AI, Z.AI, Novita** 프로바이더가 추가됐습니다. Kie는 기본 활성화지만 API 키가 필요하고, Z.AI 비디오는 Coding Plan과 무관하게 일반 API 과금이 적용됩니다. 참조 영상은 지원하지 않습니다.

## 솔직한 장점과 단점

### 👍 장점

- **실행 환경 선택지 확대**: 로컬·셀프호스팅·오픈AI 호스팅 워크스페이스까지, 상황에 맞게 고를 수 있습니다.
- **업데이트 안전성 강화**: 백업·자동 롤백으로 이전의 크래시·롤백 이슈 재발 위험이 줄었습니다.
- **꾸준한 모델·도구 확장**: 최신 모델과 미디어 프로바이더가 빠르게 편입됩니다.
- **오픈소스·MIT 유지**: 벤더 종속 없이 그대로 굴릴 수 있다는 원칙은 여전합니다.

### 👎 단점·주의점

- **Agents API는 별도 과금**: ChatGPT·Codex 구독과 무관하게 API 사용량이 청구됩니다. 비용 계획을 따로 세워야 합니다.
- **ChatGPT 로그인은 아직 베타**: 쿼터 표시·앱별 한도·일부 모델/미디어 도구가 빠져 있어, "완전한 대체"로 보긴 어렵습니다.
- **셀프호스팅 제약**: 외부 컨트롤러가 필요하고 파일 전송이 안 됩니다.
- **포인트 릴리스의 한계**: 결국 9.x 라인의 점진적 개선이라, 판을 뒤집는 메이저 변화를 기대하면 실망할 수 있습니다.

## 업데이트 팁과 추천 대상

업데이트는 평소처럼 다음 명령으로 진행하면 됩니다.

```bash
openclaw update
```

이번 버전은 **롤백 보호**가 들어갔으니, 이전보다 부담 없이 올려볼 수 있습니다. 다만 오픈AI Agents API를 쓰려면 **API 키 발급과 과금 구조**를 먼저 확인해 두는 게 좋고, ChatGPT 로그인(Beta)은 지원 범위를 문서로 확인한 뒤 붙이는 걸 권합니다.

정리하면, 이런 분들께 특히 추천합니다.

- **오픈AI API·ChatGPT 구독을 이미 쓰고 있는 분들**: 인증·실행 경로가 넓어집니다.
- **여러 머신에서 에이전트를 굴리는 분들**: 롤백 보호가 실질적인 안전판이 됩니다.
- **최신 모델(Claude Opus 5.5 등)을 빨리 붙여 쓰고 싶은 분들**
- **업무 자동화 파이프라인을 안정적으로 운영하려는 분들**

가성비 좋은(=공짜로 강력한) 오픈소스 에이전트를 찾는 분이라면, 이번 v2026.9.7은 한 번 올려볼 만한 업데이트입니다. 다만 "새 기능"보다 "안정성"에 방점이 찍힌 릴리스라는 점은 미리 알고 접근하시면 좋겠습니다.
