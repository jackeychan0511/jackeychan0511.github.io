## 1️⃣ v0.19.1 패치 릴리즈 (7월 30일) — 약 1,000개 이상 PR 반영

7월 30일, Hermes Agent **v0.19.1 (v2026.7.30)** 이 공개됐습니다. 이름은 패치 릴리즈지만, 규모가 결코 패치 수준이 아닙니다.

### 릴리즈 규모

| 항목 | 수치 |
|:----|:----|
| 🔀 머지된 PR | **약 1,000개 이상** |
| 📝 커밋 수 | 약 2,789개 |
| 📁 변경 파일 | 약 4,748개 |
| ➕ 추가/삭제 라인 | 약 44만 줄 추가 / 39만 줄 삭제 |

숫자만 봐도 "이게 패치라고?" 싶죠. 릴리즈 노트에 따르면 이번 버전의 목적은 **v0.19.0 이후 쌓인 수많은 변경을 하나의 안정적인 태그로 묶는 것**입니다. 특히 Docker 이미지, 호스팅 배포, 새로 설치하는 사용자들이 안정 버전을 바로 받을 수 있게 하려는 의도가 큽니다.

### 이번에 고쳐진 영역

공식 릴리즈 노트와 릴리즈 요약을 종합하면, 이번 패치 웨이브는 다음 4개 영역에 집중됐습니다.

- **게이트웨이(Gateway)**: 텔레그램·디스코드 등 메시징 연동의 버그 수정
- **음성(Voice) 서브시스템**: 음성 인터페이스 안정성 개선
- **데스크톱 앱**: 네이티브 앱 버그 수정
- **인스톨러**: 설치 프로그램 문제 수정

솔직히 7월 초에 게이트웨이에서 메시지가 늦게 오거나 음성이 가끔 끊기는 문제를 겪었던 분들이라면, 이번 업데이트에서 바로 체감이 될 만한 영역입니다.

### 업데이트 방법 (2분이면 끝)

```bash
# 최신 버전으로 업데이트
hermes update

# 설치 상태 진단 (문제가 있을 때)
hermes doctor
```

이미 Hermes를 쓰고 계신 분은 `hermes update` 한 줄이면 끝입니다. Docker로 쓰시는 분은 `nousresearch/hermes-agent:v2026.7.30` 태그를 받으면 되고요.

## 2️⃣ 펫 마스코트 기능 — 에이전트가 이제 "반려동물"을 키웁니다

이번에 가장 재미있게 본 기능입니다. Hermes가 이제 **애니메이션 펫 마스코트**를 보여줄 수 있어요. CLI, TUI, 데스크톱 앱 어디서든 에이전트 옆에서 캐릭터가 살아 움직입니다.

![Hermes 펫 스프라이트 시트](/assets/images/posts/hermes-agent-v0191-2026/hermes-pet-sprite.png)
*공식 저장소에 포함된 Hermes 펫 스프라이트 — 상태별 애니메이션이 시트로 구성됨 (출처: 공식 GitHub 저장소)*

### 펫이 "일하는 모습"을 보여줍니다

펫은 단순한 장식이 아니라, **에이전트가 지금 뭘 하고 있는지** 상태에 따라 반응합니다. 공식 문서 기준 상태 매핑은 이렇습니다.

| 에이전트 활동 | 펫 상태 |
|:----|:----|
| 도구 실행 중 | 🏃 `run` |
| 모델이 생각/읽는 중 | 🤔 `review` |
| 작업 완료(계획 전체 완료) | 🎉 `jump` (축하) |
| 턴 정상 종료 | 👋 `wave` |
| 작업 실패 | 💥 `failed` |
| 승인 대기(사용자 차단) | ⏳ `waiting` |
| 아무것도 안 함 | 😴 `idle` |

![Hermes 펫 애니메이션 프레임](/assets/images/posts/hermes-agent-v0191-2026/hermes-pet-frame.png)
*펫 애니메이션 프레임 예시 — 작업 성공 시 점프하며 축하하는 모션 (출처: 공식 GitHub 저장소)*

### 왜 유용한가?

솔직히 처음엔 "그냥 꾸미기 기능 아니야?"라고 생각했는데, 막상 써보니 생각보다 실용적입니다. 터미널에서 긴 작업을 돌려놓고 다른 일을 하다가 화면만 슬쩍 봐도 **"지금 실패했는지, 아직 생각 중인지, 끝났는지"** 한눈에 들어오거든요. 텍스트 로그를 일일이 훑을 필요가 없어요.

### 주의할 점 (이건 꼭 알아두세요)

- **기본적으로 꺼져 있습니다.** 설치하고 바로 보이는 게 아니라, 펫을 설치·선택해야 활성화돼요.
- **100% 꾸미기용입니다.** 공식 문서에 "프롬프트 캐싱, 토큰, 에이전트 동작에 전혀 영향 없음"이라고 명시돼 있습니다. 성능 걱정은 안 하셔도 됩니다.
- 터미널에서 **kitty, Ghostty, WezTerm, iTerm2, sixel** 같은 그래픽 프로토콜을 지원하면 풀해상도로, 아니면 유니코드 반블록으로 자동 렌더링됩니다. 파이프(파일 출력)로 쓰면 터미널 렌더링은 꺼지니 참고하세요.

### 펫 설치 & 선택 명령어

```bash
# 갤러리 둘러보기 (이름 검색 가능)
hermes pets list
hermes pets list cat

# 펫 설치 + 바로 활성화 (원스텝)
hermes pets install boba --select

# 미리보기 / 애니메이션 확인 (Ctrl+C로 종료)
hermes pets show

# 크기 조절 / 끄기
hermes pets scale 0.5
hermes pets off
```

*Petdex — Hermes 공식 문서가 참조하는 공개 펫 갤러리 (출처: crafter-station/petdex 공식 저장소)*

펫은 공개 갤러리 **Petdex**에서 가져옵니다. 커뮤니티에서 만든 3,200종 이상의 캐릭터가 등록되어 있어서, 취향에 맞는 걸 골라 설치하면 됩니다. 프로필별로 각자 다른 펫을 키울 수 있어요.

## 3️⃣ 솔직한 장단점 정리

7월 한 달간 Hermes를 쓰면서 느낀 점을 정리하면 이렇습니다.

**👍 좋은 점**
- 업데이트 주기가 짧고(월 2회 이상) 방향성이 명확함 — 속도 → 안정성 → 재미 순으로 단계를 밟는 느낌
- 펫 기능이 단순 장식이 아니라 **작업 상태 확인 UX**로 이어짐
- `hermes update` 한 줄이면 패치 반영 끝. Docker 태그도 즉시 배포
- MIT 라이선스, 완전 무료

**👎 아쉬운 점**
- v0.19.1이 "패치" 이름표를 달고 있어서 **변경점을 놓치기 쉬움** — 릴리즈 노트를 직접 봐야 규모를 압니다
- 펫은 기본 꺼짐 + 터미널 그래픽 프로토콜 지원 여부에 따라 체감이 크게 갈림
- 게이트웨이/음성 쪽은 이번 패치로 많이 나아졌지만, 완전 무결점이라고 말하긴 이릅니다
