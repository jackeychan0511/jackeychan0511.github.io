- **v0.21.0 '판테온'이 뭔지** — 8/31 정식 출시, v0.20.0 이후 5,800커밋·2,475개 PR이 모여 만든 대형 릴리스의 전체 그림

- **보안 강화** — AGENTS.md·스킬·메모리 파일은 이제 무조건 승인 후에만 수정 가능

## 도입: "어제 '대기열'만 확인했는데, 오늘 아침에 정식 출시가 떴네요"

요즘 저처럼 **오픈소스 AI 에이전트를 매일 갈아타며 테스트**하시는 분들 많으시죠? 저도 지난주 내내 Hermes Agent v0.21.0 출시를 기다리고 있었습니다. 어제(8/31) 아침에는 "출시 대기열에 286개 PR이 쌓였다"는 걸 실측해서 포스팅했는데, 그날 밤 19:29 UTC(한국시간 9/1 새벽 4시 29분)에 **드디어 v0.21.0 '판테온(The Pantheon)'이 정식 출시**됐습니다. 말 그대로 하루 만에 '대기열'에서 '정식 출시'로 넘어간 거죠.

솔직히 이번 릴리스는 규모부터가 다릅니다. **v0.20.0 이후 약 5,800커밋, 머지된 PR 2,475개, 참여 기여자 760명 이상, 닫힌 이슈 2,100개** — Nous Research가 "판테온(신들의 회의)"이라고 이름 붙인 이유를 실측 데이터가 그대로 말해줍니다. 오늘은 공식 릴리스 노트와 공식 문서, GitHub API 실측을 바탕으로 **뭐가 새로워졌고, 실제로 어떻게 쓰면 좋은지**를 정리해 드릴게요.

## Hermes Agent v0.21.0 판테온 — 핵심 변경 9가지

### ① 봇 모드(Bot Mode), 이제 데스크톱에 '기본 내장'

8월 중순 Teknium(Nous Research 공동창업자)이 스크린샷 하나로 공개해 하루 만에 공개 베타로 간 그 기능, 이제 **데스크톱 앱에 기본(default-on)으로 번들**됐습니다. 핵심은 세 가지예요.

- **이름·직책·아바타를 가진 봇 로스터** — 세션 목록 대신 'AI 직원 명단'이 뜹니다. 아바타는 결정론적으로 생성되며 랜덤/고정 컨트롤도 가능.
- **디스코드식 그룹챗** — 여러 봇과 내가 한 방에 모여 대화하고, 컴포저에서 아무 봇이나 `@멘션`으로 호출. 방 이름과 방 사진도 지정 가능.
- **채팅 앱 같은 멀티에이전트** — 예전에는 "멀티 에이전트 = 플러밍(배관 작업)"이었다면, 이제는 **직장 동료들이 모여 있는 채팅 앱**처럼 보입니다.

제가 어제까지 써본 느낌으로는, **봇 3명(리서치·코딩·브리핑)을 만들어두고 그룹챗에서 회의시키는** 용도가 제일 실용적이었어요. 2~6명 봇이 최대 3라운드까지 토론하는 구조라, 아이디어 검증용으로 딱입니다.

*Hermes Agent 데스크톱 앱의 태스크·자동화 기능 이미지 — 봇 모드와 루틴(Routines) 패널이 기본 내장됐다 (출처: hermes-agent.nousresearch.com 공식 홈페이지)*

### ② `hermes peer` — 봇끼리 DM을 주고받는다

이번 릴리스에서 제가 제일 눈여겨본 기능입니다. **어떤 Hermes 에이전트든 다른 에이전트에게 핸들(handle)로 메시지를 보낼 수 있게** 됐어요.

- CLI에서도, 대화 중에도 **프로필과 게이트웨이를 넘나들며** 다른 봇에게 메시지 전송 가능
- 예: 리서치 봇이 찾은 결과를 코딩 봇에게 넘기고, 그 답변을 다시 내가 읽을 수 있는 곳에서 수신
- 답장은 각 에이전트의 **'봇 채팅(Bot Chat)'에 영구히 쌓여서** — 불발(fire-and-forget)이 아니라 나중에 다시 열어볼 수 있는 구조

저처럼 "리서치 봇이 자료 찾으면 코딩 봇이 바로 구현 시작" 같은 **업무 핸드오프 자동화**를 원하시는 분께 특히 추천합니다.

### ③ 크론잡이 '금붕어'를 그만뒀다 — 영구 메모리 + 연속성

지난 포스팅에서 크론잡으로 매일 아침 자동출근(브리핑)을 시키는 법을 다뤘는데요, v0.21.0부터 **스케줄 잡이 기억을 갖습니다.**

- 크론 에이전트도 다른 에이전트처럼 **영구 메모리를 로드·업데이트**
- `continuity=true` — **이전 실행 결과를 다음 실행에 전달**해서 "어제 이미 보고한 건 중복 보고하지 않기" 같은 디듀프(중복 제거)가 가능
- 잡마다 **듀러블 노트패드(스크래치패드)** 지급
- **모니터 모드 잡**은 변화가 없으면 LLM 호출을 아예 생략 — 비용 절감
- 크론 출력을 특정 봇의 채팅에 넣으면 **봇이 그 결과에 실제로 응답**까지 함

제 9시 브리핑 잡이 '어제 뭐라고 말했는지'를 기억하기 시작한 게 체감상 가장 큰 변화입니다. **"매일 아침 같은 리포트를 또 보내는" 문제가 구조적으로 해결**됐어요.

### ④ 실행 중인 서브에이전트를 실시간으로 조종

`delegate_task`가 '던져두고 기다리기'에서 **관리되는 병렬 작업**으로 진화했습니다.

- 실행 중인 자식 에이전트 목록 조회
- **중간에 방향 수정(코스 코렉션)** 주입
- **조기 종료 + 부분 결과 보존** — 다 끝나기 전에 멈춰도 지금까지 한 건 챙겨줌
- 자식 출력에 **JSON 스키마 검증** 옵션
- 위임별 비용을 결과에 표시
- 기본값 상향: **반복 250회, 동시 자식 10개**

이건 "병렬로 10개 조사 돌려놓고 하나는 중간에 방향 틀기" 같은 실제 업무 패턴이 가능해졌다는 뜻이라, 작업량이 많은 분께 체감이 클 겁니다.

### ⑤ MCP 커맨드 센터

MCP 서버 목록과 카탈로그가 **하나의 데스크톱 페이지**로 통합됐습니다.

- 드래그&드롭 '붙여넣기만 하면' 임포트
- **백그라운드 헬스 체크** — 툴 호출이 실패하기 전에 재인증을 미리 알림
- 서버별 **스키마 토큰 추정치·30일 사용량** 오버레이
- `hermes://` 딥링크로 **확인 후 MCP 서버 설치**

"20개 MCP 서버 관리가 설정 파일 발굴 작업이었다면, 이제 대시보드"라는 릴리스 노트의 표현이 정확합니다.

### ⑥ CLI 파워 웨이브 — Ctrl+P 팔레트부터 터미널 펫까지

터미널 유저를 위한 개선도 잔뜩 들어갔습니다.

- **Ctrl+P 퍼지 커맨드 팔레트**
- `/model` 선택기가 **타이핑하며 필터링**
- `/status`에 추론 모드·대기 승인·컨텍스트 사용량 표시
- 상태바에 **캐시 히트율·레이턴시·tokens/sec** 실시간 표시(필드별 토글)
- **글로벌 이머전시 스톱**
- 세션 핀/언핀
- 그리고… Ghostty 수준의 **터미널 펫(terminal pets)** — "동반자가 동반자를 가져야지"라는 Nous 센스

### ⑦ 에이전트가 데스크톱 브라우저를 '직접' 조작

인앱 브라우저가 "에이전트가 바라만 보는 창"에서 **에이전트가 직접 내비게이션·클릭·읽기까지 하는 도구**로 바뀌었습니다. 페이지를 시스템 브라우저로 팝아웃하고 전체 링크 컨텍스트 메뉴도 쓸 수 있어요. **"문서 사이트를 돌아다니며 정리해줘" 같은 작업을 내 앱 안에서 지켜보는** 게 가능해졌습니다.

### ⑧ 신규 프로바이더 6종 + 모델 카탈로그 대거 추가

- **신규 프로바이더**: Meta Model API(Muse Spark), CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router, Actual Computer
- **모델 카탈로그**: GLM-5.3-Flash, qwen3.8-max/flash, Gemini 3.7 Flash, MiniMax M3(무료 SKU), Nemotron 3.5 Lightning, Meta Muse Spark 1.2 등
- **`model_overrides`** — 컨텍스트 윈도우·가격을 **릴리스 기다리지 않고 내가 직접 패치** 가능
- **데이터 학습 경고** — 모델 선택 화면마다 "이 모델은 내 데이터로 학습한다"는 경고를 통합 표시

### ⑨ 보안 강화 — "에이전트가 자기 지침서를 몰래 고치지 못하게"

- **보호 대상 지시 파일**(AGENTS.md, 스킬, 메모리 저장소)에 대한 쓰기는 **항상 승인 필수** — 프롬프트 인젝션으로 에이전트가 자기 상시 지시를 몰래 바꾸는 걸 차단
- 시크릿 **레드액션(redaction) 전면 정비** — 터미널 에러·.env 읽기·체크포인트·ACP 로그 등에서 유출 경로 폐쇄
- Windows 파괴적 명령어도 승인 시스템 적용
- **macOS 권한(TCC)이 업데이트 후에도 유지** — `hermes desktop --setup-tcc-identity`로 서명 정체성 고정

## 실제 사용감 — 솔직한 장단점

지금 이 블로그의 크론잡 포스팅 자체가 Hermes Agent로 돌아가고 있는 입장에서, v0.21.0을 실사용하며 느낀 점을 솔직히 정리하면:

**👍 좋은 점**
- **봇 모드가 '베타 체험'에서 '일상 도구'가 됐다** — 번들 기본 내장이라 설치·플러그인 관리 부담이 사라졌고, 그룹챗 UI가 실제로 안정적입니다.
- **크론잡 메모리·연속성이 '자동포스팅 파이프라인'에 완벽** — 매일 같은 주제를 중복 보도하지 않게 하는 디듀프가 이제 구조적으로 됩니다.
- **릴리스 속도가 무섭다** — 8/13 스크린샷 공개 → 8/17 베타 → 8/31 정식 기본 내장까지 18일. v0.20.0 이후 2,475개 PR이 한 번에 문서화된 것도 관리 측면에서 훌륭합니다.

**🤔 아쉬운 점 (솔직히)**
- **760+ 기여자·2,475개 PR을 한 릴리스로 묶다 보니** 패치 태그(v0.20.1~v0.20.6) 내용까지 포함해 분량이 방대합니다. '무엇부터 써야 할지' 처음엔 약간 막막할 수 있어요 — 저는 위 9가지부터 시작하길 권합니다.
- 봇 그룹챗은 봇 수가 많아질수록 **토큰 사용량이 눈에 띄게 늘어**서, 방마다 모델을 다르게(가벼운 건 무료 MiniMax M3 등) 지정하는 걸 추천합니다.

## 이런 분께 추천합니다

- **AI 직원 여러 명을 '채팅 앱'처럼 관리**하고 싶은 분 — 봇 모드 기본 내장
- **봇끼리 업무를 자동으로 넘기는** 파이프라인을 짜는 분 — `hermes peer`
- **매일 반복 업무(브리핑·모니터링)를 중복 없이** 자동화하려는 분 — 기억하는 크론잡
- **병렬 리서치를 중간에 컨트롤**하고 싶은 분 — delegate_task 라이브 오케스트레이션
- **MCP 서버를 여러 개 굴리는** 개발자 — MCP 커맨드 센터

## 업데이트 방법 — 1분이면 끝

```bash
# 최신 버전으로 업데이트 (v0.21.0 판테온)
hermes update

# 혹시 문제가 생기면 진단
hermes doctor
```

데스크톱 앱을 쓰신다면 앱을 재시작하면 업데이트가 적용되고, 이제 **모든 OS에서 '종료 → 업데이트 → 재시작'이 자동**으로 처리됩니다(대기 화면에 멈춰 있던 Windows 업데이트 문제도 수정).

## 마무리

솔직히 이번 v0.21.0은 **"멀티에이전트가 데모가 아니라 일상이 되는"** 터닝포인트라고 생각합니다. 봇 모드 기본 내장과 `hermes peer`, 기억하는 크론잡까지 — 세 기능이 합쳐지면 **"AI 팀장 + AI 직원 3명 + 자동출근"** 구성이 실제로 굴러갑니다.

참고로 이 프로젝트는 **MIT 라이선스 무료 오픈소스**이고, 오늘(9/1) 기준 GitHub 실측 **스타 238,983개·포크 48,745개**입니다. 지난주에는 Nous Research가 **약 15억 달러(한화 약 2조 원) 밸류에이션에 투자 유치 중**이라는 보도(Hypebeast KR)도 나왔죠. 오픈소스 AI 에이전트 생태계의 최전선을 무료로 써볼 수 있는, 가성비 좋은 선택지입니다.

**"AI 에이전트를 회사처럼 운영해보고 싶다"** 하시는 분들께 Hermes Agent v0.21.0 판테온 업데이트 추천합니다.
