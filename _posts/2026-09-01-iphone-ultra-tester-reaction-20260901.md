> **📌 한줄 요약:** 애플 첫 폴더블 **'아이폰 울트라'**가 9월 10일(한국시간) 새벽 2시 공개를 앞두고, 블룸버그 **마크 구루먼**이 전한 **실사용 테스터들의 첫인상**이 IT 업계 최대 화제입니다. 테스터들은 **디자인·힌지·휴대성·소프트웨어는 극찬**하면서도 **① 망원 카메라 부재 ② Face ID 대신 터치 ID** 두 가지를 아쉬워했습니다. 예상 스펙은 **내부 7.8인치 + 외부 5.5인치, A20 프로, 5,500mAh 이상 배터리, 48MP 듀얼 카메라, 펼치면 4.5mm 초박형**, 가격은 **2,000달러(약 277만 원)~2,500달러(약 346만 원)** 수준입니다. 한국은 **1차 출시국 포함** 보도가 나왔고, 사전예약은 9월 11~12일, 출시는 9월 18일 전후로 예상됩니다.

## 이 글을 읽으면 알 수 있는 것

- **'실제로 만져본 사람들'의 첫인상** — 구루먼이 취재한 테스터들은 뭐라고 했는지 (극찬 4가지 vs 아쉬움 2가지)
- **아이폰 울트라에서 빠지는 기능 3가지** — 망원 카메라·Face ID·그리고 생각보다 중요한 나머지 하나
- **예상 스펙 총정리** — 7.8인치 내부 화면·A20 프로·배터리·두께를 한눈에 보는 표

## 도입: "어제 이벤트 소식을 정리했더니, 오늘 아침엔 '만져본 사람들'의 반응이 쏟아졌네요"

요즘 저처럼 **애플 첫 폴더블 아이폰**을 손꼽아 기다리시는 분들 많으시죠? 어제(8/31) 저는 9월 9일 'Surprise and shine' 행사 확정 소식을 정리해서 포스팅했는데요, 그런데 오늘 아침 다시 확인해 보니 **화제의 중심이 '이벤트 발표'에서 '실사용 테스터들의 반응'으로 옮겨가 있더라고요.**

블룸버그의 애플 전문 기자 **마크 구루먼(Mark Gurman)**이 주말 동안 **실제로 아이폰 울트라를 만져본 사람들과 인터뷰**한 내용을 전했는데, 솔직히 요약만 들어도 심장이 뛰었습니다. *"이 기기를 본 뒤 더 이상 설레지 않을 수 없었다(I couldn't be more excited)"* — 구루먼이 이렇게까지 말하는 건 흔치 않은 일이라서요.

다만 테스터들의 반응이 **100% 호평만은 아니었습니다.** '힌지는 합격, 카메라는 글쎄'라는 평가가 지배적이었는데요. 오늘은 **테스터들이 실제로 뭐라고 했는지**, **어떤 기능이 빠지는지**, 그리고 **277만 원짜리 첫 폴더블을 사기 전에 알아야 할 것**까지 솔직하게 정리해 드릴게요.

## ① 구루먼이 전한 테스터 첫인상 — "휴대성은 굿, 카메라는 아쉽다"

구루먼의 보도(블룸버그, 주말 발행)를 종합하면, **아이폰 울트라를 미리 만져본 테스터들의 평가는 '압도적 호평 + 딱 두 가지 아쉬움'**으로 정리됩니다.

### 테스터들이 극찬한 4가지

| 항목 | 테스터 평가 |
|:-----|:-----------|
| **디자인·완성도** | 책처럼 펼치는 북타입 폴딩, 접었을 때 5.5인치로 **일반 아이폰과 비슷한 그립감** |
| **힌지** | "튼튼하다" — 폴더블의 최대 걱정인 힌지 내구성에 대한 우려를 대부분 해소 |
| **휴대성** | 접으면 주머니에 쏙, 펼치면 태블릿. **'주머니 속 태블릿'**이라는 컨셉에 높은 점수 |
| **소프트웨어** | 내부 대화면에서 **아이패드형 앱 레이아웃**이 자연스럽게 동작, 카메라 **뷰파인더로는 '최고'**라는 평가까지 |

특히 인사이트(8/25)는 **"휴대성은 굿, 카메라는 아쉽다"**고 요약했고, 뉴시스(8/27)는 **"7년 늦게 폴더블폰에 뛰어드는 애플"**이라며 삼성 갤럭시 Z 폴드8 흥행 돌풍과의 정면승부를 짚었습니다.

### 테스터들이 아쉬워한 2가지

1. **망원 카메라가 없다** — 후면 카메라는 48MP 광각 + 48MP 초광각 **듀얼 구성**입니다. 2,000달러(약 277만 원)가 넘는 역대 최고가 제품에서 **줌(망원) 카메라가 빠진다**는 건 외신들도 '명백한 약점(glaring weakness)'이라고 지적했습니다.
2. **Face ID가 사라지고 터치 ID가 부활한다** — 초박형(펼쳤을 때 4.5mm) 설계와 디스플레이 2개 구조 때문에 Face ID 부품을 두 벌 넣기 어려워, **전원 버튼 통합 터치 ID**로 돌아갈 가능성이 유력합니다. 9to5Mac은 "초슬림 설계 때문"이라고 분석했죠.

## ② 아이폰 울트라 예상 스펙 총정리

지금까지 유출된 정보를 모아 보면 이렇습니다. **아직 공식 발표 전이므로 '예상'임을 꼭 감안**해 주세요.

| 항목 | 예상 스펙 |
|:-----|:----------|
| **디스플레이** | 외부 5.5인치 + 내부 7.6~7.8인치(4:3 비율) OLED, 삼성디스플레이 공급 |
| **칩셋** | 2나노 공정 **A20 프로** (아이폰18 프로와 동일) |
| **배터리** | 5,500~5,800mAh — 아이폰 역사상 최대 용량 |
| **두께** | 접었을 때 약 9~9.5mm / 펼쳤을 때 약 **4.5mm 초박형** |
| **카메라** | 후면 48MP 광각 + 48MP 초광각 (망원 없음), 전면 2개 포함 총 4개 |
| **생체인식** | 전원 버튼 통합 **터치 ID** (Face ID 대체) |
| **프레임** | 티타늄, 개선된 힌지 |
| **가격** | **2,000달러(약 277만 원)~2,500달러(약 346만 원)** — 역대 아이폰 최고가 |
| **출시** | 9월 9일(현지) 공개 → 사전예약 9월 11~12일 → 출시 9월 18일 전후 예상 |

솔직히 **배터리와 두께는 인상적**입니다. 5,500mAh 이상이면 갤럭시 Z 폴드8(5,000mAh)보다 크고, 펼쳤을 때 4.5mm는 **현존 폴더블 중 가장 얇은 수준**이라서요. 대신 그 초박형 설계의 대가로 카메라와 Face ID가 빠진 셈이죠. **'얇음'과 '카메라'는 트레이드오프** 관계라는 걸 기억하시면 좋습니다.

## ③ 솔직한 장단점 — 277만 원짜리 첫 폴더블, 살 만할까?

### 장점 👍

- **iOS 생태계 첫 폴더블** — 아이폰·아이패드·맥을 쓰는 분이라면 '폴더블 하나로 폰+태블릿'을 대체할 유일한 선택지
- **아이패드형 앱 레이아웃** — 내부 화면에서 두 개 앱을 나란히 쓰는 멀티태스킹이 기대 이상이라는 평가
- **초박형 + 대용량 배터리** — 펼치면 4.5mm, 배터리는 5,500mAh 이상
- **힌지·완성도** — 테스터들이 가장 많이 칭찬한 부분. 1세대임에도 '덜 완성된 느낌'이 아니라고

### 단점 👎

- **망원 카메라 없음** — 277만 원짜리인데 줌이 없다? 사진을 즐겨 찍는 분에겐 치명적일 수 있습니다
- **Face ID 대신 터치 ID** — 애플페이·은행앱 등 Face ID 기반 환경에 익숙하신 분은 적응 필요
- **가격** — 2,000달러 이상. 미국 성인 4명 중 3명(75%)이 "구매 의사 없다"는 설문 결과도 나왔습니다
- **1세대 리스크** — 폴더블 힌지·내구성은 아무리 테스트해도 출시 후에야 검증됩니다
- **물량·출하 지연 가능성** — 일부 매체는 양산 일정 문제로 10월 출하 가능성도 언급

솔직한 제 생각은 이렇습니다. **"애플 폴더블을 가장 먼저 경험하고 싶다"는 분에겐 충분히 설레는 제품**이고, 반대로 **"카메라와 가성비를 우선한다면 아이폰18 프로 맥스가 더 합리적"**입니다. 첫 폴더블은 '가성비'보다 '경험'을 사는 제품이라는 점, 미리 인지하시는 걸 추천해요.

## ④ 갤럭시 Z 폴드8과 정면승부 — 2,000달러 동급 대결

삼성은 이미 갤럭시 Z 폴드8·폴드8 울트라로 폴더블 시장을 선점한 상태입니다. 같은 2,000달러(폴드8 울트라 기준) 승부에서 갈리는 선택 기준을 정리하면:

| 비교 항목 | 아이폰 울트라 (예상) | 갤럭시 Z 폴드8 울트라 |
|:----------|:-------------------|:---------------------|
| **내부 화면** | 7.6~7.8인치 | 8인치대 |
| **무게** | 미공개 (초박형 강조) | 약 215g |
| **배터리** | 5,500~5,800mAh (예상) | 5,000mAh |
| **카메라** | 48MP 듀얼 (망원 없음) | 망원 포함 트리플 구성 |
| **생체인식** | 터치 ID (예상) | 화면 내 지문 + 얼굴인식 |
| **생태계** | iOS (폴더블은 최초) | 안드로이드 + AI 기능 |
| **가격** | 2,000달러~ (예상) | 2,000달러~ |

**"손맛은 삼성, 흥행은 애플"**이라는 업계 평가가 나오는 이유가 여기 있습니다. 폴더블의 기본기(힌지·멀티태스킹)는 삼성이 앞서지만, **iOS 유저에게 폴더블은 사실상 '아이폰 울트라 = 유일한 선택지'**라서 수요가 몰릴 수밖에 없다는 거죠.

## ⑤ 구매 팁 — 행사 시청부터 사전예약까지

1. **행사 시청** — 9월 9일(현지) 오전 10시 = **한국시간 9월 10일(목) 새벽 2시**. 애플 공식 사이트·유튜브에서 생중계됩니다. 새벽이 부담되시면 다음 날 요약 포스팅을 기다리셔도 좋아요 (저도 바로 정리하겠습니다 😉).
2. **한국 출시** — 다수의 매체가 **한국 1차 출시국 포함**을 보도했습니다. 다만 폴더블 특성상 미국 선출시 후 국내 출시가 늦어질 수 있다는 신중론도 있으니, 공식 발표를 확인하세요.
3. **사전예약 예상 일정** — 공개 다음 날인 **9월 11~12일 사전예약 → 9월 18일 전후 정식 출시**가 유력합니다. 사전예약 혜택(무료 케이스·액세서리)이 출시 후보다 좋은 편이라 **예약 1~2일차가 유리**합니다.
4. **자급제 vs 통신사** — 아이폰은 자급제+알뜰폰 조합이 장기적으로 저렴한 경우가 많지만, **기기값 할인 + 요금제 결합**을 노리신다면 통신사 공시지원금을 비교해 보세요.
5. **필수 액세서리** — 폴더블은 **힌지 보호 케이스 + 내부 화면 보호필름**이 사실상 필수입니다. 사전예약 혜택에 케이스가 포함되는지 꼭 확인하세요.
