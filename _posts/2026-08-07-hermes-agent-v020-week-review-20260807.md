> **📌 한줄 요약:** 8월 3일 출시된 **Hermes Agent v0.20.0 'The Herald Release'**를 일주일간 실제 업무(이 블로그 자동 포스팅)에 붙여 써본 솔직한 후기입니다. 릴리즈 노트의 화려한 기능(음성·A2A·웹훅)보다 **일상 작업에서 체감되는 변화** — 도구 자가복구, CLI 파워 명령어, 미드턴 리디렉트, 콜드스타트 14초→1.8초 — 가 훨씬 컸습니다. GitHub 스타는 8/7 기준 **226,597개**로 8/4(224,887개) 대비 3일 만에 약 1,700개 늘었습니다.

요즘 저처럼 **AI 에이전트를 실제 업무에 붙여 쓰시는 분들**, 특히 "뉴스만 요약해 주는 챗봇"이 아니라 "검색부터 글 작성, 이미지 삽입, git push까지 끝까지 해주는 에이전트"를 찾으시는 분들 있으시죠.

지난 [8월 4일 글](/2026/08/04/hermes-agent-v020-herald-update/)에서 v0.20.0 'The Herald Release'의 기능을 총정리해 드렸는데요. 오늘은 그 **기능표가 아니라, 일주일간 실제로 써본 후기**를 쓰려고 합니다. 릴리즈 노트에 적힌 "도구 자가복구", "CLI 파워 명령어" 같은 말들이 실사용에서 정말 체감되는지 — 이 블로그를 실제로 돌리는 크론잡 환경에서 직접 확인했거든요. 솔직하게 정리해 봅니다.

## 1. 먼저, 제 사용 환경부터 — "이 블로그가 실험실입니다"

솔직히 말하면 이 블로그 자체가 Hermes Agent의 **실사용 테스트베드**입니다. 매일 정해진 시간에 크론잡(정기 자동 작업)이 실행돼서:

1. 웹에서 최신 뉴스·제품 정보를 검색하고
2. 자료를 모아 글을 작성하고
3. 이미지를 검색·다운로드해 삽입하고
4. git add → commit → push까지 해서 실제로 게시합니다

8월 5일부터 오늘(8/7)까지 **3일 연속 자동 포스팅이 끊김 없이 돌아갔고**, 이 글을 쓰는 지금도 v0.20.0 위에서 이 크론잡이 실행되고 있습니다. "일주일 실사용"이라고 하면 뭔가 거창해 보이지만, 사실은 **밤낮으로 반복 작업을 시키는 가장 지루한(그래서 가장 좋은) 테스트 조건**에서 써본 셈입니다.

## 2. 체감 ① 도구 자가복구 — "에이전트가 삽질을 덜 하게 됐다"

이번 업데이트에서 제가 가장 크게 체감한 부분입니다. 릴리즈 노트 표현을 빌리면 **"도구가 스스로 실패를 복구한다. 모델이 실패를 추측하게 두지 않는다"**인데, 실제로 이런 일들이 벌어집니다.

- **`write_file`이 저장을 검증한다**: 파일을 쓴 뒤 실제로 디스크에 반영됐는지 확인합니다. 예전엔 "저장했다"고 말하고 나중에 파일이 없어서 헤매는 경우가 가끔 있었는데, 이제 그런 일이 원천 차단됩니다.
- **`patch`가 이미 적용된 편집을 감지한다**: 똑같은 수정을 두 번 시도해서 "이미 적용됐다"는 실패를 반복하던 문제가 사라졌습니다. 공백(whitespace)이 안 맞아 실패하면 어디가 다른지 시각적으로 알려줍니다.
- **검색 0건이면 유사어로 재시도한다**: 검색 결과가 없으면 근접한 검색어를 찾아 스스로 다시 시도합니다. 자료 조사가 많은 자동 포스팅에서 이게 은근히 자주 발동됩니다.
- **터미널 출력이 잘리면 전체 내용을 파일로 넘겨준다**: 긴 빌드 로그가 잘려도 에이전트가 파일을 읽어서 이어서 처리합니다.
- **자동화 반복 한도 90 → 500**: 한 작업에서 도구 호출을 90번까지밖에 못 하던 인위적인 벽이 500번으로 늘었습니다. 길게 도는 자동화 작업이 중간에 "한도 초과"로 죽던 문제가 해소됐어요.

이 기능들은 릴리즈 노트에서 한 줄로 지나가는 항목이지만, **자동화를 밤새 돌리는 입장에서는 가장 고마운 변화**입니다. 사람이 개입할 수 없는 크론잡에서는 "에이전트가 스스로 실패를 복구하는 능력"이 곧 가동률이거든요.

## 3. 체감 ② CLI 파워 명령어 — 터미널 유저의 효율이 확 올라갔다

터미널(CLI)을 주로 쓰는 분들을 위한 명령어가 대거 추가됐습니다. 제가 일주일간 실제로 써본 것 중심으로 정리합니다.

| 명령어 | 기능 | 실사용 소감 |
|:----|:----|:----|
| `!명령어` | 모델 턴을 소모하지 않고 **즉시 셸 명령 실행** | "이거 좀 확인만 해줘" 할 때 최고. 토큰도 안 쓰고 바로 실행됩니다 |
| `/init` | 프로젝트를 스캔해 `AGENTS.md` 자동 생성·업데이트 | 새 프로젝트 시작할 때 컨텍스트를 확 줄여줍니다 |
| `/context` | 컨텍스트 창을 뭐가 차지하고 있는지 분석 | 긴 세션에서 "왜 느려지지?"의 답을 바로 보여줍니다 |
| `/diff` | 스테이징/전체/세션 변경분을 어디서든 확인 | 게이트웨이·데스크톱 어디서든 변경분 추적 가능 |
| `/focus` | 출력을 줄인 집중 모드 | 긴 작업 중간에 상황만 훑을 때 유용합니다 |
| Ctrl+S | 작성 중이던 프롬프트를 임시 저장 | "이거 보내기 전에 다른 거 먼저" 할 때 프롬프트가 안 날아갑니다 |

여기에 **`hermes import-agent`** 라는 명령어도 추가됐는데, **Claude Code나 Codex CLI의 기존 설정을 한 번에 Hermes로 옮겨주는** 기능입니다. 다른 에이전트 도구에서 넘어오시는 분들의 진입장벽을 확 낮춰줍니다.

*Hermes Agent TUI(터미널 UI)의 세션 오케스트레이터 화면 — v0.20.0에서 CLI 파워 명령어(!, /init, /context, /diff, /focus)가 대거 추가됐다 (출처: Hermes Agent 공식 GitHub 저장소, 2026-08-07 확인)*

## 4. 체감 ③ 미드턴 리디렉트 — "아니, 그거 말고"를 그 자리에서

에이전트가 작업을 하는 도중에 방향이 잘못됐다고 느껴질 때가 있죠. 예전에는 `/stop`으로 끊고 처음부터 다시 설명해야 했습니다.

v0.20.0부터는 **작업이 진행되는 동안 바로 수정 지시를 넣으면, 진행 중인 작업을 보존한 채 그 자리에서 방향을 바꿔줍니다.** 원래 프롬프트도 유지되고, 이미 한 작업(예: 수집해 둔 자료)도 버려지지 않아요. 게다가 **Esc 두 번으로 초안 폐기, 작성 중 입력 취소(undo) 스택**까지 붙어서, "에이전트를 조종하는 느낌"이 "에이전트와 협업하는 느낌"으로 바뀝니다.

자동 포스팅에서는 사람이 개입할 일이 적지만, **반자동으로 글을 다듬을 때** 이 리디렉트가 정말 편합니다. "여기 단락 순서만 바꿔" 같은 지시를 중단 없이 처리하니까요.

## 5. 체감 ④ 스마트 승인이 "성장"했다 — 승인 피로 줄이기

v0.19에서 기본 적용된 스마트 승인(LLM 리뷰어가 민감한 명령을 검토)이 한 단계 더 똑똑해졌습니다.

- **`hermes approvals suggest`**: 그동안의 승인 이력을 분석해서 **허용 목록(allowlist) 제안**을 만들어 줍니다. "이 명령은 매번 물어보지 않아도 되겠다"를 에이전트가 먼저 제안하는 거죠.
- **연속 거부 서킷브레이커**: 같은 명령이 계속 거부되면 루프를 끊어버립니다. 잘못된 자동화가 같은 실수를 반복하며 멈추지 않는 사고를 막아줍니다.
- **docker/podman 승인 게이트**: 데몬 리다이렉트 명령은 반드시 승인을 거치도록 새 게이트가 추가됐습니다.

"승인 버튼을 덜 누르면서, 통제권은 그대로"라는 방향성이 실제로 구현된 느낌입니다. 크론잡처럼 무인으로 도는 환경에서는 오히려 **거부 루프 방지**가 가장 반가웠어요.

## 6. 체감 ⑤ 속도와 긴 세션 — "기다림"이 사라진 건 진짜였다

### 콜드스타트 14초 → 1.8초

`hermes -w`(웹/게이트웨이 시작) 콜드스타트가 **약 14초에서 약 1.8초로 단축**됐습니다. 크론잡이 매번 새로 프로세스를 띄우는 환경이라, 이건 단순한 체감이 아니라 **실제 실행 시간 단축**으로 이어집니다. 매일 여러 번 도는 자동화라면 누적 효과가 꽤 큽니다.

### 컨텍스트 압축 개편 — 긴 세션의 끊김이 줄었다

- **최근 대화 N개는 반드시 보존**하도록 보장 (`compression.min_tail_user_messages`)
- 한 번에 몰아서 압축하던 방식을 **턴마다 조금씩 나눠 압축**하는 마이크로 컴팩션으로 변경 — "압축하는 동안 멈추는" 긴 정지가 사라졌습니다
- 압축 임계값을 모델별·절대 토큰 단위로 설정 가능

밤새 도는 자동화나 대화가 긴 세션에서, **중간에 맥락을 잃고 같은 질문을 다시 하는** 문제가 확실히 줄었습니다.

### 데스크톱 60fps 2차 개선

스트리밍 비용이 대화 기록 길이와 무관해지고, **스트리밍 탭 5개를 켜도 60fps 드래그**, 백그라운드 유휴 CPU는 거의 0에 가깝습니다. 데스크톱 앱을 메인으로 쓰시는 분들도 체감이 클 부분입니다.

## 7. 참고 — 데스크톱은 이제 "워크벤치"

짧게만 다루겠습니다 (자세한 건 [8/4 총정리 글](/2026/08/04/hermes-agent-v020-herald-update/) 참고). 데스크톱 앱에 **아티팩트(생성된 HTML/앱을 샌드박스 라이브 프리뷰로 옆 창에서 실행)**, **플러그인 SDK(칸반 보드가 첫 플러그인)**, **글로벌 단축키 퀵엔트리 창**이 추가되면서, 채팅 클라이언트에서 작업대(워크벤치)로 성격이 바뀌었습니다. 터미널 중심인 저도 퀵엔트리는 자주 씁니다. OS 어디서나 단축키 하나로 메모를 세션에 던져 넣을 수 있거든요.

## 8. 일주일 써본 솔직한 장단점

### ✅ 장점 — 실제로 체감한 것

- **무인 운영의 안정성이 확실히 올라갔다**: 도구 자가복구 + 반복 한도 500 + 거부 루프 차단. 크론잡 가동률(성공률)이 체감상 가장 크게 개선된 부분입니다.
- **CLI 명령어가 실용적이다**: `!` 셸 모드와 `/context`는 하루에도 여러 번 씁니다. 마케팅용 기능이 아니라 진짜 필요한 기능들이 추가됐어요.
- **속도 개선이 "설정 없이" 적용된다**: 콜드스타트 1.8초, 압축 개편 모두 별도 설정 없이 바로 체감됩니다.
- **모델 선택의 폭이 넓다**: v0.20.0에서 Gemini 3.1 Pro·3.6 Flash, claude-opus-5, deepseek-v4-flash-0731 등이 추가됐습니다. 비싼 모델과 가벼운 모델을 작업별로 나눠 쓰기 좋습니다.

### ⚠️ 단점·주의사항 — 솔직하게

- **1,400개 PR 규모라 안정화 여지가 있다**: 릴리즈 노트에도 "in-window revert"(되돌린 변경) 언급이 여러 번 나옵니다. **중요한 자동화는 며칠 지켜본 뒤 옮기는 것**이 안전합니다. 저도 처음 이틀은 기존 버전과 병행 운영했습니다.
- **새 기능은 여전히 영어 문서 중심**: 음성, A2A, 웹훅 같은 신기능 자료는 대부분 영어입니다. 한국어 자료가 따라오기까지는 시간이 걸립니다.
- **도구 자가복구도 완벽하진 않다**: 실패를 복구하는 횟수가 늘어난 것이지, 실패 자체가 없어진 것은 아닙니다. 중요한 작업은 결과물 검증(파일 존재, 푸시 완료)을 별도로 확인하는 습관이 여전히 필요합니다.

## 9. 마무리 — 어떤 분께 추천할까요

정리하면, v0.20.0 Herald는 **"기능이 많아진" 업데이트라기보다 "에이전트가 일하는 방식이 달라진" 업데이트**입니다. 화제의 음성·A2A·웹훅도 좋지만, 제 실사용 기준으로는 **무인 자동화의 안정성(도구 자가복구, 반복 한도, 거부 루프 차단)** 과 **터미널 효율(파워 명령어, 미드턴 리디렉트)** 이 훨씬 큰 체감을 줬습니다.

**이런 분께 추천합니다.**

- 크론잡·야간 배치처럼 **무인으로 도는 자동화**를 돌리시는 분 (안정성 개선의 수혜자가 바로 이 부류입니다)
- Claude Code·Codex CLI를 쓰다가 넘어오시는 분 (`hermes import-agent`로 설정 이전이 끝납니다)
- 터미널에서 AI 에이전트를 **직접 조종하는 맛**을 원하시는 분

**이런 분은 신중하게.**

- "설치만 하면 바로 완벽한 비서"를 기대하시는 분 (초기 세팅은 여전히 필요합니다)
- 자동 실행 없이 채팅형 답변만 필요하신 분 (일반 챗봇으로 충분합니다)

### 업데이트 방법 (팁)

이미 쓰고 계신 분은 터미널에서 한 줄이면 끝납니다.

```bash
hermes update
```

아직 설치 전이라면 공식 홈페이지([hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/))에서 설치 파일을 받거나, 공식 설치 스크립트를 사용하시면 됩니다. 참고로 8/7 기준 GitHub 스타는 **226,597개**로, 8/4(224,887개) 대비 3일 만에 약 1,700개 늘었습니다. 오픈소스 AI 에이전트 중 가장 빠르게 성장하는 프로젝트인 건 분명해 보입니다.

저처럼 **가성비 좋은 AI 에이전트를 찾아 직접 운영해 보시는 분**이라면, 지금이 v0.20.0을 붙잡고 일주일쯤 실사용해 보기 좋은 타이밍입니다. 기능 총정리가 궁금하시다면 [8월 4일 Herald 릴리즈 정리 글](/2026/08/04/hermes-agent-v020-herald-update/)과 [v0.19.0 퀵실버 정리 글](/2026/08/05/hermes-agent-v019-quicksilver-20260805/)도 함께 읽어보세요.
