> **📌 한줄 요약:** 2026년 8월 현재 **AI 코딩 에이전트 시장은 사실상 '오픈소스 2강 + 상용 1강' 구도**입니다. 메신저 기반 일상 자동화의 **OpenClaw**(GitHub 스타 386,329개, MIT 라이선스), 자가학습 스킬과 크론잡 자동화의 **Hermes Agent**(Nous Research, v0.20.0 Herald, MIT 라이선스), 그리고 실제 코드 품질·기업 도입 1위인 **Claude Code**(Anthropic, Pro 17~20달러/월)가 각자의 강점이 뚜렷합니다. **터미널에서 진짜 코드를 많이 치는 분은 Claude Code, 메신저로 일상을 자동화하실 분은 OpenClaw, 무료로 장기 자동화 파이프라인을 돌리실 분은 Hermes Agent**를 고르면 됩니다. 셋 다 써보면 결국 "용도가 다르다"는 결론에 도달하게 됩니다.

## 1. 요즘 저처럼 "AI 에이전트, 뭘 써야 하지?" 고민하시는 분들

요즘 저처럼 **AI 코딩 에이전트를 실제 업무에 붙여 쓰시는 분들** 많으시죠. 저도 이 블로그의 자동 포스팅 일부를 Hermes Agent 크론잡으로 돌리고 있고, OpenClaw는 메신저 자동화로, Claude Code는 코드 작업할 때 번갈아 쓰다 보니, 주변에서 "그래서 셋 중에 뭐가 제일 좋냐"는 질문을 정말 많이 받습니다.

솔직히 답은 하나가 아닙니다. 8월 14일 **Claude Code가 Auto Mode를 기본값으로 전환**하고, 8월 3일 **Hermes Agent가 프로젝트 사상 최대 업데이트 v0.20.0 'Herald 릴리스'**를 배포했으며, OpenClaw는 **GitHub 스타 386,329개로 오픈소스 역사상 최다**를 달리고 있거든요. 세 개 다 "이번 달 기준"으로 뭔가 큰 변화가 있었습니다. 오늘은 2026년 8월 15일 기준, **셋 다 실제로 써본 관점에서 5개 항목으로 승자를 가려보는** 비교 글을 준비했습니다.

## 2. 3사 한눈에 보기 — 정체성부터 다르다

### 2-1. OpenClaw — "메신저에서 사는" 오픈소스 1위 에이전트

OpenClaw는 오스트리아 개발자 **피터 스타인버거(Peter Steinberger)**가 2025년 11월 'Warelay'라는 이름으로 시작해 2026년 1월 'OpenClaw'로 개명한 **MIT 라이선스 오픈소스 AI 에이전트**입니다. 2월엔 **OpenClaw 재단(OpenClaw Foundation)**이 설립됐고, 창시자는 OpenAI로 합류하면서 커뮤니티 주도로 운영되고 있어요.

정체성은 한 문장으로, **"이미 쓰고 있는 채팅 앱이 곧 인터페이스"**입니다. 텔레그램·왓츠앱·디스코드·슬랙·시그널 등 **22개 이상의 메신저 채널**에서 봇처럼 대화하며 이메일 정리, 캘린더 관리, 항공권 체크인, 리드 발굴 자동화까지 처리합니다. 사용자 데이터와 설정은 전부 로컬에 저장되고, 모델은 Claude·GPT·제미나이·DeepSeek 등 **내가 원하는 LLM을 골라 연결**하는 구조입니다.

![OpenClaw 공식 홈페이지 대표 이미지 — "Your own personal AI assistant"](/assets/images/posts/openclaw-vs-hermes-vs-claude-code-20260815/openclaw-site-og.png)
*OpenClaw 공식 홈페이지 대표 이미지 — 오픈소스·내 기기에서 실행되는 개인 AI 어시스턴트 (출처: openclaw.ai, 확인일 2026-08-15)*

### 2-2. Hermes Agent — "스스로 성장하는" Nous Research의 자가학습 에이전트

Hermes Agent는 **Nous Research**가 2026년 2월 25일 출시한 MIT 라이선스 오픈소스 에이전트입니다. 출시 두 달 만에 GitHub 스타 43,700개를 넘기며 **올해 가장 빠르게 성장한 오픈소스 에이전트 프레임워크**가 됐고, 8월 15일 현재 **230,727개 스타**를 기록 중입니다.

가장 큰 차별점은 **'자가학습(Self-improving)'**입니다. 작업을 하면서 스킬 파일을 스스로 만들어 저장해 두고, 다음에 비슷한 작업을 하면 처음부터가 아니라 **이전 경험 위에서 시작**합니다. Nous Research 측은 "자가 생성 스킬 20개 이상 보유 시 동일 작업을 약 40% 더 빠르게 처리"한다고 설명합니다. 크론잡(예약 작업), 게이트웨이(텔레그램·디스코드·슬랙·왓츠앱·시그널·이메일 등 옴니채널), MCP, A2A 프로토콜까지 갖춰 **"시간을 가로지르는 에이전트"**라는 평가를 받습니다.

![Hermes Agent 공식 홈페이지 대표 이미지 — "The open-source agent that grows with you"](/assets/images/posts/openclaw-vs-hermes-vs-claude-code-20260815/hermes-agent-og.png)
*Hermes Agent 공식 홈페이지 대표 이미지 — "the open-source agent that grows with you" (출처: hermes-agent.nousresearch.com, 확인일 2026-08-15)*

### 2-3. Claude Code — "코딩 에이전트의 넘버 1" Anthropic의 상용 제품

Claude Code는 **Anthropic**이 만든 터미널 기반 AI 코딩 에이전트입니다. 채팅형 코딩을 넘어 **코드 작성·수정·실행·테스트까지 에이전트가 스스로 처리**하는 방식으로 개발자 사이에 폭발적으로 퍼졌고, 2026년 5월 기준 **연매출 100만 달러 이상 기업 계정만 1,000개 이상**일 정도로 기업 시장을 장악했습니다. Anthropic 2분기 매출이 전년 대비 130% 성장한 핵심 동력으로 꼽힙니다.

특히 **8월 14일부터 Pro·Max·Team 요금제에서 'Auto Mode(자동 모드)'가 기본 설정**으로 전환되면서 "AI가 사람의 승인 없이도 장시간 스스로 일하는 시대"가 기본값이 됐습니다. Anthropic은 자체 실험에서 **사람이 위험 명령을 막아낸 비율 13.6% vs Auto Mode 89%**라는 데이터를 공개하기도 했어요. 터미널·IDE(VS Code, JetBrains)·웹·iOS·안드로이드·슬랙·GitHub 어디서든 쓸 수 있습니다.

![Claude Code 공식 제품 이미지 — Anthropic의 AI 코딩 에이전트](/assets/images/posts/openclaw-vs-hermes-vs-claude-code-20260815/claude-code-og.jpg)
*Claude Code — Anthropic의 에이전트형 코딩 도구, 터미널·IDE·웹·슬랙에서 사용 가능 (출처: claude.com/product/claude-code, 확인일 2026-08-15)*

## 4. 항목별 승자 판정 — 5개 라운드

### 🏆 라운드 1. 코딩 성능 → **Claude Code**

솔직히 이 항목은 아직 클로드 코드의 영역입니다. Anthropic의 최신 코딩 모델(Opus 4.6 등)이 탑재되고, 5월부터는 **수십~수백 개의 병렬 서브에이전트가 동시에 작업하는 '다이내믹 워크플로우'**까지 지원합니다. 대규모 리팩토링, 테스트 작성, CI 오류 수정 같은 "진짜 개발"에서는 셋 중 가장 안정적이라는 평가가 지배적입니다.

오픈소스 쪽도 만만치 않습니다. Hermes Agent는 `hermes import-agent` 한 줄이면 **Claude Code·Codex CLI 설정을 그대로 이전**받아 쓸 수 있고, OpenClaw는 Codex 런타임용 클라우드 워커가 추가되며 코드 에이전트 영역을 넓히고 있습니다. 다만 "지금 당장 코드 품질 하나만 놓고 보면" 아직 클로드 코드가 앞섭니다.

### 🏆 라운드 2. 자동화(에이전트 역량) → **Hermes Agent**

"시간을 가로지르는 에이전트"라는 표현이 딱 맞는 항목입니다. Hermes는 **크론잡으로 예약 작업을 돌리고, 완료되면 서명된 웹훅으로 내 시스템에 알리고, A2A 프로토콜로 다른 에이전트와 대화**합니다. v0.20.0에서는 대화형 음성(끼어들기 가능)과 웨이크워드까지 붙어서 "방 건너편에서 터미널에 말 거는" 수준이 됐어요. 게다가 작업 경험이 스킬로 축적되니 **쓸수록 빨라지는** 구조입니다.

OpenClaw도 메신저 자동화와 클라우드 워커, macOS 컴퓨터 사용(computer.act v2)으로 강력하지만, "내가 원하는 시각에, 원하는 이벤트로, 다른 에이전트와 협업하며" 도는 깊이 있는 자동화는 Hermes가 한 수 위라고 느꼈습니다. 크론잡 자동 포스팅을 직접 돌려보는 입장에서요.

### 🏆 라운드 3. 가격 → **OpenClaw·Hermes Agent (공동 우승)**

| 항목 | OpenClaw | Hermes Agent | Claude Code |
|:----|:----|:----|:----|
| 기본 요금 | **무료 (MIT)** | **무료 (MIT)** | Pro **17~20달러/월** |
| 상위 요금 | 무료 | 무료 | Max 5x **100달러/월** / Max 20x **200달러/월** |
| 부담 비용 | **LLM API 비용만** (Claude·GPT·DeepSeek 등 선택) | **LLM API 비용만** (Nous Portal·OpenRouter 등) | 요금제에 모델 사용량 포함 (사용 제한 있음) |

오픈소스 2사는 프로그램 자체는 무료이고 **내가 연결한 LLM API 비용만** 내면 됩니다. Claude Code는 Pro(연간 결제 시 월 17달러, 월 결제 20달러)부터 시작해 Max는 100~200달러까지 올라가지만, 그 대신 고급 모델 사용이 요금제에 포함됩니다. "일단 무료로 시작"하시는 분에겐 오픈소스 2사가 압도적입니다.

### 🏆 라운드 4. 확장성 → **OpenClaw**

확장성은 채널 수에서 OpenClaw가 가장 화려합니다. **메신저 22개 이상 + ClawHub 스킬 마켓 + 플러그인 + 클라우드 워커 + 컴퓨터 사용**까지, "내 기기들이 하나의 클러스터가 된다"는 비전이 실제로 구현돼 가고 있어요. 8월 15일 기준으로도 Codex 런타임 클라우드 워커, macOS computer.act v2(Peekaboo) 같은 기능이 계속 들어오고 있습니다.

Hermes도 MCP·A2A·데스크톱 플러그인 SDK·아티팩트 샌드박스로 뒤지지 않지만, "연결할 수 있는 표면"의 숫자 자체는 OpenClaw가 많습니다. 다만 확장성은 곧 **보안 표면**이기도 해서, OpenClaw는 설치 정책 경고 승인 제도 같은 보안 강화를 8월에 계속 이어가고 있습니다.

### 🏆 라운드 5. 생태계 → **Claude Code**

기업 도입 1,000+ 계정(연매출 100만 달러 이상 기준), IDE·슬랙·GitHub 전방위 통합, 그리고 **Auto Mode 기본 전환으로 안전성 데이터까지 공개**한 Claude Code가 코딩 에이전트 생태계의 중심입니다. DeepSeek가 "Claude Code를 잡겠다"고 전용 팀을 모집할 정도로 업계의 기준점이 됐어요. 커뮤니티 규모로는 OpenClaw(GitHub 스타 386K, ClawCon 개최)도 무시할 수 없지만, **"코딩 에이전트" 생태계** 한정으로는 Claude Code의 자리가 아직 단단합니다.

## 6. 솔직한 단점 — 설치 전에 알아야 할 것

솔직히 단점도 있습니다. 저처럼 "하나만 골라서 다 해결"을 원하시는 분이라면 아래 내용 꼭 확인하고 가세요.

1. **OpenClaw — 인기만큼 따라오는 보안·안정성 논란.** 스타 수가 폭발적으로 늘면서 "봇 계정이 부풀린 게 아니냐"는 지적과, 데이트 프로필 생성 사고(MoltMatch) 같은 보안 이슈가 꾸준히 제기됩니다. 메신저에 개인 계정을 연결하는 만큼 **권한 범위를 꼭 최소화**하세요. 또 릴리스 주기가 빨라서 안정판(v2026.7.1)과 베타(v2026.8.1-beta.2) 사이 체감 차이가 큽니다.
2. **Hermes Agent — 세팅이 처음엔 만만치 않다.** 무료이고 강력하지만, 게이트웨이·모델 키·크론잡을 직접 구성해야 해서 **초기 학습곡선이 존재**합니다. 커뮤니티도 OpenClaw만큼 크지 않아 한글 자료가 아직 적은 편이에요. 다행히 `hermes import-agent`로 기존 Claude Code 설정을 이전할 수 있습니다.
3. **Claude Code — 가격이 가볍지 않고, 사용 제한이 있다.** Pro 17~20달러/월부터 시작하지만 **요금제별 사용 한도(usage limits)**가 있어서, 헤비 유저는 Max(100~200달러)로 올려야 합니다. 또 모델과 플랫폼이 Anthropic 클라우드에 묶여 있어 **완전한 자체 호스팅이 불가능**합니다. Auto Mode 전환에 대한 "승인 없이 실행되는 게 과연 안전한가" 우려도 아직 남아 있어요.

## 7. 마무리 — "가성비 좋은 에이전트 찾는 분께 추천"

2026년 8월 기준 제 결론은 이렇습니다. **코딩 에이전트 시장은 '하나를 고르는' 시장이 아니라 '용도별로 나누는' 시장**이 됐습니다. 실제로 저도 블로그 자동화는 Hermes Agent 크론잡, 메신저 알림·자동화는 OpenClaw, 코드 작업은 Claude Code로 쓰고 있어요.

- **지금 당장 코드 품질이 필요하신 분** → Claude Code (Pro부터 시작, 연간 결제 시 월 17달러)
- **무료로 시작하고 싶으신 분** → Hermes Agent 또는 OpenClaw (LLM 키만 있으면 0원)
- **메신저 자동화 + 코딩을 동시에** → OpenClaw + Claude Code 조합이 현실적입니다

셋 다 직접 써보면 "어느 하나가 압도적으로 좋다"기보다 **각자 맡은 역할이 다르다**는 걸 체감하게 됩니다. 가성비 좋은 AI 에이전트를 찾는 분께, 이 비교 글이 선택의 기준이 되면 좋겠습니다.
