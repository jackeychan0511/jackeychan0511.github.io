> **📌 한줄 요약:** **2026년 9월 29일(현지시간) OpenAI DevDay 2026**이 샌프란시스코 **포트 메이슨(Fort Mason Center)**에서 열립니다. 샘 올트먼 키이노트는 **무료 라이브스트림**으로 공개됩니다. 유출된 코드 기준으로 **① 상시 가동형 소비자 에이전트 'o', ② 개발자·기업용 관리형 에이전트 플랫폼 'Managed Agents', ③ OpenAI Platform의 신규 요금제(Free·Prototype·Accelerate)**가 예고되어 있습니다. 공식 확정은 **DevDay 일정과 키이노트뿐**이고, 제품명·가격은 아직 미확인 유출이라는 점을 먼저 못 박고 시작하겠습니다.

요즘 저처럼 **업무 자동화 파이프라인에 AI 에이전트를 붙여 실사용하시는 분들**, 이번 주는 좀 숨 가쁘셨을 겁니다. 지난주에 학습·샌드박스 통제 실패 뉴스를 정리해 올렸는데, 그 다음 날이 DevDay 하루 전입니다. 저는 이번 이벤트를 **"새 모델 자랑 무대"가 아니라 "에이전트 운영 방식이 바뀌는 무대"**로 보고 준비하고 있습니다.

## ① 이슈 요약 — DevDay 2026, 확정된 것과 아닌 것

솔직히 말하면, 지금 나오는 DevDay 관련 제품명 대부분은 **OpenAI 공식 발표가 아닙니다.** 저도 처음엔 헷갈렸는데, 정리해보면 경계가 꽤 명확합니다.

| 구분 | 항목 | 상태 |
|:---|:---|:---|
| ✅ 공식 확정 | 일시·장소: **2026년 9월 29일, 샌프란시스코 포트 메이슨** | OpenAI 공식 DevDay 페이지 |
| ✅ 공식 확정 | **샘 올트먼 키이노트 무료 라이브스트림**, 기술 세션·데모·워크숍 | OpenAI 공식 DevDay 페이지 |
| ✅ 공식 확정 | **Agent Builder·Evals Platform·Reusable Prompts 2026년 11월 30일 종료** (6월 3일 공지) | OpenAI deprecations |
| ⚠️ 미확인 유출 | 상시 가동형 에이전트 **'o'** | TestingCatalog(9/26), BleepingComputer(9/27) |

**핵심은 "무엇이 나온다"보다 "무엇이 이미 바뀌었나"입니다.** DevDay에서 뭐가 나오든, 9월 한 달 사이에 API는 이미 여섯 번 이상 바뀌었고 **11월 30일 종료 예고**는 확정입니다. 저는 이벤트 결과를 기다리는 대신, 이미 확정된 변경분부터 정리했습니다.

## ② 상세 분석 — 유출된 코드가 말하는 것

### (1) 'o' — "당신의 상시 비서"

9월 26일 TestingCatalog가 "OpenAI가 DevDay에서 상시 가동형 에이전트 'o'를 발표할 예정"이라고 보도했고, 9월 27일 BleepingComputer가 세부를 더했습니다. 핵심은 이렇습니다.

- **$100 ChatGPT Pro 요금제 혜택 목록**에 **"o, your always-on assistant"** 문구가 잠깐 노출됐다가 사라졌습니다.
- 설정 코드에 `display_name: "o"`와 **`email_suffix: "-o"`** 가 함께 발견됐습니다. **이메일 주소를 가진 에이전트**라는 뜻으로 읽히는 대목입니다.
- 같은 목록에 **최대 메모리, 100GB 파일 저장공간**이 함께 있었습니다.

제가 이 부분에서 멈칫한 이유는, "상시 가동 + 이메일 주소"가 곧 **내가 자리에 없을 때도 대신 행동한다**는 의미이기 때문입니다. 지난주 샌드박스 탈출 사안을 본 뒤라, 저는 이 조합을 **기능보다 권한 설계의 문제**로 먼저 봤습니다.

한 가지 덧붙이면, 워크스페이스용 커스텀 에이전트로 **'Aeon'** 이라는 내부 시스템 언급도 있지만, 이건 'o'와 **별개 트랙**으로 보도됐습니다. 두 개를 같은 제품으로 묶어 읽으면 안 됩니다.

### (2) Managed Agents — 이번 이벤트의 진짜 헤드라인

개인적으로 **DevDay 키이노트의 본체는 여기라고 봅니다.** 9월 7일 TestingCatalog가 코드베이스에서 발견한 내용은 다음과 같습니다.

- **에이전트 + 실행 환경(runtime)을 OpenAI가 관리**하는 구조
- **환경(environment)·스킬(skill)·플러그인(plugin)을 골라 조합**하는 생성 UI
- **셀프 호스팅 환경도 지원**
- 개발자용뿐 아니라 **비즈니스 고객용 데모**도 준비 중

쉽게 말하면 **"에이전트를 직접 조립하고 굴리던 일을 플랫폼에 넘기는"** 방향입니다. 기능 구성만 보면 **Anthropic이 먼저 제품화한 관리형 에이전트와 상당히 겹칩니다.** Forbes(9/21)는 이 발표가 소프트웨어 업종 재편 신호가 될 수 있다고 봤고, 저도 방향은 비슷하게 봅니다.

### (3) 조용하지만 확실한 변화 — 9월 API 변경분과 11월 30일

DevDay를 준비하는 입장에서 실질적인 건 이쪽입니다. OpenAI API 변경 로그 기준으로 정리했습니다.

- **9월 8~10일 — Agents API 퍼블릭 베타.** 세션 오케스트레이션, **컨텍스트 압축**, 복구, 지속 세션, 진행 상황 스트리밍, **자체 도구·MCP 서버 연결**, **OpenAI 호스팅 샌드박스 또는 자체 인프라 샌드박스**에서 실행.
- **9월 10일 — GPT-Live 1 정식 출시.** 풀듀플렉스 음성, **분당 $0.05**(백엔드 모델·도구 사용료 별도).
- **9월 10일 — API 키 만료일·최대 수명 설정, 키 생성 거버넌스.** 관리자가 서비스 계정 키만 허용하거나 신규 키 생성을 차단할 수 있습니다.
- **9월 22일 — GPT-6 Sol·Luna.** 프로모션 가격 대비 **API 가격을 50% 인하**한다고 발표했습니다.
- **GPT-6 Astra의 제약.** `none` 추론 강도, 커스텀 temperature·top_p, logprobs 미지원, **Chat Completions에서의 툴 호출 미지원.** 대신 Responses API에 비동기 툴 호출, WebSocket 기반 중간 개입(mid-turn steering), 대화 중 추론 강도 변경이 추가됐습니다.
- **9월 28일(오늘) — 레거시 모델 4종 종료.** `gpt-3.5-turbo-instruct`, `babbage-002`, `davinci-002`, `gpt-3.5-turbo-1106`이 `gpt-5.6-terra`로 안내됩니다. Sora 2 Videos API는 9월 24일 제거됐습니다.

여기서 **11월 30일**을 다시 강조하고 싶습니다. **Agent Builder로 만든 워크플로가 있다면 이미 마이그레이션 시계가 돌고 있습니다.** 종료 대상은 **Agent Builder, Evals Platform, Reusable Prompts** 세 가지이고, 커뮤니티에는 대체 경로(Agents SDK, ChatGPT Workspace Agents) 문의가 이어지고 있습니다.

## ③ 사용자·개발자에게 실제로 미치는 영향

### 개인 사용자 관점

- **'o'가 나오면 "상시"의 범위를 먼저 확인하세요.** 내가 앱을 닫아도 도는지, 어떤 데이터를 붙잡고 있는지가 요금제보다 중요합니다.
- **메모리·파일 저장공간은 편의이자 보관 위험입니다.** 100GB급 저장이 열리면 민감 파일 분리 원칙이 더 필요합니다.
- **음성(GPT-Live 1)은 분당 과금입니다.** 통화형 자동화를 붙일 계획이면 **1회 비용을 미리 계산**해보는 게 좋습니다.

### 개발자·업무 자동화 관점 (여기가 핵심)

- **모델 ID부터 훑으세요.** 오늘부로 레거시 4종이 종료됐습니다. 코드·문서·노트북에서 해당 ID를 검색해 교체 대상을 확정해야 합니다.
- **Chat Completions에서 Responses API로 이동이 사실상 강제되고 있습니다.** GPT-6 Astra가 Chat Completions에서 툴 호출을 지원하지 않는 게 그 신호입니다.
- **세션·복구는 직접 만들지 말고 플랫폼으로 넘기는 쪽이 낫습니다.** Agents API 퍼블릭 베타가 컨텍스트 압축·복구·지속 세션을 제공합니다. 직접 구현한 재시도 로직과 충돌하지 않는지 확인하세요.
- **관리형(Managed)으로 갈 때의 트레이드오프를 정하세요.** 편해지는 대신 **런타임이 OpenAI 안으로 들어갑니다.** 셀프 호스팅 옵션이 있다고 해도 기본값이 무엇인지가 중요합니다.
- **키 거버넌스를 이번 주에 켜두세요.** 키 만료·최대 수명 설정은 지금도 쓸 수 있는 기능입니다. 지난주 사고 유형(노출된 자격증명 사용)에 대한 가장 싼 방어입니다.
- **비용 재계산.** GPT-6 Sol·Luna의 50% 인하는 **태스크당 비용** 기준으로 다시 봐야 합니다. 토큰 단가만 보면 착시가 생깁니다.

저는 이번 주에 파이프라인에서 **① 레거시 모델 ID 전수 검색, ② API 키 만료 상한 설정, ③ Responses API 전환 대상 목록화** 세 가지를 끝냈습니다. DevDay 발표를 기다리지 않고도 할 수 있는 일이고, 결과가 나온 뒤에 하면 **두 배로 바빠집니다.**

## ④ 전망 — DevDay 다음 72시간

- **예상 시나리오:** 키이노트에서 **Managed Agents가 플랫폼 발표의 중심**에 서고, **'o'가 소비자 트랙**을 맡는 구성이 유력합니다. 여기에 **신규 요금제(Free·Prototype·Accelerate)**, 보안·통제 관련 발표가 붙을 가능성이 큽니다.
- **경쟁 구도:** TestingCatalog는 **Anthropic이 DevDay를 앞두고 Claude Sonnet 5.5를 며칠 내 낼 수 있다**고 봤습니다. 구글도 차기 Gemini Pro 체크포인트를 테스트 중이라는 관측이 있습니다. **발표가 겹치는 구간**이라 비교 자료가 빠르게 쏟아질 겁니다.
- **업무 자동화 시장:** 관리형 에이전트가 저렴하게 풀리면 **n8n·Zapier류 글루(glue) 워크플로의 자리가 줄어들 수 있습니다.** 반대로 데이터·권한·감사 계층의 가치는 올라갑니다.
- **규제 변수:** 지난주 에이전트 사고와 호주·미국 의회 움직임이 겹치면서, **에이전트 로그·감사·통제 기능이 신제품의 필수 항목**으로 들어올 가능성이 높습니다. 저는 이걸 **가장 확실한 발표**로 봅니다.

## 마무리 — DevDay를 기다리는 분들께

새 제품 리뷰 글에서 늘 "가성비 좋은 제품 찾는 분께 추천"이라고 쓰는데, 이번엔 순서가 다릅니다. **에이전트 자동화를 굴리고 있거나 이번 분기에 도입하려는 분들께는, 발표를 보기 전에 아래 세 줄을 먼저 권합니다.**

1. **레거시 모델 ID 전수 검색** — 오늘 4종이 종료됐습니다.
2. **API 키 만료·권한 정책 설정** — 지금 바로 가능한 가장 싼 방어입니다.
3. **Responses API 전환 대상 목록화** — Chat Completions 툴 호출 제약이 이미 시작됐습니다.

제 결론은 이렇습니다. **DevDay 2026은 "무엇이 새로 나오나"보다 "내 파이프라인이 그 변화를 감당할 준비가 됐나"를 묻는 이벤트**입니다. 화려한 데모보다, 발표 다음 날 아침에 제 자동화가 안 깨져 있는지가 저한테는 더 중요합니다. 결과 나오면 자동화 파이프라인 관점에서 다시 정리해 올리겠습니다.
