Node 22·25와 macOS 11~13.4 설치도 지원 대상에서 빠졌어요.

릴리스 노트 원문에는 PR이 1,843건 명시돼 있고, 출시 검증도 이례적으로 빡셉니다. **npm `latest` 배포, Docker 프로모션, 90개 npm 플러그인 전수 검증, ClawHub 전 플러그인 2026.9.3 태그 일치**까지 마쳤다고 공식 기록에 남아 있어요.

*OpenClaw GitHub 공식 저장소 — "The AI that really does things. Any OS. Any Platform. The lobster way. 🦞" (출처: github.com/openclaw/openclaw)*

공식 하이라이트는 **8가지**로 정리돼 있습니다.

1. **더 안전한 업데이트 (Safer updates)** — 코어·플러그인 변경을 **활성화 전 격리된 후보(candidate) 상태에서 리허설**하고, 적격한 2026.9.2 마이그레이션을 지원하며, 멀쩡한 게이트웨이를 세우지 않고도 중단된 업데이트 기록을 복구
2. **성능 개선** — 따뜻한 프롬프트 캐시 보존, 콜드 세션 업데이트·메모리 검색 중 불필요한 작업 감소, 세션 간 워커 빌드 재사용
3. **Skill Workshop** — 스킬을 워크스페이스가 아닌 **에이전트 소유의 하나의 영구 컬렉션**으로 유지, 스킬 전체 지침 비교, Doctor를 통한 안전한 정리
4. **브라우저 탭, 라이브 & 네이티브** — 에이전트가 여는 페이지가 **실시간으로 다시 그려지는 것을 감상**할 수 있고, macOS 앱에서는 외부 링크가 **네이티브 Mac 탭**으로 열림(채팅 전환에도 탭 유지)
5. **연결 계정 통합 관리** — Models 설정에서 **연결된 프로바이더 계정과 우선순위를 한곳에서 관리**
6. **선택한 대화 공유** — 세션의 기존·향후 대화 텍스트를 **회수(revoke) 가능한 읽기 전용 공개 링크**로 공유
7. **검색 가능한 회의 라이브러리** — 저장된 회의 노트 탐색·**전체 트랜스크립트 검색**·Markdown/JSONL **아카이브 내보내기**
8. **선택형 팀 활동 리포트 (Team Reports)** — GitHub 인증 활동과 명시적으로 설정한 Discord 소스를 일간·주간·월간 리포트로, 모델 요약 옵션 포함

## ⚠️ 이번 판 최대 주의점 — Node 먼저 올리세요 (SQLite 잘림 경고)

이번 v2026.9.3에서 **제일 먼저 눈여겨봐야 할 건 새 기능이 아니라 브레이킹 체인지**입니다.

> **Node 런타임 요구사항:** **Node 24.16.0 이상(24.x 기준) 또는 Node 26.1.0 이상**을 요구합니다. **Node 26이 권장**되며, **OpenClaw 업그레이드 전에 Node를 먼저 올리지 않으면 SQLite 텍스트 잘림(truncation)이 발생할 수 있습니다.** Node 22·25와 그 이전 24.x/26.x 빌드는 더 이상 지원되지 않아요. Node 기반 CLI/게이트웨이를 쓰는 **macOS 11~13.4**나 공식 Linux ARMv7 프로비저닝도 지원 대상에서 제외됩니다.

즉, 지금 Node 22나 25로 OpenClaw를 돌리시는 분이라면 **① Node를 24.16.0+/26.1.0+로 먼저 업그레이드 → ② 그다음 OpenClaw v2026.9.3으로 업데이트** 순서를 지켜야 합니다. 순서를 바꾸면 대화·메모리 데이터가 저장될 때 텍스트가 잘릴 수 있다는 게 공식 경고 내용이에요. 저처럼 맥북을 오래된 macOS에서 쓰시는 분은 "내 기기(맥OS 11~13.4)가 공식 지원 목록에서 빠졌는지"부터 확인하시는 게 좋겠습니다.

그다음 주의점은 **에이전트 소유 Skill Workshop 전환**(브레이킹)입니다. 기존에는 스킬이 워크스페이스에 귀속됐는데, 이제 **에이전트당 하나의 쓰기 가능한 Workshop 컬렉션**으로 바뀌고 `skills.workshop.allowSymlinkTargetWrites` 설정은 폐기됩니다. 시작 시점과 `openclaw doctor --fix`가 기존 스킬을 자동 마이그레이션해 주지만, 소유권이 애매한 스킬은 검토를 위해 남겨두니 업데이트 후 `doctor`를 한 번 돌려보시길 권합니다.

플러그인을 직접 만드시는 분이라면 **SDK 브레이킹 체인지**가 여럿 있습니다(execution-policy SDK의 `resolveExecModePolicy` 이동, approval SDK의 네이티브 라우트 게이트 전환, `buildChannelInboundMediaPayload` 이름 변경, Find/Grep·Ls 결과 콜백의 `details.content` 구조 변경 등). 또 **`sdk-untrusted-context-identifier-aliases`는 디프리케이션 상태로, 제거 예정 시점이 2026-09-08로 기록**됐습니다. 이번 9.3에는 여전히 export되지만, 다음 릴리스에서는 사라질 수 있으니 `MsgContext.ChannelPromptContext` 계열로 미리 옮겨두는 게 안전합니다.

## 업무 자동화에 실질적인 변화 — 공유·회의·리포트·위임

**① 대화를 '회수 가능한 공개 링크'로 공유**

세션 소유자와 게이트웨이 관리자는 이제 세션의 **기존+향후 대화 텍스트를 공개 URL로 게시**하고, 원할 때 **링크를 회수(revoke)** 할 수 있습니다. 읽기 전용 뷰에는 도구·추론·파일·이미지·실행 위젯이 빠져서, "자동화가 어떻게 돌아가는지 팀원이나 고객에게 보여주고 싶은데 전체 권한은 주기 싫은" 경우에 잘 맞아요. 공개 전 텍스트를 한번 훑어보라는 안내도 공식 노트에 있습니다.

**② 회의 라이브러리 — 트랜스크립트 검색·전체 내보내기**

회의 캡처를 쓰시는 분께는 이번 판의 숨은 알짜입니다. 저장된 회의 노트를 페이지 단위로 훑고, **전체 트랜스크립트를 검색**할 수 있으며, **Markdown이나 JSONL로 전체 아카이브를 내려받을 수** 있어요. 캡처 소스 관리도 Communications 설정에 모였습니다. "지난주 회의에서 뭐라고 했더라?"를 AI 에이전트가 정리해 주는 워크플로우가 훨씬 단단해진 느낌입니다.

**③ Team Reports (선택 설치형 플러그인)**

팀 단위 업무 자동화를 돌리시는 분이라면 눈여겨볼 만합니다. Team Reports 플러그인을 설치하면 **GitHub 활동(인증 기준)과 명시적으로 선택한 Discord 소스를 일간·주간·월간 리포트**로 만들어 주고, **모델 요약·구성원 타임라인·캘린더**까지 제공합니다. 리포트 전용 플러그인이라 기본 설치에는 포함되지 않으니 필요한 팀만 설치하는 구조예요.

**④ 재귀 위임(recursive delegation) 기본 활성화**

에이전트가 **하위 에이전트를 다시 스폰하는 '재귀적 세션 생성'이 기본으로 켜집니다.** 다만 깊이·동시성 제한과 기존 샌드박스 제약은 그대로 유지되니, "하나의 큰 작업을 트리 구조로 쪼개 처리"하는 패턴을 별도 설정 없이 쓸 수 있게 된 셈입니다.

**⑤ 브라우저·모델·디바이스 운영 편의**

- **브라우저 패널** — 에이전트가 여는 탭의 화면이 실시간 repaint로 보이고(스트리밍 불가 시 스크린샷 폴백), macOS 앱에서는 외부 링크가 네이티브 WebKit 탭으로 열려 채팅을 오가도 탭이 유지됩니다.
- **Models 설정 통합** — 연결된 프로바이더 계정을 추가·제거하고 **계정 우선순위를 직접 조정**할 수 있고, **모델 폴백(fallback) 피커**도 검색형 드롭다운으로 개선됐어요.
- **CLI 에이전트 기본 노출** — 새 세션 모델 피커에 CLI 생성 가능 에이전트가 별도 옵트인 없이 표시됩니다(`gateway.cliAgents.enabled=false`로 끌 수 있음).
- **iOS 음성 숏컷** — "Start Live Voice" 앱 숏컷으로 현재 채팅을 열고 바로 Talk를 시작할 수 있습니다.
- **macOS 앱 게이트웨이 제어 CLI** — `openclaw-mac` 명령으로 터미널·SSH에서 Mac 앱의 게이트웨이 연결을 점검·설정할 수 있어요.

## 실제 사용감 — 솔직한 장단점

며칠 사이 9.1 → 9.2 → 9.3으로 연달아 나오다 보니, **"버전이 너무 자주 바뀌는 거 아니냐"**는 피로감이 드는 건 솔직히 사실입니다. 다만 그만큼 **운영 안정성에 신경을 많이 쓴 판**이라는 인상이에요.

- 👍 **업데이트 리허설·복구** — 자동 업데이트가 실패했을 때 게이트웨이를 통째로 세우지 않고 복구할 수 있게 된 건, "아침에 일어나니 업데이트가 깨져 있었다"를 겪어본 분께 체감이 큽니다.
- 👍 **회의 라이브러리·Team Reports** — 회의록 검색과 팀 활동 리포트는 "AI 에이전트가 그냥 채팅만 해주는 도구"에서 **운영 데이터 도구**로 한 걸음 나아간 기능들이에요.
- 👎 **Node 요구사항 상향** — 구버전 Node·구형 macOS(11~13.4) 사용자에게는 **업그레이드 자체가 차단 요인**이 될 수 있습니다. 특히 "SQLite 텍스트 잘림" 경고는 순서를 어기면 데이터 손상으로 이어질 수 있어서, 업데이트 전 확인이 필수입니다.
- 👎 **플러그인 SDK 연쇄 변경** — 직접 플러그인을 운영하시는 분은 이번 판에서 마이그레이션 작업이 적지 않습니다. 디프리케이션(제거 예정 2026-09-08 기록) 항목까지 합치면 9월 안에 손봐야 할 코드가 분명히 있어요.

## 업데이트 방법 — v2026.9.2 → v2026.9.3 (순서 중요!)

1. **Node부터 확인·업그레이드** — `node -v`로 버전을 확인하고, **Node 24.16.0+ / 26.1.0+(권장) 미만이면 먼저 Node를 올립니다.** (macOS 11~13.4 사용자는 공식 지원 범위를 docs.openclaw.ai/install/node에서 먼저 확인)
2. **OpenClaw 업데이트** — npm 기준 `latest`로 v2026.9.3이 배포됐고 Docker 프로모션도 완료된 상태입니다. 평소 쓰시는 방법(CLI/Gateway/앱) 그대로 업데이트하면 됩니다.
3. **`openclaw doctor --fix` 실행** — Workshop 스킬 소유권 전환(workspace → agent) 마이그레이션과 남은 문제를 정리해 줍니다.
4. **플러그인 사용자라면** — 실행 전 `openclaw/plugin-sdk` 마이그레이션 가이드(docs.openclaw.ai/plugins/sdk-migration)에서 breaking change 목록을 확인하세요. ClawHub의 90개 공식 플러그인은 전부 2026.9.3 태그로 검증·배포 완료입니다.

## 마무리

어제 v2026.9.2가 "신모델(GPT-6 Astra·Muse Spark 1.3) 탑재판"이었다면, **v2026.9.3은 '안전한 업데이트 + 팀 운영 기능' 판**이라고 요약할 수 있겠습니다. 대화 공유, 회의 라이브러리, Team Reports까지 오면서 **"내 일을 대신 해주는 도구"에서 "팀의 일하는 방식을 기록·공유하는 도구"로 쓰임새가 넓어지는** 흐름이네요.

다만 이번 판은 **업데이트 전 Node부터 올려야 하는 브레이킹 체인지**가 끼어 있으니, "나중에 하지 뭐" 하기보다 **순서만 지켜서** 미리 올려두시길 권합니다. 저처럼 오픈소스 AI 에이전트로 업무 자동화를 직접 돌려보시는 분, 특히 **여러 대의 게이트웨이·팀 단위 자동화를 운영하시는 분께 추천**하는 업데이트입니다.
