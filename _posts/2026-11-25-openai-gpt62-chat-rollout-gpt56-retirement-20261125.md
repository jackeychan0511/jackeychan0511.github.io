> **📌 한줄 요약:** **2026년 11월 23일(현지시간)** OpenAI가 **GPT-6.2 Sol**을 ChatGPT **챗 탭**에 풀었습니다. 대상은 **Plus·Pro·Business·Enterprise**, Free와 Go는 아직 GPT-6입니다. 같은 주 OpenAI는 **GPT-5.6 Sol을 12월 23일 ChatGPT에서 은퇴**시키고, **GPT-5.6 Sol·Terra를 ChatGPT Work와 Codex에서도 같은 날 제거**한다고 공지했습니다. 이유는 명확합니다. "두 세대 전 모델은 정리한다"는 방침이고, 그렇게 비운 연산으로 더 좋은 모델을 더 많은 사람에게 돌리겠다는 것입니다.

## 하루 사이에 날아온 두 통의 공지

ChatGPT를 업무에 붙여 쓰는 분들이라면 이번 주는 좀 정신이 없습니다. 같은 모델 이름이 붙은 소식이 **"새 모델 들어옴"**과 **"쓰던 모델 나감"** 두 갈래로 동시에 도착했기 때문입니다.

- **11월 23일(현지시간)** — GPT-6.2 Sol이 ChatGPT 앱의 **챗(Chat) 탭**에 배포 시작. MacRumors는 OpenAI가 이날 Plus·Pro·Business·Enterprise 요금제로 롤아웃을 시작했다고 보도했습니다.
- **같은 주, X 공지** — GPT-5.6 Sol의 **12월 23일 은퇴**. GPT-5.6 Sol과 Terra는 같은 날 **ChatGPT Work와 Codex에서도 제거**됩니다.

OpenAI가 X에 올린 문구는 이렇습니다. "모든 모델에게는 전성기가 있다. GPT-5.6은 이제 물러날 시간"이라는 뉘앙스였고, 은퇴 기준은 **"새 모델을 내놓은 뒤 두 세대 전 모델은 정리한다"**는 원칙입니다. 덧붙여 **"그렇게 비운 연산(compute)으로 더 많은 사람이 더 성능 좋은 모델을 쓸 수 있게 된다"**고 설명했습니다.

정리하면 이번 주 뉴스의 본질은 하나입니다. **챗의 기본 모델이 GPT-6.2 Sol로 갈아 끼워지고, 그 대가로 GPT-5.6이 퇴장한다.** 신모델 소식과 은퇴 공지가 한 묶음인 셈입니다.

## GPT-6.2 Sol, 챗에서 실제로 뭐가 달라졌나

지난 11월 17일 공개된 GPT-6.2 Astra·Sol은 원래 **ChatGPT Work와 Codex**용이었습니다. 이번에 챗 탭으로 내려온 것은 그중 **일상 대화용으로 튜닝한 Sol**입니다. Work·Codex 쪽 모델은 그대로 유지됩니다.

OpenAI가 강조한 변화는 크게 네 가지입니다.

| 구분 | GPT-6 (기존 챗) | GPT-6.2 Sol (새 챗) |
|:---|:---|:---|
| 여러 조건 동시 처리 | 조건이 많으면 일부를 흘림 | 예산·위치·취향을 **동시에** 놓고 후보를 좁힘 |
| 이미지 세부 판독 | 간판·라벨의 작은 글자에서 약함 | 사진 속 **기호·라벨 텍스트** 판독 개선 |
| 온라인 선택 | 검색 결과를 나열하는 수준 | 사용자 우선순위에 맞춰 **옵션을 골라 제안** |
| 후속 행동 제안 | 대화에서 끝남 | "가격 내리면 알려줄까요?"처럼 **다음 행동을 제안** |

호텔을 고르는 상황을 예로 들면 차이가 확실합니다. "예산은 하루 20만 원, 역에서 도보 10분, 조용한 동네"라는 조건을 주면, 기존 모델은 조건 세 개 중 두 개만 반영한 후보를 섞어 놓는 경우가 있었습니다. GPT-6.2 Sol은 세 조건을 동시에 계산해 후보를 추린 뒤, 조건을 포기해야 하는 지점을 따로 알려주는 방식으로 동작합니다.

이미지 쪽 개선도 실무에 바로 체감되는 부분입니다. 간판의 작은 글씨, 제품 라벨의 성분 표기, 영수증의 항목처럼 **"사진은 찍혔는데 글자가 흐릿한"** 케이스에서 판독률이 올라갔습니다.

### 숫자로 본 변화

![GPT-6 → GPT-6.2 Sol 주요 지표 변화](https://pub-a8e00ddf355f47339bd2e01ff3221de7.r2.dev/assets/images/posts/openai-gpt62-chat-rollout-gpt56-retirement-20261125/01-bench.png)
*OpenAI 내부 테스트 수치를 바탕으로 정리한 그래프 (U18 안전규정은 77~80% → 91~94% 구간의 중간값 표기)*

OpenAI 내부 테스트에서 가장 큰 폭으로 올라간 항목은 **이미지 인식**입니다. 수치는 **47.4% → 71.7%**, **+24.3%p**입니다. 외신들이 공통으로 인용한 부분도 이 항목입니다.

검색 난이도가 높은 정보를 찾는 **BrowseComp(초고난도 설정)** 는 **54.4% → 64.5%**로 **+10.1%p** 올랐습니다. 눈에 띄는 건 **청소년(U18) 안전 규정 준수율**입니다. 섭식장애·정서적 의존·연령 제한 상품 같은 민감 주제에서 정책을 지킨 비율이 **77~80%에서 91~94%**로 뛰었습니다. 모델 성능 개선과 안전 개선이 같이 온 경우는 최근 릴리스 중에서도 드문 편입니다.

## 12월 23일 은퇴 — 실무에서 걸리는 지점

은퇴 공지는 짧지만, 실제로 손봐야 할 곳은 세 군데입니다.

1. **ChatGPT 챗 탭** — GPT-5.6 Sol이 사라지고 GPT-6.2 Sol로 자동 전환됩니다. 사용자가 따로 설정할 것은 없지만, 문체·요약 습관이 달라집니다.
2. **ChatGPT Work** — GPT-6.2 Astra·Sol이 이미 기본이고, GPT-5.6 Sol·Terra가 12월 23일 빠집니다.
3. **Codex** — Work와 동일하게 GPT-5.6 Sol·Terra가 제거됩니다.

문제는 **"같은 프롬프트인데 결과물이 달라지는" 구간**입니다. 은퇴 발표 직후 X와 레딧에는 반발이 붙었습니다. 테크레이더가 인용한 사용자 반응 중 눈에 띄는 것은 이런 것들입니다.

- "다른 모델들은 5.6의 지능과 뉘앙스에 근접하지도 못한다. Pro 구독을 해지하겠다."
- "5.6 Sol은 사이버보안 리서치에 쓸 수 있는 유일한 모델이었다."
- 레딧에서는 GPT-6 계열이 **"요약을 과하게 한다"**는 지적과, **"5.6이 마지막으로 훌륭했던 글쓰기 모델"**이라는 평가가 함께 나왔습니다.

물론 이건 취향과 용도에 따라 갈리는 평가입니다. 다만 **문체가 중요한 작업(카피·번역·장문 편집)** 을 GPT-5.6에 붙여 두었다면, 12월 23일 전에 결과물을 다시 뽑아 비교해 두는 편이 안전합니다.

## 영향 정리 — 사용자와 개발자

### 일반 사용자 관점

| 요금제 | 지금 상태 | 해둘 일 |
|:---|:---|:---|
| Plus·Pro | GPT-6.2 Sol 배포됨 | 기존 대화의 말투가 달라졌는지 확인 |
| Business·Enterprise | GPT-6.2 Sol 배포됨 | 사내 가이드·프롬프트 문서의 모델명 갱신 |
| Free·Go | **아직 GPT-6** | 일정 미공개, 별도 조치 없음 |

Free와 Go는 이번 배포에서 빠졌고, OpenAI는 해당 요금제의 전환 시점을 밝히지 않았습니다. 무료로 쓰는 입장에서는 당장 바뀌는 게 없다는 뜻이고, 유료 사용자는 이미 모델이 바뀐 상태로 대화를 이어가고 있다는 뜻입니다.

### 개발자·자동화 운영 관점

이번 은퇴는 **ChatGPT 앱 안의 모델 교체**입니다. API 카탈로그의 지원 종료 일정은 별도 문서로 관리되기 때문에, API로 붙여 쓴다면 콘솔의 deprecation 공지를 따로 확인해야 합니다.

자동화 파이프라인을 운영하는 입장에서 진짜 비용은 모델 성능차가 아니라 **회귀 테스트**입니다. 모델명을 고정(pin)해 두면 은퇴 공지마다 파이프라인을 다시 검증해야 하고, 최신 모델을 자동 추종하면 어느 날 갑자기 출력 형식이 달라집니다. 현실적인 타협은 이렇습니다.

- 모델명은 **설정 파일 한 곳**에서만 관리하고, 코드에 하드코딩하지 않기
- 은퇴 공지가 뜨면 **대표 입력 20~30개**로 출력 회귀 테스트 돌리기
- 요약 길이·말투·JSON 키 이름처럼 **형식이 깨지기 쉬운 항목**을 테스트 케이스에 고정
- 챗과 Work/Codex는 **모델이 다르게 움직인다**는 전제로 문서 분리

## 전망 — "두 세대 뒤 은퇴"가 만드는 새 리듬

이번 공지에서 가장 중요한 문장은 은퇴 날짜가 아니라 **원칙**입니다. "새 모델이 나오면 두 세대 전 모델은 정리한다." 이 원칙이 유지되면 모델 수명은 대략 **2~3개월**로 계산됩니다. 실제로 GPT-5.5는 지난 10월 14일 ChatGPT에서 은퇴했고, GPT-5.6은 12월 23일 차례입니다. 석 달 남짓 간격입니다.

여기서 갈리는 지점이 몇 가지 있습니다.

1. **릴리스 속도 vs 사용자 적응 속도** — 모델은 빨리 좋아지는데, 사용자가 프롬프트와 워크플로를 다시 맞추는 속도는 그만큼 빠르지 않습니다. GPT-4o·GPT-4.5·음성 모드 은퇴 때도 같은 반발이 있었고, 이번에도 반복됐습니다.
2. **챗과 Work/Codex의 분리 운영** — 같은 "GPT-6.2"라도 챗용은 대화 최적화, Work·Codex용은 작업 최적화로 갈라집니다. 모델 이름만 보고 같은 성능을 기대하면 어긋납니다.
3. **Free·Go 확대 시점** — 유료 요금제만 먼저 올리고 무료는 GPT-6에 남겨 두는 패턴이 굳어지면, 무료 사용자와 유료 사용자의 체감 격차는 더 벌어집니다.
4. **연산 배분** — "은퇴로 비운 연산을 재분배한다"는 설명은, 앞으로도 신모델이 나올 때마다 구모델 정리가 세트로 따라온다는 신호입니다.

결국 이번 주 뉴스는 **모델 하나가 바뀐 사건**이라기보다, **"모델은 3개월짜리 부품"이라는 운영 방식이 굳어지는 신호**로 읽는 게 맞습니다. 새 모델이 좋아진 건 분명한 사실이고, 그 좋아진 모델을 언제까지 쓸 수 있는지가 앞으로의 진짜 변수입니다.

## 정리 — 12월 23일 전에 할 일

- 챗에서 **GPT-6.2 Sol**로 이미 전환됐는지 확인 (Plus·Pro·Business·Enterprise)
- 문체·요약 길이가 중요한 작업은 **GPT-6.2 Sol로 다시 뽑아 비교**
- Work·Codex에서 **GPT-5.6 Sol·Terra**를 쓰는 워크플로가 있는지 점검
- 자동화 파이프라인의 **모델명 하드코딩** 제거, 회귀 테스트 케이스 정비
- Free·Go 전환 공지가 나오면 일정 재확인

성능이 올라간 건 반가운 일이지만, 챗 기본 모델이 한 세대 넘어간 만큼 **"지금 잘 나오던 결과물"을 한 번 백업해 두는 습관**이 필요해진 시점입니다.
