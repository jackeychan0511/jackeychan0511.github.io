## 1. 요즘 저처럼 "어제 패치했는데 또?" 하시는 분들

요즘 저처럼 **Hermes Agent 업데이트를 매일 쫓아가시는 분들**, 특히 이 블로그처럼 **크론잡 자동 포스팅**을 맡기고 계신 분들 많으시죠. 지난주 Herald 릴리스(v0.20.0) 이후 패치가 **8/13 v0.20.1 → 8/16 v0.20.2 → 8/17 v0.20.3**까지, 하루 걸러 하나씩 나오더니 — **8월 18일(한국시간 오후 4시 26분) v0.20.4**가 또 나왔습니다. 전날 v0.20.3 이후 **하루 만에 ~74개 PR**이 롤업된 거예요.

솔직히 "또 패치? 이번엔 뭐가 달라졌지?" 싶으실 텐데, 이번 v0.20.4를 뜯어보니 **데스크톱을 매일 여는 사람**, **스킬을 자주 설치하는 사람**, **크론잡에 이미지를 붙여 보내는 사람**에게 체감이 큰 수정이 유독 많았습니다. 릴리스 노트 원문과 커밋 로그를 기준으로 하나씩 정리해 봤습니다.

숫자만 보면 v0.20.3(8/16.2 태그, 8/17 배포)보다 규모가 작아 보이지만, **"기능 추가보다 다듬기"에 집중한 패치**라는 점에서 오히려 실사용자에게는 더 반가운 내용이 많습니다. 릴리스 노트 표현을 빌리자면 v0.20.3 이후 병합된 약 74개 PR을 안정 태그로 롤업한 것으로, **데스크톱 경험(글래스 UI·사이드바), Bot Mode 안정화, 보안(스킬 스캔), 자동화(크론 미디어)** 네 축이 핵심입니다.

### ② 핵심 변경 포인트 8가지

1. 데스크톱 **글래스/반투명 표면 작업** — 매트 글래스·프로스트 픽커·macOS 사전선택
2. **탭형 SESSIONS|BOTS 사이드바** + 봇별 **숨김/표시**
3. **Bot Mode 그룹챗 수정** — 장시간 실행 멤버 턴·마크다운 렌더링·크로스머신 라우팅
4. **NVIDIA SkillEvaluator Tier 1 어드바이저리 스캔** — 스킬 설치 시 라이선스·보안 검사
5. **크론 미디어 전송 하드닝** — 설정 가능한 타임아웃·수동 실행 첨부·missed-fire 표면화

7. **`hermes update` parked-branch 정직성** — 업데이트 상태를 속이지 않음
8. **칸반 네이티브 OS 알림**

이 중에서 제 기준 **가장 체감 큰 3가지**(글래스 UI, 스킬 보안 스캔, 크론 미디어 하드닝)를 중심으로 자세히 풀어보겠습니다.

## 3. 데스크톱 글래스/반투명 UI — "창이 유리처럼" 바뀌는 디테일

### ① 매트 글래스·프로스트 픽커·macOS 사전선택

이번 v0.20.4의 데스크톱 작업 중 가장 눈에 띄는 건 **글래스(Glass)/반투명 표면(translucency) 작업**입니다. 릴리스 노트에는 **matte glass(매트 글래스), frost picker(프로스트 픽커), macOS pre-select(macOS 사전선택)** 세 가지 키워드가 함께 묶여 있는데요.

- **매트 글래스** — 단순히 투명한 게 아니라 **표면에 매트(무광) 처리된 유리 질감**으로, 뒤에 있는 창이 비치되도 텍스트 가독성이 떨어지지 않게 하는 방식입니다.
- **프로스트 픽커** — 유리 효과의 **흐림(프로스트) 정도를 고르는 UI 컨트롤**이 추가된 것으로 보입니다. 취향껏 "맑은 유리 ↔ 뿌연 유리" 사이를 조절할 수 있게 됐다는 뜻이에요.
- **macOS 사전선택** — macOS에서는 **시스템 기본값(다크/라이트 모드 등)에 맞춰 글래스 스타일을 자동으로 미리 골라주는** 동작이 들어갔습니다.

솔직히 이건 "기능"이라기보다 **분위기**에 가까운 변화라, "에이전트가 뭘 더 잘하게 됐나"를 기대하신 분들께는 실망일 수도 있어요. 다만 **매일 아침 데스크톱을 여는 사람** 입장에서는, 하루 종일 쳐다보는 창이 유리처럼 반투명해지고 흐림 정도를 내 취향에 맞출 수 있다는 것 자체가 꽤 기분 좋은 변화입니다. 예전처럼 "윈도우는 그냥 네모난 판"이 아니게 되는 거죠.

### ② 탭형 SESSIONS|BOTS 사이드바 — 봇이 많아지면 필요한 관리

같은 맥락에서 **사이드바가 SESSIONS|BOTS 탭 구조**로 바뀌었습니다. v0.20.3에서 Bot Mode가 기본 탑재되면서 봇 로스터가 세션 목록과 한 화면을 공유했는데, 봇이 5~10개가 넘어가면 **"내 대화는 어디 있고 봇은 어디 있지?"** 하기 쉬웠거든요. 이제 탭으로 분리되고, **봇별 숨김/표시(hide/unhide)**까지 지원해서 로스터가 지저분해지는 걸 막을 수 있습니다.

## 4. Bot Mode 그룹챗 수정 — "장시간 턴·마크다운·크로스머신" 3종 세트

v0.20.3에서 기본 탑재된 Bot Mode의 **그룹챗 안정화**도 이번 패치의 주요 축입니다. 릴리스 노트에 명시된 세 가지 수정이 특히 의미 있는데요.

1. **장시간 실행 멤버 턴(long-running member turns)** — 봇 하나가 오래 생각하는 동안 그룹챗 전체가 멈추거나 타임아웃되던 문제 수정
2. **마크다운 렌더링(Markdown rendering)** — 그룹챗에서 봇들이 주고받는 마크다운(코드 블록·표 등)이 제대로 렌더링되도록 수정
3. **크로스머신 라우팅(cross-machine routing)** — 다른 PC·Hermes Cloud에 있는 봇(@name-device 핸들)으로 메시지를 넘길 때 라우팅이 꼬이던 문제 수정

저처럼 **"봇 3~4마리를 팀으로 굴려서 아침 브리핑을 만들게"** 하는 분들께는, v0.20.3에서 기능이 생겼다면 이번엔 **그 기능이 실제로 돌아가게** 된 느낌입니다. 아직 "실시간 인터럽트"가 안 되는 건 v0.20.3 때와 동일하지만, **긴 작업 중 멈춤·렌더링 깨짐·라우팅 오류**라는 실제 사용 중 부딪히는 문제들이 줄었다는 점이 반갑습니다.

## 5. NVIDIA SkillEvaluator Tier 1 스캔 — "스킬 설치 전에 검사부터"

이번 패치에서 제가 **기능적으로 가장 반가웠던** 변경입니다. **NVIDIA SkillEvaluator의 Tier 1 어드바이저리 스캔**이 **스킬 설치 시점**에 돌아가기 시작했는데요.

쉽게 말하면:

- 스킬(에이전트의 재사용 가능한 지식·도구 묶음)을 설치할 때, 이제 **라이선스 검사 + 보안 검사**가 자동으로 실행됩니다.
- **Tier 1 어드바이저리(advisory)**는 "설치를 막는" 강제 검사가 아니라 **"경고를 먼저 보여주는"** 참고용 검사라는 뜻입니다. 라이선스가 애매하거나 보안상 위험 신호가 보이면 **설치 전에 어드바이저리(권고)를 띄워주는** 방식이에요.
- NVIDIA의 스킬 검증 기술(SkillEvaluator)이 에이전트 생태계의 스킬 설치 파이프라인에 결합된 첫 사례라는 점에서, **오픈소스 에이전트의 '앱 스토어 심사' 같은 안전망**이 생기기 시작했다고 볼 수 있습니다.

솔직히 저는 스킬을 커뮤니티에서 받아 쓸 때 **"이거 뭘 하는 코드인지 모르고 넣는"** 경우가 많았는데, 설치 단계에서 라이선스·보안 어드바이저리가 뜨면 **한 번 더 생각하게 되는** 장치가 생긴 셈입니다. 아직 Tier 1(권고) 수준이지만, v0.21.0에서 더 강한 단계가 붙을 가능성도 있어서 지켜볼 만합니다.

## 6. 크론 미디어 전송 하드닝 — "알림에 붙인 사진이 씹히던 문제"

이 블로그처럼 **크론잡이 완료 알림에 이미지·파일을 붙여 보내는** 자동화를 돌리시는 분들, 공감되실 텐데요. 가끔 **알림에 첨부한 사진/파일이 전송되지 않거나**, **첨부 때문에 잡 전체가 타임아웃** 되는 일이 있었습니다. 이번 v0.20.4의 크론 미디어 전송 하드닝은 정확히 그 지점을 겨냥합니다.

| 시나리오 | 수정 내용 |
|:----|:------|
| **미디어 전송 타임아웃** | 전송 시간 제한을 **설정 가능(configurable)**하게 변경 — 느린 업로드에 잡이 통째로 죽는 문제 방지 |
| **수동 실행 시 첨부** | 크론잡을 수동 실행(manual run)할 때도 **미디어 첨부가 정상 동작**하도록 수정 |
| **missed-fire 표면화** | 실행을 놓친 잡(missed-fire)의 **미디어 전송 상태도 놓치지 않고 표면화** |

특히 **타임아웃을 설정할 수 있게 된 것**이 체감이 큽니다. 예전엔 "이미지 3장 붙이면 잡이 죽는" 상황이 오면 로그를 뒤져서야 알았는데, 이제는 **내 환경(네트워크·파일 크기)에 맞게 타임아웃을 조정**할 수 있어서, v0.20.3에서 들어온 크론 셀프힐(EMFILE·고아 클레임·wedged 잡 복구)과 합쳐지면 **"조용히 죽는 크론잡" 문제가 사실상 한 겹 더 줄어든** 느낌입니다.

## 7. 기타 — SessionDB·hermes update·칸반 알림 (소소하지만 확실한 수정들)

- **SessionDB 이벤트 루프 스레드·경합 수정** — 세션 데이터베이스(SessionDB)가 **이벤트 루프 스레드에서 돌던 문제와 동시성 경합(contention)**을 고쳤습니다. 세션이 많아질수록 멈칫거리던 느낌이 줄어드는 쪽으로 가는 수정이고, 게이트웨이 `/loop` 경로도 SessionDB 캐시를 오프루프에서 미리 데우도록 바뀌었습니다. 저처럼 **세션을 수십 개 쌓아두는** 사람에게 반가운 안정화입니다.
- **`hermes update` parked-branch 정직성** — 업데이트 중 **parked branch(작업 중 멈춰둔 브랜치)** 상황에서 상태를 **정직하게 보고**하도록 수정됐습니다. "업데이트 완료"라고 뜨는데 실제로는 반쯤 멈춰있는, **거짓 완료 메시지**가 사라진다는 뜻입니다. 자동화로 `hermes update`를 돌리는 분들께 특히 중요한 수정이에요.
- **칸반 네이티브 OS 알림** — 칸반(kanban) 작업이 완료되거나 상태가 바뀌면 **OS 네이티브 알림**이 뜹니다. 에이전트가 칸반으로 작업을 관리하는 워크플로우를 쓰는 분들은 "탭 안 들여다봐도 끝난 걸 안다"가 됩니다.

## 8. 솔직한 장단점 — v0.20.4를 쓰면서

### 👍 장점

1. **크론 미디어 전송 하드닝** — 첨부가 씹히거나 잡이 죽던 문제를 정조준. 자동 포스팅 블로거에겐 이번 패치 최고의 선물
2. **SkillEvaluator Tier 1 스캔** — 스킬 설치 시 라이선스·보안 어드바이저리가 뜨는 것만으로도 "무심코 설치"를 한 번 막아줌
3. **글래스 UI + 탭형 사이드바** — 매일 여는 앱의 분위기와 정리 상태가 확 달라짐. 봇이 많아진 사람에겐 숨김/표시가 실용적
4. **Bot Mode 그룹챗 3종 수정** — 기능이 "생긴 것"에서 "도는 것"으로. 팀 봇 워크플로우의 신뢰도 상승
5. **`hermes update` 정직성** — 자동 업데이트를 믿고 맡기는 사람에게 "거짓 완료"가 사라진 건 큰 안정감

1. **글래스 UI는 취향 영역** — 반투명이 오히려 어지럽게 느껴지는 사람도 있음. 그래서 프로스트 픽커로 조절할 수 있게 된 게 다행
2. **SkillEvaluator는 아직 Tier 1(권고)** — 설치를 막는 강제 검사가 아니어서, "경고만 보고 넘어가면 그만"인 단계
3. **큐레이티드 릴리스 노트는 여전히 v0.21.0까지 대기** — 지금은 릴리스 노트 원문과 커밋 로그로 갈음해야 함
4. **하루 단위 패치가 이어짐** — v0.20.2→3→4가 사흘 연속. 빠른 건 좋지만 변경 추적·검증 부담은 따라옴
5. **크론 미디어 타임아웃 설정 위치** — "설정 가능"해졌지만 어디서 어떻게 바꾸는지 문서화가 아직 얕아서, `hermes cron edit` 화면을 뒤져야 할 수 있음

## 9. 마무리 — 업데이트 방법과 사용 팁

정리하면, v0.20.4의 키워드는 **"다듬기(finishing)"**입니다. v0.20.3이 '기능을 쏟아냈다'면, 이번엔 **데스크톱 경험(글래스 UI·사이드바), 팀 봇(그룹챗 수정), 안전망(스킬 스캔·크론 미디어), 내부 안정화(SessionDB·업데이트 정직성)**를 다듬은 패치예요. 신기능보다 **"매일 쓰는 게 더 편해지는"** 변화라, 저처럼 데스크톱 + 크론잡 조합으로 쓰시는 분들께 특히 추천드립니다.

업데이트는 여전히 한 줄이면 끝입니다.

```
# 기존 설치 업데이트
hermes update
# 새로 설치 (공식 인스톨러)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

**사용 팁 3가지:**

1. **크론잡이 이미지를 붙여 보내는데 가끔 씹힌다면** — 업데이트 후 `hermes cron edit <잡>`에서 **미디어 전송 타임아웃을 확인**해 보세요. 네트워크가 느린 환경이면 기본값보다 넉넉히 잡아주는 게 안전합니다.
2. **커뮤니티 스킬을 자주 설치한다면** — 설치 시 뜨는 **SkillEvaluator 어드바이저리(라이선스·보안 경고)**를 한 번 더 읽는 습관을 들여보세요. Tier 1이라 막아주진 않지만, "이 스킬이 뭘 하는지" 다시 보게 해줍니다.
3. **봇이 많아서 로스터가 지저분하다면** — **SESSIONS|BOTS 탭 분리 + 봇별 숨김/표시**를 활용해서 자주 쓰는 봇만 앞에 두세요. 그룹챗도 장시간 턴 수정 덕분에 훨씬 안정적으로 돌아갑니다.

솔직히 저처럼 **"알림에 붙인 이미지가 씹히지 않았으면"**, **"스킬을 마음 편히 설치하고 싶은"** 분들, 그리고 **데스크톱을 매일 여는 사람**이라면 이번 v0.20.4 업데이트, 생각보다 체감이 큽니다. 가성비 좋은(사실상 무료인 MIT) AI 에이전트 찾는 분께 추천드리며, v0.21.0의 큐레이티드 노트가 나오면 또 정리해 올게요!
