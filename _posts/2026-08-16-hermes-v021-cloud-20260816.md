## 1. 요즘 저처럼 "AI 에이전트를 24시간 돌리고 싶은데 서버가 부담"이신 분들

요즘 저처럼 **AI 에이전트를 매일 쓰시는 분들**, 특히 이 블로그처럼 **크론잡 자동 포스팅을 Hermes Agent로 돌리시는 분들** 많으시죠. 저도 이 블로그의 자동 포스팅 일부를 Hermes Agent 크론잡으로 돌리고 있는데, 늘 고민이 하나 있었습니다. **"내 맥북이 켜져 있을 때만 일하는 에이전트"**라는 한계요. 집을 비우거나 노트북을 닫으면 크론잡이 멈추니까, \"에이전트를 24시간 상시 가동하려면 VPS를 파야 하나, systemd를 만져야 하나\" 하는 게 숙제였습니다.

그런데 지난주부터 상황이 확 바뀌었습니다. **8월 3일 v0.20.0 Herald 릴리스**(대화형 음성·A2A v1.0)에 이어 **8월 13일 v0.20.1 안정화 패치**가 나왔고, 7월 8일 발표된 **Hermes Cloud 프리뷰**가 '2클릭·60초 배포'로 이 고민을 정면으로 해결해 주는 중입니다. 게다가 8월 7일에는 **Hermes Agent가 OpenRouter에서 주간 1.5조 개 토큰**을 찍으며 전체 앱 49개의 합계와 맞먹는 기록을 세웠다는 뉴스까지. 최신 소식 3개를 한 번에 정리해 봤습니다.

### ② 실사용자가 체감할 만한 포인트

이번 패치의 특징은 **"기능이 아니라 견고함"**입니다. 저처럼 크론잡으로 매일 자동 포스팅을 돌리는 입장에서 짚어보면:

- **데스크톱 앱 안정화** — 멀티 GUI 창·아티팩트·플러그인 SDK 등 v0.20.0에서 추가된 워크벤치 기능들의 엣지 케이스가 대거 정리됨
- **게이트웨이 플랫폼 수정** — 텔레그램·디스코드·슬랙 등 메신저 게이트웨이의 연결 안정성 개선
- **인스톨러·툴 시스템·프로바이더 카탈로그** — 설치 경로와 모델/도구 목록의 최신화

솔직히 **"10일 만에 656개 PR"이라는 개발 속도** 자체가 이 프로젝트의 체력을 보여주는 지표입니다. 참고로 **큐레이티드 릴리스 노트(하이라이트·기여자 크레딧 포함)는 v0.21.0에서 v0.20.0부터 전부 묶어서 발행**된다고 하니, 자세한 기능 정리는 그때 다시 정리해 드릴게요.

## 3. Hermes Cloud 프리뷰 — 2클릭·60초면 '상시 가동 에이전트'가 생깁니다

### ① 이게 왜 중요한가 — '내 컴퓨터가 꺼져도 일하는 에이전트'

제 첫머리 고민("맥북 꺼지면 크론잡 멈춤")을 정확히 겨냥한 게 **Hermes Cloud**입니다. 7월 8일 누스 리서치가 발표한 관리형 클라우드 서비스로, **누스 포털(Nous Portal)에서 2클릭, 약 60초면 상시 가동(always-on) 에이전트가 배포**됩니다. VPS도 SSH도 systemd도 필요 없어요.

핵심 구조를 정리하면:

- **배포·스케줄링** — 에이전트가 24시간 가동되며, 활동량에 따라 컴퓨트가 자동 증감 (유휴 시 **scale-to-zero**)
- **채널 커넥터** — 텔레그램·디스코드·슬랙·이메일·CLI에서 같은 에이전트에 네이티브로 접근
- **샌드박스** — 에이전트마다 격리된 하드닝 환경에서 실행
- **영구 메모리** — 콜드 스타트나 스케일-투-제로가 돼도 대화 이력·도구 컨텍스트가 유지

![Hermes Cloud 히어로 이미지](/assets/images/posts/hermes-v021-cloud-20260816/cloud-hermes-cloud-hero.jpg)
*Hermes Cloud 프리뷰 — 누스 포털에서 배포하는 상시 가동 에이전트 컨셉 (출처: agentos.guide Hermes Cloud 가이드, 2026-08-16 확인)*

### ② 가격 구조 — 유휴 $0, 중단 시 스토리지 전용 요금

가격 정책이 솔직히 가장 궁금했던 부분인데, 공식 제품 페이지 기준 이렇게 정리됩니다.

| 항목 | 내용 |
|:----|:------|
| **배포 조건** | 크레딧 **최소 $10** 또는 활성 구독 필요 |
| **가동 중** | 에이전트가 실제로 일하는 동안만 과금 |
| **유휴 시** | **$0** (스케일-투-제로) |
| **중단 시** | **스토리지 전용 요금** — 메모리는 유지하되 컴퓨트 비용 없음 |

즉 **"쓰는 만큼만 내고, 안 쓰면 0원, 멈추면 보관비만"** 구조입니다. 다만 솔직히 단점도 있는데, **시간당 요율·인스턴스 규모가 아직 공개되지 않았고**(포털 FAQ 일부가 Cloudflare 인증 뒤에 있음), 전용 문서 페이지도 아직 없습니다. 프리뷰 단계라 **문서가 기능을 쫓아가지 못하는** 상황이에요. 예산을 정밀하게 잡아야 하는 팀이라면 이 부분은 좀 답답할 수 있습니다.

### ③ 최신 패치 — 데스크톱 자동 발견 + 콜드스타트 수정

클라우드도 계속 업데이트 중입니다.

- **7월 10일** — Hermes Desktop이 누스 포털 로그인 시 **클라우드 에이전트를 자동 발견**하기 시작
- **8월 14일** — **PR #86477** 병합: 콜드스타트 시 클라우드 에이전트가 포털 재로그인 전까지 안 보이던 버그(이슈 #73495) 수정. 새로 프로비저닝한 에이전트가 데스크톱에 즉시 표시됩니다

## 4. OpenRouter 주간 토큰 1.5조 개 — "에이전트가 사람을 추월한 숫자"

8월 7일, 또 하나 의미심장한 뉴스가 나왔습니다. **Hermes Agent가 OpenRouter에서 주간 1.5조 개 토큰을 처리**했는데, 이게 **플랫폼에서 추적되는 다른 앱 49개의 합계와 거의 맞먹는 수치**라는 겁니다.

- **누적 토큰 33.1조 개** (2026년 3월 출시 이후) — OpenRouter 글로벌 일일 랭킹 1위
- **407개 모델 활용** — 단일 백본에 의존하지 않고 작업별로 모델을 골라 쓰는 구조
- **에이전트 > 사람** — OpenRouter에서 에이전트가 인간 대화를 토큰 사용량으로 추월. 에이전틱 워크플로우(도구 호출·추론·멀티스텝)가 대화형 사용보다 토큰을 몇 배로 소모하는 구조적 변화의 신호입니다

![OpenRouter GitHub 소셜 카드](/assets/images/posts/hermes-v021-cloud-20260816/openrouter-github-og.png)
*OpenRouter 공식 GitHub 저장소 소셜 카드 — 통합 AI 추론 라우팅 플랫폼 (출처: github.com/openrouter-ai/openrouter, 2026-08-16 확인)*

저처럼 에이전트를 실제 자동화에 붙여 쓰는 입장에서 이 숫자는 꽤 반가운데, **"오픈소스 에이전트가 실제 프로덕션 트래픽을 이만큼 소화한다"**는 생태계의 성숙도를 보여주는 지표거든요. 물론 토큰이 많다고 다 좋은 건 아니고, **"에이전트가 토큰을 태우는 속도 = 비용 관리의 중요성"**도 함께 커진다는 뜻입니다.

## 5. 솔직한 장단점 — v0.20.1 + Hermes Cloud를 쓰면서

### 👍 장점

1. **업데이트가 그냥 '한 줄'** — 기존 설치자는 `hermes update` 한 줄이면 v0.20.1 적용. 10일 만에 656개 PR의 안정화를 따라잡는 게 이렇게 쉽습니다
2. **클라우드 배포 진입장벽이 사실상 사라짐** — VPS·SSH·systemd 없이 2클릭·60초. 제 첫머리 고민이던 "컴퓨터 꺼지면 멈추는 크론잡" 문제가 구조적으로 해결되는 길이 열렸습니다
3. **유휴 $0 요금제** — 안 쓰는 시간에 돈이 안 나가서, 개인 블로거 같은 소규모 사용자도 부담 없이 시도 가능
4. **영구 메모리 + 멀티 채널** — 텔레그램으로 지시하고, 이메일로 결과 받고, 메모리는 클라우드에 유지

### 👎 단점

1. **클라우드 요율·인스턴스 규격 미공개** — 프리뷰라서 시간당 요금이 투명하지 않습니다. 팀 단위 예산 산정엔 아직 정보가 부족해요
2. **전용 문서 부재** — Hermes Cloud 전용 docs 페이지가 아직 없고, 포털 FAQ 일부는 Cloudflare 인증 뒤에 있어 확인이 어렵습니다
3. **v0.21.0까지 큐레이티드 노트 공백** — v0.20.0 이후의 전체 하이라이트 정리는 다음 메이저 릴리스에서 나옵니다. 지금은 릴리스 노트 원문 + 커뮤니티 분석으로 갈음해야 합니다
4. **토큰 사용량 = 비용** — 1.5조 토큰 같은 숫자가 멋지긴 하지만, 개인이 클라우드 에이전트를 막 돌리면 토큰 비용 관리가 새로운 숙제가 됩니다

## 6. 마무리 — 업데이트 방법과 체험 팁

정리하면, 이번 주 Hermes Agent 소식의 키워드는 **"안정화(v0.20.1) + 상시 가동(Hermes Cloud) + 생태계 검증(OpenRouter 1.5조 토큰)"**입니다. Herald 릴리스가 '기능의 폭'을 넓혔다면, v0.20.1은 '견고함'을, Hermes Cloud는 '운영의 자유'를 더하는 흐름이에요.

기존 설치자라면 업데이트는 이 한 줄이면 끝입니다.

```
# 기존 설치 업데이트
hermes update
# 새로 설치 (공식 인스톨러)
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```
