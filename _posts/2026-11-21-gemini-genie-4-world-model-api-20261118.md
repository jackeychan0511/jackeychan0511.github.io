> **📌 한 줄 요약:** 2026년 11월 18일, 구글 딥마인드가 **Genie 4** 월드 모델을 공개했습니다. 19일에는 **Gemini API(Interactions API)와 AI Studio**에 정식으로 열렸습니다. 핵심은 세 가지입니다. **① 720p·24fps 영상에 동기화된 네이티브 오디오**, **② 세션 도중 자연어 프롬프트로 날씨·조명·캐릭터·사건을 즉시 바꾸는 실시간 편집**, **③ 제미나이 추론이 세계 상태를 계속 일관되게 유지**하는 구조입니다. Project Genie에서는 **Google AI Ultra 구독자**가 바로 쓸 수 있고, API는 **유료 티어 전용, 초당 약 0.10달러**입니다.

"월드 모델"이라는 말이 아직 낯설게 느껴지는 분들이라면, 게임 안의 배경을 떠올리면 이해가 빠릅니다. 지금까지 영상 생성 모델은 **끝난 장면을 만들어 주는 방식**이었습니다. 프롬프트를 넣고, 몇 초짜리 클립이 나오고, 마음에 안 들면 다시 뽑는 구조죠. Genie 4는 그 클립을 **끝나지 않는 공간**으로 바꿔 놓았습니다. 화면이 계속 이어지고, 키보드로 걸어 다닐 수 있고, 걷는 동안 "비 와라"라고 입력하면 정말 비가 옵니다.

이 변화가 개발자에게 중요한 이유는 따로 있습니다. **에이전트와 로봇을 학습시킬 때 필요한 '무한히 반복 가능한 환경'** 을 API 한 줄로 빌릴 수 있게 됐기 때문입니다.

구글 딥마인드의 디에고 리바스·파반 쿠마르 그룹 프로덕트 매니저는 블로그에서 **"프로젝트 지니 초기 테스터들이 세계 안에서 일어나는 일에 대한 더 깊은 통제권과, 쉽게 만들고 공유하는 방법을 원했다"** 고 밝혔습니다. 그래서 이번 업데이트는 모델 성능만 올린 게 아니라 **만들고, 공유하고, 리믹스하는 흐름**까지 한 묶음으로 정리했습니다.

## 2. Genie 4가 실제로 달라진 지점

### ① 세션 중간에 세계를 고친다

기존 방식은 "월드를 생성 → 그 안을 탐험"이었습니다. Genie 4는 여기에 **중간 개입**을 넣었습니다. 탐험하는 도중에 프롬프트를 입력하면 날씨가 바뀌고, 캐릭터가 등장하고, 진행 방향이 틀어집니다. 구글 표현대로라면 **"날씨를 바꾸고, 캐릭터를 떨어뜨리고, 사건의 방향을 다시 잡는"** 수준입니다.

### ② 영상과 오디오가 같이 생성된다

이번 버전에서 가장 실질적인 변화는 **네이티브 실시간 오디오**입니다. 화면만 나오고 소리는 따로 입히는 구조가 아니라, **환경음부터 캐릭터 대사까지 장면이 unfolding되는 동안 함께 생성**됩니다. 48kHz 스테레오, 16비트 PCM으로 스트리밍됩니다.

솔직히 이 부분이 실무에서 제일 체감이 큽니다. 데모 영상을 만들 때 화면은 그럴듯한데 소리가 비어 있으면 바로 티가 나거든요. 오디오가 영상과 같은 모델에서 나오면 그 어긋남이 줄어듭니다.

### ③ 상태 일관성은 제미나이가 잡는다

실시간 생성에서 가장 무너지기 쉬운 건 **일관성**입니다. 문을 열고 나갔다가 돌아왔을 때 방 배치가 달라져 있으면 몰입이 깨집니다. 구글은 **제미나이 추론이 세계 상태를 일관되고 정합성 있게 유지한다**고 설명합니다. 1세대 월드 모델들이 "재밌지만 금방 깨지는 데모"였던 지점을 정면으로 건드린 셈입니다.

성능 수치는 **720p 해상도, 24fps, 16:9, 실시간 키보드 조작(WASD·방향키) + 텍스트 이벤트**입니다. 첫 프레임이 나오기까지는 대략 **5~9초**, 이후에는 스트리밍으로 이어집니다.

## 3. Project Genie: 구독자용 창구는 이렇게 바뀌었다

Ultra 구독자가 쓰는 화면 쪽 변화도 꽤 큽니다.

**Project Genie 에이전트**가 생겼습니다. 한 줄 프롬프트로 끝나는 게 아니라, **자연어 대화로 세계를 설계**합니다. 에이전트가 구글의 멀티모달 모델들을 조합해 초기 비주얼과 분위기에 맞는 배경 음악까지 잡아 줍니다. 탐험 중에는 제미나이가 화면을 관찰하면서 **다음에 갈 만한 곳을 제안하는 칩**을 띄우거나, 월드 안 이벤트를 자동으로 발동시킵니다.

**커뮤니티 갤러리**도 열렸습니다. 만든 세계를 올리고, 남의 세계를 리믹스할 수 있습니다. 공개된 예시만 봐도 성격이 드러납니다. 고딕 저택을 방마다 미스터리로 꾸민 *Villa Giallo*(크리에이티브 테크놀로지스트 Will aka BLVCKL!GHT 협업), 개미 시점으로 군체를 누비는 *The Life of Ants*(영화감독 아난드 간디 협업), 개인 사진을 탐험 가능한 공간으로 바꾸는 *Living Memory*, 360도 파노라마로 공룡 서식지를 만드는 *Dino Field Guide* 같은 사례입니다.

한 가지 실용적인 팁. **Genie 4가 최고 화질이지만, Genie 3도 모델 선택기에 남아 있습니다.** 긴 세션(최대 3분, 기존 60초)이나 파노라마 시드가 필요할 때는 Genie 3가 여전히 유효합니다. 3분 세션·월드 체이닝·360도 파노라마 그라운딩·실시간 이벤트는 이번에 Genie 3 쪽에 들어간 업데이트입니다.

## 4. 개발자에게 열린 창구 — 요금과 함정

여기가 이번 소식의 핵심입니다. Genie 4는 **Interactions API(v1beta)** 를 통해 제공됩니다. 텍스트 프롬프트, 16:9 참조 이미지, 또는 둘 다로 월드를 시드하고, **WebRTC(브라우저) 또는 WebSocket(Python·Node.js)** 으로 붙습니다.

| 항목 | 값 |
|---|---|
| 해상도·프레임 | 720p, 24fps, 16:9 |
| 오디오 | 48kHz 스테레오(영상에 포함) |
| 입력 요금 | 100만 토큰당 **$1.50** |
| 텍스트 출력 | 100만 토큰당 **$9.00** |
| 비디오 출력 | 100만 토큰당 **$17.50** (초당 약 **$0.10**) |
| 프레임당 토큰 | **240개** (24fps에서 초당 5,760토큰) |
| 이용 조건 | **유료 티어 API 키 필수** |
| 서빙 리전 | 미국·서유럽·일본 |

숫자로 환산하면 감이 옵니다. **1분 세션이 약 6달러, 10분이면 약 60달러**입니다. 영상 생성 API를 시간 단위로 빌리는 셈이니, "일단 켜 두고 보자" 식으로 접근하면 청구서가 무서워집니다.

> **⚠️ 과금이 새는 지점 — 문서에 명시된 함정**
> 브라우저 탭을 닫거나 로컬 블록을 빠져나가도 **서버 생성이 즉시 멈추지 않습니다.** 트랜스포트만 분리될 뿐입니다. 반드시 `session.complete()`를 호출해서 세션을 종료해야 과금이 끝납니다. 자동화 파이프라인에 붙일 때 이 한 줄을 빼먹으면, 아무도 안 보는 화면에 돈이 계속 나갑니다.

**리전 레이턴시**도 설계에 영향을 줍니다. Genie 4는 미국·서유럽·일본 데이터센터에서 서빙합니다. 북미·서유럽·동아시아에서는 **150ms 이하 왕복 지연**이 기대되지만, 그 밖의 지역에서는 키보드 조작 반응이 늦어져 체감 프레임이 떨어질 수 있습니다. 한국에서 테스트한다면 일본 리전 경유가 사실상 기본값이라고 보면 됩니다. 반응 속도가 중요한 조작을 붙일 때는 **타깃 지역에서 WebRTC 지연을 먼저 재 보는 것**이 순서입니다.

**키 관리**도 짚어 둘 만합니다. 브라우저 클라이언트에는 장기 키를 넘기지 말고, 서버에서 `interactions.create` 후 **단일 세션용 임시 토큰**을 발급해 내려보내는 구조가 권장됩니다. 실시간 세션은 길게 열려 있기 때문에, 키가 한 번 새면 피해 시간도 그만큼 길어집니다.

## 5. 그래서 어디에 쓸 수 있나

구글이 직접 제시한 용도는 세 가지입니다. **인터랙티브 경험 프로토타이핑, 공간·설계 개념의 시각화, 로보틱스와 AI 에이전트 학습**. 세 번째가 업무 자동화 쪽에서 가장 현실적인 접점입니다.

- **에이전트 평가 환경**: 실제 서비스에 붙이기 전에, 통제된 3D 공간에서 이동·조작·판단 루프를 반복 학습시키는 용도. 같은 공간을 몇 번이고 되감아 쓸 수 있다는 게 핵심입니다.
- **로보틱스 시뮬레이션**: 카메라 입력과 조작 반응을 실시간으로 주고받아야 하는 작업. 다만 물리 정확도는 아직 연구 단계라는 전제가 붙습니다.
- **공간 기획 검토**: 인테리어·전시·매장 동선을 도면 대신 **걸어 보는 형태로** 검토. 클라이언트 앞에서 "여기 벽을 없애면"을 즉석에서 보여 줄 수 있습니다.
- **콘텐츠 제작**: 게임 배경 컨셉, 뮤직비디오 배경, 교육용 탐험형 콘텐츠의 초안 뽑기.

## 6. 아직 남은 것들

구글 스스로 인정한 한계가 분명합니다. **카메라 레이턴시, 복잡한 물리 상호작용, 실시간 오디오 정밀도, 장기 장면 영속성**은 여전히 풀어야 할 과제입니다. 즉 지금의 Genie 4는 **"완성된 게임 엔진"이 아니라 프런티어 연구의 결과물**입니다. 물체를 집어 던지고 쌓는 수준의 상호작용을 기대하면 실망할 가능성이 큽니다.

안전장치 쪽은 **SynthID 워터마킹**이 모든 영상·오디오 출력에 들어가고, 모델 입출력 전체가 안전 심사를 거칩니다. 실사에 가까운 합성 영상이 실시간으로 나오는 만큼, 워터마크가 기본값이라는 점은 기억해 둘 만합니다.

접근 범위도 좁습니다. Project Genie는 **Ultra 구독자**부터이고, **AI Pro 구독자는 대기자 명단**입니다. API는 유료 티어 전용입니다. "일단 무료로 써 보고 판단"이 안 되는 구조라는 뜻입니다.

## 7. 전망

이번 발표에서 읽어야 할 신호는 **모델 성능이 아니라 배포 방식**입니다. 구글은 같은 주에 **Gemini 4 Neon GA(11월 18일)**, **Genie 4 GA**, **Tool Retrieval 프리뷰(11월 19일)**, **오피스 문서·스프레드시트·영상 구간 슬라이싱(11월 18일)** 을 연달아 내놨습니다. 모델을 하나씩 크게 발표하는 대신, **API 표면을 빠르게 넓히는 국면**입니다.

앞으로 지켜볼 지점은 세 가지입니다.

1. **가격**: 초당 0.10달러는 프로토타이핑엔 부담스럽고, 대량 평가엔 여전히 비쌉니다. 배치·캐싱 할인이 붙는지가 관건입니다.
2. **리전 확대**: 한국이 서빙 리전에 들어오느냐. 지금은 일본 리전 의존이라 왕복 지연이 조작감을 좌우합니다.
3. **물리 정확도**: 로보틱스 학습용으로 쓰려면 중력·충돌·마찰이 믿을 만해야 합니다. 구글이 "연구 단계"라고 선을 그은 부분입니다.

- **API로 붙여 볼 생각이라면** 세션 길이를 먼저 정하세요. 1분 6달러라는 숫자가 예산 설계의 출발점입니다.
- **파이프라인에 넣을 거라면** `complete()` 호출을 종료 조건에 반드시 묶으세요. 탭을 닫는 것과 세션을 끝내는 것은 다릅니다.
- **로보틱스·에이전트 학습이 목적이라면** 지금은 파일럿 단계가 맞습니다. 물리 정확도가 아직 연구 단계라는 점을 전제로 잡으세요.

생각보다 실용적인 건 **Genie 3의 3분 세션과 360도 파노라마 그라운딩**입니다. 최신 모델만 쫓지 말고, 목적에 따라 모델 선택기를 바꿔 쓰는 편이 비용과 결과 모두에서 낫습니다. 실시간 합성 환경이 필요했던 분들이라면, 이번 주가 첫 삽을 뜨기 좋은 시점입니다.
