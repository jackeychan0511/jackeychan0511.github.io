> **📌 한줄 요약:** 2026년 **10월 28일(현지시간)** OpenAI API 변경로그에 **ChatGPT Pro·Business 구독자 대상 월 최대 500달러 API 크레딧** 혜택이 게시됐고, 29일부터개발자 커뮤니티와 외신 보도로 빠르게 확산됐습니다. **Pro 100·200·500 등급은 각각 100·200·500달러**, **Business는 Standard 좌석당 20달러·Premium 좌석당 100달러**(워크스페이스당 월 500달러 상한)입니다. 핵심은 **"구독료 안에서 API까지 쓴다"**는 구조라는 점입니다. 다만 **월 단위로 소멸하고 이월되지 않으며, API 키로 쓰는 Codex 사용량은 제외**됩니다.

## 1. 무슨 일이 있었나 — "구독에 API 크레딧이 붙었다"

AI 에이전트를 실사용하고 자동화 파이프라인을 운영하는 입장에서, 이번 소식은 모델 출시만큼 체감이 큰 변화입니다. 지금까지 ChatGPT 구독과 OpenAI API는 **완전히 별개의 지갑**이었습니다. 채팅으로 쓰는 구독료와, 코드에서 호출하는 API 종량제 요금이 따로 청구되는 구조였죠. 이번 변경으로 **구독 하나로 API 결제까지 커버**할 수 있는 경로가 열렸습니다.

공식 문서 기준 핵심 문장은 이렇습니다.

> "Eligible ChatGPT Pro and Business subscriptions can claim free API credits as part of their subscription benefits." — OpenAI 개발자 문서, *API credits for ChatGPT subscribers*

정리하면 다음과 같습니다.

| 구분 | 내용 |
|:---|:---|
| 공지 시점 | 2026년 10월 28일 (API 변경로그) |
| 적용 대상 | 유료 ChatGPT **Pro**, **Business** 구독 |
| 최대 금액 | **월 500달러** |
| 지급 방식 | 구독 갱신 시 자동 지급 (최초 1회 연결 필요) |
| 사용 기한 | **해당 결제 주기 종료 시 소멸**, 이월 없음 |

중요한 건 "현금으로 500달러를 준다"가 아니라 **연결한 API 조직의 사용액을 크레딧으로 먼저 차감**하는 방식이라는 점입니다. 즉 API 결제수단을 등록하지 않아도, 크레딧이 살아 있는 동안은 API를 호출할 수 있습니다.

## 2. 등급별 지급액 — 숫자는 단순하지만 조건이 붙는다

가장 많이 궁금해할 부분입니다. 공식 문서에 명시된 지급액은 아래와 같습니다.

| ChatGPT 구독 | 월 API 크레딧 |
|:---|:---|
| Pro (100달러 등급) | 100달러 |
| Pro (200달러 등급) | 200달러 |
| Pro (500달러 등급) | 500달러 |
| Business Standard | 유료 Standard 좌석당 20달러 |
| Business Premium | 유료 Premium 좌석당 100달러 |

Business는 좌석 단가로 계산해 **워크스페이스 단위로 합산(pooling)** 되고, **월 500달러 상한**이 걸립니다. 예를 들어 Standard 좌석 3개 + Premium 좌석 2개를 운영하면 20×3 + 100×2 = **260달러**가 매달 풀에 쌓이는 구조입니다. 연간 선결제 워크스페이스는 **연간 지급분을 한 번에** 받는 대신, 그 크레딧은 **연간 결제 주기가 끝날 때 소멸**합니다.

### 자격 요건 — 생각보다 까다롭다

- **유료 Pro 또는 Business 구독**이어야 하고, **구독 경과 7일 이상**이어야 합니다. 무료 체험·프로모션 구독은 제외입니다.
- **ChatGPT 구독(또는 Business 워크스페이스)의 소유자**이면서 **크레딧을 받을 API 조직의 소유자**여야 합니다. 즉 팀원 계정으로는 신청 자체가 어렵습니다.
- **ChatGPT 계정과 API 계정의 이메일 주소가 같아야** 합니다. 이 조건에서 막히는 분들이 꽤 나올 겁니다 — 개인 이메일로 구독하고 회사 이메일로 API를 쓰는 조합은 그대로는 연결되지 않습니다.
- **Enterprise는 대상이 아닙니다.** Business에서 Enterprise로 전환하면 링크가 결제 주기 말에 해제됩니다.

### 신청 경로는 두 갈래

1. **ChatGPT에서 시작**: 설정 → Billing에서 API 크레딧 혜택을 찾아 연결 (Business는 워크스페이스 결제 설정 또는 Admin Console)
2. **API 플랫폼에서 시작**: platform.openai.com 로그인 → Billing → 크레딧 혜택에서 구독 선택 후 연결

어느 쪽으로 들어가든 **동일한 구독 혜택을 하나의 API 조직에 연결**하는 절차입니다. 연결 후에는 API 플랫폼의 Billing 화면에서 잔액을 확인할 수 있습니다.

## 3. 무엇까지 결제되나 — 커버 범위와 제외 범위

"API 크레딧"이라고 하면 텍스트 생성만 떠올리기 쉽지만, 공식 문서가 명시한 범위는 꽤 넓습니다.

| 구분 | 내용 |
|:---|:---|
| ✅ 포함 | **Responses API** (텍스트·코드·이미지 이해), **Agents API**(에이전트 실행 및 OpenAI 호스팅 샌드박스 요금), **Decisions API**, **GPT-Live·Realtime API**(실시간 음성), **Images API**, **내장 도구**(웹 검색, 파일 검색, Code Interpreter 등 사용·저장 요금), 그 외 API 플랫폼 과금 |
| ❌ 제외 | **API 키를 통한 Codex 사용** |

특히 **Agents API의 호스팅 샌드박스 요금까지 포함**된다는 점이 실무적으로 의미가 큽니다. 에이전트를 상시 돌리는 구조에서 샌드박스 실행 비용이 은근히 붙는데, 이 부분이 크레딧으로 커버되는지는 비용 설계에직접 영향을 줍니다.

반대로 **API 키로 Codex를 호출하는 사용량은 이 혜택에서 빠집니다.** 또 크레딧이 쌓인다고 해서 **ChatGPT나 로그인 상태의 Codex 사용 한도가 올라가지는 않습니다.** 이 둘은 완전히 별개 계량입니다.

## 4. 실전에서 돈 새는 지점 — 5가지 주의사항

솔직히, 혜택 자체는 좋지만 **구조를 모르고 쓰면 체감이 반감**됩니다. 공식 문서에서 확인되는 함정들을 정리했습니다.

**① 무료 크레딧이 먼저 차감되고, 소진되면 요청이 실패한다**
조직에 구매 크레딧이 남아 있으면 그것으로 이어서 과금되지만, **둘 다 없으면 API 요청이 HTTP 429(`credit_balance_exhausted`)** 로 떨어집니다. 자동화 파이프라인이라면 이 에러를 만나는 순간 배치가 통째로 멈춥니다. Auto Recharge를 켜 두거나, 크레딧 잔액 모니터링을 파이프라인에 넣어 두는 편이 안전합니다.

**② 이월이 없다 — "모아뒀다 몰아쓰기"가 안 된다**
미사용 크레딧은 **결제 주기 종료 시 소멸**합니다. 월초에 조용하다가 월말에 대량 배치를 돌리는 패턴이라면, 앞선 주기의 크레딧은 그냥 사라진 셈입니다. 반대로 매달 꾸준히 쓰는 구조라면 사실상 **구독료 인하**와 같습니다.

**③ 크레딧은 '조직'에 귀속된다**
연결한 **특정 API 조직**에만 적용됩니다. 그 조직을 선택하고 **그 조직의 프로젝트 API 키**로 호출해야 반영됩니다. 여러 조직을 쓰는 경우, 크레딧이 붙은 조직과 실제 호출 조직이 어긋나면 혜택을 못 받습니다. 연결 조직 변경은 셀프서비스가 아니라 **지원팀 요청**입니다.

**④ 등급 변경 시 링크가 끊길 수 있다**
Plus·Go·Free로 **다운그레이드하면 결제 주기 말에 조직 링크가 해제**됩니다. 이미 지급된 크레딧은 소멸 시점까지 쓸 수 있지만, 이후 신규 지급은 중단됩니다. Pro에서 Business로 옮기면 **Pro 링크는 종료**되고, Business 구독이 7일 이상 경과한 뒤 워크스페이스 소유자가 **새로 연결**해야 합니다.

**⑤ 10월 29일의 'Pro 한도 2배'와는 다른 이야기다**
같은 주에 OpenAI는 Pro 100·200·500과 Business Premium의 사용 한도를 2배로 올렸습니다. 이건 **ChatGPT·Codex 안에서의 사용량** 이야기이고, 이번 API 크레딧은 **API 결제** 이야기입니다. 두 가지를 같은 혜택으로 착각하면 "왜 API 청구서가 그대로지?" 하는 상황이 생깁니다.

## 5. 영향 — 사용자와 개발자에게 각각 무엇이 달라지나

### 개발자·자동화 운영자
가장 직접적인 수혜입니다. 지금까지는 소규모 자동화를 굴리려면 **구독료 + API 종량제**를 이중으로 부담해야 했습니다. 이번 구조에서는 **구독료 안에서 API 실험·운영 비용 일부가 흡수**됩니다. 특히 프로토타입 단계나 사내 소규모 에이전트 운영처럼 "트래픽은 적지만 꾸준히 도는" 워크로드에 잘 맞습니다.

다만 **API 키 기반 Codex는 제외**이고 **월 단위 소멸**이므로, 대규모 배치나 상시 고부하 워크로드는 여전히 별도 예산 설계가 필요합니다. "무료 크레딧으로 다 커버된다"는 기대는 금물입니다.

### 일반 사용자·기업 구매 담당
일반 ChatGPT 사용자에게는 직접 효과가 거의 없습니다. 반면 기업에서는 **구독과 API를 한 장부에서 관리**할 수 있다는 점이 실무적으로 편합니다. 다만 좌석 단가 기반으로 크레딧이 계산되고 워크스페이스 상한이 500달러이므로, **Premium 좌석을 얼마나 둘지**가 곧 API 예산 설계가 됩니다.

### 업계 맥락 — 번들 크레딧이 '표준'이 되는 중
이번 변화는 OpenAI만의 움직임이 아닙니다. 2026년 10월 초 **Anthropic도 Max·Team 구독에 월 100·200·500달러 상당의 API 크레딧을 붙였습니다**(Team은 좌석 합산, 상한 500달러). 두 회사가 사실상 **같은 구조의 구독-API 번들**로 맞붙은 셈입니다. 표면적 구독료는 그대로인데 **실질 가치가 올라간 가격 경쟁**으로 읽는 편이 정확합니다.

## 6. 전망 — 관전 포인트 세 가지

1. **Enterprise 확대 여부**: 현재 Enterprise는 제외입니다. 대형 고객이 "Business와 같은 혜택"을 요구하면 정책이 넓어질 가능성이 있습니다.
2. **Codex API 포함 여부**: 가장 아쉬운 구멍입니다. API 키 기반 Codex가 포함되면 자동화 개발자에게 체감 가치가 크게 올라갑니다.
3. **이월·누적 정책**: 월 단위 소멸은 OpenAI 입장에서 비용 예측이 쉽지만, 사용자 입장에서는 불리합니다. 경쟁이 심해지면 "일정 기간 이월" 같은 완화 카드가 나올 수 있습니다.

## 7. 정리 — 지금 확인할 체크리스트

- [ ] 내 ChatGPT 구독이 **Pro 또는 Business**이고 **7일 이상** 경과했는지
- [ ] ChatGPT 계정과 API 계정의 **이메일이 동일**한지
- [ ] 크레딧을 받을 **API 조직을 하나로 정했는지** (소유자 권한 포함)
- [ ] **Billing 화면에서 실제 지급액** 확인 (계획 금액과 실제 계정 숫자가 다를 수 있고, 숫자는 계정이 우선)
- [ ] 월 단위 소멸에 맞춰 **Auto Recharge·잔액 모니터링**을 걸어 뒀는지

가성비 좋은 AI 구독을 찾는 분들이라면, 이제는 "월 구독료"만 보지 말고 **구독에 딸린 API 크레딧까지 합쳐서** 실질 가치를 따져야 하는 시점입니다. 자동화 파이프라인을 운영하거나 에이전트를 붙여 보려는 분들께는, 이번 변화가 올해 하반기 가장 실용적인 정책 업데이트 중 하나라고 봅니다.

### 이번 주 함께 나온 소식 (짧게)

- **10월 29일 — Model Spec 개정**: OpenAI가 모델 행동 규범 문서를 **다섯 가지 핵심 가치** 중심으로 재편했습니다. 문서 전체에서 "the assistant" 표현이 **"GPT"** 로 바뀌었고, 자율 에이전트의 판단·감독(oversight) 관련 지침이 보강됐습니다.
- **10월 30일 — GPT-6 Rosalind 공개**: 생명과학 연구 특화 모델로, **승인된 조직 대상 trusted-access 프로그램**을 통해 제공됩니다. 일반 API 카탈로그에서 바로 쓰는 모델은 아닙니다.
