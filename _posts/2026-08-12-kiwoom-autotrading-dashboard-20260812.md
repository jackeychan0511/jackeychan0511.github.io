## 1️⃣ 시작 단계 — 왜 만들었나

주식을 하다 보면 이런 생각이 들 때가 있죠.

- "새벽에 눈 뜨자마자 미국장 확인하는 게 지겹다" 😪
- "급등하는 종목을 놓쳐서 아쉽다"
- "매도 타이밍을 기계적으로 정해두고 싶다"

저는 특히 감정적인 매매를 막고 싶었습니다. 사람은 손실이 커질수록 손절을 미룬다거나, 조금 오르면 바로 팔아버리는 실수를 하기 마련이니까요. 그래서 정한 목표는 이랬습니다.

- ✅ 매매 전략을 규칙으로 정의하고, 규칙이 발동하면 자동으로 주문
- ✅ 잘못된 매매로 큰 손실이 나지 않도록 강력한 리스크 관리
- ✅ 매일 아침 관심종목 리포트를 텔레그램으로 수신
- ✅ 대시보드에서 내 계좌/전략/수익률을 한눈에 확인

## 2️⃣ 기술 스택 선정

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| 백엔드 | Python + FastAPI | 키움 OpenAPI+가 Python 연동을 잘 지원하고, 개발 속도가 빠름 |
| 프런트 | React + Vite + TypeScript | 실시간 데이터를 표로/차트로 깔끔하게 보여주기 좋음 |
| 데이터 저장 | SQLite (SQLModel) | 개인용이면 충분하고 설치/백업이 간단 |
| 매매 연동 | 키움증권 OpenAPI+ (REST + 실시간 웹소켓) | 국내 증권사 API 중 가장 자료가 많고 안정적 |
| 알림 | 텔레그램 봇 | 무료이고 API가 간단, 모바일 알림까지 한 번에 |
| AI 어시스턴트 | Hermes 에이전트 연동 | 대시보드에서 자연어로 잔고/공시/지수 조회 가능 |

> ⚠️ **여기서 가장 중요한 함정 하나!** 키움 OpenAPI+는 TR(Transaction) 요청에 초당 제한이 있습니다. 이 프로젝트에서는 **4 req/s**로 rate limit을 걸어 과도한 요청이 쌓이지 않게 했어요.

## 4️⃣ 메인화면 — 국내·해외 지수

## 8️⃣ 자동매매 엔진 — 전략 프리셋 5종 🎯

자동매매의 핵심! 가격 임계값 트리거 기반으로 전략 프리셋 5종을 만들었습니다.

| 프리셋 | 동작 | 방향 |
|---|---|---|
| ⚡️ 초단타 급등 추격 매수 | 현재가 ≥ 기준가 | 매수 |
| 🛡 초단타 급락 손절 | 현재가 ≤ 기준가 | 매도 |
| 🎯 데이트레이딩 익절 | 현재가 ≥ 기준가 | 매도 |
| 📉 단타 지지선 저점 매수 | 현재가 ≤ 기준가 | 매수 |
| 🌊 스윙 추세 돌파 매수 | 현재가 ≥ 기준가 | 매수 |

![자동매매 화면](/assets/images/posts/kiwoom-autotrading-dashboard-20260812/6.jpg)
*자동매매 설정 화면 — 전략 프리셋과 조건을 등록하는 페이지*

종목과 기준가만 입력하면 1초 만에 규칙이 등록됩니다. 규칙이 발동하면 시장가 주문이 나가고, 실시간 웹소켓 틱을 감시하다가 조건이 맞는 순간 주문을 실행합니다.

```python
# 가격 임계값 트리거 (요약)
if rule.trigger_type == "price_threshold":
    price = latest_price(rule.stock_code)
    if rule.price_operator == ">=" and price >= rule.price_value:
        fire_buy_order(rule)   # 조건 충족 → 자동 매수
    elif rule.price_operator == "<=" and price <= rule.price_value:
        fire_sell_order(rule)  # 조건 충족 → 자동 매도
```

## 9️⃣ 볼린저 밴드 스크리닝 + 승인형 자동매수 📡

여기서부터는 좀 더 고급 기능입니다.

- 평일 15:00 → 거래량 상위 200종목 스캔
- 볼린저 밴드(20, 2) 하단을 이탈 + 거래량 배율 1.2배 이상 → 후보 선정
- 상위 5종목을 대시보드에 표시 → 내가 직접 매수 승인
- 승인된 종목은 익일 개장 첫 틱에 시장가 자동 매수
- 체결 후 익절 +2% / 손절 -3% 매도 규칙이 자동 생성

![볼린저 밴드 차트](/assets/images/posts/kiwoom-autotrading-dashboard-20260812/7.jpg)
*삼성전자 일봉 — MA5/20/60 + 볼린저 밴드(20, 2) 오버레이 (BB 상단 290,466 / 하단 206,262)*

핵심 철학은 "종목 선택은 사람이, 실행은 기계가" 입니다. AI가 고른 종목을 무조건 사는 게 아니라, 최종 결정권은 저한테 있는 구조로 설계했어요. 🧠

## 🔟 수익률 / 보호설정 / 공매도 분석

- 💹 **수익률 카테고리**: 일별/주별/월별/특정기간/누적 수익률을 차트와 표로. 키움의 일별잔고수익률 TR로 과거 잔고 스냅샷까지 조회해 시계열을 구성했습니다.
- 🔒 **보호설정**: 보유 종목에 "보호"를 걸면 자동매매가 그 종목을 절대 매도하지 못함. 봇의 실수 매도를 원천 차단하면서 수동 매도는 그대로 허용하는 안전장치입니다.
- 📉 **공매도현황**: 종목별 공매도 추이(수량·금액·매매비중)를 기간으로 조회. 일별 테이블과 요약 카드로 한눈에 파악됩니다.

## 🛡 리스크 관리 — 이 프로젝트의 자랑 🚨

자동매매에서 가장 중요한 건 "돈을 잃지 않는 장치"라고 생각합니다. 그래서 리스크 가드를 백엔드에 내장했습니다.

| 장치 | 내용 |
|---|---|
| 주문 한도 | 1회 주문 30만원 / 100주 이하 |
| 일일 손실 한도 | 당일 누적 실현손실 20만원 도달 시 전 주문 차단 |
| 쿨다운 | 같은 종목 5초 내 연속 주문 불가 (무한루프 방지) |
| 킬스위치 | 비상 시 원클릭 전체 매매 중지 |
| 안전 기본값 | 서버 시작 시 자동매매 강제 OFF (수동으로 켜야 동작) |
| 속도 제한 | API 요청 초당 4건 제한 |

```python
# 일일 손실 한도 초과 시 차단 (요약)
if state.daily_realized_loss_krw >= settings.daily_loss_limit_krw:
    raise RiskViolation(
        f"당일 누적 실현손실이 한도에 도달해 신규 주문이 차단되었습니다."
    )
```

이 리스크 가드는 자동매매는 물론, 텔레그램 봇 명령에도 동일하게 적용됩니다. 어떤 경로로 주문이 들어와도 안전장치를 우회할 수 없는 구조예요.
