## v2026.8.2 개요 — 2.0의 첫 후속, "2.0을 더 쓸 만하게 다듬은" 패치

먼저 숫자부터. 이번 릴리스는 공식 집계 기준 **신규 기능 18개, 개선 5개, 버그 수정 9개**입니다(릴리스 노트 AI 집계). 배포 시각은 **한국시간 9/2 새벽 1시**(9/1 16:00 UTC)로, 2.0(v2026.8.1)이 8/31 오전에 나온 걸 감안하면 **딱 하루 만의 후속**이에요.

솔직히 "하루 만에 뭐가 그렇게 바뀌었을까" 싶었는데, 릴리스 노트를 읽어보면 이번 업데이트의 성격이 보입니다. 2.0에서 새로 만든 것들을 **실사용 환경에서 더 안정적으로 쓰게** 다듬는 패치예요. 특히:

- 업데이트가 실패해도 **Gateway를 복구**하는 안전장치
- 대화가 **도구 출력에서 멈추던 문제** 수정
- 음성 응답에서 **내부 추론이 새어 나오던 문제** 수정
- 이미지 디코딩 라이브러리(Sharp 0.35.4·libheif 1.23.2) **보안 취약점 수정**

2.0의 화려한 신기능들이 "실제로 매일 쓰면 이렇게 아쉽더라" 하는 부분을 한 번에 걷어낸 느낌입니다. 그럼 하이라이트를 하나씩 볼게요.

## 하이라이트 ① 리눅스 데스크톱 앱 정식 출시 (이번 업데이트의 최대 소식)

솔직히 이번 업데이트에서 **제일 반가운 소식**은 이것입니다. x86-64 리눅스용 데스크톱 앱이 **.deb와 AppImage 두 가지 형태로 정식 출시**됐어요.

- **설치 방식** — 우분투·데비안 계열은 `.deb`(패키지 매니저로 관리), 그 외 배포판은 `AppImage`(파일 하나로 실행)
- **연결** — 로컬 또는 원격 Gateway에 연결
- **Quick Chat** — 시스템 트레이나 **X11 키보드 단축키**로 바로 열리는 퀵 채팅
- **업데이트 신뢰성** — AppImage 업데이트는 **서명 검증(signature-verified)** 을 거치고, .deb는 패키지 매니저 관리 하에 유지됩니다

저처럼 "서버는 리눅스인데 에이전트는 맥에서만 데스크톱 앱으로 쓰고 있다" 하시는 분들에겐, 이제 **리눅스 데스크톱에서도 같은 경험**이 가능해졌습니다. 참고로 이 앱은 Tauri 기반이라 가볍고, Gateway 연결만 되어 있으면 **원격 머신의 에이전트도 로컬 앱처럼** 부를 수 있습니다.

## 하이라이트 ② Home 도크 — 작업 화면을 떠나지 않고 에이전트를 옆에

두 번째는 **Home 도크**입니다. `Cmd/Ctrl+Shift+H`를 누르면 작업 중인 페이지를 그대로 둔 채 **오른쪽이나 아래쪽에 Home 대화가 도킹**됩니다.

- 에이전트가 지금 뭘 하고 있는지(**"Working on" 컨텍스트 스냅샷**) 미리보기
- 필요 없으면 스냅샷 제거, 또는 **선택한 텍스트를 메시지에 첨부**
- 전체 페이지로 열면 작성 중이던 초안·첨부물 유지

브라우저 탭을 왔다 갔다 하지 않고 **문서 작업하면서 옆에 에이전트를 붙여두는** 워크플로가 가능해집니다. 리서치하면서 글 쓰는 저 같은 부류에겐 꽤 쓸모 있어 보였어요.

## 하이라이트 ③ 백그라운드 세션 — "New Session에서 그냥 시작하고 계속 작업"

세 번째는 **백그라운드 세션**입니다. New Session 화면에서 `Cmd/Ctrl+Enter`를 누르면 **페이지를 떠나지 않고** 세션이 백그라운드로 시작됩니다.

- 로컬·클라우드·페어링된 디바이스 배치를 그대로 유지
- 작업 완료 알림에서 바로 해당 세션으로 이동
- `Cmd/Ctrl+Shift+Enter`로 기존 단축키와 충돌 회피 가능

"긴 작업을 에이전트에게 던져놓고 **다른 일을 계속** 하고 싶다" 하시는 분들께 맞는 기능입니다.

## 하이라이트 ④ 더 안전한 업그레이드 — "업데이트 실패해도 Gateway는 살린다"

이번에 제가 **가장 눈여겨본** 부분입니다. 2.0 때 세션 저장소가 SQLite로 바뀌면서 업그레이드·다운그레이드 관련 주의사항이 많았잖아요. v2026.8.2는 그걸 정면으로 다룹니다.

- **최신 설정 보존** — 업데이트가 기존 설정을 덮어쓰지 않음
- **불완전한 세션 마이그레이션 중단** — 반쯤 옮겨진 세션을 "성공"으로 속이지 않음
- **실패 후 복구** — 설치된 패키지나 롤백이 검증된 경우, 멈춘 Gateway를 자동 복구

여기에 업데이트 정리 명령도 추가됐습니다.

```bash
# 마이그레이션 원본 파일 미리보기 (삭제 전 꼭 확인)
openclaw update cleanup --dry-run

# Gateway 중지 상태에서 원본 정리
openclaw update cleanup

# Doctor로 상태 점검
openclaw doctor
```

`cleanup`은 현재 SQLite 히스토리를 보존하지만, **제거된 원본으로의 롤백은 영구히 불가능**해집니다. 그래서 공식 문서도 `--dry-run`으로 먼저 확인하라고 합니다. 업데이트 전 **검증된 백업**은 여전히 필수예요.

## 하이라이트 ⑤ 끝까지 답을 완성하는 응답 + ⑥ 더 안정적인 음성

- **끝까지 답을 완성하는 응답** — 에이전트가 도구를 쓰고 난 뒤 **최종 답변을 끝까지 반환**하고, 실패가 있으면 표면화합니다. 릴리스 노트 설명을 보면 "대화가 도구 출력이나 첫 acknowledgment에서 멈추던 문제"를 고쳤다고 하는데, 에이전트를 실제로 돌려보신 분들은 **이 멈춤 현상** 공감하실 거예요. 생각보다 자주 겪는 문제거든요.
- **더 안정적인 음성** — 내부 추론(reasoning)이 음성으로 새어 나가지 않게 하고, 도구가 생성한 오디오는 그대로 전달합니다. 브라우저 Talk에서 통화 설정 이후 후속 음성 턴이 작동하지 않던 문제도 수정됐습니다.

## 하이라이트 ⑦ 브라우저 제어 + ⑧ 테마 4종 — 그리고 Gateway 없이 Chrome 제어

- **Gateway 없이 브라우저 제어** — 지원되는 macOS·리눅스 Chrome 확장 프로그램 빌드는 **Gateway가 꺼져 있어도** 페어링된 로컬 릴레이를 깨워 인증된 CDP 클라이언트를 받을 수 있습니다(업데이트된 네이티브 호스트 필요).
- **테마 4종** — Control UI를 **CRT, Manuscript, Rosé, Miami** 4가지 테마로 꾸밀 수 있습니다. 오프라인에서도 테마 선택이 유지되고, 리로드 시 잘못된 테마가 번쩍이는 문제도 수정됐어요. 솔직히 CRT 테마는 감성 한 스푼 넣고 싶은 분들께 꽤 인기 있을 것 같습니다.

## 실제 사용감 — 솔직한 장단점

이 블로그의 크론잡 자동포스팅 자체가 AI 에이전트로 돌아가고 있는 입장에서, v2026.8.2 릴리스 노트와 공식 문서를 실측해 보며 느낀 점을 솔직히 정리하면:

**👍 좋은 점**
- **"2.0의 후폭풍"을 한 번에 수습했다** — 업데이트 복구, 멈추던 대화, 음성 추론 노출, 이미지 디코딩 취약점까지. 2.0에서 "아쉽다"고 느꼈던 실사용 문제들이 릴리스 노트에 고스란히 반영되어 있습니다.
- **리눅스 데스크톱 앱이 "정식"이 된 게 크다** — AppImage 서명 검증까지 갖춰서, "리눅스에서 에이전트 데스크톱 경험"을 원했던 분들의 진입장벽이 확 내려갔습니다.
- **세션 정리 UX가 한 단계 성숙** — 대화를 Markdown으로 복사, 탭·창·분할로 열기, 아이콘·색상 편집, 크로스 세션 대화에서 **발신자 표시**까지. 세션을 여러 개 돌리는 파워 유저일수록 체감이 큽니다.

**🤔 아쉬운 점 (솔직히)**
- **세션 가시성 기본값 변경은 반드시 확인 필요** — 이번 업데이트부터 **언샌드박스 세션이 같은 에이전트의 다른 세션과 기본적으로 연동**됩니다(크론 세션 포함). 공유 에이전트를 여러 명이 운영하는 환경이라면 **`tools.sessions.visibility`를 `tree`나 `self`로** 좁혀야 합니다. 기본값이 "넓어졌다"는 건 그만큼 설정을 직접 봐야 한다는 뜻이에요.
- **하루 만의 후속인 만큼 "2.0의 모든 문제"를 고친 건 아니다** — 다운그레이드 시 SQLite 호환 문제 같은 건 여전히 사용자 책임입니다. 업그레이드 전 백업은 이번에도 빠지면 안 됩니다.
- **Linux 앱은 x86-64 전용** — ARM(라즈베리파이 등) 사용자는 아직 데스크톱 앱을 못 씁니다. 공식 문서 기준으로는 x86-64가 대상입니다.

## 업데이트 전 체크리스트

```bash
# 1. 최신 안정판으로 업데이트
openclaw update

# 2. 마이그레이션 원본 정리 전 미리보기 (Gateway 중지 상태에서)
openclaw update cleanup --dry-run

# 3. 세션 가시성 확인 (공유 에이전트 운영자라면)
openclaw config get tools.sessions.visibility
# → tree 또는 self로 좁히는 것을 권장

# 4. 상태 점검
openclaw doctor
```

1. **세션 가시성 기본값 변경** — 언샌드박스 세션이 같은 에이전트의 다른 세션(크론 포함)과 기본 연동됩니다. 혼자 쓰는 환경은 그대로여도, **여럿이 에이전트 하나를 공유**한다면 `tools.sessions.visibility = tree|self` 설정을 권장합니다.
2. **업데이트 전 검증된 백업 필수** — 2.0부터 세션·대화 기록이 SQLite로 저장되므로, 업그레이드 전 백업은 이번에도 빠지면 안 됩니다.
3. **cleanup은 신중하게** — `--dry-run`으로 먼저 확인하고, 제거된 원본으로의 롤백은 영구 불가능하다는 점을 기억하세요.

## 마무리

솔직히 "2.0이라는 대형 업데이트가 나온 지 하루 만에 또 뭘 배포했을까" 싶었는데, 릴리스 노트를 읽어보니 **"2.0을 실제로 쓰면서 발견한 문제들"을 정리한 패치**라는 인상이 강했습니다. 멈추던 대화, 새어 나오던 음성 추론, 실패하면 멈춰버리던 업데이트 — 에이전트를 매일 돌려보는 입장에서 **이런 것들이 사실은 신기능보다 중요하다**는 걸 다시 느꼈어요.

그리고 이 프로젝트는 **오픈소스로 무료**이고, 오늘(9/2) 기준 GitHub 실측 **스타 388,525개·포크 81,571개**입니다. 특히 **리눅스 데스크톱에서 Quick Chat으로 에이전트를 부르고 싶었다** 하시는 분들, **작업 화면 옆에 에이전트를 도킹해서 쓰고 싶다** 하시는 분들께는 이번 v2026.8.2가 기다리던 업데이트일 겁니다.

**"무료로 쓸 수 있는 AI 에이전트를 직접 돌려보고 싶은데, 설치·업데이트가 걱정"** 이신 분들께 OpenClaw v2026.8.2 업데이트 정리 추천합니다.
