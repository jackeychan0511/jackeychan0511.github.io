## 1. 요즘 저처럼 "AI 에이전트 업데이트를 매일 확인하시는 분들"

요즘 저처럼 **Hermes Agent로 블로그 자동 포스팅 크론잡을 돌리시는 분들**, 특히 이번 주 내내 릴리스 노트를 매일 확인하신 분들 많으시죠. 솔직히 저도 그렇습니다. 8월 3일 v0.20.0 **Herald 릴리스**(대화형 음성·A2A v1.0) 이후로 업데이트가 워낙 빠르게 나오니까, 하루만 지나도 "어제 버전이 옛날 버전"이 되는 기분이거든요.

그런데 어제(8월 16일), 또 새로운 태그가 찍혔습니다. **Hermes Agent v0.20.2(v2026.8.16)** — 지난 13일 v0.20.1이 나온 지 **정확히 3일 만**이에요. 이번엔 기능 추가보다 **"견고함"**에 초점을 맞춘 안정 태그인데, 막상 내용을 뜯어보니 자동화를 실제로 돌리는 입장에서 체감할 만한 수정이 꽤 많더라고요. 오늘은 그 내용을 제 실사용 관점에서 정리해 봤습니다.

## 3. 데스크톱 앱이 제일 많이 바뀌었습니다 — 다중 게이트웨이 'Connections'

### ① 여러 메신저 게이트웨이를 한 앱에서 — Connections 레지스트리

이번 v0.20.2에서 제일 눈에 띄는 변경은 **데스크톱 앱의 다중 게이트웨이 'Connections' 레지스트리**입니다. 저처럼 텔레그램으로 지시하고 디스코드로 알림을 받는 식으로 **여러 메신저 게이트웨이를 동시에 쓰는 분들**에게 유용한데요, 데스크톱에서 게이트웨이 연결 상태를 한곳에서 등록·관리할 수 있게 됐습니다.

![Hermes Agent 데스크톱 Connections 기능](/assets/images/posts/hermes-v0202-20260817/hermes-feature-connect.webp)
*Hermes Agent 공식 사이트 'Connections' 기능 아트 — 데스크톱에서 여러 채널·게이트웨이를 연결하는 컨셉 (출처: hermes-agent.nousresearch.com, 2026-08-17 확인)*

같은 맥락에서 이번 창에 **"Connecting Desktop to Many Hermes Instances" 공식 가이드**도 문서에 추가됐습니다. 데스크톱 하나로 여러 Hermes 인스턴스(로컬 프로필 + 클라우드 에이전트 등)를 오가는 사용자가 늘어난 걸 반영한 거죠.

### ② MCP 헬스 체크·딥 링크, 프로필 스코프 새로고침

- **MCP 헬스 체크·딥 링크** — 데스크톱에서 MCP 서버 상태를 확인하고 딥 링크로 바로 진입
- **프로필 스코프 새로고침(profile-scoped refreshes)** — 여러 프로필을 켜 놓아도 새로고침이 특정 프로필에만 안전하게 적용
- **find-in-page 개선** — 대소문자 무시 패스트패스, React 리렌더 간 하이라이트 유지 등 찾기 기능 안정화
- **멀티 소스 에이전트 end-to-end** — 소켓·로스터·SDK·팬아웃 업데이트까지, 데스크톱에서 여러 소스의 에이전트를 한 화면에 띄우는 기반 정비
- **턴 처리 안정화** — 메시지 시작 대기 없이 제출 시점에 진행 타이머를 걸고, assistant 페이로드 없이 끝나는 턴도 깔끔하게 정리

솔직히 개별 항목은 작아 보이지만, **"여러 채널 + 여러 프로필 + 여러 인스턴스"**를 동시에 쓰는 요즘 사용 방식에는 다 체감되는 수정들이에요.

## 4. CLI·게이트웨이·크론 — 자동화를 돌리는 사람이 체감할 포인트

### ① CLI — Kitty 키보드 프로토콜 Ctrl+C 수정이 반가운 이유

CLI 쪽에서 제일 반가웠던 건 **Kitty 키보드 프로토콜이 Ctrl+C를 깨뜨리던 문제 수정**입니다. Kitty 터미널(또는 키티 프로토콜 지원 터미널)에서 Hermes CLI를 쓰면 가끔 Ctrl+C가 안 먹혀서 답답했는데, 이번에 프로토콜 푸시를 중단하면서 해결됐어요. 그 외에 **Windows 업데이트 프로브** 개선, 채팅 `-c` 플래그 하드닝, 업데이트 시 **stale git lock 자가 치유**·얕은 클론(shallow clone)에서의 가짜 '업데이트 가능' 알림 수정까지, 설치·업데이트 경험이 전반적으로 다듬어졌습니다.

### ② 게이트웨이 — 지속 모델 라우트·`/loop` 완료·텔레그램 DM 토픽

- **지속 모델 라우트(persisted model routes)** — 게이트웨이 재시작 후에도 모델 라우팅 설정이 유지됩니다. "재시작하면 또 설정해야지" 하던 분들께 유용해요
- **`/loop` 완료** — 게이트웨이에서 반복 실행 작업의 완료 처리 경로 보강
- **텔레그램 DM 토픽** — 텔레그램 DM에서 토픽 지원 정리

### ③ 크론잡 — one-shot `cron run` 고아 잡 방지 (제 최애 수정)

이 블로그처럼 **Hermes 크론잡으로 자동 포스팅을 돌리는 분들**께는 이게 핵심입니다. 이번 패치에서 **one-shot CLI `cron run`이 잡(job)을 고아로 만들던 문제**를 수정하고, 실행 전 **stale 실행 클레임(stale execution claims)을 정리**하도록 바뀌었어요. 크론이 '한 번 실행'과 '스케줄 반복' 사이에서 꼬여서 잡이 유령처럼 남아 있던 문제가 줄어든다는 뜻입니다.

### ④ 비용·보안 직결 변경 — 프롬프트 캐싱과 `key_cmd`

- **LiteLLM Claude 프롬프트 캐싱(OpenAI 와이어)** — LiteLLM 경유 Claude 호출에 프롬프트 캐싱이 적용돼, 반복 호출이 많은 자동화에서 **토큰 비용 절감** 효과를 기대할 수 있습니다
- **`key_cmd` 인증 소스** — 커스텀 프로바이더용으로 API 키를 외부 명령에서 가져오는 `key_cmd` 크레덴셜 소스가 추가됐고, no-TTL 토큰 캐시도 제한됩니다. 키를 파일에 박아 두지 않고 명령으로 주입하는 방식이라 보안에도 도움이 돼요

## 5. 솔직한 장단점 — v0.20.2를 쓰면서

### 👍 장점

1. **업데이트가 '한 줄'로 끝남** — 기존 설치자는 `hermes update` 한 줄이면 3일 만의 397개 PR을 따라잡습니다. 이번 주에만 v0.20.1 → v0.20.2 두 번을 이렇게 넘겼는데, 정말 편합니다
2. **크론잡 안정화가 실사용에 직결** — one-shot `cron run` 고아 잡 수정·stale 클레임 정리는 자동 포스팅을 매일 돌리는 저 같은 사용자에게 가장 반가운 변경
3. **다중 게이트웨이 시대에 맞는 데스크톱** — Connections 레지스트리 + "여러 Hermes 인스턴스 연결" 가이드까지, 채널과 인스턴스가 늘어나는 사용 흐름을 따라잡음
4. **비용 절감 요소 포함** — LiteLLM Claude 프롬프트 캐싱은 반복 호출이 많은 크론잡·자동화에서 토큰 비용을 아껴 줍니다
5. **인스톨러·업데이터 견고성** — stale git lock 자가 치유, Windows/Linux 인스톨러 보강으로 '설치하다 멈춤' 류의 스트레스가 줄었습니다

### 👎 단점

1. **기능 추가는 없음** — 어디까지나 안정 태그라서 새 기능을 기대하면 실망할 수 있습니다. Herald(v0.20.0)의 음성·A2A 같은 '와!' 하는 변화는 v0.21.0을 기다려야 해요
2. **큐레이티드 노트는 여전히 공백** — v0.20.0 이후의 전체 하이라이트 정리는 v0.21.0에서 나옵니다. 지금은 릴리스 노트 원문 + 커뮤니티 분석으로 갈음해야 합니다
3. **3일 만의 릴리스 = 추적 피로** — 장점이자 단점인데, 하루하루 릴리스가 쏟아지니 "어제 버전이 옛날 버전"이 되는 속도에 적응이 필요합니다. 개인 사용자는 굳이 매 패치를 쫓지 않아도 됩니다

## 6. 마무리 — 업데이트 방법과 사용 팁

정리하면, v0.20.2의 키워드는 **"3일 만의 안정화 롤업 + 데스크톱 Connections + 크론·비용 안정화"**입니다. v0.20.1이 '안정화의 첫 단추'였다면, v0.20.2는 **자동화 운영자 입장에서 실제로 만지는 부분(크론·게이트웨이·캐싱·인스톨러)을 다듬은 패치**예요.

기존 설치자라면 업데이트는 이 한 줄이면 끝입니다.

```
# 기존 설치 업데이트
hermes update
# 새로 설치 (공식 인스톨러)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```
