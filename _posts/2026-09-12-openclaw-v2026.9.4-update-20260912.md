## 이 글을 읽으면 알 수 있는 것

- v2026.9.4가 **언제, 어떤 규모로 출시**됐는지(PR 1,558개·기여자 293명)와 9월 안정 트레인(9.1→9.2→9.3→9.4)에서의 위치
- **스킬·플러그인 통합 검색**과 **대화로 배우는 스킬 학습(Visible Skill Learning)** 이 업무 자동화에 주는 실질적 변화
- **GPT Image 2.5**(Flare·Sunburst)와 **클라우드 워커 제어** 등 새 기능의 실제 활용 포인트
- **터미널 질문·시크릿 입력**, **Node 자동 회복** 같은 생활형 개선
- 업그레이드 **순서와 주의사항** — 특히 제거된 번들 스킬 대체

## 도입: "9.3 정리하고 이틀 뒤, 9.4가 또 와 있더라고요"

요즘 저처럼 **AI 에이전트 릴리스 소식을 매일 아침에 체크하시는 분들**, 많으시죠? 저는 9/9에 v2026.9.3을 정리하면서 "이번 주는 한 번 쉬어가겠지" 싶었어요. 그런데 오늘(9/12) GitHub Releases를 다시 열어보니 **v2026.9.4 안정 태그**가 이미 올라와 있더라고요. 게시 시각이 한국시간 **9/11 낮 12:46**(UTC 9/11 03:46)이에요.

솔직히 "9.1 → 9.2 → 9.3 → 9.4, 도대체 한 달에 몇 번이냐" 싶을 정도인데요. 그래도 이번 판은 **성격이 조금 다릅니다.** 지난 9.3이 '안전한 업데이트 + 팀 운영 기능'이었다면, **9.4는 '스킬을 찾고, 배우게 하는' 판**이에요. 제가 제일 반가웠던 건 **Node 때문에 시작조차 못 하는 상황을 OpenClaw 스스로 해결**해 주는 기능이 들어온 거고요(9.3에서 Node 요구사항이 확 올라가면서 생긴 불편을 다음 판에서 바로 메운 셈입니다). 오늘도 공식 릴리스 노트(docs.openclaw.ai, 원문 약 778KB)와 GitHub Releases 원문을 기준으로 **꼭 알아야 할 것만** 정리해 드립니다.

## 업무 자동화에 실질적인 변화 — 스킬 검색·학습·이미지·클라우드

### ① 스킬 & 플러그인 통합 검색 — "설치한 것과 받을 것을 한 화면에서"

이번 판에서 제가 가장 유용하게 볼 부분입니다. **Skills 페이지가 내 PC에 설치된 스킬과 ClawHub(공개 레지스트리)를 함께 검색**해 줍니다. 이제 "이 기능 이미 깔았나?"를 확인하려고 창을 오갈 필요가 없어요. 카드에는 해당 스킬이 **바로 쓸 수 있는지(ready), 설정이 더 필요한지** 표시되고, 에이전트를 바꾸면 **그 에이전트가 쓸 수 있는 스킬만** 보입니다. 검색어를 입력하지 않아도 **인기 스킬을 훑어볼 수 있어** "뭘 깔지" 고민이 확 줄어들어요.

### ② 대화로 배우는 스킬 — Skill Workshop의 '지난 대화로 배우기'

이번 판의 **최대 하이라이트**입니다. Skill Workshop에서 **"Learn from past conversations(지난 대화로 배우기)"** 를 고르면, 지난 대화를 뒤져 스킬을 개선하는 작업을 **채팅창에서 눈으로 따라가며 방향을 제시하거나 중단**할 수 있습니다. 모드는 두 가지예요.

- **Auto** — OpenClaw가 찾아낸 개선점을 **알아서 적용**
- **Propose** — 개선 제안만 남기고 **내가 승인**

중요한 건 **"이걸 내가 직접 시작해도 자동 자기학습이 켜지는 건 아니다"** 라는 점이에요(정상적인 모델 요금·권한은 그대로 적용). 즉 **에이전트가 조용히 스킬을 건드리는 게 아니라, 내가 보고 조종하는 '가시적인(visible)' 학습**이라는 게 핵심입니다. 참고로 **예전 형식의 미완료 학습 기록은 새 흐름에서 이어가지 못하니 새 학습 채팅을 시작**해야 하고, 주간 자동 리뷰가 스케줄링 꺼짐 때문에 멈춰 있으면 Workshop이 그 이유를 알려줍니다.

### ③ GPT Image 2.5 지원 — 이미지 생성·편집 품질 한 단계 위

**GPT Image 2.5(Flare·Sunburst 변종)** 로 이미지를 생성·편집할 수 있게 됐습니다. **OpenAI 또는 fal** 경유로 쓸 수 있고, **커스텀 크기**와 **고품질 설정**, **투명 PNG/WebP 출력**을 지원해요. 편집 시 참조 이미지는 **OpenAI 경유 최대 5장 / fal 경유 최대 16장**까지 넣을 수 있고, 한 번에 **최대 4장**을 돌려받습니다. 다만 **기본 이미지 모델은 그대로**라, 쓰려면 새 변종을 직접 골라야 하고, OpenAI 직접 접속은 API 키가(이미 ChatGPT 로그인을 쓴다면 별도 선택), fal은 자체 자격증명이 필요합니다.

### ④ 클라우드 워커 제어 — 팀 단위 자동화를 돌리는 분께 알짜

여러 대의 클라우드 컴퓨터에서 에이전트를 굴리는 분들께는 이번 판이 특히 좋습니다.

- **준비된 워커 재사용** — 이미 세팅된 프로젝트를 새 클라우드 세션이 **그대로 재사용**해 반복 설치·준비 시간을 아낍니다(로컬 프로젝트 또는 공개 GitHub 저장소에서 시작 가능)
- **여분 대기(Ready workers)** — 다음 세션이 **이미 돌고 있는 컴퓨터를 바로 쓸 수 있게** 미리 한 대를 대기시킵니다. 리눅스 프로젝트 기준 **프로필당 기본 1대, 공유 최대 4대**. 단, **삭제 확인 전까지는 비용이 발생**하니 프로필 값 0으로 끄거나 공유 풀 상한을 0으로 줄일 수 있습니다
- **OS 선택** — 프로필/세션별로 클라우드 컴퓨터의 OS를 **Linux·Windows·WSL2·macOS** 중 고를 수 있습니다(맥 워커는 AWS Dedicated Host·On-Demand 필요, 데스크톱 접속·재사용 이미지는 리눅스 전용)
- **스냅샷 관리** — 준비된 프로젝트 스냅샷을 저장·핀(pin)·삭제·롤백하고, 새 워커에 이전 스냅샷을 골라 쓸 수 있습니다
- **업데이트 중에도 유지** — 지원되는 클라우드 컴퓨터는 **OpenClaw 업데이트를 거쳐도 파일·설치된 도구·데스크톱을 유지**하고, 세팅/동기화 중 보낸 메시지는 **큐에 쌓였다가 컴퓨터가 준비되면 자동 시작**됩니다

### ⑤ 터미널에서 에이전트 질문·시크릿 입력

생활형 편의 기능도 눈에 띕니다. 이제 **에이전트가 물어보는 것에 터미널에서 바로 답할 수 있어요.** 옵션을 고르거나 직접 타이핑해 응답할 수 있고, 작업이 내 답을 기다리는 중에도 됩니다. **Esc로 잠시 미뤄두고 `/question`으로 다시 불러오기**도 되고요. **시크릿 요청은 마스킹 입력창**으로 받아서 **대화 기록·입력 히스토리에 남지 않습니다**(저장에는 Gateway 연결이 필요하고, 터미널 입력은 한 줄씩). "웹앱 켜기 귀찮은데 터미널에서 다 끝내고 싶다" 하는 분께 딱이에요.

### ⑥ Node 문제 자동 회복 — 9.3의 불편을 다음 판에서 메움

지난 9.3에서 **Node 24.16.0+/26.1.0+ 요구**로 업그레이드 장벽이 생겼는데, 9.4가 이걸 완화합니다. **OpenClaw가 시작되지 않을 때 호환되는 Node를 컴퓨터에서 찾아 쓰거나, OpenClaw 전용으로만 설치**해 줍니다(첫 설치는 내 승인 필요, 이후 자동 재사용). **시스템의 기존 Node를 건드리지 않고** 다른 앱에 영향을 안 준다는 게 포인트예요. Alpine Linux 등 일부 시스템은 여전히 수동 설치가 필요하고, 백그라운드 서비스가 옛 Node를 쓰고 있으면 **`openclaw gateway install`로 지원 버전으로 전환**할 수 있습니다.

### 그 밖에 눈에 띄는 변화

- **음성 메모 전사에 Deepgram Flux 옵션 추가** — 영어·다국어 선택 가능, ffmpeg 설치 필요(기본은 Nova 유지)
- **웹검색 기본 모델이 Gemini 3.6 Flash로** — 별도 지정이 없으면 이 모델을 사용, Gemini 3는 검색 쿼리당 과금이라 비용 차이 확인 권장
- **새 웹 UI** — 메시지 내비게이터 레일(긴 대화 미리보기), 선택 텍스트를 초안에 인용("Add to chat"), **재연결 중 캐시된 대화·사이드바 표시**, 보낼 비디오 미리보기, 파일 편집 시 **최신 변경 덮어쓰기 경고**(Reload/Overwrite 선택)
- **번들 video-frames 스킬 제거** — ⚠️ 영상에서 정지 이미지를 뽑던 번들 스킬/헬퍼가 **삭제**됐습니다. 쓰시던 분은 **ffmpeg를 직접 쓰거나 별도 프레임 추출 스킬 설치**가 필요하고, 기존 워크플로가 자동 변환되지는 않습니다
- **Android 앱 개선** — 읽던 위치 유지, 도구 상세 보기, 알림 답장, 폴딩폰 레이아웃 등

## 실제 사용감 — 솔직한 장단점

9월 들어 나흘 간격으로 안정판이 쏟아지다 보니 **"버전 피로감"** 은 솔직히 있습니다. 그런데 이번 9.4는 **"9.3에서 생긴 Node 장벽을 바로 메우고, 스킬 관리 UX를 손본"** 판이라 체감이 확실한 편이에요.

- 👍 **Node 자동 회복** — 9.3 때문에 업데이트를 미뤄둔 분들께 이번 판이 사실상 구원투수입니다. 시스템 Node를 안 건드린다는 게 특히 반가워요.
- 👍 **스킬 통합 검색 + 대화로 배우기** — "무슨 스킬 깔았는지, 이 대화에서 뭘 배웠는지"가 눈에 보이니, 에이전트를 **운영 자산**으로 관리하기가 훨씬 수월해졌습니다.
- 👍 **클라우드 워커 재사용·여분 대기** — 여러 프로젝트를 병렬로 돌리는 분은 세팅 대기 시간이 크게 줄어듭니다(단, 여분 대기 컴퓨터는 **돈이 나간다**는 점은 꼭 기억하세요).
- 👎 **video-frames 스킬 제거** — 영상 프레임 추출을 이 번들 스킬에 의존하던 워크플로는 **대체 작업이 필요**합니다. 자동 변환이 안 되니 미리 확인하세요.
- 👎 **여전한 업데이트 속도** — 기능은 좋지만 나흘 간격 릴리스는 팀 단위로 운영하시는 분께 검증 부담이 될 수 있습니다. 안정 트레인을 정해두고 주 1회만 따라가는 것도 방법이에요.

## 업데이트 방법 — v2026.9.3 → v2026.9.4

1. **백업 먼저** — 공식 안내대로 **업그레이드 전에 OpenClaw 데이터를 백업**하세요. 구버전은 새 데이터 형식을 못 읽어 **앱만 롤백해도 복구가 안 됩니다**
2. **OpenClaw 업데이트** — npm `latest` 기준 v2026.9.4가 배포됐으니 평소 방식(CLI/Gateway/앱)으로 업데이트하면 됩니다
3. **Node 문제가 있었더라도 일단 실행** — 9.4는 시작 시 호환 Node를 찾거나 전용 설치를 제안합니다. 백그라운드 서비스가 옛 Node면 `openclaw gateway install`로 전환
4. **`openclaw doctor --fix` 실행** — Workshop 관련 알려진 문제를 Doctor가 수리합니다(모호한 제안·백업은 검토용으로 남겨둠)
5. **영상 프레임 작업이 있으면** — 제거된 video-frames 대신 ffmpeg 또는 대체 스킬로 미리 갈아타세요
6. **클라우드 워커 사용자라면** — 저장된 워커 이미지를 쓴다면 OpenClaw와 이미지 캡처를 멈추고 Doctor 업그레이드 단계를 먼저 따르세요. Crabbox는 0.55.0 이상 필요

## 마무리

9.2가 '신모델 탑재판', 9.3이 '안전한 업데이트 + 팀 운영 기능'이었다면, **9.4는 '스킬을 찾고·배우고·공유하는 운영 판'** 이라고 요약할 수 있겠습니다. 특히 **지난 대화를 스킬로 바꾸는 과정을 사용자가 직접 조종**하게 된 건, "AI가 알아서 잘하겠지"에서 **"내가 학습 방향을 관리한다"** 로 넘어가는 변화라 의미가 큽니다. 여기에 9.3의 Node 장벽을 스스로 메운 것도 실사용자 입장에서 반가운 대목이고요.

특히 **오픈소스 AI 에이전트로 업무 자동화를 직접 돌리시는 분**, 그중에서도 **스킬을 여러 개 관리하거나 클라우드 컴퓨터로 병렬 작업을 돌리는 분께 추천**하는 업데이트입니다. 가성비 좋은(무료·오픈소스) AI 툴을 찾는 분께도 여전히 좋은 선택지예요. 다만 나흘 간격 릴리스에 지치셨다면, **백업만 챙기고 한 템포 쉬어가며** 안정 트레인을 따라가시는 걸 권합니다.
