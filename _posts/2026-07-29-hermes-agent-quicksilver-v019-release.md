요즘 저처럼 AI 에이전트에 관심 많으신 분들, Hermes Agent 들어보셨죠? Nous Research에서 만든 이 오픈소스 AI 에이전트가 **v0.19.0 퀵실버(Quicksilver) 릴리즈**를 7월 20일에 쏘아올렸습니다.

솔직히 이번 업데이트, 규모가 어마어마합니다. 2,245개의 커밋, 1,065개의 머지 PR, 450명 이상의 커뮤니티 기여자가 참여한 역대 최대 규모의 릴리즈인데요. 코드명 퀵실버(Quicksilver)답게 **콜드스타트 속도를 80%나 줄인** 게 가장 눈에 띕니다.

직접 써보며 느낀 변화와 핵심 기능들을 정리해봤습니다.

## 🚀 퀵실버 릴리즈, 왜 중요한가?

Hermes Agent는 원래도 빠른 에이전트였습니다. 그런데 이번 업데이트는 **"첫 응답까지의 대기 시간"** 자체를 근본적으로 개선했어요.

| 항목 | v0.18.x | v0.19.0 (퀵실버) | 개선율 |
|:----|:-------|:-----------------|:------|
| ⚡ 콜드스타트 TTFT | ~4.3초 | **~0.9초** | **80% ↓** |
| 🧠 리즈닝 스트리밍 | 수동 설정 필요 | **기본 활성화** | — |
| 🛡️ 명령 승인 방식 | 수동/자동 선택 | **Smart Approval 기본** | — |
| 🔄 서브에이전트 | 실행만 확인 가능 | **실시간 트랜스크립트** | — |
| 🔐 시크릿 관리 | 환경변수만 | **Bitwarden·1Password** | — |

콜드스타트 시간이 4.3초에서 0.9초로 줄었다는 건, **Hermes에게 첫 질문을 던지고 결과를 보기까지 기다리는 시간이 거의 사라졌다**는 뜻입니다. CLI, 데스크톱, 게이트웨이, TUI, 크론잡 — 모든 플랫폼에서 동일하게 적용됩니다.

---

## 🔥 5가지 핵심 변화 살펴보기

### 1. ⚡ 80% 빨라진 첫 응답 (Cold-Start TTFT 0.9초)

이번 업데이트의 가장 체감되는 변화입니다. 예전에는 Hermes를 켜고 첫 명령을 입력하면 "생각하는 시간"이 꽤 길게 느껴졌는데요. 퀵실버에서는 **거의 즉시 반응**합니다.

터미널에서 `hermes` 입력하고 첫 질문까지 걸리는 시간이 확연히 줄었어요. 여러 모델을 번갈아 쓸 때도 모델 로딩과 컨텍스트 초기화가 대폭 최적화되어 있어서 답답함이 없습니다.

### 2. 🧠 리즈닝 스트리밍 — AI의 생각 과정을 실시간으로

이제 Hermes가 어떤 추론 과정을 거쳐 답변을 만드는지 **실시간으로 볼 수 있습니다**. 리즈닝 스트리밍이 기본 활성화되었기 때문인데요.

장점은 명확합니다. 에이전트가 지금 무슨 생각을 하고 있는지, 어떤 도구를 실행하려는지 투명하게 공개되니까 믿음이 가고, 결과가 늦어져도 기다릴 수 있게 되죠.

단점이라면 화면이 좀 더 복잡해 보일 수 있다는 점 — 하지만 설정에서 끌 수 있으니 취향에 따라 선택하세요.

### 3. 🛡️ Smart Approval — AI가 스스로 판단하는 명령 승인

보안 측면에서 가장 큰 변화입니다. **Smart Approval**이 이제 기본 모드가 되었어요.

기존의 `approvals.mode: manual`은 모든 액션을 사람이 일일이 확인해야 해서 생산성이 떨어졌고, `auto`는 보안이 걱정됐죠. Smart Approval은 별도의 LLM이 명령을 검토한 후 **저위험 명령은 자동 승인, 고위험 명령만 사용자에게 질의**합니다.

> 💡 실제 사용 팁: 민감한 파일 작업이나 결제 관련 명령은 여전히 확실히 물어봅니다. 일반적인 파일 읽기, 웹 검색, 코드 작성 같은 일상 작업은 자동으로 처리되니 업무 효율이 훨씬 좋아졌어요.

### 4. 🔄 실시간 서브에이전트 트랜스크립트

`delegate_task`로 작업을 위임할 때, 이제 **서브에이전트의 진행 상황을 실시간으로 볼 수 있습니다.**

예전에는 "서브에이전트가 일하고 있습니다"라는 메시지만 보고 기다려야 했는데요. 이제는 각 서브에이전트가 어떤 도구를 실행하고, 중간 결과가 무엇인지 실시간으로 표시됩니다. 여러 서브에이전트가 동시에 작업할 때도 각각의 진행 상황을 따로 확인할 수 있어서 답답함이 확 줄었어요.

여기에 **내구성 있는 백그라운드 위임(Durable Background Delegation)** 기능이 추가되어, 서브에이전트 작업 중 연결이 끊겨도 작업이 유실되지 않고 백그라운드에서 계속 실행됩니다.

### 5. 🔐 Bitwarden & 1Password 연동 — 시크릿 관리의 혁명

API 키, 토큰, 비밀번호를 더 이상 환경변수나 설정 파일에 하드코딩하지 않아도 됩니다. **Bitwarden**과 **1Password**를 시크릿 소스로 직접 연결할 수 있어요.

이 기능은 팀 단위로 Hermes를 운영하는 환경에서 특히 유용합니다. 개인 개발자도 API 키 관리가 훨씬 편해졌다는 점이 매력적이에요.

## 📥 업데이트 방법

이미 Hermes Agent를 사용 중이라면 업데이트는 간단합니다.

```bash
hermes update
```

한 줄이면 v0.19.0 퀵실버로 자동 업데이트됩니다. 데스크톱 앱 사용자라면 앱 내에서 업데이트 알림이 뜨니 안내에 따라 진행하세요.

> ⚠️ 주의: 일부 사용자에게서 Windows 업데이트 시 state.db 관련 이슈가 보고되었습니다. 업데이트 전에 `~/.hermes/state.db`를 백업해두는 것을 추천합니다.

새로 설치하는 분들은 [공식 사이트](https://hermes-agent.nousresearch.com)에서 데스크톱 설치 프로그램을 다운로드하거나, 터미널에서 아래 명령어로 설치할 수 있습니다.

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

## 🤔 직접 써본 소감

솔직히 말하면, Hermes Agent는 초기 버전부터 꾸준히 써왔는데요. 이번 퀵실버 업데이트는 **"드디어 에이전트라는 게 이렇게 빨라야 하는구나"** 싶을 정도로 체감이 큽니다.

특히 0.9초 콜드스타트는 실제 업무 흐름에서 체감 차이가 큽니다. 예전에는 "Hermes한테 물어볼까… 아, 켜지는 거 기다려야 되나" 하고 망설였던 적이 있었는데, 지금은 그냥 바로 입력합니다.

Smart Approval도 생각보다 민감도가 잘 조정되어 있어서, 보안은 보안대로 챙기면서 불편함은 최소화한 느낌이에요.

다만 주의할 점:
- Windows에서 업데이트 시 `state.db` 손상 이슈가 보고됨 — **업데이트 전 백업 필수**
- 초보자에게는 리즈닝 스트리밍 UI가 다소 복잡해 보일 수 있음
- 일부 커스텀 모델 설정에서 fallback_providers 라우팅 이슈 발생 가능

## 🎯 마무리

Hermes Agent v0.19.0 퀵실버는 단순한 기능 추가를 넘어, **AI 에이전트의 사용자 경험 자체를 한 단계 끌어올린 릴리즈**입니다.

콜드스타트 0.9초라는 수치는 그냥 숫자가 아니라, "아 이거 편하네"라는 일상적인 느낌으로 연결됩니다. Nous Research가 오픈소스 생태계에서 보여주는 업데이트 속도와 품질은 정말 인상적이에요.

아직 Hermes Agent를 안 써보셨다면, 지금이 시작하기 딱 좋은 타이밍입니다. 무료(MIT 라이선스)에, 한국어 완벽 지원, 설치도 2분이면 끝납니다.

이 글을 보시는 분들 중에서 "AI 에이전트, 어떤 걸 골라야 하지?" 하고 고민 중이시라면, Hermes Agent를 한번 써보시길 추천합니다. 특히 이번 퀵실버 업데이트 이후로는 그 격차가 더 벌어졌다고 생각해요.
