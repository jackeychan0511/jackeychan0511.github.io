## 1. 오늘(8/3) 아침 커밋에서 확인한 것 — 크롬 확장프로그램 공식 등재 신호

먼저 제가 오늘 아침 한국 시간 기준 **오전 9시 19분~10시 24분(UTC 00:19~01:24)** 사이에 올라온 커밋 중, 일반 사용자에게 의미 있는 것부터 정리합니다.

### ① 앱 페이지에 Chrome 웹스토어 링크 추가 🔥

`feat(ui): link the Chrome Web Store listing from the apps page (#118327)` — OpenClaw 앱(Apps) 페이지에서 **Chrome 웹스토어 등록 페이지로 바로 가는 링크**가 추가됐습니다. 사실 OpenClaw는 지난주부터 공식 문서([Chrome Extension 가이드](https://docs.openclaw.ai/tools/chrome-extension))를 통해 **"브라우저 코파일럿(Browser Copilot)"**을 밀고 있었는데요, 이제 앱 페이지에서 웹스토어로 직접 연결되면서 **설치 경로가 공식적으로 하나로 정리**된 셈입니다.

Chrome 웹스토어에는 현재 두 가지 확장프로그램이 등록돼 있습니다.

| 확장프로그램 | 용도 |
|:----|:----|
| **OpenClaw Extension** | 로컬·원격 AI 어시스턴트를 **Chrome 사이드 패널**에 직접 통합하는 브라우저 코파일럿 |
| **OpenClaw Browser Relay** | OpenClaw가 **현재 열린 Chrome 탭**을 보안 로컬 CDP 릴레이로 제어 |

![OpenClaw 크롬 확장프로그램 공식 스크린샷](/assets/images/posts/openclaw-aug3-20260803/openclaw-chrome-extension-screenshot.jpg)
*Chrome 웹스토어에 등록된 OpenClaw Extension 공식 스크린샷 (출처: Chrome Web Store, 확인일 2026-08-03)*

기존에는 OpenClaw가 별도 관리 브라우저 프로필을 띄워서 제어하는 방식이었는데, 확장프로그램은 **이미 로그인된 내 Chrome 창을 그대로** 제어합니다. `chrome.debugger` API를 쓰기 때문에 원격 디버깅 프롬프트가 뜨지 않고, "OpenClaw started debugging this browser" 배너만 표시된다고 문서에 설명돼 있어요. 로그인된 사이트를 AI가 직접 다루는 만큼 **권한과 보안은 신중히** 설정하시는 걸 추천합니다.

### ② 채널 라이프사이클 2차 물결 — 15개 채널 추가

`feat(channels): lifecycle wave 2 — fifteen more channels publish recorded lifecycle (#118298)` — 지난주 1차 물결에 이어 **15개 채널이 추가로 "기록된 라이프사이클(recorded lifecycle)"**을 갖추게 됐습니다. 쉽게 말하면 채널이 어떤 상태(시작·중지·오류)인지를 **게이트웨이가 정확히 기록하고 복구**한다는 뜻입니다. 여기에 `fix(gateway): recover channel autostart after crash loops (#118311)` — **크래시 루프 후 채널 자동 재시작 복구**까지 묶여서, 밤새 자동화를 돌려놓는 분들의 "아침에 보니 채널이 죽어있던" 문제가 줄어들 것으로 보입니다.

### ③ 게이트웨이 HTTPS 가이드 + iOS·모바일 개선

- `docs: add stable gateway HTTPS guide (#118340)` — 게이트웨이를 **안정적으로 HTTPS로 운영하는 공식 가이드**가 추가됐습니다. 외부 채널 연동 시 "보안 연결이 필요하다"는 오류를 만나셨던 분께 도움이 됩니다.
- `fix(ios): finish Calendar and Reminders grants without relaunch (#116504)` — iOS에서 **캘린더·미리알림 권한 승인 후 앱 재시작 없이** 바로 사용 가능하도록 수정
- `fix(ios): route forced realtime consults through Gateway relay (#117485)` — iOS 실시간 통화(리얼타임)가 게이트웨이 릴레이를 거치도록 정리
- `fix(ui): keep chat Send and Stop responsive on mobile (#116104)` — 모바일 채팅의 **전송·중지 버튼 반응성** 개선
- `fix(sms): reject a zero SMS_TEXT_CHUNK_LIMIT instead of sending one text per character (#118158)` — SMS 설정값이 0일 때 **문자 한 글자마다 SMS를 보내는** 황당한 버그 방지
- `fix(memory): keep wiki search inside protected recall visibility (#118265)` — 메모리 위키 검색의 보호된 회상(protected recall) 범위 정리

솔직히 "화려한 신기능"은 아니지만, **iOS에서 실제로 쓰는 사람에게 체감되는 수정**들이 오늘 아침에 몰려 올라왔습니다.

## 3. v2026.7.2 정식 릴리즈 임박 — 베타.7 릴리즈 노트에 이미 "완성판 하이라이트"가 정리됨

어제 글에서 "베타.7부터 도입된 릴리즈 검증 절차 = 정식판 임박 신호"라고 말씀드렸는데, 오늘 확인해보니 그 신호가 더 강해졌습니다. **베타.7의 릴리즈 노트에는 이미 v2026.7.2 전체 하이라이트가 통째로 정리**돼 있습니다. 정식판을 위한 "최종 문서"가 사실상 준비된 상태라는 뜻입니다.

![OpenClaw 공식 위키미디어 스크린샷](/assets/images/posts/openclaw-aug3-20260803/openclaw-wikimedia-screenshot.png)
*OpenClaw 실제 사용 화면 (출처: Wikimedia Commons, 확인일 2026-08-03)*

v2026.7.2 하이라이트 중 이번에 특히 눈길이 가는 것만 골라보면:

- **상태 안전성·복구**: 기본 DB가 손상돼도 살아남는 격리 저장소(quarantine store), 크래시 복구 SQLite 스냅샷, 스키마 업그레이드 시 데이터 손실 거부
- **지속 채널 전달**: Telegram·Signal·Slack·QQBot·Twitch·IRC·Zalo 등 **재시작·크래시에도 메시지 유실 방지** (죽은 편지함 복구 포함)
- **세션 되감기·브랜칭**: 메시지 단위로 대화를 되감거나 포크하고, 웹·네이티브 앱에서 브랜치 전환
- **인터랙티브 MCP 앱**: 티켓 방식 MCP 앱을 채널 답장에서 열고 대시보드에 고정
- **질문·승인 everywhere**: 채널·웹·macOS에서 구조화된 질문 카드, 승인 알림·푸시·헤드리스 해결
- **미팅·실시간 Talk**: Teams·Zoom·Google Meet 참여 및 내구성 있는 회의록, OpenAI·Gemini 영상 Talk
- **Wear OS 컴패니언**: 손목에서 에이전트·세션 선택, 실시간 Talk 컨트롤
- **로컬 추론**: 램 기반 llama.cpp/Gemma 경로, 로컬 제공자 자동 감지
- **모델**: Claude Opus 5, Kimi K3, GPT Live 추가

이 중에서도 **"브라우저 코파일럿(Browser Copilot)"**이 아까 말씀드린 크롬 확장프로그램과 연결되는 기능입니다. 정식판에선 **이미 로그인된 Chrome 탭을 AI가 직접 제어**하는 흐름이 기본이 될 예정이라, "AI가 내가 쓰는 브라우저를 그대로 다뤄주는" 경험을 원하시는 분이라면 이번 업데이트가 특히 반가우실 겁니다.

## 4. 지금 설치해도 될까? — 버전 현황과 솔직한 판단

오늘(8/3) 기준 버전 현황은 이렇습니다.

| 채널 | 버전 | 상태 |
|:----|:----|:----|
| npm 안정판 | **2026.7.1-2** (2026-07-18 발행) | 현재 공식 최신 안정판 |
| npm 베타판 | **2026.7.2-beta.7** (2026-08-02 발행) | 안정화 막바지 |
| 예정 | **v2026.7.2 정식판** | 릴리즈 노트 문서 완비 → **임박** |

```bash
# 안정판 유지
npm install -g openclaw@latest

# 베타 미리 써보기
npm install -g openclaw@beta

# 버전 확인 & 문제 자동 수정
openclaw version
openclaw doctor --fix
```

**제 솔직한 판단**은 이렇습니다. 이미 베타.6·베타.7을 쓰고 계신 분은 그대로 쓰셔도 좋고, 안정판 유지 중이신 분은 **정식 v2026.7.2가 나오면 한 번에 올리는 것**이 가장 안전합니다. 다만 주의할 점 하나 — 베타.6부터 **GPT Live는 OpenAI Platform API 키가 필수**로 바뀌었으니, Codex 로그인(OAuth)으로 실시간 Talk를 쓰던 분은 정식판 업데이트 전에 API 키를 미리 준비해두시는 걸 추천합니다. 그리고 지난 글에서도 말씀드렸듯 **Wear OS 페어링 버그(#116049)**는 아직 베타에 남아 있습니다.

## 마무리 — 오늘 소식 한 줄 정리

1. **크롬 확장프로그램 공식 등재 신호** — 앱 페이지에 Chrome 웹스토어 링크 추가, 브라우저 코파일럿 설치 경로 정리 (8/3 커밋)
2. **채널 안정화 2차 물결** — 라이프사이클 15개 채널 확대 + 크래시 루프 후 자동 재시작 복구
3. **스타 384,958개 (8/3 오전)** — 어제보다 +55, GitHub 글로벌 6위, 5위와 격차 약 8~9천 개
4. **v2026.7.2 정식 릴리즈 임박** — 베타.7 릴리즈 노트에 하이라이트 문서 완비, npm 안정판은 여전히 2026.7.1-2

저처럼 **"AI 에이전트가 내 브라우저까지 대신 다뤄주는"** 그 날을 기다리시는 분께는, 크롬 확장프로그램 공식 등재가 꽤 반가운 소식일 겁니다. 다만 로그인된 브라우저를 AI가 제어하는 만큼 **권한 범위를 꼭 확인**하시고, 중요한 작업은 신뢰할 수 있는 스킬·채널에서만 시키시는 걸 권합니다.

관련해서 지난 글([베타.6·베타.7 총정리](/2026/08/02/openclaw-v202672-beta7-update/), [베타 프리뷰: 세션 되감기·브랜칭](/2026/08/01/openclaw-v202672-beta-preview/), [v2026.7.1 LTS·성숙도 점수카드](/2026/07/31/openclaw-v202671-lts-maturity-scorecard/))과 함께 읽으시면 전체 흐름이 잡힙니다. 정식 v2026.7.2가 나오는 대로 다시 찾아뵙겠습니다.
