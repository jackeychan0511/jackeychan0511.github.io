## 한 줄 요약: '출시 기념가'가 12월 1일에 끝난다

Gemini API를 붙여서 자동화 파이프라인을 돌리는 분들이라면 지금 확인해야 할 숫자가 하나 있습니다. 구글 Gemini API 공식 가격표(2026년 10월 22일 갱신)에 **Gemini 4 Argon의 단가가 2026년 12월 1일부터 정확히 2배가 된다**는 조건이 명시돼 있습니다.

- 입력: 100만 토큰당 **$2.00 → $4.00**
- 출력(사고 토큰 포함): 100만 토큰당 **$10.00 → $20.00**
- 컨텍스트 캐싱: 100만 토큰당 **$0.10 → $0.20**

"인상"이라는 단어 대신 "through November 30, 2026 / starting December 1, 2026"이라는 날짜 표기로 조용히 들어간 변화입니다. 같은 방식으로 **Gemini 3.8 Flash도 2026년 12월 31일까지가 현행가, 2027년 1월 1일부터 2배**입니다(입력 $0.75 → $1.50, 출력 $3.75 → $7.50).

즉 10월 13일 Argon 공개 당시 붙은 가격표는 **한시적 도입가**였고, 12월 1일부터 본가격이 적용되는 구조입니다.

## 공식 가격표에 찍힌 숫자들

구글 문서에 적힌 그대로를 표로 옮기면 이렇습니다. 모든 단가는 100만 토큰 기준, USD입니다.

### Gemini 4 Argon — Standard 티어

| 항목 | 2026년 11월 30일까지 | 2026년 12월 1일부터 |
|:---|:---|:---|
| 입력 | $2.00 | **$4.00** |
| 출력(사고 토큰 포함) | $10.00 | **$20.00** |
| 컨텍스트 캐싱 | $0.10 | **$0.20** |
| 무료 티어 | 제공 안 함 | 제공 안 함 |

### 같은 2배가 적용되는 다른 티어

| 티어 | 입력 (12/1부터) | 출력 (12/1부터) |
|:---|:---|:---|
| Batch (50% 할인) | $1.00 → **$2.00** | $5.00 → **$10.00** |
| Flex | $1.00 → **$2.00** | $5.00 → **$10.00** |
| Priority | $3.60 → **$7.20** | $18.00 → **$36.00** |
| Contributor(초대제) | $1.00 → **$2.00** | $5.00 → **$10.00** |

Batch·Flex·Priority·Contributor까지 **전 티어가 동일 비율로 2배**입니다. "배치로 돌리면 싸니까 배치로 우회하자"는 식의 회피가 통하지 않는다는 뜻입니다.

여기에 붙어 있는 조건도 짚어둘 만합니다.

- **Argon은 무료 티어에서 아예 쓸 수 없습니다.** 문서에 "Gemini 4 Argon is not available on the Free tier"라고 명시돼 있습니다.
- **명시적 컨텍스트 캐싱은 지원되지 않습니다.** 암시적 캐싱만 되고, 그 단가도 2배가 됩니다.
- **Grounding(Google 검색 연동)은 Gemini 3 이상 모델 전체가 월 5,000회까지 무료, 이후 1,000회당 $14**를 공유해서 씁니다. 모델 단가를 아무리 낮춰도 검색 그라운딩을 많이 쓰는 에이전트는 이쪽에서 비용이 새어 나갑니다.

### Gemini 3.8 Flash — 2027년 1월 1일부터 2배

| 항목 | 2026년 12월 31일까지 | 2027년 1월 1일부터 |
|:---|:---|:---|
| 입력 | $0.75 | **$1.50** |
| 출력 | $3.75 | **$7.50** |
| 컨텍스트 캐싱 | $0.075 | **$0.15** |
| 캐시 저장 | 100만 토큰·시간당 $0.50 | **$1.00** |

Argon보다 한 달 늦게, 같은 2배 인상이 예고된 셈입니다. 사실상 **Gemini 4 세대 전체의 가격대가 한 단계 위로 올라간다**고 보는 편이 정확합니다.

## 왜 갑자기 2배인가 — "컴퓨트가 부족하다"

배경은 가격표가 아니라 발언 쪽에 있습니다. 순다르 피차이 구글 CEO는 Alex Heath의 팟캐스트 'Sources' 인터뷰(10월 20일 공개)에서 이렇게 말했습니다.

> "Argon이 출시된 뒤 첫 72시간 동안 약 25조 토큰을 처리했습니다. 3.0이 같은 기간에 처리한 양의 약 3배입니다."

여기에 "구글은 여전히 용량 제약(capacity constrained) 상태이며, 모든 사람에게 이 모델을 열어줄 만큼의 컴퓨팅 파워가 없다"는 설명이 붙습니다. PPC Land가 이 인터뷰를 정리한 내용을 보면, 피차이는 Ultra 전체와 Gemini 앱의 Pro 구독자, 이후 Antigravity의 Pro 티어 순으로 접근을 열었고 **증류(distillation)로 "거의 비슷한 성능에 훨씬 효율적인 버전"을 만들어 접근을 계속 확대하겠다**고 밝혔습니다. 다만 무료 티어에 Argon 계열 모델이 언제 들어오는지는 날짜를 주지 않았습니다.

정리하면 구조는 이렇습니다.

1. **수요가 예상을 3배 넘겼다** — 72시간 25조 토큰
2. **공급(컴퓨트)이 못 따라간다** — 전 사용자 개방 불가
3. **가격으로 수요를 조절한다** — 12월 1일부터 2배, 무료 티어 미제공

가격 인상은 "성능이 좋아져서"가 아니라 **"너무 많이 써서"** 일어난 변화라는 점이 중요합니다. 실제로 지난 10월 9일부터 Gemini 앱 무료 사용자는 Flash-Lite 중심의 '자동 모델 선택'으로 제한됐고, Argon은 유료 구독자 전용으로 남아 있습니다. 무료 사용자에게 돌아가는 모델과 유료 개발자가 API로 사는 모델의 간극이 점점 벌어지는 흐름입니다.

## 영향 1: 개발자 — 월 청구서가 두 배가 되는 지점

계산은 단순합니다. 아래는 **한 달에 입력 5,000만 토큰, 출력 500만 토큰**을 쓰는 에이전트 파이프라인 가정입니다.

| 구분 | 11월까지 | 12월 1일부터 |
|:---|:---|:---|
| 입력 50M | $100 | **$200** |
| 출력 5M | $50 | **$100** |
| 합계 | **$150** | **$300** |

여기에 사고(thinking) 토큰이 붙습니다. Argon은 출력 단가에 사고 토큰이 포함되기 때문에, 복잡한 추론 작업을 길게 돌리는 에이전트일수록 체감 인상 폭이 더 큽니다. 문서에 적힌 "long-decode generation up to 1M tokens"처럼 긴 디코딩을 전제로 한 모델이라, 출력 토큰이 많은 워크로드일수록 2배 인상이 그대로 때립니다.

반대로 **입력이 압도적으로 많은 RAG·문서 요약형 작업**은 캐싱 단가($0.10 → $0.20)와 배치 단가($1.00 → $2.00)의 영향을 크게 받습니다. 캐싱을 걸어두면 실질 단가가 내려가지만, 캐싱 단가 자체가 2배가 되니 "캐싱을 쓰니까 안전하다"는 계산도 다시 해야 합니다.

## 영향 2: 업무 자동화 — 원가 구조를 다시 봐야 하는 이유

자동화 파이프라인을 운영하는 입장에서 이번 변화가 까다로운 이유는 **인상 시점이 명확하다는 점**입니다.

- 12월 1일 이전에 만들어 둔 스케줄 작업·에이전트가 12월 1일 이후에도 같은 빈도로 돌면, 코드는 그대로인데 비용만 2배가 됩니다.
- 반면 성능은 그대로입니다. **같은 작업에 두 배를 내는 구간**이 생깁니다.
- 그래서 지금 필요한 건 모델 교체 검토가 아니라 **토큰 회계**입니다. 작업별로 입력/출력 토큰을 로그로 남기고, 12월 1일 기준으로 월 예상액을 다시 계산해 두면 인상폭이 청구서로 튀어나오기 전에 대응할 수 있습니다.

바로 쓸 수 있는 우회 수단은 세 가지입니다.

1. **배치로 옮길 수 있는 작업은 배치로** — 단가 자체는 2배가 되지만 Standard의 절반($2.00/$10.00)이라는 상대 우위는 유지됩니다. 실시간성이 필요 없는 야간 배치·정기 리포트가 대상입니다.
2. **모델 라우팅** — 모든 요청을 Argon으로 보내지 말고, 분류·요약·포맷 변환 같은 단순 단계는 Flash로 내리고 Argon은 판단이 필요한 구간에만 씁니다. Flash도 1월에 2배가 되지만 절대 단가는 여전히 Argon의 5분의 1 수준입니다.
3. **출력 토큰 다이어트** — 출력이 2배로 오르는 구조이므로, 응답 형식을 JSON 스키마로 고정하고 불필요한 설명 문장을 잘라내는 것만으로도 체감 인상 폭이 줄어듭니다.

## 영향 3: 사용자 — 무료와 유료의 간극

일반 사용자 입장에서 이번 가격 변화는 직접 닿지 않습니다. Gemini 앱의 구독 요금(Gemini 앱 내 Argon 사용)은 별도 정책이고, 바뀐 건 **API 단가**입니다. 다만 방향은 분명합니다.

- 무료: Flash-Lite 중심의 자동 모델 선택
- AI Plus/Pro: 제한적 고성능 모델 + 사용량 한도
- Ultra·API 유료: Argon 전체 성능

"무료로도 최신 모델을 쓸 수 있다"는 구간이 계속 줄어드는 흐름이고, 이번 인상은 그 흐름이 **가격표에 숫자로 확정된 사건**입니다.

## 전망: 12월 1일 전에 벌어질 일들

**첫째, 11월 말에 사용량이 몰릴 가능성.** 도입가가 끝나기 전에 대량 배치를 돌려두려는 수요가 생깁니다. 이미 컴퓨트 제약을 인정한 상태라, 11월 하순에는 레이트 리밋이나 지연이 평소보다 심해질 수 있습니다. 마감이 걸린 대량 작업이라면 11월 초중순으로 앞당겨 두는 편이 안전합니다.

**둘째, Gemini 4 Flash의 등장.** Argon의 축소·증류 버전이 나오면 "Argon급 성능을 더 싸게" 쓰는 경로가 열립니다. SDK 코드에서 Gemini 4 Flash 문자열이 발견됐다는 보도가 나온 상태지만, 구글 공식 발표는 아직 없습니다. 이 경우 Argon 인상은 **모델 라인업을 위로 재배치하는 작업**의 일부로 읽힙니다.

**셋째, 경쟁 구도.** 같은 시기 다른 진영도 장문 컨텍스트 모델을 내놓고 있어, 2배 인상이 그대로 유지될지 아니면 경쟁에 밀려 조정될지는 12월~1월 사용량 지표로 판가름 납니다. 최소한 지금 문서에 적힌 날짜는 **확정된 조건**이므로 그대로 예산에 반영하는 게 맞습니다.

## 정리: 지금 해둘 체크리스트

- [ ] Gemini API 청구서에서 Argon 사용 비중 확인 (Standard / Batch / Priority)
- [ ] 12월 1일 기준 월 예상액 재계산 (입력·출력 토큰 분리)
- [ ] 실시간성 없는 작업은 Batch로 이동 검토
- [ ] 단순 단계는 Flash로 라우팅, Argon은 판단 구간에만
- [ ] 출력 형식 고정(JSON 스키마)으로 출력 토큰 절감
- [ ] 그라운딩 사용량 확인 (월 5,000회 무료 한도, 이후 1,000회당 $14)
- [ ] 11월 하순 대량 배치는 일정 앞당기기

가격이 오르는 뉴스는 반갑지 않지만, **날짜가 공식 문서에 박혀 있다는 점**은 오히려 기회입니다. 12월 1일이라는 마감이 있는 만큼, 지금 토큰 회계를 한 번 정리해 두면 인상 이후에도 같은 작업을 같은 원가로 유지할 여지가 남습니다. AI 에이전트를 실사용하며 자동화 파이프라인을 운영하는 분들이라면, 이번 주에 청구서 한 장을 열어볼 가치가 충분합니다.
