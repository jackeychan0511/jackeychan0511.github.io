## ① 데스크톱 플러그인 SDK 웨이브 — 이번 릴리스의 본체

솔직히 이번 업데이트에서 제일 눈에 띄는 건 모델도 성능도 아닙니다. **데스크톱 플러그인 SDK**예요.

기존에도 데스크톱 플러그인은 있었습니다. 단일 ESM 파일 하나를 `$HERMES_HOME/desktop-plugins/<id>/plugin.js`에 떨어뜨리면 앱이 몇 초 안에 로드하고, 저장할 때마다 핫리로드되는 구조였죠. 문제는 **플러그인이 손댈 수 있는 표면이 좁았다**는 겁니다.

이번 창에서 추가된 건 다음과 같습니다.

- **composer 드래프트 API** — 플러그인이 입력창(composer)의 드래프트를 읽고 쓸 수 있음
- **세션 목록 · 행 장식(row-decoration) 슬롯** — 세션 리스트에 자기 항목을 끼워 넣거나 배지를 붙일 수 있음
- **사이드바 내비 설정(sidebar nav prefs)** — 플러그인이 좌측 내비게이션에 자기 자리를 가질 수 있음
- **모델 필 라벨 프로바이더(model-pill label providers)** — 모델 표시 이름을 플러그인이 공급
- **설정 · 스킬 · 툴셋 · 프로필 타입 브리지** — 타입이 붙은 브리지로 코어 설정 계층에 접근
- **샌드박스 임베드 프리미티브** — 플러그인이 임의 UI를 안전하게 임베드
- **appearance-settings 슬롯** — 테마/외형 설정 화면 확장
- **플러그인 백엔드용 공개 이벤트 브리지** — 플러그인 백엔드가 앱 이벤트를 구독

개발자 문서(`Desktop Plugin SDK`)를 보면 코어가 자기 UI를 등록하는 방식과 플러그인이 등록하는 방식이 **같은 중앙 레지스트리**를 쓴다고 설명합니다. 그러니까 이번 SDK 웨이브는 "플러그인을 위한 별도 구멍"을 뚫은 게 아니라, **코어와 플러그인의 권한 격차를 실제로 좁힌 것**에 가깝습니다. 개인적으로 이게 이번 릴리스에서 가장 업무 자동화에 직결되는 변화라고 봅니다. 사내 승인 플로우나 커스텀 상태바를 붙이려면 예전엔 코어를 건드려야 했는데, 이제는 플러그인 레이어에서 끝낼 수 있으니까요.

## ② 커넥터 페이지가 MCP 탭을 대체 — 붙이는 동선이 짧아졌다

두 번째 변화는 UI 쪽입니다. **MCP 탭이 사라지고 '커넥터(Connectors)' 페이지로 대체**됐어요.

달라진 점을 정리하면 이렇습니다.

- 방금 설치한 플러그인의 **MCP 서버를 'Connect now' 버튼 하나로** 연결
- 설치된 플러그인의 **툴과 스킬이 열려 있는 모든 채팅에 즉시 반영**
- 온보딩 단계에서 **커넥터 옆에 카탈로그 플러그인도 함께 제안**
- `tool_search`로 커넥터 툴(Gmail, Linear, Notion 등)을 검색해서 찾는 흐름 유지

예전에는 "MCP 서버를 어디서 등록하지?" → "이 플러그인은 무슨 툴을 주지?" → "그 툴이 지금 세션에 왜 안 보이지?" 하는 세 단계가 따로 놀았습니다. 이제는 커넥터 페이지 한 곳에서 연결하고, 연결한 게 바로 대화에 살아납니다. **업무 도구를 붙이는 마찰이 줄어드는 건 자동화 파이프라인을 운영하는 입장에서 조용하지만 큰 변화**예요.

## ③ 프로필별 중지·시작·재시작 + `gateway.standalone`

세 번째는 운영자에게 바로 와닿는 부분입니다. **호스트 멀티플렉서 아래에서 프로필별로 중지·시작·재시작**이 가능해졌습니다. 그리고 `gateway.standalone` 설정으로 **특정 프로필을 게이트웨이에서 빼는(opt out)** 것도 가능해졌어요.

저처럼 한 호스트에서 여러 프로필을 돌리는 경우, 예전에는 게이트웨이를 건드리면 **전체가 같이 흔들렸습니다**. 프로필 하나를 재시작하려고 해도 옆 프로필의 세션이 끊기는 일이 생겼죠. 이제는 격리해서 다룰 수 있습니다. 반대로 "이 프로필은 게이트웨이에 안 태우고 따로 굴리겠다"는 선택지도 생겼고요.

조합해 보면 이런 운영이 가능해집니다.

- **항상 떠 있어야 하는 프로필** — 게이트웨이에 태워서 상시 대기
- **무거운 배치성 프로필** — `gateway.standalone`으로 빼서 따로, 필요할 때만 올리고 내리기
- **장애 격리** — 문제 생긴 프로필만 재시작, 나머지는 그대로 유지

## 실제 사용감 — 솔직히 이런 느낌

며칠 전 v0.21.4에서 게이트웨이가 "호스트당 하나"로 정리된 게 기억나실 겁니다. 이번 v0.21.5는 그 위에 **프로필 단위 제어**를 얹은 셈이에요. 구조 변경(0.21.4) → 세밀한 제어(0.21.5) 순서로 온 게 흐름상 자연스럽고, 실제로 만져 보면 "아, 이제 게이트웨이를 안 부수고도 프로필 하나를 내릴 수 있구나" 하는 감각이 먼저 옵니다.

체감 우선순위를 매기면 저는 이렇게 봅니다.

1. **프로필별 중지·시작·재시작** — 매일 쓰는 운영 편의. 즉시 체감
2. **커넥터 페이지 통합** — 도구 붙이는 마찰 감소. 며칠 쓰면 "예전엔 왜 이랬지" 소리 나옴
3. **데스크톱 플러그인 SDK** — 당장은 개발자용이지만, 남들이 만든 플러그인이 쏟아지면 일반 사용자도 체감
4. **Simple/Advanced 모드** — 팀 배포할 때 진가 발휘

반대로 **당장 눈에 안 보이는 변화**도 많습니다. 성능 작업, 설정 로딩 개선 같은 건 "빨라진 것 같은데?" 수준이고, 다국어 카탈로그도 한국어 사용자에겐 크게 와닿지 않아요.

## 장점

- **"패치" 이름값을 안 하는 내용** — 460개 PR, 475개 이슈가 사흘 만에 롤업. 스테이블 태그라 배포용으로 안전
- **확장 표면이 실제로 넓어짐** — 데스크톱 플러그인 SDK의 슬롯·브리지·이벤트가 한 번에 들어옴
- **운영 격리** — 프로필별 재시작 + `gateway.standalone`으로 장애 반경을 줄일 수 있음
- **커넥터 동선 단축** — 연결 → 툴 노출 → 세션 반영이 한 흐름으로
- **모델 선택지 확대** — GPT-6 Sol/Terra/Luna, Claude Opus 5.5가 카탈로그에 정식 등록
- **무료·오픈소스(MIT)** — 이 정도 확장성을 이 가격(0원)에 쓰는 게 여전히 놀랍습니다. GitHub 스타도 24만 8천 개대(9월 24일 기준 약 248.7k)까지 올라왔어요

## 단점 · 아쉬운 점

- **정식 큐레이션 노트가 없음** — 이번 창의 항목은 릴리스 노트의 "일부러 문서화하지 않음" 문단과 커밋 로그로만 확인 가능. v0.22.0까지 기다려야 전체 그림이 보입니다
- **"패치" 태그의 함정** — 이름만 보고 "사소한 버그픽스겠지" 하고 넘기면, 플러그인 개발자에게는 판이 바뀐 릴리스를 놓칩니다
- **문서·서드파티 정보와의 시차** — 커넥터 페이지·SDK 관련 외부 문서가 아직 이전 구조(MCP 탭) 기준인 곳이 있음
- **다국어 확대는 한국어 사용자에겐 무관** — 프/독/스 카탈로그 완성이 이번 하이라이트 중 하나지만, 한국어는 이번 목록에 없습니다
- **롤백이 항상 쉽지는 않음** — 최근 릴리스들은 상태 DB 마이그레이션이 끼는 경우가 있어, 검증된 백업 없이 "일단 올리고 되돌리기"는 위험합니다

## 그래서 지금 올릴까? — 업데이트 판단 기준

**① 데스크톱 앱을 주 인터페이스로 쓰는 분**
올리세요. 커넥터 페이지, Simple/Advanced 모드, 커스텀 모델 직접 입력까지 UI에서 끝나는 게 확 늘었습니다.

**② 서버에서 여러 프로필을 굴리는 분**
올리는 걸 권합니다. 프로필별 중지·시작·재시작과 `gateway.standalone`은 운영 방식 자체를 바꿔 줍니다. 다만 **올리기 전에 프로필별 설정 백업**은 필수예요.

**③ 데스크톱 플러그인을 만들거나 쓰는 분**
이번 릴리스는 사실상 "SDK 릴리스"입니다. `hermes update`로 올리고, 문서(`Desktop Plugin SDK`)와 커밋 로그를 같이 보시길 권합니다.

**④ 자동화 파이프라인을 운영하는 분**
겁내지 않아도 됩니다. 이번 태그는 Docker·Hermes Cloud용 **스테이블 태그**로 나왔고, 컨테이너 이미지도 이 태그로 빌드됩니다. 다만 상시 가동되는 작업이 있다면 **커넥터 페이지 전환 이후 툴 노출이 그대로인지 한 번 확인**하고 넘어가세요.

공통으로 하나만 더 붙이면, **업데이트 전 백업은 이제 습관**입니다. 요즘 릴리스들은 사흘 간격으로 큰 창이 롤업되니까, 무중단으로 굴리는 환경일수록 태그를 확인하고 천천히 따라가는 게 안전합니다.

## 마무리

정리하면 v0.21.5는 **"성능 릴리스"도 "모델 릴리스"도 아닌, 확장 릴리스**입니다. 데스크톱 플러그인 SDK가 코어와 같은 레지스트리를 쓰게 되면서 **Hermes Agent는 '에이전트를 쓰는 앱'에서 '확장해서 쓰는 플랫폼' 쪽으로 한 칸 더 넘어갔습니다.** 커넥터 페이지로 도구 붙이는 동선이 짧아진 것, 프로필별로 게이트웨이를 내리고 올릴 수 있게 된 것도 같은 방향이에요.

저처럼 **한 대의 서버에 프로필 여러 개를 얹고, 사내 도구까지 붙여서 업무 자동화 파이프라인을 운영하시는 분들**이라면 이번 업데이트는 체감이 확실합니다. 반대로 **가볍게 채팅만 쓰시는 분**은 굳이 사흘 만에 따라올 필요 없이 다음 정식 노트(v0.22.0)까지 기다려도 충분하고요.

무료·오픈소스(MIT)에 이 정도 확장성과 릴리스 속도를 유지하는 건 여전히 인상적입니다. **가성비 좋은 AI 툴을 찾는 분께는 계속 추천할 만한 선택지**예요.
