## 1. v2026.8.1-beta.1 상세 노트 — 8월 베타 라인의 실제 내용물

어제 글에서 "8월 라인의 기반을 다지는 릴리즈로 읽힌다"고 말씀드렸는데, 상세 노트를 보니 **기반을 다지는 동시에 알찬 기능들도 꽤 실려 있습니다.** 눈에 띄는 항목만 추려볼게요.

### ① 네트워크·툴 출력 보안 강화 (제일 중요한 변경)

- 웹·검색·프로바이더·MCP·툴 출력에서 **악의적인 콘텐츠를 정리(sanitize)**하는 로직이 강화됐습니다.
- 스트리밍 마커, 인용(citation), 오류 메시지, 취소 신호까지 **모든 출력 경로가 검증 대상**이 됐어요.

에이전트가 인터넷을 돌아다니면서 받아온 내용을 그대로 믿고 쓰는 구조다 보니, 이 부분은 생각보다 중요합니다. **외부에서 주입되는 악성 지시를 차단하는 보안 레이어**가 한 겹 더 생긴 셈입니다.

### ② 공유채팅 메모리 프라이버시

- 그룹·채널 채팅 컨텍스트에서 **개인 루트 `MEMORY.md`가 빠지도록** 수정됐습니다. (Fix #84466)
- 개인 세션의 메모리는 그대로 유지하면서, **여럿이 보는 채팅에는 내 메모리가 새어나가지 않게** 한 건데요. 게이트웨이를 여럿이 쓰는 분이라면 반가운 변경입니다.

### ③ Twilio MMS·배송 상태 확인

- SMS 플러그인으로 **MMS(사진·영상 메시지) 수신·발신**이 가능해졌습니다.
- 프로바이더가 받았다고 끝이 아니라, **서명된 배송 결과(delivered/failed/undelivered/conflicted)**까지 확인할 수 있습니다.

### ④ 배치 툴 서치(Batched Tool Search)

- 한 번의 요청으로 **최대 16개 쿼리를 묶어** 여러 기능군을 동시에 탐색할 수 있습니다.
- 기존 스칼라 계약은 그대로 유지하면서, **여러 스킬·툴을 한 번에 찾아야 하는 에이전트 워크플로**에 유용합니다.

### ⑤ 브라우저 확장 CDP 연동

- **Puppeteer나 chrome-devtools-mcp 같은 외부 CDP 클라이언트**가 원격 디버깅 권한 프롬프트 없이 페어링된 Chrome을 직접 제어할 수 있게 됐습니다.
- `openclaw browser extension cdp` 명령으로 릴레이 엔드포인트와 인증 헤더도 확인 가능합니다. **브라우저 자동화를 코드로 직접 다루는 개발자 분들께** 유용한 기능이에요.

### ⑥ Codex 0.147 정렬

- 관리형 앱서버·프로토콜 픽스처가 **Codex 0.147.0**에 맞춰 정렬됐습니다.
- 차단 프롬프트는 유지하되, 비차단 `request_user_input` 요청은 120초로 제한하는 방식입니다.

## 2. 자동화 운영자를 위한 변경 — 실패 10회면 알아서 멈춘다

이번 노트에서 제가 가장 주목한 건 따로 있습니다. **자동화 실패 컨테인먼트(Automation failure containment)**인데요.

- **시간 기반 반복 작업이 10회 연속 실행 실패하면 자동으로 비활성화**됩니다.
- 실패 사유와 횟수가 기록에 남고, **복구 명령과 함께 담당 에이전트에게 알림**이 갑니다.

솔직히 저처럼 **밤새 자동화를 돌려놓는 사람** 입장에서는 이게 가장 든든한 변경입니다. 예전엔 API 키가 만료되거나 채널이 끊기면 그 작업이 **조용히 실패를 반복**하다가 아침에 확인하고 당황하는 일이 많았거든요. 이제는 10회 실패 시 알아서 멈추고 알려주니, **조용히 새는 자동화를 미리 막을 수 있습니다.**

### 운영자를 위한 CLI도 강화

- **세션 생명주기 CLI**: `openclaw sessions archive <key...>`, `openclaw sessions delete <key...>` — 헤드리스·SSH 환경에서도 세션 정리가 가능해졌습니다.
- **`--json` 출력 확장**: config, models, plugins, cron, docs, hooks, proxy, skills 등 **보고형 명령 대부분이 JSON 출력**을 지원합니다. 스크립트로 자동화하시는 분께 유용합니다.
- **로컬 모델 셋업**: Ollama, llama.cpp, LM Studio 셋업 옵션이 Control UI·macOS에 노출되고, 준비된 모델을 검증한 뒤 성공을 알려줍니다. **로컬 모델만 쓰시는 분**께는 체감이 큰 변경입니다.

> 참고로 **컨텍스트 엔진 호스트 파라미터(`context-engine-legacy-host-param-default`) 호환 레코드는 2026-08-12(오늘!)까지만 유효**합니다. 플러그인 개발자시라면 `ContextEngineInfo.acceptedHostParams` 선언을 확인해두세요.

## 3. 메인브랜치 새 소식 — Kimi K3 비디오 입력, 세션 환경설정 동기화

릴리즈 노트만큼 중요한 게 **메인브랜치의 최근 커밋**입니다. 다음 베타에 실릴 기능들이 보이거든요. 8/11~8/12 커밋에서 눈에 띈 항목입니다.

### ① Kimi K3 네이티브 비디오 입력 (feat: moonshot)

- **`feat(moonshot): add native K3 video input`** — Moonshot의 차세대 모델 **Kimi K3에 네이티브 비디오 입력**을 지원하는 커밋이 8/11 들어왔습니다. (#122337)
- Kimi K3는 Moonshot AI가 공개한 **2.8T 파라미터 오픈웨이트 모델(활성 104B)**로, 코딩·에이전트·긴 컨텍스트에서 SOTA급 성능을 목표로 하는 모델입니다.
- 항상 thinking이 활성화되고 `reasoning_effort`(low/high/max)로 추론 깊이를 조절하는 구조인데, OpenClaw에서 **비디오 입력까지 네이티브로** 받을 수 있게 되는 셈입니다.

**영상 기반 자동화(영상에서 정보 추출, 화면 분석 등)를 생각하시는 분**이라면 다음 베타에서 꼭 확인해볼 기능입니다.

![Kimi K3 허깅페이스 모델 카드](/assets/images/posts/openclaw-v202681-beta-20260812/kimi-k3-huggingface.png)
*Moonshot AI의 Kimi K3 모델 카드 (출처: huggingface.co/moonshotai/Kimi-K3, 확인일 2026-08-12)*

### ② 세션 환경설정·최근 항목 동기화

- **`feat: sync new-session preferences and recents by identity`** (#121816) — 새 세션 환경설정과 최근 항목이 **사용자 신원(identity) 기준으로 동기화**됩니다. 여러 기기에서 게이트웨이를 쓰는 분께 체감이 큰 변경입니다.

### ③ 자잘하지만 꼼꼼한 수정들

- **Windows**: npm으로 설치한 네이티브 세션 CLI 실행 문제 수정 (#122334)
- **Gateway**: 세션 타이틀 프리워밍 복구 (#122368), 아카이브 전환 중 세션 정체성 보존 (#121169)
- **Memory**: dreaming 아티팩트 원자적 게시 (#122343)
- **UI**: 채팅 공유 메뉴 컴팩트화, 채팅 테이블 카드 정렬, 트랜스크립트 렌더링 정합성 등 다수

## 4. Kimi K3, 잠깐 짚고 갑니다

Kimi K3가 처음이신 분들을 위해 간단히만 정리하면:

| 항목 | 내용 |
|:-----|:-----|
| **개발사** | Moonshot AI (중국) |
| **규모** | 2.8T 파라미터 오픈웨이트, 활성 104B (MoE) |
| **특징** | 코딩·에이전트·긴 컨텍스트·채팅 특화, 항상 thinking 활성 |
| **추론 제어** | `reasoning_effort`: low / high / max (기본 max) |
| **OpenClaw 지원** | 기존 Moonshot 프로바이더 + 메인브랜치에서 **비디오 입력 네이티브 지원 추가 중** |

OpenClaw는 원래부터 **모델 자유도가 높은 게 장점**입니다. GPT, Claude, DeepSeek에 이어 Kimi까지, 비디오 입력까지 가능해지면 **"뇌"를 상황에 맞게 골라 쓰는** 재미가 확실히 커질 것 같습니다.

## 5. 지금의 버전 구도와 스타 수 — 8월 12일 기준

어제 글에서 정리한 구도에서 크게 달라진 건 없지만, 수치 하나는 갱신됐습니다.

| 구분 | 버전 | 상태 |
|:-----|:-----|:-----|
| **안정판 (Stable)** | v2026.7.1-2 | 8/4 핫픽스 반영, 무난하게 운영 가능 |
| **연장 안정판 (Extended-Stable)** | v2026.6.34 | 8/8 보안·안정화 릴리즈, 장기 운영용 |
| **베타 (Beta)** | v2026.8.1-beta.1 | 8/10 시작, 상세 노트 공개됨 |

**GitHub 스타는 385,965개(2026-08-12 확인)**로, 어제(385,827개)보다 하루 만에 약 140개가 늘었습니다. 포크는 81,118개입니다. 40만 개 돌파가 이제 정말 눈앞입니다.

### 지금 뭘 설치하면 좋을까?

- **운영 중이신 분**: 안정판 `v2026.7.1-2` 또는 장기 운영용 `v2026.6.34` 그대로 추천합니다.
- **새 기능 미리 보고 싶은 분**: `v2026.8.1-beta.1` — 특히 **Twilio MMS, 배치 툴 서치, CDP 연동**을 직접 만져보고 싶다면 베타로 올라타볼 만합니다.
- **Kimi K3 비디오 입력**은 아직 메인브랜치 단계이니, **다음 베타(8.1-beta.2+)에서 확인**하시는 걸 권합니다.

```bash
# 안정판
npm install -g openclaw@latest

# 베타판
npm install -g openclaw@beta

# 버전 확인 & 문제 자동 수정
openclaw version
openclaw doctor --fix
```

## 마무리 — 오늘 소식 핵심 정리

1. **v2026.8.1-beta.1 상세 노트 공개** — 네트워크 출력 보안 강화, 공유채팅 메모리 프라이버시, Twilio MMS, 배치 툴 서치, CDP 연동, Codex 0.147 정렬
2. **자동화 실패 자동 차단** — 반복 작업 10회 연속 실패 시 자동 비활성화 + 복구 안내 (운영자에게 가장 유용한 변경)
3. **메인브랜치: Kimi K3 비디오 입력 지원** — 다음 베타에서 영상 기반 자동화 기대
4. **세션 환경설정·최근 항목 신원 기준 동기화** — 멀티 디바이스 사용자 체감 개선
5. GitHub 스타 **385,965개** — 하루 약 +140개, 40만 개 돌파 임박

저처럼 **AI 에이전트를 직접 운영하시는 분**이라면, 이번 주는 "안정판은 그대로, 베타는 상세 노트 확인 후 선택"이면 충분합니다. 특히 **자동화를 많이 걸어두시는 분**은 v2026.8.1 라인이 안정판으로 내려올 때 **실패 자동 차단**을 꼭 활용해보시길 권합니다. 조용히 새는 자동화 하나가 밤잠을 설치게 만드는 경우가 많으니까요.
