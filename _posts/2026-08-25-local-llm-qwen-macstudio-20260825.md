## Qwen 3.8 Flash Next — 8월 27일 자정 출시

알리바바의 Qwen 시리즈 신형 모델 **Qwen 3.8 Flash Next**가 한국 시간 기준 **8월 27일 자정**에 릴리즈됩니다.

이번 모델의 핵심 스펙은:

- **125B 파라미터 MOE(Mixture of Experts) 모델** — 기존 Qwen 3.8 35B MOE와는 다른 라인업
- **N-GRAM 임베딩 51B 추가** — 총 125B + 51B 구성
- SSD 오프로드 관련 언급 — 대용량 모델 특성상 메모리 관리가 관건

문제는 **구동 난이도**입니다. VRAM 120GB를 가진 DGX Spark, AI MAX, Mac Ultra 같은 워크스테이션급 하드웨어가 필요한데, **4비트 양자화를 적용해도 RTX 5090 두 장으로는 부족**할 가능성이 높다는 게 크리에이터의 분석입니다.

다만 MOE 모델 특성상 활성 파라미터가 6B 수준이라, **최소 96GB 메모리만 있으면 쓸만한 속도**가 나올 것이라는 전망도 나옵니다.

## B70 그래픽카드 3장 멀티 GPU 구성 성공

로컬 LLM 크리에이터 **소울시커**는 B70 그래픽카드 3장을 한 메인보드에 연결하는 데 성공했습니다.

- 메인보드 1·2번 슬롯(CPU 직결) + 3번 슬롯(칩셋 직결) 구성
- 2·3번 슬롯 간격 문제는 **라이저 케이블**로 해결
- 기존에 논란이 됐던 "멀티 GPU 인식 불가" 문제를 해결

대용량 모델을 돌리려면 결국 GPU 여러 장을 연결해야 하는데, 실제로 되는 구성과 안 되는 구성이 갈린다는 점에서 실전 정보가 될 수 있는 내용입니다. 자세한 구성 방법은 다음 영상에서 다룰 예정이라고 합니다.

## 애플 M5 Max/Ultra Mac Studio 공개 — 1.2TB/s 메모리 대역폭

애플이 8월 25일 **M5 Max와 M5 Ultra 칩을 탑재한 신형 Mac Studio**를 공개했습니다.

가장 주목할 점은 **메모리 대역폭 1.2TB/s**입니다. 이는 RTX 3090이나 5080보다 높은 수치로, **5090과 RTX PRO 6000만이 더 빠른** 수준입니다. 디코딩 토큰 생성 속도가 크게 기대되는 이유입니다.

| 구성 | 가격 | 특징 |
|---|---|---|
| M5 Max 36GB | 약 429만원 | 27B 모델 6비트 양자화 가능 |
| M5 Max 64GB | 약 600만원 | 27B 모델 8비트 양자화 가능 |
| M5 Max 128GB | 약 871만원 | 대용량 구성 가성비 |
| M5 Ultra 256GB | 약 1,629만원 | 로컬 LLM 올인원 구성 |
| M5 Ultra 512GB | 10월 하순 출시 | 최상위 구성 (예상 3천만원대) |

256GB 최저 구성이 1,629만원인데, 데스크탑에서 같은 메모리 대역폭·용량을 맞추려면 수천만원이 든다는 점에서 **로컬 LLM 용도로는 가성비**라는 평가입니다.

다만 단점도 분명합니다:
- CUDA 생태계 사용 불가 → **MLX 환경**에서 지원되는 소프트웨어 위주로 사용해야 함
- Mac Mini는 메모리 대역폭이 낮아 AI 용도로는 비추천
- 512GB 모델은 10월 하순 출시 예정

## 시사점: 로컬 LLM 하드웨어의 패러다임 변화

이번 소식들이 시사하는 바는 명확합니다. **모델은 점점 커지고, 그만큼 메모리 용량과 대역폭이 경쟁력의 핵심**이 되고 있다는 것.

Qwen 3.8 Flash Next 같은 125B급 모델이 나오면, 이제 GPU 한두 장으로는 부족하고 **대용량 메모리 워크스테이션(Mac Studio, DGX Spark, AI MAX)이 새로운 표준**이 될 가능성이 높습니다.

대용량 메모리 구성이면 LLM, 비디오 모델, 오디오 모델을 **동시에 올려 오케스트레이션**할 수 있어서, AI 에이전트 워크스테이션으로서의 활용도도 크게 높아집니다.

**8월 27일 Qwen 3.8 Flash Next 출시**와 **Mac Studio 사전 주문 시작**이 겹치는 날, 로컬 LLM 커뮤니티의 향후 방향이 정해질 것으로 보입니다.
