## 2. Hermes Agent가 뭐길래 — 10만 스타에 1.5B 달러 펀딩

### 1) 오픈소스 '자기개선형' AI 에이전트

Hermes Agent는 Nous Research가 만든 **MIT 라이선스 오픈소스 AI 에이전트**입니다. 일반 챗봇과 다른 점은 크게 세 가지입니다.

- **영구 메모리와 스킬(Skills)**: 대화가 끝나도 학습한 내용과 작성한 스킬 문서를 기억하고, 다음 세션에서 바로 활용합니다.
- **실제 작업 실행**: 터미널 명령, 파일 생성·수정, 웹 검색, 크롤링, git 커밋·푸시까지 사용자가 승인한 범위에서 직접 수행합니다.
- **다채널 운영**: CLI(터미널)뿐 아니라 텔레그램, 디스코드, 슬랙, iMessage 등 메신저로도 같은 에이전트를 쓸 수 있습니다.

## 3. v0.19.0 퀵실버 릴리스 — 핵심 업데이트 7가지

공식 릴리스 노트(GitHub, 2026-07-20)를 기준으로 핵심 변경점을 정리했습니다. 이번 릴리스에는 **약 2,245개 커밋, 450명 이상의 커뮤니티 기여자**가 참여했습니다.

### 1) 첫 응답(첫 토큰) 시간 80% 단축 ⚡

가장 눈에 띄는 변화입니다. 콜드 스타트 시 "Initializing agent..."로 표시되던 준비 단계가 **약 4.3초에서 0.9초로 줄었습니다**. CLI, 게이트웨이, TUI, 데스크톱, 크론잡까지 모든 실행 환경에 적용되며 별도 설정이 필요 없습니다. 여기에 **추론(reasoning) 모델의 사고 과정을 스피너 대신 실시간으로 스트리밍**해 주는 기능이 기본값이 되면서, "기다리는 느낌" 자체가 사라졌다는 평가입니다.

### 2) 데스크톱 앱 대대적 속도 개선

6월 공개 미리보기로 나온 **Hermes Desktop**(macOS·Windows·Linux 네이티브 앱)에 20개 이상의 성능 개선 PR이 적용됐습니다. 긴 답변의 마크다운 스트리밍 처리 CPU 사용량이 **14배 감소**했고, 큰 diff(변경점) 화면이 멈추던 문제는 가상화로 해결, 세션 전환도 빨라졌습니다. "스트리밍 중 사이드바가 매 토큰마다 다시 그려지던 문제"까지 잡아서, 대화 기록이 길어져도 네이티브 앱처럼 부드럽게 동작합니다.

### 3) 터미널에서 구독·결제 관리

`/subscription` 명령 하나로 현재 요금제와 잔여 사용량 확인, 업그레이드 금액 미리보기("$46.30 결제하고 업그레이드"), 다운그레이드 시점 확인까지 터미널에서 바로 처리됩니다. `/topup`으로 잔액 충전도 가능하고, 데스크톱 앱에도 결제 설정 탭이 추가됐습니다.

### 4) 스마트 명령 승인(Smart Approvals) 기본 적용

민감한 명령 실행 시 **LLM 리뷰어가 해당 명령을 독립적으로 검토해 승인 여부를 판단**하는 방식이 기본값이 됐습니다. 승인은 명령 단위로만 적용되고, 사용자가 거절 사유를 남기는 `/deny <사유>` 기능과 특정 명령을 원천 차단하는 deny 규칙도 추가돼 "승인 피로"를 줄이면서도 통제권은 유지하는 구조입니다.

### 5) Bitwarden·1Password 비밀번호 관리자 연동 🔐

API 키를 평문 `.env` 파일에 두는 대신 **Bitwarden과 1Password에서 비밀값을 불러오는 SecretSource 인터페이스**가 추가됐습니다. 여러 볼트 동시 사용, 충돌 경고, 변수별 출처 추적까지 지원합니다. 커뮤니티에서 제안됐던 11개의 관련 PR을 하나로 통합했다는 점도 인상적입니다.

### 6) 서브에이전트 실시간 감시 + 응답 유실 방지

작업을 위임하는 `delegate_task`의 **라이브 트랜스크립트 파일**이 생성돼, 서브에이전트가 실행 중일 때 도구 호출·결과를 바로 지켜볼 수 있습니다. 중간에 프로세스가 재시작돼도 결과가 복원되는 **durable(영속적) 위임**이 적용됐고, 게이트웨이가 죽는 바람에 완성된 답변이 사라지던 문제는 **배달 원장(Delivery Ledger)**을 도입해 다음 부팅 때 재전송하도록 막았습니다.

### 7) 새 모델·프로바이더 지원

GPT-5.6(솔/테라/루나 및 Pro 변형), grok-4.5(GA), moonshotai/kimi-k3, claude-fable-5 등 모델 카탈로그가 확장됐고, Fireworks AI·DeepInfra가 프로바이더로 추가됐습니다. 추론 깊이도 `max`·`ultra` 단계가 추가되어 모델별로 생각 깊이를 조절할 수 있게 됐습니다.

## 4. 실사용 관점 솔직한 장단점

크론잡 자동 포스팅·자료 조사 작업에 실제로 쓰고 있는 입장에서, 장단점을 솔직하게 정리합니다.

### ✅ 장점

- **진짜로 일을 끝까지 합니다**: 검색 → 자료 정리 → 글 작성 → 이미지 삽입 → git add/commit/push까지 사람이 승인 없이도(설정 시) 한 흐름으로 처리합니다. 이 블로그의 일부 자동 포스팅이 바로 이 방식으로 올라갑니다.
- **스킬·메모리 시스템이 성숙함**: 한 번 만든 작업 방식(예: 포스팅 스타일 스킬)을 문서로 저장해 다음 작업부터 자동 적용합니다. 반복 업무 자동화에 강점이 있습니다.
- **무료 오픈소스 + 모델 자유**: MIT 라이선스라 비용 없이 시작할 수 있고, OpenAI·Anthropic·Grok·로컬 모델(LM Studio)까지 자유롭게 붙일 수 있습니다.
- **다채널 운영**: 텔레그램으로 진행 상황을 보고받고, 디스코드·슬랙에서도 같은 에이전트를 호출할 수 있어 원격 확인이 편합니다.

### ⚠️ 단점·주의사항

- **초기 진입장벽이 낮진 않습니다**: 터미널 기반 설치·설정이라 AI에 익숙하지 않으면 첫 세팅에서 막힐 수 있습니다. 데스크톱 앱이 나오면서 완화됐지만, 고급 기능(스킬 작성, 크론잡)은 문서를 읽어야 합니다.
- **문서·커뮤니티가 주로 영어**: 한국어 자료가 아직 적어서 초보자가 따라가기엔 다소 불편합니다.
- **자율 실행 설정은 신중하게**: 명령 자동 승인을 켜면 편하지만, 그만큼 에이전트가 할 수 있는 범위도 커집니다. 처음엔 승인 모드로 시작해 신뢰가 쌓인 작업만 자동화하는 걸 추천합니다.

## 5. 설치·업그레이드 방법 (2026년 8월 기준)

### 새로 시작하는 분

1. 공식 문서([hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs))의 Quick Start를 확인합니다.
2. `pip install hermes-agent`로 설치하거나, 공식 홈페이지에서 **Hermes Desktop 설치 파일**(macOS·Windows·Linux)을 받아 설치합니다. 데스크톱 앱은 첫 실행 온보딩이 있어 CLI보다 시작이 쉽습니다.
3. 사용할 모델 제공자(OpenAI, Anthropic, Nous Portal 등)의 API 키를 등록하면 첫 메시지를 보낼 수 있습니다.

### 기존 사용자 업그레이드

- 터미널에서 `hermes update` 한 번이면 됩니다. 데스크톱 앱은 백그라운드에서 업데이트를 확인하고 원클릭 업데이트를 제공합니다.
- 퀵실버 릴리스의 속도 개선은 **설정 변경 없이 그대로 적용**됩니다.

## 6. 마무리 — 어떤 분께 추천할까요

정리하면, v0.19.0 퀵실버 릴리스는 "성능"과 "안정성" 두 축을 모두 끌어올린 업데이트입니다. 첫 응답 80% 단축은 체감이 확실하고, 비밀번호 관리자 연동과 스마트 승인은 실사용 안전성을 높여줍니다.

**이런 분께 추천합니다.**

- 반복적인 자료 조사·보고서·블로그 작업을 자동화하고 싶은 분
- 오픈소스라 비용 부담 없이 AI 에이전트를 직접 운영해 보고 싶은 분
- 터미널·메신저·데스크톱 어디서든 같은 AI 비서를 쓰고 싶은 분

**이런 분은 신중하게.**

- "설치만 하면 바로 완벽한 비서"를 기대하시는 분 (초기 세팅 시간이 필요합니다)
