요즘 저처럼 오픈소스 AI 에이전트 소식을 매일 체크하시는 분들, 드디어 기다리던 그 버전이 나왔습니다. 지난주 [v0.19.1 정리 글](/2026/08/02/hermes-agent-quicksilver-update/)에서 "다음 정식 릴리즈는 v0.20.0, 8월 안에 나올 가능성이 높다"고 말씀드렸는데, **8월 3일 v0.20.0이 실제로 출시**됐어요. 코드네임은 **"The Herald Release"**.

솔직히 릴리즈 노트를 열어보고 규모에 놀랐습니다. v0.19.0 이후 **약 3,650개 커밋, 머지된 PR 1,400개, 참여 기여자 647명**이죠. 이전 업데이트와는 비교가 안 되는 덩치입니다. 오늘은 이번 v0.20.0에서 **실제로 써보면 체감되는 핵심 기능 5가지**와, 지금 바로 업데이트하는 방법까지 정리해드립니다.

## 1. v0.20.0 Herald, 도대체 뭐가 달라졌나

릴리즈 노트의 한 줄 요약이 인상적입니다. "헤르메스는 신들의 전령"이라는 뜻에서 착안해, 이번 버전의 4대 축을 이렇게 정의했어요.

1. **말한다** — 실시간 음성 대화
2. **다른 에이전트에게 소식을 전한다** — A2A v1.0
3. **내 시스템에 이벤트를 알린다** — 서명된 웹훅
4. **출처를 밝힌다** — 검증 가능한 인용 리서치

여기에 데스크톱 앱의 플랫폼화, CLI 파워 명령어, 성능 개선까지 더해졌습니다. 하나씩 풀어보겠습니다.

---

## 2. ① 진짜 대화가 되는 음성 — 끼어들기·웨이크워드

이번 업데이트의 가장 큰 체감 포인트는 **음성 모드가 "대화"가 됐다**는 겁니다.

예전에는 말을 하면 답변 전체가 생성될 때까지 기다렸다가 긴 오디오 파일을 듣는 구조였죠. 이제는 **스트리밍 방식으로 문장 단위로 바로바로 읽어주고, 말하는 도중에 끼어들면(barge-in) 그 자리에서 멈추고 들어줍니다.** 모델도 "사용자가 중간에 끼어들었다"는 사실을 인지해서 대화 흐름이 자연스러워졌어요.

- **온디바이스 웨이크워드**: "헤이 헤르메스" 같은 직접 만든 호출어로 원격에서 깨울 수 있습니다. 감지가 기기에서 처리돼서 대기 중에는 오디오가 외부로 나가지 않습니다.
- **플랫폼 음성메모**: WhatsApp, LINE, DingTalk 등에서 음성 메모를 보내면 알아서 받아 적고 답변합니다. 자동 TTS 답변도 플랫폼별 포맷(opus 등)에 맞춰 전달됩니다.
- **"stop" 한 마디로 종료**: 키보드 없이 음성만으로 대화를 끝낼 수 있습니다.

터미널에 말을 걸 수 있다는 것 자체가 처음엔 낯설지만, 요리하면서 레시피를 물어보거나 회의 중 빠르게 메모할 때는 확실히 유용합니다.

## 3. ② 에이전트가 에이전트와 대화한다 — A2A v1.0

이번 릴리즈에서 기술적으로 가장 의미 있는 부분은 **A2A(Agent-to-Agent) v1.0 프로토콜 플러그인**입니다.

쉽게 말해 **서로 다른 회사가 만든 AI 에이전트끼리도 표준 프로토콜로 대화할 수 있게 된 것**이에요. 내 Hermes 에이전트가 다른 A2A 호환 에이전트를 발견하고, 대화하고, 반대로 다른 시스템에서 Hermes를 구동시킬 수도 있습니다.

재미있는 포인트는 이 기능이 저장소에서 **가장 오래된 기능 요청 중 하나(issue #514)를 해결**했다는 점입니다. 여러 에이전트를 조합해서 쓰는 분들에게는 이번 업데이트의 하이라이트라고 볼 수 있어요. 아직 국내에서 이걸 다루는 자료가 많지 않은데, 에이전트 간 통신이 본격적으로 열리는 신호라고 생각합니다.

## 4. ③ 내 시스템으로 이벤트를 보낸다 — 서명된 웹훅

지금까지 Hermes와 연동하려면 플랫폼에 접속해 폴링하거나 수신 대기하는 방식뿐이었습니다. 이번에 **아웃바운드 웹훅**이 추가되면서 상황이 완전히 바뀌었어요.

- 세션 활동, 턴 완료, 도구 실행 같은 **라이프사이클 이벤트를 내가 등록한 HTTP 엔드포인트로 Push**
- **HMAC 서명**으로 수신측이 진위를 검증 가능
- CI/CD, 홈오토메이션, 대시보드 등 HTTP를 쓰는 어떤 서비스와도 폴링 없이 연동

예를 들어 "에이전트가 야간 리포트 작성을 끝내면 슬랙 웹훅으로 알림을 보내고, 실패하면 내 서버에 장애 이벤트를 쏜다" 같은 자동화가 가능해집니다. 밤새 자동화를 돌리는 분에게 특히 반가운 기능입니다.

## 5. ④ 출처를 검증하는 리서치 — grounded-citations

AI 리서치를 자주 시키는 분이라면 "출처가 진짜인지" 확인하느라 고생한 적이 있을 겁니다. 이번에 추가된 **grounded-citations 스킬**이 이 문제를 직접 겨냥합니다.

- 모든 주장에 **검증 가능한 출처 링크**를 달아줍니다
- 인용문은 **실제 페이지 텍스트와 대조**해서, 모델이 지어낸 인용이 아니라 실제 존재하는 문장인지 확인합니다
- **팩트체크 모드**는 내가 준 문서나 주장을 같은 방식으로 검증해서 "확인됨 / 확인 안 됨 / 검증 불가"로 나눠줍니다

지난 8/2 글에서 "Hermes를 리서치 용도로 쓰면 '그럴듯한'과 '증명된'의 차이가 생긴다"고 했는데, 이번에 그 말이 기능이 됐습니다.

## 6. 데스크톱이 플랫폼으로 — 아티팩트·플러그인 SDK·칸반

데스크톱 앱이 단순한 채팅 클라이언트에서 **워크벤치**로 진화했습니다.

- **아티팩트**: 생성된 HTML이나 앱을 **샌드박스 라이브 프리뷰**로 옆 창에서 바로 실행해볼 수 있습니다. 버전별 카드로 관리돼서 이전 버전과 비교도 가능해요.
- **플러그인 SDK**: 첫 공식 플러그인으로 **칸반 보드**가 포함됐습니다. 에이전트가 작업을 칸반 카드로 관리하고, 보드에서 작업별 모델·사고 깊이까지 지정할 수 있습니다.
- **퀵엔트리 창**: OS 어디서나 글로벌 단축키로 메모 창을 띄워 어떤 세션이든 바로 입력할 수 있고, **멀티 윈도우**도 지원합니다.

## 7. CLI 파워 유저를 위한 명령어들

터미널을 주로 쓰는 분들을 위한 명령어도 대거 추가됐습니다. 제가 가장 유용하다고 본 것만 골랐습니다.

| 명령어 | 기능 |
|:----|:----|
| `!명령어` | 모델 턴을 소모하지 않고 **즉시 셸 명령 실행** |
| `/init` | 프로젝트를 스캔해서 `AGENTS.md` 자동 생성·업데이트 |
| `/diff` | 스테이징/전체/세션 변경분을 어디서든 확인 |
| `/context` | 내 컨텍스트 창을 뭐가 차지하고 있는지 분석 |
| `/focus` | 출력을 줄인 집중 모드 |
| `hermes import-agent` | **Claude Code / Codex CLI 설정을 한 번에 마이그레이션** |

특히 `hermes import-agent`는 다른 도구를 쓰다 넘어오는 분들에게 진입장벽을 확 낮춰줍니다. 그리고 작업 중간에 잘못 가고 있다 싶으면 `/stop` 후 재설명할 필요 없이, **작업이 진행되는 동안 바로 수정 지시를 넣으면 그 자리에서 방향을 바꾸는 "미드턴 리다이렉트"**도 추가됐습니다.

## 8. 성능·안정성 — 콜드스타트 14초 → 1.8초

기능만큼이나 바닥을 다지는 작업도 컸습니다.

- **`hermes -w` 콜드스타트 약 14초 → 약 1.8초** (약 87% 단축)
- **도구 자가복구**: 터미널 출력이 잘리면 전체 내용을 파일로 넘겨주고, `patch`는 이미 적용된 편집을 감지해서 중복 실패를 막고, `write_file`은 디스크에 실제로 저장됐는지 검증합니다. 검색이 0건이면 유사어로 재시도하는 등 **모델이 실패를 추측하는 대신 도구가 스스로 복구**하는 방향으로 대거 개선됐습니다.
- **자동화 반복 한도 90 → 500**: 긴 자동화 작업이 인위적인 벽에 막히는 문제가 해소됐습니다.
- **컨텍스트 압축 개편**: 최근 대화 N개는 반드시 보존하도록 보장하고, 한 번에 몰아서 압축하던 방식을 턴마다 조금씩 나눠 압축하는 방식으로 바꿔 긴 세션의 끊김을 줄였습니다.

추가로 신규 모델 지원(Gemini 3.1 Pro·3.6 Flash, claude-opus-5, deepseek-v4-flash-0731), Buzz(Block/Nostr 메신저) 플랫폼 지원도 포함됐습니다.

## 9. 지금 업데이트하는 방법 — 그리고 솔직한 총평

업데이트는 한 줄이면 끝납니다.

```bash
hermes update
```

아직 설치 전이라면 공식 홈페이지에서 설치하시면 됩니다.

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

참고로 8월 4일 기준 GitHub 스타는 **224,887개**(제가 GitHub API로 직접 확인)로, 지난주 글 작성 시점(224,097개)보다도 꾸준히 늘고 있습니다.

**솔직한 총평**을 하자면, 이번 v0.20.0은 "기능 추가"보다는 **"AI 에이전트가 일하는 방식 자체를 바꾸는"** 릴리즈입니다. 음성은 보조 수단이 아니라 실제 대화 인터페이스가 됐고, A2A와 웹훅은 에이전트를 단독 도구에서 **시스템의 한 축**으로 올려줍니다. 물론 1,400개 PR 규모라 아직 안정화가 필요한 부분도 있을 수 있으니, 중요한 자동화는 며칠 지켜본 뒤 옮기는 것도 방법입니다.

저처럼 **가성비 좋은 오픈소스 AI 에이전트를 찾는 분**, 그리고 이미 Hermes를 쓰면서 "다음 버전만 나오면" 하고 기다리셨던 분이라면 — 지금 `hermes update` 한 줄이면 충분합니다.
