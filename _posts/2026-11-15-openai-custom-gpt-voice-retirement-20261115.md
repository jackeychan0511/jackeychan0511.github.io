사내 문서 검색용으로, 보고서 초안용으로, 고객 응대 문구 생성용으로 커스텀 GPT를 하나씩 만들어 두는 경우가 많습니다. 링크를 동료에게 공유하고, 지시문을 조금씩 다듬으면서 팀 안에서 굴러가게 만든 그 구조 말입니다.

그 구조를 **2026년 12월 11일**에 손봐야 합니다. OpenAI가 커스텀 GPT(GPTs)를 종료한다고 공식 헬프센터 FAQ에 명시했습니다. 같은 날 **Advanced Voice와 Standard Voice도 함께 종료**됩니다. 하루에 두 개의 큰 기능이 동시에 문을 닫는 셈입니다.

솔직히 처음 이 날짜를 봤을 때는 "또 기능 하나 정리하는 소식이겠지" 싶었습니다. 그런데 이전 항목을 하나씩 뜯어보면 이야기가 달라집니다. 이번 건은 **기능이 없어지는 게 아니라, 만들어 둔 것이 옮겨지지 않는** 유형의 변화입니다. 그리고 그 옮겨지지 않는 항목이 하필 업무 자동화의 접착제 역할을 하던 부분입니다.

---

## 1. 확정된 사실부터 — 같은 날짜, 두 개의 종료

먼저 오해가 없도록 확정된 내용만 표로 정리하겠습니다.

| 항목 | 내용 |
|:---|:---|
| 종료 대상 ① | 커스텀 GPT(GPTs) 및 각 GPT의 페이지 |
| 종료 대상 ② | Advanced Voice, Standard Voice |
| 종료일 | **2026년 12월 11일** |
| 대체 경로 ① | **플러그인(Plugins)** — 지시문·참조 파일·연결 앱을 묶는 재사용 단위 |
| 대체 경로 ② | **GPT-Live** — 전체 이중(full-duplex) 방식 음성 모델 |
| 적용 범위 | 전 요금제 (Free·Go·Plus·Pro·Business·Enterprise) |
| 예외 일정 | FedRAMP 워크스페이스 및 승인된 연기(deferral) Enterprise 워크스페이스는 **2027년 2월 11일** |
| 기존 대화 | 종료 후에도 열람 가능 (GPT 자체는 접속 불가) |

출처는 OpenAI 헬프센터의 "Custom GPT retirement and migration FAQ"와 제품 릴리스 노트입니다. 여기서 짚어야 할 부분은 **"GPT 페이지가 사라진다"**는 문장입니다. 링크를 공유해 두었다면 그 링크는 죽습니다. 대화 기록은 남지만, 그 대화를 이어갈 입구는 닫힙니다.

그리고 이미 1차 조치가 시작됐습니다. 개인 요금제(Free·Go·Plus·Pro)에서는 **신규 GPT 생성이 막힌 상태**입니다. 11월 중순 현재 ChatGPT 플러그인 목록에서도 일부 커넥터가 내려가는 움직임이 관측됩니다. 종료일 공지가 나온 뒤 실제 정리 작업이 순차적으로 진행되는 국면으로 보는 편이 안전합니다.

## 2. 진짜 문제는 '무엇이 넘어가지 않는가'입니다

마이그레이션 도구가 있어서 다행이라고 생각할 수 있습니다. 하지만 이전 범위가 전부가 아닙니다. OpenAI FAQ 기준으로 정리하면 이렇습니다.

| 구성 요소 | 플러그인으로 이전 | 비고 |
|:---|:---:|:---|
| 지시문(Instructions) | ✅ 이전 | 플러그인 내부의 스킬 형태로 재구성 |
| 지식 파일(Knowledge) | ✅ 이전 | 업로드 문서·참조 자료 |
| 연결 앱(Connected apps) | ✅ 이전 | 계정 연동 방식은 재확인 필요 |
| **커스텀 액션(Custom actions)** | ❌ **이전 안 됨** | OpenAPI 스키마 기반 외부 호출 |
| **모델 선택** | ❌ **이전 안 됨** | 특정 GPT 모델을 지정해 두었다면 초기화 |
| 공개 범위 | ⚠️ 변경 | 이전된 플러그인은 **기본 비공개**로 시작 |

표에서 눈에 걸리는 건 역시 **커스텀 액션**입니다. 커스텀 GPT를 단순한 "프롬프트 묶음"으로 쓰는 경우라면 영향이 작습니다. 그런데 실무에서 커스텀 GPT가 진짜 값을 내는 지점은 대개 액션입니다. 사내 위키 조회, CRM에 고객 정보 요청, 스프레드시트에 행 추가, 티켓 생성 — 전부 액션으로 붙입니다.

액션이 넘어가지 않는다는 건 **봇 하나가 사라지는 게 아니라 워크플로 하나가 끊기는 것**에 가깝습니다. 지시문은 복사할 수 있지만, 인증 헤더와 스키마 설계, 실패 시 재시도 규칙까지 딸린 연결부는 다시 만들어야 합니다.

여기에 실무 함정이 하나 더 있습니다. 이전된 플러그인이 **기본 비공개**로 시작한다는 점입니다. 팀에 공유해서 쓰던 GPT라면, 이전 직후 "왜 안 보이지" 하는 문의가 반드시 나옵니다. 배포 범위를 다시 지정하는 작업을 일정에 넣어야 합니다.

참고로 세부 이전 범위와 플러그인 접근 권한은 계정·워크스페이스 단위로 다를 수 있습니다. OpenAI도 인프로덕트 안내를 우선 확인하라고 안내하고 있습니다. 위 표는 기본 경로이고, 예외가 있을 수 있다는 전제로 읽는 편이 맞습니다.

## 3. 음성 모드 종료 — 조용하지만 체감은 더 큰 변화

![ChatGPT 대화 화면 예시](https://pub-a8e00ddf355f47339bd2e01ff3221de7.r2.dev/assets/images/posts/openai-custom-gpt-voice-retirement-20261115/chatgpt-interface.jpg)
*이미지: ChatGPT 대화 예시 화면 — Wikimedia Commons, Lugab89, CC BY 3.0*

같은 12월 11일에 **Advanced Voice와 Standard Voice가 종료**됩니다. 대체는 GPT-Live입니다.

GPT-Live는 기존 음성 비서와 구조가 다릅니다. 지금까지의 음성 모드는 사실상 직렬 처리였습니다. 사용자 말이 끝나면 → 텍스트로 변환 → 모델이 생각 → 다시 음성으로 합성. 그래서 말이 겹치면 끊기고, "네", "음" 같은 맞장구에는 반응하지 못했습니다.

GPT-Live는 **전체 이중(full-duplex)** 방식입니다. 듣는 동시에 말하고, 1초에 여러 번 "지금 말할지, 멈출지, 끼어들지"를 판단합니다. 실제 대화에 가까운 리듬이 나오는 이유입니다.

티어 구조도 정리됐습니다.

- **GPT-Live-1** — Go·Plus·Pro 기본 음성 모델
- **GPT-Live-1 mini** — Free 기본
- **API** — GPT-Live-1이 API 플랫폼에도 올라와 있습니다

주의할 점은 두 가지입니다. 첫째, **라이브 비디오와 화면 공유는 GPT-Live가 지원할 때까지 Advanced Voice에 남습니다.** 즉 12월 11일 이후 카메라를 켜고 화면을 보여주는 용도는 경로가 달라집니다. 둘째, **커스텀 GPT에서의 Advanced Voice 접근도 같은 날 끝납니다.** 음성으로 쓰던 커스텀 GPT가 있다면 이중으로 영향권입니다.

## 4. 영향 정리 — 사용자와 운영자, 시각이 다릅니다

**일반 사용자 관점**
- 저장해 둔 GPT 링크가 12월 11일 이후 열리지 않습니다.
- 대화 기록은 남으므로, 중요한 답변은 지금 백업(복사·내보내기)해 두는 편이 안전합니다.
- 음성 사용 습관 중 "카메라·화면 공유" 조합은 별도 확인이 필요합니다.

**개발자·운영자 관점**
- 커스텀 액션 기반 자동화는 재설계 대상입니다. 플러그인은 액션을 물려받지 않으므로, 외부 호출은 **Responses API·Agents SDK 같은 코드 경로**나 MCP 기반 커넥터로 옮기는 선택지가 현실적입니다.
- GPT를 "모델 지정 + 프롬프트"로 쓰던 방식은 더 이상 유지되지 않습니다. 모델 라우팅은 호출하는 쪽에서 결정해야 합니다.
- 공유 범위·권한 재설정을 배포 절차에 넣어야 합니다.

**업무 자동화 관점**에서 이번 변화의 본질은 **재사용 단위의 이동**입니다. "개별 봇 하나"를 만들어 링크로 공유하던 방식에서, "작업에 붙는 스킬과 도구의 묶음"으로 중심이 옮겨갑니다. 자동화 파이프라인을 운영하는 입장에서는 관리 대상이 줄어드는 대신, 각 단계의 연결부를 직접 소유하게 되는 변화입니다. 편해지는 것과 책임이 늘어나는 것이 같이 옵니다.

## 5. 12월 11일 전에 확인할 체크리스트

실무에서 순서대로 처리할 만한 항목만 골랐습니다.

1. **보유 GPT 목록화** — 내 계정과 워크스페이스 각각에서 만든 GPT를 전부 적습니다. 다른 계정에서 만든 GPT는 그 계정 기준 일정이 적용됩니다.
2. **액션 사용 여부 표시** — 커스텀 액션이 붙은 GPT를 별도 표시합니다. 이쪽이 재작업 대상입니다.
3. **중요 대화 백업** — 자주 참조하던 대화는 복사해 둡니다. 종료 후 열람은 되지만, 의존은 피하는 편이 낫습니다.
4. **마이그레이션 실행 및 테스트** — 계정에 마이그레이션 옵션이 열렸다면 이전 후 **지시문이 스킬로 제대로 쪼개졌는지** 확인합니다. 커뮤니티에서도 플러그인 편집 경험에서 지시문 제어가 둔해졌다는 불만이 나옵니다.
5. **공유 범위 재설정** — 기본 비공개로 시작하므로, 팀 배포를 다시 지정합니다.
6. **액션 대체 경로 결정** — 코드 호출로 옮길지, 커넥터로 대체할지, 아니면 사람이 개입하는 반자동으로 낮출지 정합니다.
7. **Enterprise는 예외 일정 확인** — FedRAMP 및 승인된 연기 워크스페이스는 2027년 2월 11일입니다. 다만 이 날짜가 모든 워크스페이스에 적용되지는 않습니다.

## 6. 전망 — 표면을 줄이고, 연결을 남기는 방향

이번 정리를 한 문장으로 요약하면 **"사용자가 만든 표면을 줄이고, 도구 연결은 표준화한다"** 입니다.

커스텀 GPT는 2023년 이후 ChatGPT 생태계의 사실상 앱스토어였습니다. 누구나 봇을 만들고 공유할 수 있었지만, 그 안에서 벌어지는 일은 통제하기 어려웠습니다. 반면 플러그인은 지시문·파일·앱을 묶되 기본 비공개로 시작하고, 실행 경로가 상대적으로 명확합니다. 관리 가능성을 택한 셈입니다.

음성도 같은 방향입니다. 모드를 여러 개 두는 대신 하나의 모델(GPT-Live)로 수렴시키고, 부가 기능(비디오·화면 공유)은 지원 시점에 맞춰 옮깁니다. 표면은 줄고, 품질 관리는 쉬워집니다.

다만 전환 비용은 사용자 몫입니다. 특히 커스텀 액션으로 사내 시스템과 붙여 둔 팀이라면, 12월 11일은 "기능이 사라지는 날"이 아니라 **"연결을 다시 만드는 날"**이 됩니다.

가성비 좋은 대안을 찾는 분들께는 이렇게 정리해 드리고 싶습니다. 새 봇을 더 만드는 것보다, 지금 굴러가는 자동화 중 **어디가 끊길지 먼저 확인하는 것**이 남는 장사입니다. 3주 남았습니다. 목록화와 백업만 해 두어도 12월 11일 아침은 훨씬 조용합니다.
