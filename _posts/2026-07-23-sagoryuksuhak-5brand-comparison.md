## 1️⃣ 시매쓰 (Cmath / ㈜오메가포인트)

### 기본 정보
- **운영사:** ㈜오메가포인트 (2000년 설립, 매출 약 141억)
- **공동대표:** 이충기, 한정규
- **본사:** 서울 서초구 강남대로
- **홈페이지:** [cmath.co.kr](https://cmath.co.kr)

## 2️⃣ CMS 영재교육센터 (크레버스)

### 기본 정보
- **운영사:** 크레버스(CREVERSE)
- **설립:** 1997년 (5개 브랜드 중 **최장수**)
- **대상:** 5세~중3
- **홈페이지:** [creverse.com](https://creverse.com)

### 교육 철학: 폴리아 4단계 학습법

CMS의 핵심은 **폴리아(POLIA) 4단계 학습법**입니다.

| 단계 | 내용 |
|:---:|:------|
| 문제 탐구 | 스스로 문제를 이해하고 분석 |
| 발문과 토론 | 자신의 생각을 언어화하고 친구와 토론 |
| 추론 및 해결 | 논리적으로 문제 해결 |
| 창의적 적용 | 배운 내용을 새로운 문제에 적용 |

### 프로그램

| 과정 | 특징 |
|:----|:------|
| **CMS키즈** | 유아 대상, 교구 중심 |
| **CMS사고력** | 초등 저학년, 발문·토론 중심 |
| **CMS영재** | 초등 고학년~중등, 심화·경시 대비 |

### 강점
- **500여 가지** 독자적 사고력 콘텐츠 보유
- AI 맞춤형 학습 시스템 도입
- 전국 200여 곳으로 **가장 많은 학원 수**
- 27년 업력의 노하우

### 고려사항
- 학원별 수업 퀄리티 차이
- 타 브랜드 대비 수강료 높은 편
- 발문·토론 중심 →内向적인 아이는 적응 시간 필요

## 3️⃣ 와이즈만 영재교육

### 기본 정보
- **설립:** 2006년
- **대상:** 6세~중2
- **특징:** 수학+과학 **STEAM 융합 교육**
- **홈페이지:** [wiseman.kr](https://wiseman.kr)

### 교육 방식

와이즈만의 가장 큰 차별점은 **수학과 과학을 함께 가르치는 STEAM 융합 접근법**입니다.

```
수학 개념 → 과학 실험 → 창의 융합 프로젝트
```

### 프로그램

| 과정 | 대상 | 특징 |
|:----|:----|:------|
| **창의사고력 수학** | 초등 | 문제해결력 + 논리력 |
| **창의사고력 과학** | 초등 | 탐구 실험 중심 |
| **STEAM 융합** | 초등 고학년 | 수학+과학 통합 프로젝트 |

### 강점
- 유일한 **수학+과학 융합** 커리큘럼
- 서울대 교수진 기획·감수로 전문성 높음
- 실험과 프로젝트 중심으로 흥미 유발

### 고려사항
- 수학만 집중하기엔 과학 비중이 부담될 수 있음
- 학원 수가 100여 곳으로 상대적으로 적음
- 수학만 원하는 경우 비효율적일 수 있음

## 4️⃣ 생각하는 황소수학

### 기본 정보
- **설립:** 2014년 (5개 중 **가장 늦음**)
- **대상:** 초1~중3
- **특징:** `개념 → 적용 → 심화`의 단계별 올인원

### 프로그램

| 과정 | 특징 |
|:----|:------|
| **정규 A** | 개념 정리 + 기본 문제 풀이 |
| **정규 S** | 심화 문제 + 사고력 훈련 |
| **정규 T** | 최상위권 도약, 영재·경시 대비 |
| **영재 반** | 특별 선발, 고난도 문제 집중 |

### 강점
- **개념부터 심화까지 한 곳에서** 해결
- 레벨 테스트가 엄격해 **실력별 반 편성**이 정확
- 최상위권 학생들에게 높은 선호도

### 고려사항
- **수강료가 가장 비쌈** (월 25~35만원)
- 학원 수가 70여 곳으로 적음 (주로 강남·목동·분당 등)
- 경쟁이 치열하고 숙제량이 많음
- 수업 분위기가 다소 엄격할 수 있음

## 5️⃣ 씨투엠 (C2M)

### 기본 정보
- **설립:** 2018년 (5개 중 **가장 젊음**)
- **대상:** 6세~초6
- **특징:** 문제해결력 집중 훈련

### 프로그램

| 과정 | 특징 |
|:----|:------|
| **생각하는 유아수학** | 6~7세, 놀이+수학 |
| **팡세** | 초등 저학년, 패턴 발견 훈련 |
| **씨투엠 사고력** | 초등 전학년, 문제해결력 집중 |

### 강점
- **상대적으로 저렴한 수강료** (12~18만원)
- 문제해결력에 특화된 커리큘럼
- 자체 교재 출판

### 고려사항
- 브랜드 역사가 짧아 노하우 축적 부족
- 학원 수 50여 곳으로 **접근성 제한**
- 온라인 시스템 부재
- 고학년 심화 과정 약함

## 👨‍👩‍👧‍👦 학부모 선택 가이드

### 우리 아이 상황별 추천

| 상황 | 추천 브랜드 |
|:-----|:----------|
| 🧒 **첫 사고력수학, 부담 없이 시작** | 시매쓰 or 씨투엠 |

| 💬 **발표력·토론 능력도 키우고 싶다** | CMS or 시매쓰 |
| 💰 **가성비 중요** | 씨투엠 or 시매쓰 |

### 방문 전 체크리스트

1. ✅ **가까운 지점 방문** — 강사님과의 면담이 가장 중요
2. ✅ **레벨 테스트** — 우리 아이 수준에 맞는 반 배정 확인
3. ✅ **수업 참관 가능 여부** — 직접 수업 분위기 확인
4. ✅ **숙제량과 학습 분량** — 아이가 소화 가능한 수준인지
5. ✅ **환불 규정** — 중도 포기 시 불이익 없는지

## 💡 마치며

사고력수학 학원 선택에서 가장 중요한 것은 **"우리 아이에게 맞는 방식인가"** 입니다.

| 브랜드 | 한 줄 요약 |
|:------|:----------|
| **시매쓰** | 26년 전통 + 하이브리드 학습, 무난한 첫 선택 |
| **CMS** | 가장 오랜 역사, 발문과 토론의 강자 |
| **와이즈만** | 유일한 수학+과학 융합 |
| **황소수학** | 비싸지만 강력한 실력 향상, 도전적인 아이에게 |
| **씨투엠** | 가성비 좋은 문제해결력 집중 훈련 |

> 어떤 브랜드가 좋다고 단정할 수 없습니다. **아이의 성향과 학습 스타일, 그리고 가까운 지점의 강사진**을 직접 확인해보시는 것이 가장 현명한 선택입니다.
