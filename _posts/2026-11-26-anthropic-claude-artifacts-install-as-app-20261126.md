챗에서 만든 타이머나 계산기를 쓰려고 매번 클로드 창을 열어 대화를 찾아 올라가는 게 번거롭게 느껴지는 분들이라면, 이번 소식이 반가울 겁니다. 아티팩트를 **데스크톱 앱처럼 설치해서 따로 실행**할 수 있게 됐기 때문입니다. 앱 아이콘을 더블클릭하면 되고, 메뉴 막대에 상주시킬 수도 있습니다.

솔직히 처음엔 "아티팩트를 바로가기로 빼주는 수준이겠지" 싶었는데, 공식 문서를 읽어보니 생각보다 범위가 넓었습니다. 알림, 단축키, 파일 접근까지 OS 권한을 요청하는 구조였습니다. 그만큼 조심할 부분도 같이 생겼습니다.

## 무슨 일이 있었나 — 11월 24일, 조용히 시작된 베타

2026년 11월 24일, 앤트로픽이 Claude 데스크톱 앱에 **Install as app(앱으로 설치)** 기능을 베타로 풀었습니다. 뉴스룸 대신 헬프센터 문서와 데모 앱 쇼케이스로 먼저 공개된 방식이라, 첫날에는 기능 자체보다 "이게 진짜 앱이냐"는 반응이 더 많았습니다.

핵심만 먼저 정리하면 이렇습니다.

| 구분 | 내용 |
|---|---|
| 시작일 | 2026년 11월 24일, **베타** |
| 대상 플랜 | Free·Pro·Max·Ultra·Team·Enterprise **전 플랜** |
| 필요 버전 | Claude for Mac / Claude for Windows **6.28899.0 이상** |
| 지원 OS | **macOS·Windows만** (리눅스·웹·모바일 미지원) |
| 설치 방법 | 아티팩트 우클릭 → **Install as app** → Install |

## 어떻게 쓰는가 — 세 번 클릭이면 끝

절차는 단순합니다. 클로드 데스크톱에서 아티팩트를 연 뒤, 아티팩트 제목 메뉴를 열거나 우클릭해서 **Install as app**을 고르고 **Install**을 누르면 됩니다. 공유(Share) 메뉴 아래에도 같은 항목이 있습니다. 재미있는 건, 아티팩트가 **스스로 설치 버튼을 만들어 넣을 수도** 있다는 점입니다. "설치 버튼이 있는 앱으로 만들어줘"라고 요청하면 아티팩트 내부에 설치 UI가 생깁니다. 어느 경로로 설치하든 클로드가 한 번 더 확인을 받습니다.

설치된 앱의 위치는 다음과 같습니다.

- **macOS**: 홈 폴더의 `Applications` 안 `Claude Apps` 폴더 (스포트라이트에서도 검색됨)
- **Windows**: 시작 메뉴의 `Claude Apps` 폴더, 또는 바탕화면 바로가기
- 클로드 안에서 열려면 아티팩트의 **Open installed app**, 또는 `File > Apps`

단, **완전히 독립된 앱은 아닙니다.** 실행하려면 인터넷에 연결돼 있고 클로드 데스크톱에 로그인돼 있어야 합니다. 오프라인 실행은 안 됩니다. 앱이 클로드와 커넥터를 쓰는 방식도 원래 아티팩트와 같습니다. 즉 "내 컴퓨터에 설치된, 클로드에 묶인 앱"에 가깝습니다.

## 실제로 무엇이 되나 — 메뉴 막대에 살고, 파일을 건드린다

권한을 허용하면 설치된 앱은 일반 앱처럼 OS와 상호작용합니다. 공식 문서에 정리된 권한은 다섯 가지입니다.

| 권한 | 할 수 있는 일 |
|---|---|
| 알림 | 다른 앱을 쓰는 중에도 알림 표시 |
| 키보드 단축키 | 다른 앱 사용 중에도 특정 키 조합에 반응 |
| 다른 창 위에 표시 | 창 위에 콘텐츠를 띄우고, 화면의 마우스 위치를 읽음 |
| 메뉴 막대(macOS) / 트레이(Windows) | 앱이 열려 있는 동안 아이콘 상주 |
| **컴퓨터 전체 접근** | 프로그램 실행, 파일 읽기·수정·삭제를 매번 묻지 않고 수행 |

마지막 항목이 이번 기능의 성격을 결정합니다. 전체 접근을 허용하면 그 앱은 사실상 **로컬 프로그램**입니다. 실제로 앤트로픽이 공개한 데모에는 멀티레이어 이미지 편집기(Linnet), 시스템 셸을 쓰는 터미널, 파일 관리자, 디스크 사용량 분석기, 시스템 모니터, 방 배치 도구, 심지어 명상용 가드닝 시뮬레이션까지 들어 있습니다. "챗봇이 만든 위젯"이라기보다, 말로 주문해서 받은 유틸리티 모음에 가깝습니다.

메뉴 막대나 트레이 아이콘이 있는 앱은 **창을 닫아도 계속 실행**됩니다. macOS는 독에서 종료하거나 `Cmd+Q`, Windows는 트레이 메뉴의 Exit로 꺼야 합니다.

## 권한 모델 — 여기가 이 기능의 진짜 핵심

기능 소개보다 중요한 건 승인 구조입니다. 앤트로픽이 문서에 꽤 자세히 적어뒀는데, 요약하면 **"한 번 허용은 한 버전에만 유효"** 합니다.

- 앱이 업데이트되면, 심지어 내가 직접 수정해도 **다시 물어봅니다.**
- **거부(Don't allow)는 내가 바꿀 때까지 유지**됩니다.
- 앱이 외부 사이트에서 코드를 불러오면, 그 코드는 **새 승인 없이 바뀔 수 있습니다.**
- 조직 밖에서 왔거나 제작자를 확인할 수 없는 앱은 요청 시 **경고**가 뜹니다.
- 그런 앱에는 **전체 접근을 잘 허용해주지 않습니다.** Free·Pro·Max·Ultra에서 "조직 밖"은 곧 "나 말고 다른 사람"입니다.
- 전체 접근을 끄면 앱이 띄운 프로그램은 중지되지만(스스로 분리된 프로세스 제외), **이미 만들어진 변경은 되돌리지 않습니다.**
- 앱 공유가 중단되면 그 앱이 실행한 프로그램도 함께 멈춥니다.

그리고 문서에 명시된 문장 하나는 꼭 기억할 만합니다. **"Anthropic doesn't review apps before you install them."** 설치 전 앱을 검토하지 않는다는 뜻입니다. 스토어 심사 같은 안전망은 없습니다.

## 관리자 입장에서 — Team은 켜져 있고, Enterprise는 꺼져 있다

조직 단위 설정이 플랜별로 다릅니다.

- **Team**: 기능은 기본 활성화, 다만 **최고 권한(전체 접근)은 관리자가 켜기 전까지 꺼져 있음**
- **Enterprise**: 기능 전체가 **꺼진 상태**로 시작. 소유자가 `Organization settings > Artifacts`에서 켜야 함
- **HIPAA** 준비 구성 조직: 사용 불가
- **Claude for Teachers·K-12**: 전체 접근 불가
- **ZDR(제로 데이터 보존)** 조직: 소유자가 켜면 설치는 가능하지만, 설치된 앱은 ZDR 적용 대상이 아님

관리자 입장에서는 "기본값이 안전한 쪽"으로 잡혀 있다는 점이 다행입니다. 반대로 현업에서 바로 쓰고 싶다면 관리자 승인 절차를 먼저 확인해야 합니다.

## 솔직한 단점 — 베타답게 구멍이 있다

좋은 것만 적으면 리뷰가 아니니까, 제약도 그대로 정리합니다.

1. **리눅스·웹·모바일 미지원.** 데스크톱 맥·윈도우만 됩니다. 리눅스용 클로드가 베타인 점을 감안해도 아쉬운 부분입니다.
2. **템플릿 아티팩트는 설치 불가.** Docs·Slides·Sheets 같은 템플릿 기반, 레거시 아티팩트, Claude Cowork의 라이브 아티팩트는 대상이 아닙니다.
3. **오프라인 실행 불가.** 로그인과 네트워크가 전제입니다. 출장지에서 인터넷이 끊기면 앱도 멈춥니다.
4. **사용량이 플랜 한도에 포함.** 앱을 만드는 것도, 앱이 클로드에 보내는 요청도 사용량으로 잡힙니다. 앱을 여러 개 띄워두면 체감 소모가 빨라질 수 있습니다.
5. **macOS 컴퓨터 사용과 충돌.** 클로드가 컴퓨터를 조작할 때 설치된 앱을 **볼 수는 있지만 클릭·타이핑은 못 합니다.**
6. **제거해도 아티팩트는 남음.** Uninstall은 권한만 지우고 아티팩트 자체는 삭제하지 않습니다.

## 영향 — 누구에게 의미가 있나

**비개발자·실무자**에게는 "사내에 요청할 도구가 없어서 엑셀로 버티던 일"을 직접 만드는 통로가 열립니다. 예를 들어 문서에 적힌 예시처럼 "매시간 스트레칭을 알려주는 작은 앱", "폴더 사진 이름을 날짜로 바꾸는 앱" 같은 수준은 대화 몇 번으로 끝납니다. 무료 플랜에서도 되니 진입 장벽은 낮습니다.

**개발자**에게는 배포 부담이 줄어드는 쪽입니다. Electron으로 패키징하고 서명하고 업데이트 서버 붙이던 사내 유틸을, 아티팩트 하나로 대체할 수 있는 여지가 생겼습니다. 다만 클로드 데스크톱과 로그인에 종속되므로, 외부 사용자에게 나눠주는 제품에는 맞지 않습니다.

**자동화 파이프라인을 운영하는 입장**에서는 판단 기준이 하나 늘었습니다. 지금까지는 스크립트·크론·에이전트로 처리하던 반복 작업 중 "사람이 화면에서 눌러야 하는 것"을 데스크톱 앱으로 빼는 선택지가 생겼기 때문입니다. 다만 전체 접근 권한을 준 앱은 사실상 로컬 실행 권한을 위임하는 것이므로, 직접 작성한 앱에만 허용하는 식으로 선을 긋는 게 안전합니다.

## 전망 — '앱스토어'의 씨앗인가, 울타리 친 정원인가

이번 베타를 두고 "AI가 만든 앱을 설치하는 시대"라는 기대와 "클로드 없이는 아무것도 못 돌아가는 종속 구조"라는 우려가 동시에 나옵니다. 기술적으로는 후자에 가깝습니다. 앱은 클로드 데스크톱과 로그인, 네트워크에 묶여 있고, 공유도 클로드 계정을 전제로 합니다.

그래도 실용적인 가치는 분명합니다. **아티팩트가 '대화 속 결과물'에서 '내 책상 위 도구'로 승격**된 것이 이번 변화의 본질입니다. 앞으로 (1) 앱 서명·검토 체계, (2) 리눅스·모바일 확장, (3) 팀 단위 앱 카탈로그 같은 기능이 붙으면 그림이 완성됩니다. 반대로 이 세 가지가 계속 비어 있으면, 베타의 편의성만 남고 생태계는 안 커질 겁니다.

## 구매(도입) 팁 — 이렇게 시작하는 게 낫습니다

돈 드는 기능이 아니니 "구매 팁"이라기보다 도입 순서입니다.

- **먼저 무료 플랜으로 확인.** 전 플랜 베타라 결제 없이 테스트할 수 있습니다.
- **전체 접근은 본인이 만든 앱에만.** 남이 공유한 앱은 알림·단축키 수준부터 시작하세요.
- **업데이트 후 재승인 알림을 무시하지 마세요.** 앱 내용이 바뀌었다는 신호입니다.
- **회사 기기라면 관리자 설정부터 확인.** Team은 전체 접근이 기본 꺼짐, Enterprise는 기능 자체가 꺼짐입니다.
- **앱이 안 보이면 버전 확인.** macOS는 `Claude > Check for Updates`, Windows는 메뉴 `☰ > Help > Check for Updates`.

베타 특성상 UI와 권한 정책은 바뀔 가능성이 큽니다. 새로운 도구를 싸게 굴려보고 싶은 분, 사내 잔업을 줄이고 싶은 분께는 지금 시도해볼 만한 기능입니다. 가성비 좋은 자동화를 찾는 분이라면 특히.
