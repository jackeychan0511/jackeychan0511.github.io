## 1. 드디어 출시 — v2026.8.1-beta.2 (8/15 14:36 KST 배포)

먼저 다들 궁금해하실 출시 소식입니다.

- **배포 시각**: 2026-08-15 05:36 UTC = **한국시간 8/15 오후 2시 36분**
- **npm 태그**: 베타 라인이 `2026.8.1-beta.1` → **`2026.8.1-beta.2`**로 갱신
- **현재 3트랙 배포 상태**: 최신 안정판 `2026.7.1-2` / 베타 `2026.8.1-beta.2` / 확장 안정판(extended-stable) `2026.6.34`

## 2. ⭐ GPT-5.6 Ultra + 런타임 전환 — Sol·Terra·Luna를 한 번에 (#103234)

이번 베타의 헤드라인 기능입니다. **GPT-5.6 Ultra를 비롯한 Sol·Terra·Luna 모델군을 OpenClaw 엔진과 Codex 엔진 양쪽에서 모두 지원**하게 됐어요.

- **모델·런타임·thinking 선택이 '원자적'으로** — `/model` 명령과 폴백(fallback)에서 **모델, 런타임, 사고(thinking) 수준이 한 덩어리로 유지**됩니다. 중간에 하나만 바뀌어서 꼬이는 경우가 없어졌다는 뜻이에요.
- **새 설정 기본값도 GPT-5.6으로** — API 키로 처음 설정하면 `openai/gpt-5.6`(Sol 별칭), Codex/OAuth로 처음 설정하면 `openai/gpt-5.6-sol`, 기본 reasoning은 Sol 기준 **medium**.
- 기존에 쓰던 프라이머리·폴백·별칭·GPT-5.5 명시 선택은 그대로 보존됩니다.

솔직히 저처럼 **코딩 에이전트(Codex 하네스)와 메신저 에이전트(OpenClaw 런타임)를 같이 쓰는 분**이라면, 이 "원자적 전환"이 제일 체감될 부분입니다. 모델 바꿨더니 런타임이 안 맞아서 세션이 꼬이던 경험이 한 번쯤 있으실 거거든요.

## 3. 데이터 안전 — SQLite 스냅샷 백업 + 시크릿 이그레스 바인딩

### ① `openclaw backup sqlite` — 이제 DB를 통째로 백업·검증·복원

그동안 OpenClaw 상태(대화·메모리·크론잡)는 SQLite에 쌓이는데 **백업 명령이 마땅치 않다**는 지적이 있었죠. 이번에 전용 명령이 추가됐습니다.

```
openclaw backup sqlite create   # 스냅샷 생성
openclaw backup sqlite list     # 목록 확인
openclaw backup sqlite verify   # 무결성 검증
openclaw backup sqlite restore  # 복원 (신규 대상 전용)
```

- **글로벌 DB와 에이전트별 DB를 모두** 작고 검증 가능한 아티팩트로 스냅샷합니다.
- 복원은 **fresh-target-only**(새 대상 전용)라서, 기존 데이터 위에 덮어쓰는 사고를 원천 차단합니다.

저처럼 크론잡 자동화를 OpenClaw에 맡기는 입장에선 **"상태가 통째로 백업된다"는 것 자체가 안도감**입니다. 업데이트 전에 `backup sqlite create` 한 줄 습관을 들이시길 권해요.

### ② 시크릿 이그레스 호스트 바인딩 — "시크릿은 정해진 호스트로만 나간다"

보안 쪽도 묵직합니다. **공유 스토어(shared-store)에 저장된 시크릿을 CLI·게이트웨이 RPC·Control UI 전반에서 '정확한 HTTPS 대상 호스트'에 바인딩**합니다.

- 바인딩되지 않은 센티널 치환은 **평문 유출 전에 fail-closed**(차단)됩니다.
- 즉 "이 시크릿은 이 호스트로만 나갈 수 있다"가 코드 레벨에서 강제되는 구조예요. API 키가 엉뚱한 곳으로 새어 나가는 시나리오를 막는 핵심 방어선입니다.

### ③ 플러그인 설치 출처 경고 — `--force` 없이는 임의 실행 소스 거부

플러그인 설치 보안도 강화됐습니다.

- **임의의 실행 가능한(arbitrary executable) 플러그인 소스**는 CLI·채팅 설치 모두 **명시적 `--force` 인정**이 있어야 진행됩니다.
- 반대로 **ClawHub·번들·공식 카탈로그·추적 업데이트** 흐름은 그대로 매끄럽게 유지되고요.
- **Crestodian(온보딩 에이전트)의 설치 대상은 신뢰 소스로 제한**됩니다.

## 4. macOS 앱 프로필 — 앱 인스턴스를 완전히 격리

맥 사용자분들께 반가운 기능입니다. **macOS 앱에서 '이름 붙은 앱 프로필(named app profiles)'**이 생겼어요.

- 프로필별로 **상태·환경설정·키체인(Keychain)·게이트웨이 서비스·중복 인스턴스 소유권**이 분리됩니다.
- 호스트 전체 로그인·노드 서비스는 그대로 두면서, **"업무용 프로필 / 개인용 프로필"을 한 앱에서 완전히 갈라** 쓸 수 있습니다.

저처럼 맥 한 대에서 블로그 자동화(크론잡)와 개인 메신저 에이전트를 같이 돌리는 분이라면, 키체인·설정이 서로 안 섞인다는 점이 꽤 유용할 거예요.

## 5. 채널·UI·음성 소식 — IRC·Synology Chat·Google Chat 이주, ClickClack 온보딩, Fish Audio

- **채널 인그레스 모니터 공통화** — 내구성 있는 수신(admission)·폴링·정리·클레임 신원 검증·인계·종료를 담당하는 **공유 플러그인 SDK 모니터**가 생기고, **IRC·Synology Chat·Google Chat이 공유 수명주기로 이주**했습니다.
- **ClickClack 채널** — `openclaw onboard` 또는 `openclaw channels add clickclack`으로 URL·토큰·워크스페이스를 묻는 **가이드 설정**과, 봇별 명령 자동완성(composer autocomplete), **봇 협업 인바운드 디스패치**(기본 차단, 명시 승인 시 활성)가 추가됐습니다.
- **Fish Audio 음성** — 호스팅 **S2.1 합성**(스트리밍·음성 노트·음성 발견·전화)과, macOS 네이티브 Talk에서 **로컬 Fish S2 Pro 레퍼런스 보이스 스트리밍**을 지원합니다.
- **Meta provider** — `muse-spark-1.1` 모델이 번들 지원(Responses API 스트리밍·도구 호출·암호화 reasoning 리플레이 포함)됩니다.
- **Control UI 개선** — 사이드바 풋터 페이스파일 클릭 시 **온라인 명단(who's-online roster)**, 게이트웨이 **호스트 상태**(OS·런타임·업타임·CPU·메모리·디스크), **크론잡 모델 선택**, GitHub 이슈/PR 호버 카드, 세션 워크스페이스 단축키(⇧⌘B), 설정 단축키(⇧⌘,) 등이 들어왔습니다.
- **Dashboard MCP 앱** — MCP 앱 뷰를 **대시보드 위젯으로 고정**해서 살아있는 상태로 볼 수 있습니다.
- **외부 게이트웨이 감독** — `OPENCLAW_SUPERVISOR_MODE=external` 환경변수로 **OCM 같은 라이프사이클 소유자**가 네이티브 서비스 권한 없이 검증된 재시작·연기 동작을 유지하는 계약이 추가됐습니다.
- **iOS 오프라인 채팅·Android 개선** — iOS는 페어링 시 보호된 캐시로 최근 세션을 오프라인 프리페인트, Android는 **채팅 화면에서 바로 에이전트 전환**·코드 하이라이트가 지원됩니다.
- **CJK 마크다운 강조 픽스** — 인접한 **한국어·중국어·일본어 강조 문장 부호**가 채널에서 리터럴 마커로 새어 나가던 문제가 수정됐습니다. 한국어 블로거로서 반가운 픽스였어요.

## 7. 솔직한 단점 — 이번 베타, 사후 검증이 실패했습니다

좋은 점만 나열하면 솔직한 리뷰가 아니죠. 이번엔 **릴리스 노트가 직접 인정한 아쉬운 점**이 있습니다.

1. **사후 전체 검증(Full Release Validation) 실패** — 릴리스 노트 마지막에 **"Post-publication Full Release Validation: failed"**라고 명시됐습니다. 정상 CI·패키지 텔레그램·Docker 런타임·설치/업데이트·플러그인 런타임 검사·실제 모델 턴은 통과했지만, **릴리스 도구/테스트 픽스처 쪽 실패**가 노출됐고, 공식 문구로 **"수정 후속판과 그린 검증 없이는 이 베타를 정식판으로 승격하지 말 것"**이라고 경고합니다. 즉 **베타.2가 정식(8.1 stable)이 되려면 후속 수정판이 나와야** 합니다.
2. **npm OIDC provenance 미지원** — 핵심 퍼블리셔가 이전 베타 태그 조회 중 타임아웃, Fish Audio 패키지의 OIDC가 거부되면서 **`openclaw`·핵심 서브패키지 3종·`@openclaw/fish-audio-speech`는 npm OIDC 출처 증명 없이 배포**됐습니다. 레지스트리 서명·타르볼 정체성은 검증됐다고 합니다.
3. **ClawHub 미발행** — 이번 베타는 npm 전용 경로라 **ClawHub에는 게시되지 않았습니다.** ClawHub 셀렉터 사용자는 기존 릴리스 유지.
4. **문서가 아직 안 따라옴** — 제가 확인해 보니 **docs.openclaw.ai의 2026.8.1 릴리스 노트 페이지는 아직 404**입니다(8/16 확인). 커뮤니티에서도 "beta.1은 npm에 있는데 문서에 없다"는 지적이 나오는 상황이에요. 새 기능을 문서로 확인하려면 며칠 더 기다려야 합니다.

## 8. 마무리 — 설치 방법과 추천 대상

정리하면, **이번 v2026.8.1-beta.2의 키워드는 "모델 선택의 자유(GPT-5.6 Ultra) + 데이터 안전(백업·시크릿 바인딩) + 검증의 엄격함(사후 검증 실패 공개)"**입니다. 특히 **검증 실패를 릴리스 노트에 그대로 공개**하는 태도는, 오픈소스 프로젝트로서 신뢰가 가는 부분이기도 했어요.

설치는 아래 한 줄이면 끝입니다.

```

npm install -g openclaw@beta
```
