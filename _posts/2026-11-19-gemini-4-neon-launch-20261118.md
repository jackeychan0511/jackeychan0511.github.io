> **📌 한 줄 요약:** 2026년 11월 18일, 구글이 **Gemini 4 Neon**을 공개했습니다. 최상위 **Carbon**과 경량 **Hydrogen** 사이에 들어가는 중간급 모델인데, 구글 주장대로라면 **Carbon에 가까운 품질을 32% 낮은 작업당 비용으로** 처리합니다. 100만 토큰 컨텍스트, 4단계 사고 수준(Low·Medium·High·XHigh), 입력 $3·출력 $15(100만 토큰 기준) 가격이 붙었습니다. **Gemini API 유료 티어, AI Studio, Antigravity, Gemini for business, GitHub Copilot**까지 동시에 열렸습니다. 다만 지금은 **토큰 단가가 Carbon보다 비싼 구간**이라, 무작정 갈아타면 청구서가 오히려 늘 수 있습니다.

반복되는 코딩·문서 분석·데이터 정리를 AI에게 맡기다 보면 결국 두 가지 벽에 부딪힙니다. **정확도가 아쉽거나**, **비용이 무섭거나**. 최상위 모델은 똑똑한 대신 느리고 비싸고, 경량 모델은 빠른 대신 복잡한 작업에서 자꾸 미끄러집니다. 그 사이를 메우는 모델이 계속 나오는 이유가 여기에 있습니다.

Neon은 정확히 그 빈칸을 노린 카드입니다. 이번 글은 보도자료 문구를 그대로 옮기지 않고, **숫자로 확인되는 것**과 **가격표에 숨은 조건**, 그리고 **지금 당장 쓸 수 있는 사람과 없는 사람**을 나눠서 정리했습니다.

## 무슨 일이 있었나 — Gemini 4 패밀리의 '중간층'이 채워졌다

구글 DeepMind의 코레이 카부크추올루 SVP는 이번 발표를 "프런티어급 지능을 **빠른 종단간(end-to-end) 작업 완료**와 함께 제공한다"고 설명했습니다. 대상은 복잡한 소프트웨어 엔지니어링, 지식 노동, 과학 워크플로입니다.

이름이 낯설다면, Gemini 4 패밀리는 원소 이름을 쓰고 있습니다. **Carbon**(가장 무겁고 느린 최상위), **Hydrogen**(가볍고 빠른 일상용), 그리고 이번 **Neon**. 여기에 사이버보안 특화 변형까지 붙습니다.

| 항목 | 내용 |
|:---|:---|
| 발표·출시일 | **2026년 11월 18일** (Google 공식 블로그·DeepMind 모델 카드) |
| 패밀리 내 위치 | **Carbon(최고 난도) ↔ Hydrogen(일상 실행) 사이** |
| 컨텍스트 | 입력·출력 합산 최대 **100만 토큰** (긴 디코딩 지원) |
| 사고 수준 | **Low / Medium / High / XHigh** 4단계 |
| API 가격 | 입력 **$3** / 출력 **$15** (100만 토큰) · 캐시 입력 **$0.15**(95% 할인) |
| 모달리티 | 텍스트·이미지·오디오·비디오 입력 |
| 모델 ID | `gemini-4-neon` |

구글은 Neon을 "**Carbon이 가장 어려운 장기 프로젝트를 맡고, Hydrogen이 빠른 일상 실행을 맡는다면, Neon은 깊이와 효율의 균형**을 잡는 모델"이라고 규정했습니다. 마케팅 문구처럼 들리지만, 실제 벤치마크 숫자를 보면 포지셔닝이 대충 만든 건 아닙니다.

## 비용 — '작업당'은 싸고, '토큰당'은 지금 비싸다

![Gemini 4 Neon 벤치마크 및 비용 효율 그래픽](https://pub-a8e00ddf355f47339bd2e01ff3221de7.r2.dev/assets/images/posts/gemini-4-neon-launch-20261118/neon-aa.jpg)
*출처: Google 공식 블로그 「Introducing Gemini 4 Neon」 벤치마크 그래픽 (2026.11.18)*

구글의 주장은 명확합니다.

- 기본 **High** 사고 수준에서 **Carbon 대비 작업당 비용 32% 절감**
- **XHigh**에서는 경쟁 프런티어 모델의 최고 설정 대비 **36% 이상 저렴**
- Vals·Agent Arena 파레토 프런티어에서 경쟁 모델보다 **작업당 50~80% 저렴**

그런데 여기에 함정이 하나 있습니다. **토큰 단가는 지금 Neon이 더 비쌉니다.**

현재 Carbon과 Argon은 **11월 30일까지 프로모션 가격**(입력 $2 / 출력 $10)으로 판매 중입니다. Neon은 정가 **$3 / $15**입니다. 즉 **12월 1일 이전까지는 Neon의 토큰 단가가 Carbon보다 50% 높습니다.** 12월 1일부터 Carbon이 정가($4 / $20)로 돌아가면 그때 Neon이 25% 저렴해집니다.

| 모델 | 현재(11/30까지) | 12/1 이후 |
|:---|:---|:---|
| Carbon / Argon | $2 / $10 (프로모션) | $4 / $20 (정가) |
| **Neon** | **$3 / $15** | **$3 / $15** |
| Hydrogen | $1.5 / $7.5 | $1.5 / $7.5 |

정리하면 이렇습니다.

- **작업당 비용**은 지금도 Neon이 유리할 수 있습니다. 토큰을 적게 쓰고 한 번에 끝내기 때문입니다(구글 주장 -32%).
- **토큰을 많이 흘리는 워크로드**(긴 문서 반복 요약, 대량 분류)라면 11월 말까지는 **Carbon 프로모션 가격이 더 쌉니다.**
- **12월 예산**은 가격 인상 전제로 다시 짜야 합니다. Carbon 정가 인상은 Neon 출시와 별개로 이미 예고된 일정입니다.

"작업당 비용"과 "토큰 단가"를 구분하지 않고 마이그레이션하면, 벤치마크는 좋아지는데 청구서도 같이 올라가는 상황이 생깁니다.

## 어디서 쓸 수 있나 — 무료 사용자는 아직 아니다

배포 범위가 꽤 넓지만, **경계가 분명**합니다.

| 대상 | 제공 범위 |
|:---|:---|
| 개발자 | **Gemini API 유료 티어**, Google AI Studio, Android Studio |
| 구독자 | Google AI **Pro·Ultra** → Antigravity, AI Studio |
| 기업 | **Gemini for business** (API 또는 모델 드롭다운), Antigravity |
| 소비자 | Gemini 앱 모델 선택창 (Pro·Ultra 구독자) |
| 코딩 도구 | **GitHub Copilot** Pro+·Max·Business·Enterprise (GA, 점진 롤아웃) |
| 보안 | **Fairwind 프로그램** 승인 대상자 (향후 며칠 내 순차 개방) |

주목할 점은 **무료 티어가 없다**는 것입니다. 구글 블로그도 "Gemini API **유료** 티어"라고 못 박았습니다. Gemini 앱에서도 Neon은 Pro·Ultra 구독자 전용이라, 무료 사용자는 계속 Hydrogen 기반으로 동작합니다.

또 하나, 9to5Google 보도에 따르면 이번 출시와 함께 **Gemini 앱의 모델 선택창이 정리**됩니다.

- **Gemini 3.1 Pro는 선택지에서 빠집니다** (사실상 은퇴)
- **Neon이 Argon 자리를 대체**합니다
- **3.5 Flash-Lite는 유료 사용자 기준 'Auto'로 이름이 바뀝니다**

앱에서 특정 모델을 골라 쓰던 루틴이 있었다면, 모델 이름이 사라졌다고 당황할 필요는 없습니다. 대체 매핑이 위와 같이 이미 정해져 있습니다. 다만 **자동화 스크립트에서 모델 ID를 하드코딩**해 둔 경우라면, 3.1 Pro·Argon ID가 언제 종료되는지 공지를 확인해 두는 게 안전합니다.

## 보안·안전 — 사이버 방어가 이번엔 전면에 나왔다

이번 발표에서 이례적으로 비중이 큰 부분이 **사이버보안**입니다. Neon은 코딩 모델이면서 동시에 방어 도구로 포지셔닝됩니다.

| 평가 | 결과 |
|:---|:---|
| AutoBaxBench (보안 코드 생성, hard) | **76%** (SOTA) |
| WebExploitBench v1.2 | **51.26%** (경쟁 대형 모델 대비 절반 비용) |
| SEC-bench Pro (취약점 탐지) | **90.5%** (SOTA) |
| Collinear CWE-bench v2 (패치) | **70.7%** (Carbon 대비 +3.4%p) |
| Gray Swan IPI (간접 프롬프트 인젝션) | **공격 성공률 0.0%** (최고 사고 수준+실시간 보호) |

에이전트를 오래 돌릴수록 무서운 건 성능이 아니라 **간접 프롬프트 인젝션**입니다. 웹페이지나 메일에 심어둔 악성 지시를 에이전트가 읽고 엉뚱한 짓을 하는 사고죠. Neon은 이 항목에서 "해당 벤치마크의 모든 공격을 막았다"고 보고했습니다. 물론 **구글 자체 측정**이라는 점은 감안해야 합니다.

행동 품질 쪽 수치도 함께 공개됐습니다.

- Terminal-Bench 4.0에서 **거짓 결과 보고(cheating) 0.0%**
- 자체 코딩 치팅 평가에서 지름길 사용 **2.45%** (Gemini 4 모델 중 최저)
- 에이전트 안전 스위트의 **오정렬 행동률 0.09%**
- 에이전트 정직성 평가 **통과율 99.2%**
- 과소 수행(under-service) **43~56% 감소**, 과잉 개입(overreach) **15~35% 감소**

업무 자동화에서 진짜 골치인 건 "일을 안 끝내는 것"과 "시키지 않은 일까지 하는 것"입니다. 이 두 항목을 정량으로 개선했다고 밝힌 건, 벤치마크 점수보다 실무적으로 더 중요할 수 있습니다.

## 그래서 누가 써야 하나

**1) 코딩 에이전트를 상시 돌리는 팀**
Neon의 강점은 단발 질문이 아니라 **도구를 여러 번 호출하는 장기 세션**입니다. 중복 파일 읽기를 줄이고, 진행 상황을 공유하고, 긴 세션에서 컨텍스트 압축을 안정적으로 처리한다고 합니다. Antigravity에서 **Hydrogen 서브에이전트를 병렬로 지휘하는 오케스트레이터**로 쓰는 시나리오도 공식 예시로 나옵니다. "비싼 모델 하나로 전부" 하던 구조를 **Neon(지휘) + Hydrogen(실행)** 으로 쪼개면 비용 구조가 달라집니다.

**2) 스프레드시트·PDF·계약서를 다루는 실무**
법률 리서치(Legal Research Bench), 세무 에이전트(Tax Agent Bench)에서 1위를 기록했다고 밝혔습니다. 100만 토큰 창에 스프레드시트·PDF·차트·오디오를 한꺼번에 넣고 구조화된 결과물을 뽑는 용도에 맞춰져 있습니다. 다만 **한국어 세무·법률 문서**에서의 성능은 별도 검증이 필요합니다. 벤치마크는 영어권 문서 기준입니다.

**3) GitHub Copilot 유료 사용자**
Copilot Pro+·Max·Business·Enterprise에서 모델 선택창에 이미 올라왔습니다. 별도 API 키 없이 써볼 수 있는 가장 빠른 경로입니다. 관리자라면 **모델 정책에서 기본 활성화 여부**를 확인해야 합니다. 기본 설정은 "새 모델 자동 활성화"라, 원치 않으면 명시적으로 꺼야 합니다.

**4) 무료 사용자**
아직 아닙니다. Gemini 앱 무료 티어는 Hydrogen 계열로 남습니다. 무료로 Neon을 쓰려면 별도 개방 발표를 기다려야 합니다.

## 전망 — 한 달에 쏟아진 모델, 이제 '선택'이 문제다

2026년 11월 한 달만 봐도 구글은 **Carbon 정식 출시(11/11) → Hydrogen(11/13) → Neon(11/18)** 순으로 모델을 쏟아냈습니다. 이제 Gemini 4 패밀리 안에서도 "무엇을 어디에 쓸지"를 고르는 일이 성능 비교보다 어려워졌습니다.

| 용도 | 권장 |
|:---|:---|
| 가장 어려운 장기 프로젝트, 최고 난도 추론 | **Carbon** |
| 고빈도·고난도 코딩·분석·에이전트 지휘 | **Neon** |
| 일상 대화, 빠른 초안, 대량 단순 처리 | **Hydrogen** |
| 비용 최우선·단순 반복 | **Flash-Lite / Auto** |

앞으로의 관전 포인트는 세 가지입니다.

1. **12월 1일 가격 정상화** — Carbon 프로모션이 끝나면 Neon의 가성비가 실제로 드러납니다. 지금의 "작업당 -32%"가 유지되는지가 핵심입니다.
2. **무료 티어 개방 시점** — Neon이 무료로 풀리는 순간, 경량 모델을 쓰던 자리가 통째로 대체됩니다.
3. **서드파티 검증** — 지금 공개된 수치는 대부분 구글 자체 또는 협력 평가입니다. Artificial Analysis·Vals 같은 독립 지표에서 순위가 유지되는지 2~3주 지켜볼 필요가 있습니다.

## 정리 — 지금 갈아탈지, 12월까지 기다릴지

솔직히, 이번 발표의 핵심은 "새 모델이 나왔다"가 아니라 **"같은 성능을 더 싸게, 더 빨리"라는 주장을 가격표로 증명하려 한다**는 점입니다. 특히 작업당 비용을 전면에 내세운 건, 토큰 단가만 보고 모델을 고르던 관행을 겨냥한 메시지입니다.

그렇다면 판단 기준은 이렇게 잡으면 됩니다.

- **코딩 에이전트·자동화 파이프라인을 이미 돌리고 있다** → Neon으로 A/B 테스트할 가치가 충분합니다. 특히 도구 호출이 많은 작업에서 차이가 납니다.
- **긴 문서를 대량으로 반복 처리한다** → 11월 말까지는 Carbon 프로모션 가격이 유리할 수 있습니다. 12월 1일 이후 재비교가 정석입니다.
- **월 예산이 빠듯하다** → 토큰 단가가 아니라 **작업당 비용**으로 측정해야 합니다. 같은 작업을 3번 돌려 평균 토큰 사용량을 재보는 것만으로도 판단이 갈립니다.
- **무료로 써보고 싶다** → 아직 아닙니다. Copilot 유료 플랜이나 AI Studio 유료 티어가 가장 빠른 접근 경로입니다.

새 모델이 나올 때마다 전부 갈아타는 건 비용만 늘리는 일입니다. **작업 난도별로 모델을 나누고, 비용은 작업당으로 재는 것** — 이번 Neon 발표가 실질적으로 던진 숙제는 그쪽입니다.

> 참고: 본문 수치는 Google 공식 블로그(2026.11.18), Google DeepMind 모델 카드, GitHub Copilot 체인지로그, 9to5Google 보도를 기준으로 정리했습니다. 벤치마크는 측정 환경에 따라 달라질 수 있으며, 상당수가 구글 자체 발표치입니다.
