## 이 글을 읽으면 알 수 있는 것

- **v2026.9.6이 언제 배포됐고**, 9월 안정 트레인(9.1→…→9.5→9.6)에서 어떤 위치인지
- **macOS 앱 '실행 불가' P0 크래시**가 무엇이·어디서·얼마나 터진 문제인지(원인 스택과 재현 환경 포함)
- 팀이 취한 조치 — **Sparkle 업데이트 피드 철회·2026.9.7 핫픽스**, 그리고 **영향 없는 범위(npm·Gateway)**
- 이번 판의 실질 변화 — **신규 모델·결정 모델·원격 워크스페이스·GitHub 리더·재시작 복구**
- **지금 내가 무엇을 해야 하는지**(맥 앱 사용자 vs CLI/게이트웨이 사용자)와 복구 방법

## 도입: "업데이트 버튼이 제일 무서운 순간이 됐습니다"

요즘 저처럼 **AI 에이전트를 업무 파이프라인의 일꾼으로 굴리시는 분들**, 많으시죠? 저는 오픈소스 AI 에이전트를 실사용하면서 자잘한 자동화를 맡겨두고 있는데, 솔직히 요즘 **가장 긴장되는 순간은 '업데이트 버튼을 누르는 순간'** 입니다.

기능이 좋아지는 건 반갑지만, 잘 돌던 앱이 **업데이트 직후 안 열려 버리면** 그 다음은 **아무것도 못 합니다.** 문제를 진단해 달라고 물어볼 상대가 바로 그 앱이니까요. 그런데 **이번 v2026.9.6**에서 정확히 그 일이 벌어졌습니다. 새 모델과 기능이 한가득 담긴 판이 나온 **같은 날**, **macOS 앱이 업데이트하면 실행조차 안 되는** 문제가 보고된 거죠. 오늘은 **GitHub 릴리스 노트·이슈 #156861·npm 레지스트리(dist-tags)** 를 기준으로, **꼭 알아야 할 것만** 정리해 드립니다.

## 핵심 이슈 — macOS 앱이 업데이트하면 '아예 안 열린다' (P0)

이번 판에서 **가장 먼저 봐야 할 건 새 기능이 아니라 이 사고**입니다.

### 무슨 일이 있었나

릴리스 노트 최상단에 이런 경고가 붙었습니다.

> "**macOS 앱: 아직 2026.9.6으로 업데이트하지 마세요.** 2026.9.6 macOS 앱은 인앱 업데이트 후 **실행할 때마다 크래시**할 수 있습니다(#156861). **Sparkle 업데이트 피드에서 철회**했고, **2026.9.7 Mac 핫픽스를 준비 중**입니다. 앱이 더 이상 열리지 않으면 **2026.9.5 macOS 빌드를 재설치**하세요. **npm·Gateway 패키지 2026.9.6은 영향이 없습니다.**"

이슈 #156861의 제목은 **"fix(macos): 2026.9.6 업데이트 후 두 대의 Mac 모두에서 OpenClaw가 완전히 실행 불가"** 입니다. 라벨은 **`P0`**, **`impact:crash-loop`**, **`impact:ux-release-blocker`** — 즉 **릴리스 차단급(Release Blocker)** 으로 분류됐습니다.

### 원인과 재현 환경

- **증상** — 설정 → 업데이트로 **2026.9.4 또는 2026.9.5에서 2026.9.6으로** 올린 직후, 앱이 재실행되지 않고 **이후 실행할 때마다 크래시**
- **크래시 종류** — 세 건의 크래시 리포트 모두 **동일한 Swift 동시성 abort**, 스택에 **`CookieSyncManager.scheduleReconcile(resetRetry:delay:)`**
- **환경** — **MacBook 2건 + Mac Studio 1건**, 즉 **서로 다른 두 대의 맥**에서 같은 문제가 재현됐습니다
- **성격** — **회귀(regression)** — 예전엔 되던 동작이 이번 판에서 깨진 유형

솔직히 이게 **가장 아픈 지점**입니다. 앱이 열려야 설정도 열고 롤백도 하는데, **앱 자체가 실행이 안 되면 사용자가 스스로 복구할 여지가 거의 없어요.** 팀이 **업데이트 피드를 즉시 내린 건** 그만큼 파급을 막으려는 판단으로 보입니다.

### 다행인 부분 — 영향 범위가 갈린다

반대로 **안심할 부분도 분명**합니다.

- ✅ **npm·Gateway 패키지 2026.9.6은 영향 없음** — 서버·CLI로 돌리는 분들은 이번 사고와 무관합니다
- ✅ **자동 업데이트 피드에서 철회** — 아직 업데이트하지 않은 사용자는 **자동으로 9.6 맥 빌드를 받지 않습니다**
- ✅ **복구 경로가 명시됨** — 이미 열리지 않는 상태라면 **2026.9.5 macOS 빌드를 재설치**하면 됩니다
- ⏳ **2026.9.7 핫픽스 준비 중** — 현재 GitHub 최신 릴리스는 여전히 **v2026.9.6**이고, 9.7은 아직 배포 전입니다

## 그럼 알맹이는 뭘까 — v2026.9.6의 실질 변화

사고만 보면 이번 판이 '사고난 판' 같지만, **CLI·게이트웨이 사용자에게는 알찬 업데이트**입니다. 업무 자동화에 영향이 큰 것만 골랐습니다.

### ① 신규 모델 — Opus 5.5·GPT-6 Sol/Luna·Grok 4.7·MiMo V2.6

- **Anthropic** — **Claude Opus 5.5**(`anthropic/claude-opus-5-5`, 별칭 `opus-5.5`/`opus-5-5`)가 **적응형 사고(adaptive thinking)·1M 컨텍스트·Claude CLI 지원·Opus 5.5 요금**으로 들어왔습니다. 단, **맨 `opus` 별칭은 여전히 Opus 5**로 해석됩니다(원하는 판을 쓰려면 별칭을 명시하세요)
- **OpenAI** — **GPT-6 Sol·GPT-6 Luna**가 API와 임베디드 ChatGPT 전송에서 **컨텍스트 한도·추론 레벨·티어 요금**까지 맞춰 추가됐습니다
- **그 외** — **xAI Grok 4.7**, **Xiaomi MiMo V2.6**도 지원 목록에 올랐고, **provider 목록이 낡아도 발견된 모델을 표시**하도록 개선됐습니다

### ② 결정 모델(Decision Model) — 에이전트마다 '판단 전용' 모델을 따로

이번 판에서 구조적으로 가장 눈에 띄는 변화입니다. **에이전트별로 별도의 '결정 모델'을 지정**할 수 있게 됐고, **호스팅·로컬 System One 서버**를 공식 플러그인으로 붙일 수 있습니다. **ONNX 기반 로컬 결정 모델**도 지원해 **로컬에서 판단을 돌리는 구성**이 현실해졌어요.

주의할 점도 있습니다. **결정 모델 도구(TypeSafe)가 별도 설치형 공식 플러그인 `@openclaw/typesafe`로 분리**되면서 **OpenClaw 2026.9.6 이상을 요구**합니다. 기본은 기존 호스팅 동작 유지, 로컬 결정을 쓰려면 **루프백 엔드포인트**를 설정해 **호스팅 키를 넘기지 않고** 돌릴 수 있습니다.

### ③ 원격 워크스페이스(Remote Workspaces)

**페어링된 노드 워크스페이스에서도 Agent 문서·첨부파일·Memory 파일·Skills를 쓸 수 있게** 됐습니다(파일 접근·설치 정책은 그대로 보존). 단 **Gateway와 노드가 같은 OpenClaw 버전**이어야 합니다 — 이 조건 안 맞으면 동작하지 않으니 업그레이드 시 **양쪽을 같이** 올리세요.

### ④ GitHub 리더 — 채팅 옆에서 이슈·PR·커밋·diff 열기

**공개 이슈·PR·커밋·코멘트·diff를 채팅 옆에서 바로** 열 수 있습니다. 단 **플러그인 허용 목록(allowlist)을 명시한 설치**라면 미리보기를 유지하려면 **`github`를 목록에 추가**해야 합니다.

### ⑤ 재시작 복구·사용량·회의 — 운영 안정화

- **재시작 복구** — **고립된 대화를 복구**하고, **Node 재시작 중 진행 중 작업을 보존**, 형제 완료 재생을 원래 요청자 입력에 붙여 유지
- **사용량** — **생성자별 분석·날짜 선택·합계**를 포함한 **완전한 30일 이력 뷰** 복원
- **회의** — 회의를 캡처하는 동안 **자동 갱신되는 스크립트와 중간 요약**을 따라감
- **업데이트** — **Node.js 설치 경로가 바뀐 뒤에도 관리형 Gateway 업그레이드를 완료**하도록 수정
- **Telegram** — 긴 붙여넣기 같은 **연속 텍스트 청크를 300ms 조용한 창으로 한 턴에 묶어** 부분 프롬프트·중복 답변 방지(창을 `0`으로 두면 끔)

### ⑥ 그 밖에 눈에 띄는 변화

- **도구 탐색(Tool Search)** — 임베디드·Copilot 실행에서 **구조화된 도구 탐색이 기본 활성**. 직접 스키마를 쓰려면 `tools.toolSearch: false`
- **macOS 아키텍처별 릴리스** — 맥 빌드가 아키텍처별로 나뉘어 배포됨
- **FaceTime** — **실험적 실시간 음성 브리지 플러그인** 추가
- **로컬 브라우저** — 데스크톱 앱·터미널이 **하나의 Chrome 설정 흐름**을 공유, Incognito 세션을 정확한 URL로 열기
- **테마·플러그인** — 에이전트가 개인·플러그인 테마를 **목록화·가져오기·적용**, 플러그인 팔레트는 **핫 리로드** 반영
- **게이트웨이 응답성** — 세션 목록·트랜스크립트·카탈로그 작업을 **메인 스레드 밖으로** 옮겨 큰 이력에서도 채팅이 매끄럽게

## 실제 사용감 — 솔직한 장단점

솔직히 이번 판은 **"기능은 진짜 알찬데, 맥 앱 때문에 신뢰가 깎인"** 케이스입니다. 그래도 양쪽을 다 짚어야 공정하겠죠.

- 👍 **모델 지원이 빠르다** — Claude Opus 5.5와 GPT-6 Sol/Luna가 **같은 시기 모델 출시 흐름에 맞춰** 들어온 건 실사용자에게 확실한 이득입니다. 에이전트마다 다른 모델을 붙여 굴리는 분께 특히요.
- 👍 **결정 모델 & 로컬 ONNX** — '판단'만 별도 모델로 빼고 **로컬로 돌릴 수 있게** 한 건, 비용과 데이터 통제 양쪽에서 의미가 큽니다. TypeSafe가 별도 플러그인으로 분리된 건 관리 부담이 늘지만 **경계가 명확해진** 이점도 있어요.
- 👍 **재시작 복구·GitHub 리더** — 긴 작업 도중 Node가 재시작돼도 **맥락이 살아남고**, 이슈·PR을 **채팅 옆에서 바로** 보는 건 실제로 자주 쓰게 되는 기능입니다.
- 👎 **맥 앱 P0 회귀** — 아무리 npm·게이트웨이가 무사하다 해도, **맥 앱을 쓰는 사람에겐 치명적**입니다. 앱이 열리지 않으면 **그 기기에서는 아무것도 못 하니까요.** 핫픽스(9.7)가 나오기 전까지는 **맥 앱 업데이트를 미루는 게 정답**입니다.
- 👎 **잦은 릴리스 + 검증 부담** — 5일 간격으로 안정판이 나오는 속도 자체가 **개인 운영자에겐 부담**입니다. "안정 트레인을 정해두고 주 1회만 따라가기"가 여전히 현실적인 전략이에요.

## 지금 무엇을 해야 하나 — 체크리스트

**① macOS 앱 사용자라면**
- **아직 9.6으로 올리지 마세요.** 이미 자동 피드에서 내려갔으니, 안 올렸으면 그대로 두면 됩니다
- **이미 앱이 안 열린다면** → **2026.9.5 macOS 빌드를 재설치**하세요(`github.com/openclaw/openclaw/releases/tag/v2026.9.5`)
- 열리지 않는 앱을 억지로 여러 번 실행하지 말고, **재설치로 복구**하는 게 빠릅니다

**② CLI·게이트웨이(npm) 사용자라면**
- **영향 없습니다.** `npm install -g openclaw@latest` 또는 `openclaw update`로 9.6을 받아도 됩니다
- 단 **원격 워크스페이스**를 쓴다면 **Gateway와 노드를 같은 버전으로** 맞추세요
- **TypeSafe(결정 모델)** 를 쓴다면 별도 플러그인 설치와 **2026.9.6 이상** 요건을 확인하세요

**③ 공통**
- **업데이트 전 백업**은 이제 습관입니다. 최근 릴리스들은 **DB 마이그레이션을 되돌리지 못하는** 경우가 있어, 검증된 백업 없이 "일단 올리고 문제 있으면 되돌리기"는 위험해요
- **2026.9.7 핫픽스**가 나오면 맥 앱은 그때 올리는 게 안전합니다 (현재 GitHub 최신은 여전히 **v2026.9.6**)

## 마무리

9.3이 '안전한 업데이트', 9.4가 '스킬 발견', 9.5가 '운영 안전 + 협업'이었다면, **9.6은 '판단(결정 모델)과 연결(원격·GitHub)을 넓힌 판'** 입니다. 모델 지원과 결정 모델, 원격 워크스페이스는 **업무 자동화에 실질적으로 얹히는 변화**예요.

다만 결론은 명확합니다. **돌아가는 판을 함부로 건드리지 않는 게 운영의 기본**이라는 걸, 이번 P0 크래시가 다시 한 번 보여줬습니다. 특히 **맥 앱을 주 인터페이스로 쓰시는 분**, 그중에서도 **에이전트를 멈추기 어려운 상황에서 돌리는 분**은 **9.7 핫픽스가 나올 때까지 맥 앱 업데이트를 보류**하시고, **CLI·게이트웨이 사용자라면 9.6을 편하게 올려** 새 모델과 결정 모델을 써보시길 권합니다. 무료·오픈소스인데 이 정도 기능이 붙는 걸 보면, 가성비 좋은 AI 툴을 찾는 분께는 여전히 매력적인 선택지예요.
