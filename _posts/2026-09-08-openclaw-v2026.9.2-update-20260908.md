## 최대 화제 — GPT-6 Astra 공식 지원 (Feat. Muse Spark 1.3)

이번 판에서 업무 자동화 관점에서 **가장 큰 변화**는 단연 GPT-6 Astra 지원입니다. OpenAI가 이번 주 공개한 신형 프론티어 모델인데, OpenClaw에서는 9.2부터 바로 쓸 수 있어요.

- **선택 방법** — `openai/gpt-6-astra`. **OpenAI API 키 프로필** 또는 **자격이 있는 ChatGPT/Codex 구독 계정** 모두에서 선택 가능합니다(구독은 계정 발견(account discovery)이 성공해야 목록에 노출).
- **입력·출력** — 텍스트·이미지 입력 모두 지원, **컨텍스트 105만 토큰(1,050,000)·출력 최대 12.8만 토큰**. OpenClaw 기본 활성 입력 예산은 27.2만 토큰으로 유지되고, 비용 추정치는 긴 컨텍스트 요금제를 반영합니다.
- **생성 중 라이브 수정 (스티어링)** — 공식 OpenAI 엔드포인트 + API 키 + 내장 OpenClaw 런타임 조합에서는 **Astra가 답변을 마칠 때까지 기다리지 않고 캐시된 WebSocket으로 수정 지시(텍스트·이미지)를 보낼 수 있습니다.** 수락된 지시는 재연결·연속 세션에서도 대화에 유지돼요.
- **비동기 도구 실행** — 같은 조건에서 직접 함수 도구가 **비동기로 병렬 실행**됩니다. 도구가 도는 동안에도 Astra는 추론과 응답을 계속하는 구조예요.
- **`/think ultra` 위임** — 런타임이 허용하는 환경에서는 `/think ultra`로 **서브에이전트에 사전 위임**(OpenClaw는 max, 네이티브 Codex는 xhigh 강도)이 가능합니다.
- **Azure 유지** — Azure 배포는 명시적으로 구성된 기능을 그대로 유지합니다.

같은 판에 **Meta Muse Spark 1.3**도 추가됐습니다. `meta/muse-spark-1.3`(Standard)과 `meta/muse-spark-1.3-contributor`(Contributor) 두 가지 선택지가 있고, 둘 다 텍스트·이미지 입력과 추론 컨트롤을 지원해요. 컨텍스트는 1,048,576토큰, 출력은 최대 131,072토큰입니다.

솔직히 GPT-5.6 라인을 메인으로 쓰던 저같은 사람에게는 "이번 주에 나온 최신 모델을 에이전트에서 당일 설정으로 쓸 수 있다"는 점 자체가 이 도구의 가장 큰 매력 포인트네요.

## 업무 자동화에 실질적인 변화 — 재시작 복구·Swarm·워크스페이스

**① 게이트웨이 재시작 후 작업이 이어집니다 (Replies survive restarts)**

지금까지 OpenClaw에서 가장 아쉬웠던 점 하나가 "게이트웨이를 재시작하면 진행 중이던 긴 작업이 허공으로 사라진다"였는데, 9.2에서 **활성·대기·위임된 응답이 재시작 후 복구**됩니다. 완료된 한 응답의 복구 마커가 다른 응답을 덮어쓰지 않도록 처리하고, 컴팩션·재시도 과정에서도 계속 지시(continuation instructions)를 보존해요. 장시간 도는 자동화 배치를 운영하는 분께는 체감이 꽤 클 변경입니다.

**② Swarm(멀티에이전트 오케스트레이션)이 기본 활성화**

여러 헬퍼 에이전트를 오케스트레이션하고 구조화된 결과를 모아주는 **Swarm이 이제 별도 활성화 절차 없이 기본 제공**됩니다(여전히 experimental이며, 해제는 Settings → Agents & Tools → Labs → Swarm에서 가능). 기존 도구 권한·제한을 그대로 따르고, Code Mode는 별도 옵트인으로 유지돼요. "하나의 큰 작업을 에이전트 여럿이 나눠 처리"하는 업무 자동화 패턴이 기본 기능이 된 셈입니다.

**③ 작업형 워크스페이스 — 대시보드·터미널·파일을 메인 뷰로**

웹 UI에서 **대시보드·브라우저·터미널·파일·리뷰 뷰를 메인 영역에 두고 채팅은 옆에** 배치할 수 있게 됐습니다(Swap·Focus·Restore split). 저장된 대시보드는 **갤러리에서 눈으로 찾아** 열 수 있고, `/dashboard` 명령으로 세션용 보드를 바로 요청할 수도 있어요. 패널을 숨겼다 다시 열어도 위젯 입력값·채팅 초안·터미널 상태가 보존됩니다.

**④ 재시작 없이 적용되는 설정 확대**

에이전트·모델·도구·채널·브라우저·노드·접근·터미널 설정 중 더 많은 항목이 **실행 중인 소유자에게 즉시 적용**됩니다. 여전히 재시작이 필요한 설정은 설정 레퍼런스에 표시돼 있어요.

**⑤ 로컬 모델 셋업이 똑똑해짐**

관리형 llama.cpp 셋업이 **실행 중인 컴퓨터의 메모리·GPU·디스크를 보고 모델을 추천**하고, 기본값으로 바꾸기 전에 **실제 파일 읽기 도구 호출까지 검증**합니다(실패하면 이전 모델 유지). 최소 8GiB 메모리부터 시작하는 레시피 구조고요.

**⑥ 공유 게이트웨이에서 개인 모델 계정 연결**

여러 사람이 게이트웨이를 공유할 때 **각자 자기 모델 계정을 채팅별로 연결**할 수 있어서, 다른 사람의 기본값을 바꾸지 않아도 됩니다.

## ⚠️ 꼭 읽어야 할 보안 노트 — 공유 게이트웨이 업그레이드 전 점검

이번 판에서 **제일 주의 깊게 봐야 할 부분**이 공식 노트에 명시돼 있습니다. 그대로 옮기면,

> **공유 게이트웨이용 업그레이드 노트:** 한 게이트웨이에서 여러 에이전트를 운영 중이라면 **업그레이드 전 대화 접근 권한을 검토**하세요. 설정을 생략하면 이제 **세션 도구를 가진 에이전트가 다른 에이전트의 대화(다른 사용자 대화 내용 포함)를 읽고 검색**할 수 있게 됩니다. 필요하면 가시성과 에이전트 페어 접근을 명시적으로 좁히고, **서로 신뢰하지 않는 사용자는 별도 게이트웨이를 사용**해야 합니다.

구체적으로는 **세션 도구가 기본적으로 전체 세션 가시성(all-session visibility)을 갖고, 일반 에이전트 간 접근(agent-to-agent)이 기본 활성화**되는 변경입니다. 범위를 좁히려면,

```bash
# 세션 도구 가시성을 내 에이전트(또는 나)로 제한
tools.sessions.visibility = agent   # 또는 self
```

이런 식으로 설정하면 됩니다. 1인 사용자나 신뢰할 수 있는 단일 팀 게이트웨이에서는 크게 문제되지 않지만, **게스트나 외부인과 게이트웨이를 공유하는 환경이라면 업그레이드 전에 꼭 확인**하세요. 보안·개인정보 설정의 전체 제한 항목은 공식 Security and Privacy 문서에 정리돼 있습니다.

## 실제 사용감 — 솔직한 장단점

**👍 좋은 점**
- **최신 모델을 당일 설정으로** — GPT-6 Astra가 나온 지 며칠 만에 정식 지원. '모델 출시 → 에이전트 적용' 속도가 정말 빨라졌습니다.
- **긴 작업의 안전망** — 재시작 후 작업 복구 + 백업 보존 강화. 자동화를 '밤새 돌려놓는' 운영 패턴의 리스크가 확실히 줄어듭니다.
- **Swarm 기본화** — 멀티에이전트 분업을 lab에서 꺼내 쓰던 불편이 사라졌어요. 진입 장벽이 한 단계 내려간 느낌.
- **작업 중심 UI** — 대시보드를 메인에 두고 채팅을 옆에 배치하는 방식은 "모니터링하면서 지시하는" 업무 흐름에 생각보다 잘 맞습니다.

**⚠️ 주의할 점 / 단점**
- **공유 게이트웨이 권한 기본값 변경** — 위 보안 노트 그대로입니다. 여러 에이전트·여러 사용자를 한 게이트웨이에 두는 분은 **업그레이드 전 대화 접근 범위 점검 필수**예요. 솔직히 이 기본값은 커뮤니티에서 논란이 될 만한 부분입니다.
- **1,245개 PR 규모의 변경 폭** — 9.1보다 큰 마이그레이션이라 업데이트 전 백업을 권합니다(이번 판이 백업 보존을 강화한 이유이기도 하죠).
- **Astra 기능은 조건부** — 라이브 수정·비동기 도구·`/think ultra`는 공식 OpenAI 엔드포인트 + 내장 런타임 조합 등 **조건이 맞을 때만** 동작합니다. 모든 연결에서 되는 건 아니에요.
- **주말 배포** — 9/6 새벽(한국시간) 게시라 평일 아침에 확인하는 사람은 하루 늦게 알게 되는 타이밍이었습니다.

## 업데이트 방법 — v2026.9.1 → v2026.9.2

기존 사용자는 터미널 한 줄이면 됩니다.

```bash
openclaw update
```

- **신규 설치** — `npx openclaw@latest` (9.1부터 기존 Claude Code·Codex 로그인 자동 감지)
- **업데이트 후 상태 점검**
  ```bash
  openclaw doctor
  openclaw doctor --fix
  ```
- **공유 게이트웨이 운영자 체크리스트**
  1. 업그레이드 전 각 에이전트의 대화 접근 범위 확인
  2. 필요 시 `tools.sessions.visibility = agent`(또는 `self`)로 축소
  3. 신뢰하지 않는 사용자와의 게이트웨이 공유는 별도 인스턴스로 분리

## 마무리

정리하면, **v2026.9.2는 '9.1의 패치'가 아니라 1,245개 PR 규모의 후속 정식 릴리스**입니다. GPT-6 Astra·Muse Spark 1.3 지원으로 **이번 주 AI 업계 최대 화제를 에이전트에서 바로 쓸 수 있게** 됐고, **재시작 복구·Swarm 기본화**는 장기 자동화 운영의 실질적인 안전망이 되어줍니다. 다만 **공유 게이트웨이 권한 기본값 변경**은 업그레이드 전에 꼭 확인하셔야 할 항목이에요.

요즘 저처럼 **무료 오픈소스 AI 에이전트로 업무 자동화를 직접 해보시는 분들**, 특히 **최신 모델을 가장 먼저 워크플로에 올려보고 싶은 분들**께는 이번 업데이트 충분히 추천할 만합니다. 솔직히 요즘 AI 툴 중에 **가성비 좋은 제품 찾는 분께 추천**할 만한 건 OpenClaw가 계속 1순위네요. 🦞

저도 이제 `openclaw update` 누르고, **GPT-6 Astra 실제 사용 후기**로 다시 찾아오겠습니다.
