## 4. 상세 설명
별똥이 부서진 밤, 작은 몽글이들이 태어났어요.
같은 몽글이끼리 부딪혀 합치면 점점 커지고, 마지막에는 하늘로 돌아가는 '별의 정령'이 된대요.

■ 이렇게 즐겨요
- 손가락으로 위치를 잡고, 떼면 톡! 한 손으로 쉽게
- 같은 몽글이 둘이 만나면 한 단계 진화 (총 11단계)
- 연쇄 합체 콤보로 높은 점수에 도전

■ 특징
- 쫀득쫀득 말랑한 젤리 물리와 슬라임 타격감 (진동 지원)
- 스테이지 모드: 목표 점수를 채우면 클리어, 상자가 넘치면 실패
- 일반 모드와 '오늘의 별똥' 데일리 챌린지(모두 같은 순서로 도전)
- 6가지 테마: 별똥 밤하늘 · 우주 정거장 · 몽글 식당 · 눈꽃 겨울밤 · 벚꽃 봄밤 · 오싹 할로윈
- 테마마다 다른 배경음악과 몽글이 캐릭터 11종, 도감 수집
- 흔들기·폭파 아이템, 마스코트 별똥이의 반응
- 회원가입 없이 바로 시작 (게임 플레이는 오프라인 가능, 광고는 온라인일 때만)

## 7. 연령 등급 설문 가이드 (답변 예상)
폭력성·선정성·공포·약물·도박·언어 모두 '없음'. 실제 금전 거래·사용자 간 소통·위치 공유 없음.
(원스토어 자체 등급 분류 신청 화면에서 위 기준으로 답변)

## 8. 등록 절차 체크리스트
- [ ] 원스토어 개발자센터 가입 / 개발자 인증(개인·사업자, 본인인증)
- [ ] 앱 등록 > 바이너리 업로드
  - AAB 선택 시: 바이너리 유형 AAB, 서명키 옵션에서 원스토어 앱 서명 사용
  - APK 선택 시: 자체 서명한 `app-release.apk` 업로드 (이후 업데이트도 같은 키)
- [ ] 아이콘 / 그래픽 이미지 / 스크린샷 등록
- [ ] 이름·소개·상세 설명·키워드·카테고리 입력
- [ ] 개인정보처리방침 URL 입력
- [ ] 연령 등급 신청 (필요 시 등급분류 자료 제출)
- [ ] 심사 신청 → 승인 후 출시

## 9. 출시 전 확인
- 광고: 게임오버 후 '다시 하기', 스테이지 클리어 후 '다음 스테이지' 시 AdMob 전면광고(최소 20초 간격). 앱 ID/전면 ID는 `apps/blobdrop-android/gradle.properties`.
- 원스토어 등록 시 '광고 포함' 항목 체크, 개인정보처리방침 URL 입력.
- AdMob 콘솔에서 앱을 원스토어 앱으로 등록(스토어 URL 미등록 상태에서는 광고 노출이 제한/지연될 수 있음). 본인 기기 테스트는 AdMob 테스트 기기 등록 또는 테스트 ID 사용(실광고 직접 클릭 금지).
- 실기기 설치 테스트(APK) 필수.
