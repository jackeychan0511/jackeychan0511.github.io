# 네온 레인 기원 정리: 스케이트보드 게임 시절

작성일: 2026-11-06

## 1. 결론

스케이트보드 시절의 **결과물(코드·이미지·기획서)은 현재 확인 가능한 곳에 남아 있지 않습니다.** 남아 있는 것은 당시 **대화에서 나온 기획 설명**뿐입니다. 아래 내용은 그 기록에서 확인되는 사실만 정리했습니다.

## 2. 확인한 곳과 결과

| 위치 | 결과 |
|---|---|
| 저장소(`games/`, git 이력) | 스케이트보드 파일·커밋 없음. 폴더는 `blob-drop`, `delivery-rush`, `neon-lane`뿐 |
| 저장소 문서 | `_posts/2026-11-02-neonlane-devlog-release.md`(1장, 개발 타임라인)에만 언급 |
| Google Drive 검색 ("스케이트", "skate") | 관련 문서 없음 (무관한 PDF·2편 초안만 검색됨) |
| 이 세션의 대화 기록 | 첫 요약에만 기획 개요가 있음. 원문 대화는 이 세션 이전이라 없음 |

## 3. 대화 기록에서 확인되는 초기 아이디어

사용자 요청을 시간순으로 요약한 기록입니다. 원문 전체가 아니라 요약입니다.

1. **스케이트보드 게임 구상.** 스케이트보더가 세로 4개 차선을 오르내리며, 무한 모드/타임어택 랭킹을 둔다는 아이디어였습니다. 사용자가 "어떻게 생각해??"라고 의견을 물었습니다.
2. **조작 요청.** 양손으로 쓰는 화면 하단 좌/우 화살표 버튼을 요청했습니다. 다른 테마(예: 4차선 자동차)와 수익화 가능한 아이디어도 함께 물었습니다.
3. **레이싱 접목.** 추천안을 받아들여 레이싱을 접목했고, 주유·타이어 교체 같은 선택 타이밍과 32비트풍 도트 이미지를 요청했습니다. 이 결과가 `games/delivery-rush/`(배달 레이싱)입니다.
4. **방향 전환.** 자동차 모드가 식상하다고 판단하고 리듬 러너로 바꿨습니다. 이것이 네온 레인입니다.

## 4. 진화 경로

```
스케이트보드 4차선 (아이디어 단계)
  → 4차선 배달 레이싱 (games/delivery-rush, 코드 남아 있음)
    → 네온 리듬 러너 (games/neon-lane, 현재)
```

세 단계에서 이어진 것은 **4개 세로 차선과 좌우 이동, 랭킹 구조**입니다. 바뀐 것은 소재(스케이트보더 → 차 → 빛)와 규칙(장애물 회피 → 박자 맞추기)입니다.

## 5. 남은 자료

- 코드로 남은 직계 전신: `games/delivery-rush/index.html`
- 현재 게임: `games/neon-lane/index.html`
- 서사 정리: 블로그 글 1장 (`/2026/11/02/neonlane-devlog-release/`)
